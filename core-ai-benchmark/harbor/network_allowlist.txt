# Base egress allowlist for Terminal-Bench runs (Harbor network_mode="allowlist").
#
# Only hosts required to provision toolchains belong here. Task-specific hosts
# go into network_hosts.json so that a task can reach what it legitimately
# needs without opening the same hosts for every other task.
#
# Never add github.com, raw.githubusercontent.com, api.github.com,
# hub.harborframework.com, marginlab.ai or r.jina.ai: they serve the benchmark's
# own tests, reference solutions and published expectations.
#
# Hosts are matched by SNI, so a CDN served from many IPs still works. Use
# "*.example.com" for subdomains (the apex needs its own entry).
