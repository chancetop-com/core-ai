# Hello plugin

Use this skill when the user asks for a greeting or wants to verify that a desktop plugin's skill
reached the local engine.

## Instructions

1. Ask for a name only if the user did not provide one.
2. Reply with one short greeting paragraph.
3. Do not call tools unless the user asks for one; the greeting is pure text.
