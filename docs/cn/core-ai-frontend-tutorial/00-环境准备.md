## 0.2 Node.js 安装

### 0.2.1 检查现有 Node.js

```bash
# 检查 Node.js 版本
node -v

# 检查 npm 版本
npm -v

# 如果已安装 Node.js 18+，会显示类似：
# v20.11.0
```

### 0.2.2 安装 Node.js 20 LTS

#### macOS

```bash
# 使用 Homebrew 安装
brew install node@20

# 设置环境变量
echo 'export PATH="/opt/homebrew/opt/node@20/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

# 验证安装
node -v
npm -v
```

#### Ubuntu/Debian

```bash
# 使用 NodeSource 安装
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# 验证安装
node -v
npm -v
```

#### Windows

1. 下载 [Node.js 20 LTS](https://nodejs.org/)
2. 运行安装程序
3. 验证安装：
```powershell
node -v
npm -v
```

### 0.2.3 使用 nvm 管理版本（推荐）

```bash
# 安装 nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash

# 重新加载 shell
source ~/.zshrc  # 或 ~/.bashrc

# 安装 Node.js 20
nvm install 20
nvm use 20
nvm alias default 20

# 验证
node -v
```

## 0.3 IDE 配置

### 0.3.1 VS Code 配置（推荐）

#### 安装扩展

```bash
# 安装核心扩展
code --install-extension dbaeumer.vscode-eslint
code --install-extension esbenp.prettier-vscode
code --install-extension bradlc.vscode-tailwindcss
code --install-extension dsznajder.es7-react-js-snippets
code --install-extension mhutchie.git-graph

# 安装可选扩展
code --install-extension formulahendry.auto-rename-tag
code --install-extension christian-kohler.path-intellisense
```

#### 配置 settings.json

```json
{
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.formatOnSave": true,
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": "explicit"
  },
  "typescript.tsdk": "node_modules/typescript/lib",
  "tailwindCSS.experimental.classRegex": [
    ["className\\s*=\\s*['\"]([^'\"]*)['\"]", ""]
  ],
  "emmet.includeLanguages": {
    "typescriptreact": "html"
  }
}
```

### 0.3.2 WebStorm 配置

#### 安装插件

1. 打开 `Settings → Plugins`
2. 安装：
   - ESLint
   - Prettier
   - Tailwind CSS
   - GitToolBox

#### 配置 TypeScript

1. 打开 `Settings → Languages & Frameworks → TypeScript`
2. 设置 `TypeScript version` 为 `node_modules/typescript`
3. 勾选 `Recompile on changes`

## 0.4 浏览器配置

### 0.4.1 Chrome 配置（推荐）

#### 安装扩展

- **React Developer Tools** - React 调试
- **Redux DevTools** - 状态管理调试（可选）

#### 开发者工具配置

1. 打开 `F12` 或 `Cmd+Option+I`
2. 设置：

   - `Preferences → Console → Enable custom formatters`

### 0.4.2 Firefox 配置

#### 安装扩展

- **React Developer Tools**
- **Web Developer**
- **JSONView**

## 0.5 项目结构

### 0.5.1 前端模块结构

```
core-ai-frontend/
├── src/
│   ├── main.tsx                    # 应用入口
│   ├── App.tsx                     # 根组件
│   ├── index.css                   # 全局样式
│   ├── vite-env.d.ts              # Vite 类型声明
│   ├── api/                        # API 层
│   │   ├── client.ts              # HTTP 客户端
│   │   ├── auth.ts                # 认证 API
│   │   ├── capabilities.ts        # 能力检查
│   │   ├── session.ts             # 会话 API
│   │   ├── files.ts               # 文件 API
│   │   ├── a2a.ts                 # A2A 协议
│   │   ├── speech.ts              # 语音 API
│   │   └── permissions.ts         # 权限 API
│   ├── components/                 # 通用组件
│   │   ├── Layout.tsx             # 布局组件
│   │   ├── ErrorBoundary.tsx      # 错误边界
│   │   ├── RequirePermission.tsx  # 权限守卫
│   │   ├── CodeMirrorEditor.tsx   # 代码编辑器
│   │   └── ...
│   ├── hooks/                      # 自定义 Hooks
│   │   └── useTheme.ts            # 主题 Hook
│   ├── pages/                      # 页面组件
│   │   ├── chat/                  # Chat 页面
│   │   ├── agents/                # Agent 管理
│   │   ├── workflows/             # 工作流
│   │   ├── traces/                # Trace 查看
│   │   ├── prompts/               # Prompt 管理
│   │   ├── skills/                # 技能管理
│   │   ├── mcp/                   # MCP 服务器
│   │   ├── tools/                 # 工具管理
│   │   ├── datasets/              # 数据集
│   │   ├── projects/              # 项目管理
│   │   ├── experiments/           # 实验系统
│   │   ├── settings/              # 系统设置
│   │   ├── login/                 # 登录注册
│   │   └── ...
│   └── test/                       # 测试配置
│       └── setup.ts
├── public/                         # 静态资源
├── index.html                      # HTML 模板
├── package.json                    # 依赖配置
├── tsconfig.json                   # TypeScript 配置
├── vite.config.ts                  # Vite 配置
├── tailwind.config.js              # Tailwind 配置
└── eslint.config.js                # ESLint 配置
```

### 0.5.2 核心目录说明

| 目录 | 说明 |
|------|------|
| **api/** | API 调用层，封装所有后端接口 |
| **components/** | 可复用的通用组件 |
| **hooks/** | 自定义 React Hooks |
| **pages/** | 页面级组件，按功能模块划分 |
| **test/** | 测试配置和全局测试工具 |

## 0.7 验证环境

### 0.7.1 启动开发服务器

```bash
# 进入项目目录
cd core-ai-frontend

# 启动开发服务器
npm run dev

# 输出示例：
#   VITE v8.0.0  ready in 500 ms
# 
#   ➜  Local:   http://localhost:3000/
#   ➜  Network: use --host to expose
#   ➜  press h + enter to show help
```

💡 **说明**：默认端口 3000，API 代理到 http://localhost:8080

### 0.7.2 访问应用

打开浏览器访问 http://localhost:3000

首次访问会显示登录页面（如果后端启用了认证）。

### 0.7.3 构建生产版本

```bash
# 构建生产版本
npm run build

# 构建产物位于
ls -lh build/dist/

# 预览生产版本
npm run preview
```

### 0.7.4 运行测试

```bash
# 运行所有测试
npm test

# 运行特定测试
npm test -- Chat

# 监听模式
npm run test:watch
```

### 0.7.5 代码检查
