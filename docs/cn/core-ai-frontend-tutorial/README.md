## 📚 教程概览

core-ai-frontend 是一个功能强大的 Web 前端应用，提供丰富的 AI Agent 管理、对话交互、工作流编排、追踪调试等功能。

### 核心能力

- 💬 **智能对话** - SSE 实时流式对话，支持多会话管理
- 🤖 **Agent 管理** - Agent 创建、配置、记忆管理
- 🔀 **工作流编排** - 可视化工作流设计、版本管理
- 📊 **追踪调试** - Trace 查看、Span 分析、性能监控
- 🛠️ **工具集成** - MCP 服务器、API 工具、内置工具
- ✨ **技能系统** - 技能市场、技能上传、技能管理
- 🎯 **项目管理** - 项目跟踪、主题分析、KPI 管理
- 🧪 **实验系统** - 记忆实验、重放实验、A/B 测试
- ⚙️ **系统配置** - Gateway 提供商、模型管理、用户管理

### 技术栈

- **语言**: TypeScript 5.9
- **框架**: React 19
- **构建**: Vite 8
- **样式**: Tailwind CSS 4
- **路由**: react-router-dom 7
- **代码编辑**: CodeMirror 6
- **流程图**: @xyflow/react 12
- **Markdown**: react-markdown + remark-gfm
- **语音**: Microsoft Cognitive Services Speech SDK
