## 0.1 实验管理

实验管理是评估和优化 Agent 性能的核心功能。

### 0.1.1 记忆注入实验

记忆注入实验位于 `pages/experiments/MemoryExperimentList.tsx`，测试 Agent 的记忆检索策略。

**核心数据结构：**

```typescript
interface ExperimentRun {
  agent_id: string;              // Agent ID
  enabled: boolean;              // 是否启用
  enabled_layers: string[];      // 启用的记忆层
  ranking_strategy: string;      // 排序策略
  top_k: number;                 // 取前 K 条记忆
  injection_probability: number; // 注入概率 (0-1)
  injected_memory_ids: string[]; // 已注入的记忆 ID
}

interface AgentMemoryExperimentConfig {
  enabled_layers: string[];
  ranking_strategy: string;
  top_k: number;
  injection_probability: number;
}
```

**主要 API：**

```typescript
// 获取实验运行列表
const runs = await api.experiments.listRuns();

// 保存配置
await api.experiments.saveConfig(agentId, {
  enabled_layers: ['episodic', 'semantic'],
  ranking_strategy: 'recency',
  top_k: 10,
  injection_probability: 0.8
});
```

💡 **设计意图**：记忆注入实验允许精确控制记忆层、排序策略和注入概率，帮助找到最优的记忆策略。

### 0.1.2 回放调试实验

回放调试位于 `pages/experiments/ReplayWorkbench.tsx`，用于回放和调试历史执行。

**核心数据结构：**

```typescript
interface ReplayExperiment {
  id: string;
  origin: 'SPAN' | 'BLANK';     // 来源类型
  trace_id: string;              // 追踪 ID
  original_input: string;        // 原始输入
  original_output: string;       // 原始输出
  runs: ReplayRun[];
}

interface ReplayRun {
  model: string;                 // 使用的模型
  temperature: number;           // 温度参数
  reasoning_effort: string;      // 推理力度
  sample_count: number;          // 采样数量
  samples: ReplaySample[];
}
```

**主要 API：**

```typescript
// 创建运行
const run = await api.replay.createRun(experimentId, {
  model: 'gpt-4',
  temperature: 0.7,
  reasoning_effort: 'medium',
  sample_count: 5
});

// 取消运行
await api.replay.cancelRun(experimentId, runId);
```

💡 **设计意图**：回放调试允许改变模型参数对比不同配置的输出质量，多次采样评估输出的稳定性。

## 0.4 系统设置

系统设置位于 `pages/settings/`，包含 API 密钥、网关提供商和全局配置。

### 0.4.1 网关提供商

网关提供商位于 `pages/settings/GatewayProviders.tsx`，管理 LLM 服务提供商。

**核心数据结构：**

```typescript
interface GatewayProvider {
  id: string;
  name: string;
  type: string;                  // openai, anthropic, etc.
  baseUrl: string;
  apiKeyMasked: string;
  defaultChatModel: string;
}

interface GatewayModel {
  modelId: string;
  displayName: string;
  providerId: string;
  contextWindow: number;         // 上下文窗口
  supportsStream: boolean;       // 支持流式
  supportsTools: boolean;        // 支持工具
  supportsVision: boolean;       // 支持视觉
  supportsVideo: boolean;        // 支持视频
  pricing: object;
}
```

**主要 API：**

```typescript
// 创建提供商
await api.gateway.createProvider({
  name: 'OpenAI',
  type: 'openai',
  baseUrl: 'https://api.openai.com',
  apiKey: 'sk-...'
});

// 发现模型
const discovered = await api.gateway.discoverModels(providerId);

// 导入模型
await api.gateway.importModels(providerId, discovered);

// 设置默认模型
await api.gateway.setDefaultModel(providerId, modelId);
```

💡 **设计意图**：网关支持多 LLM 提供商统一接入。模型发现功能自动获取支持的模型列表。能力标记帮助系统选择合适的能力。
