Usage: core-ai-cli report push [-h] [--insecure] [--json] [--quiet] [--raw]
                               [--api-key=<apiKey>] [--name=<name>]
                               -p=<project> -s=<subject> [--server=<server>]
                               file
Upload a local report file into a project subject on core-ai-server
      file                  Report file (html, pdf, md, csv, ...)
      --api-key=<apiKey>    API key (overrides CORE_AI_API_KEY / auth.json)
  -h, --help                Show help
      --insecure            Skip TLS certificate verification (e.g. self-signed
                              local server)
      --json                Machine-readable single-line JSON output
      --name=<name>         Display name on the server (defaults to the file
                              name)
  -p, --project=<project>   Project id or name
      --quiet               Suppress progress and metadata output on stderr
      --raw                 Call mode: print only the tool text content to
                              stdout
  -s, --subject=<subject>   Subject id or name inside the project (the business
                              line)
      --server=<server>     core-ai-server base URL (overrides CORE_AI_SERVER /
                              auth.json)
