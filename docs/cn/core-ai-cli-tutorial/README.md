## 📚 教程概览

core-ai CLI 是一个功能强大的命令行交互式 AI Agent 客户端，提供丰富的终端 UI、命令系统、会话管理等功能。

### 核心能力

- 🖥️ **交互式终端** - 丰富的终端 UI，支持 Markdown 渲染、代码高亮
- 💬 **会话管理** - 多会话管理、会话恢复、会话切换
- 🔧 **命令系统** - 斜杠命令系统，支持自动补全
- 🧠 **记忆系统** - 本地记忆管理、知识提取
- 🔐 **认证系统** - 多种认证方式、OAuth 支持
- 🔌 **插件系统** - 插件发现、安装、管理
- 🌐 **远程代理** - A2A 协议支持、远程 Agent 连接
- 📦 **技能系统** - 技能管理、技能 provision
- 🔄 **自动更新** - 版本检查、自动升级

### 技术栈

- **语言**: Java 21+
- **终端库**: JLine 3（终端交互）
- **Markdown**: flexmark（Markdown 渲染）
- **HTTP**: OkHttp（HTTP 客户端）
- **JSON**: core-ng JSON（JSON 处理）
- **构建**: Gradle
