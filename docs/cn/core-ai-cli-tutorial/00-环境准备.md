## 0.1 系统要求

### 0.1.1 硬件要求

| 配置 | 最低要求 | 推荐配置 |
|------|---------|---------|
| **CPU** | 2 核 | 4 核+ |
| **内存** | 4 GB | 8 GB+ |
| **磁盘** | 5 GB | 10 GB+ |

💡 **说明**：CLI 应用资源消耗较低，但开发时 IDE 会占用较多资源。

### 0.1.2 软件要求

| 软件 | 版本要求 | 说明 |
|------|---------|------|
| **JDK** | 21+ | Java 21 或更高版本 |
| **Gradle** | 8.0+ | 构建工具（项目自带 wrapper） |
| **Git** | 2.0+ | 版本控制 |
| **IDE** | 最新版 | IntelliJ IDEA 推荐 |
| **终端** | 支持 ANSI | 支持 ANSI 转义序列的终端 |

💡 **终端推荐**：
- **macOS**: iTerm2, Terminal.app
- **Linux**: GNOME Terminal, Konsole, Alacritty
- **Windows**: Windows Terminal, PowerShell

## 0.2 JDK 安装

### 0.2.1 检查现有 JDK

```bash
# 检查 Java 版本
java -version

# 如果已安装 JDK 21+，会显示类似：
# openjdk version "21.0.1" 2023-10-17
```

### 0.2.2 安装 JDK 21

#### macOS

```bash
# 使用 Homebrew 安装
brew install openjdk@21

# 设置环境变量
echo 'export PATH="/opt/homebrew/opt/openjdk@21/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

# 验证安装
java -version
```

#### Ubuntu/Debian

```bash
# 添加 OpenJDK 仓库
sudo add-apt-repository ppa:openjdk-21
sudo apt update

# 安装 JDK
sudo apt install openjdk-21-jdk

# 验证安装
java -version
```

#### Windows

1. 下载 [Oracle JDK 21](https://www.oracle.com/java/technologies/downloads/#java21)
2. 运行安装程序
3. 设置环境变量 `JAVA_HOME`
4. 将 `%JAVA_HOME%\bin` 添加到 `PATH`

## 0.4 IDE 配置

### 0.4.1 IntelliJ IDEA 配置

#### 导入项目

1. 打开 IntelliJ IDEA
2. 选择 `File → Open`
3. 选择 `core-ai` 项目根目录
4. 等待项目加载完成

#### 配置 JDK

1. 打开 `File → Project Structure`
2. 选择 `Project` 标签
3. 设置 `SDK` 为 JDK 21
4. 设置 `Language level` 为 21

#### 配置 Gradle

1. 打开 `File → Settings` (Windows/Linux) 或 `IntelliJ IDEA → Preferences` (macOS)
2. 导航到 `Build, Execution, Deployment → Build Tools → Gradle`
3. 设置 `Gradle JVM` 为 JDK 21
4. 勾选 `Delegate IDE build/run actions to Gradle`

#### 安装推荐插件

- **Lombok** - 简化代码
- **JLine 3 Support** - JLine 支持（可选）
- **Terminal** - 内置终端

### 0.4.2 VS Code 配置

#### 安装扩展

```bash
# 安装 Java 扩展包
code --install-extension vscjava.vscode-java-pack

# 安装 Gradle 扩展
code --install-extension vscjava.vscode-gradle

# 安装 Terminal 扩展
code --install-extension formulahendry.code-terminal
```

#### 配置 settings.json

```json
{
  "java.configuration.runtimes": [
    {
      "name": "JavaSE-21",
      "path": "/path/to/jdk-21",
      "default": true
    }
  ],
  "java.jdt.ls.java.home": "/path/to/jdk-21"
}
```

## 0.5 终端配置

### 0.5.1 终端选择

CLI 需要支持 ANSI 转义序列的终端，推荐以下终端：

#### macOS

**iTerm2**（推荐）:
```bash
brew install --cask iterm2
```

配置：
- Preferences → Profiles → Terminal → Enable mouse reporting
- Preferences → Profiles → Terminal → Silence bell

**Terminal.app**（系统自带）:
- 已支持 ANSI，无需额外配置

#### Linux

**GNOME Terminal**（推荐）:
```bash
sudo apt install gnome-terminal
```

**Alacritty**（GPU 加速）:
```bash
# macOS
brew install --cask alacritty

# Linux
sudo apt install alacritty
```

#### Windows

**Windows Terminal**（推荐）:
- 从 Microsoft Store 安装
- 支持 ANSI、Unicode、多标签

**PowerShell**:
```powershell
# 启用 ANSI 支持
$Host.UI.RawUI.ForegroundColor = "White"
```

### 0.5.2 终端字体配置

推荐等宽字体：

- **JetBrains Mono**（推荐）
- **Fira Code**
- **Source Code Pro**
- **Menlo**（macOS）
- **Consolas**（Windows）

```bash
# 安装 JetBrains Mono
# macOS
brew install --cask font-jetbrains-mono

# Linux
sudo apt install fonts-jetbrains-mono
```

### 0.5.3 终端主题配置

推荐深色主题：

- **Dracula**
- **Solarized Dark**
- **One Dark**
- **Monokai**

## 0.7 依赖配置

### 0.7.1 查看依赖

```bash
# 进入项目根目录
cd core-ai

# 查看 CLI 模块依赖
./gradlew :core-ai-cli:dependencies

# 输出示例：
# runtimeClasspath - Runtime classpath
# +--- project :core-ai
# +--- project :core-ai-api
# +--- org.jline:jline:3.25.0
# +--- com.vladsch.flexmark:flexmark:0.64.8
# +--- com.squareup.okhttp3:okhttp:4.12.0
# \--- core.framework:core-ng:9.4.2
```

### 0.7.2 主要依赖说明

| 依赖 | 版本 | 说明 |
|------|------|------|
| **core-ai** | - | core-ai 核心框架 |
| **core-ai-api** | - | core-ai API 定义 |
| **jline** | 3.25.0 | 终端交互库 |
| **flexmark** | 0.64.8 | Markdown 渲染 |
| **okhttp** | 4.12.0 | HTTP 客户端 |
| **core-ng** | 9.4.2 | core-ng 框架 |

### 0.7.3 JLine 配置

JLine 是 CLI 的核心依赖，提供终端交互功能：

```gradle
// build.gradle.kts
dependencies {
    implementation("org.jline:jline:3.25.0")
    implementation("org.jline:jline-terminal:3.25.0")
    implementation("org.jline:jline-reader:3.25.0")
}
```

💡 **JLine 功能**：
- 命令行编辑（光标移动、删除、插入）
- 历史记录
- 自动补全
- 语法高亮
- 终端尺寸检测

### 0.7.4 flexmark 配置

flexmark 用于 Markdown 渲染：

```gradle
// build.gradle.kts
dependencies {
    implementation("com.vladsch.flexmark:flexmark:0.64.8")
    implementation("com.vladsch.flexmark:flexmark-ext-tables:0.64.8")
    implementation("com.vladsch.flexmark:flexmark-ext-gfm-strikethrough:0.64.8")
}
```

💡 **flexmark 功能**：
- Markdown 解析
- HTML 渲染
- 表格支持
- GFM 扩展
