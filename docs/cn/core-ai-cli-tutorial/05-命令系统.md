## 5.1 命令系统概述

### 5.1.1 命令系统的角色

命令系统负责处理所有以 `/` 开头的斜杠命令，包括：

- 命令注册与发现
- 命令解析与分发
- 命令自动补全
- 命令处理器管理

💡 **设计意图**：将用户界面操作与核心逻辑解耦，提供可扩展的命令体系。

### 5.1.2 核心组件

| 组件 | 位置 | 职责 |
|------|------|------|
| `SlashCommand` | `command/` | 命令描述（record） |
| `SlashCommandRegistry` | `command/` | 命令注册表（静态列表） |
| `CommandDispatcher` | `agent/` | 命令分发器（路由） |
| `SlashCommandCompleter` | `ui/` | Tab 自动补全 |
| 各 Handler | `command/` | 命令处理器（具体实现） |

### 5.1.3 命令分类

命令按优先级分为 5 层：

```
1. Session 命令    → /model, /thinking, /stats, /tools, /copy, /undo, /compact, /resume, /clear
2. Config 命令     → /model <name>, /thinking <level>, /export, /memory, /login, /logout, /status, /server
3. Agent 命令      → /agents, /agents create, /agents delete
4. Plugin 命令     → /skill, /mcp, /plugins
5. 兜底（REPL）     → /help, /init, /debug, /exit
```

💡 **说明**：高优先级命令先匹配，避免冲突。

## 5.3 CommandDispatcher 命令分发

### 5.3.1 类定义

**位置**: `agent/CommandDispatcher.java`

```java
public class CommandDispatcher {
    private final HandlerContext handlers;
    private final BlockingQueue<String> queue;
    
    public CommandDispatcher(HandlerContext handlers, BlockingQueue<String> queue) {
        this.handlers = handlers;
        this.queue = queue;
    }
    
    // 命令分发入口
    public boolean dispatch(String trimmed) {
        // 按优先级尝试分发
        if (dispatchSessionCommand(trimmed)) return true;
        if (dispatchConfigCommand(trimmed)) return true;
        if (dispatchAgentCommand(trimmed)) return true;
        if (dispatchPluginCommand(trimmed)) return true;
        
        // 兜底：REPL 命令处理器
        return handlers.commands().handle(trimmed);
    }
}
```

💡 **说明**：
- 按优先级逐层匹配
- 返回 `boolean` 表示是否匹配成功
- 兜底处理器处理未知命令

### 5.3.4 Agent 命令分发

```java
private boolean dispatchAgentCommand(String trimmed) {
    if (!trimmed.startsWith("/agents")) return false;
    
    String[] parts = trimmed.split("\\s+");
    
    return switch (parts.length) {
        case 1 -> {
            // /agents - 列出所有 Agent
            handleAgentList();
            yield true;
        }
        case 2 -> {
            if ("create".equals(parts[1])) {
                // /agents create - 创建新 Agent
                new CreateAgentCommandHandler().handle();
            } else {
                showError("Unknown subcommand: " + parts[1]);
            }
            yield true;
        }
        case 3 -> {
            if ("delete".equals(parts[1])) {
                // /agents delete <name> - 删除 Agent
                String name = parts[2];
                handleAgentDelete(name);
            } else {
                showError("Unknown subcommand: " + parts[1]);
            }
            yield true;
        }
        default -> false;
    };
}

private void handleAgentDelete(String name) {
    // 删除 .core-ai/agents/<name>.md
    Path agentFile = Path.of(".core-ai/agents/" + name + ".md");
    try {
        Files.deleteIfExists(agentFile);
        
        // 同时删除 ~/.core-ai/agents/<name>.md
        Path userAgentFile = Path.of(System.getProperty("user.home"))
            .resolve(".core-ai/agents/" + name + ".md");
        Files.deleteIfExists(userAgentFile);
        
        // 刷新 AgentProfileRegistry 缓存
        AgentProfileRegistry.invalidate();
        
        System.out.println("Agent deleted: " + name);
    } catch (IOException e) {
        showError("Failed to delete agent: " + e.getMessage());
    }
}
```

💡 **说明**：
- `/agents` 支持子命令：`create`、`delete`
- 删除 Agent 同时清理工作空间和用户目录

### 5.4.1 ReplCommandHandler

**位置**: `command/ReplCommandHandler.java`

```java
public class ReplCommandHandler {
    private final TerminalUI ui;
    
    public ReplCommandHandler(TerminalUI ui) {
        this.ui = ui;
    }
    
    // 处理 REPL 命令（兜底）
    public boolean handle(String trimmed) {
        return switch (trimmed.split("\\s+")[0]) {
            case "/help" -> {
                handleHelp();
                yield true;
            }
            case "/init" -> {
                handleInit();
                yield true;
            }
            case "/debug" -> {
                handleDebug();
                yield true;
            }
            case "/exit" -> {
                // 不处理，由循环检测
                yield false;
            }
            default -> {
                // 未知命令警告
                if (trimmed.startsWith("/")) {
                    ui.showError("Unknown command: " + trimmed);
                }
                yield false;
            }
        };
    }
    
    private void handleHelp() {
        ui.println();
        ui.println("Available commands:");
        ui.println();
        
        for (SlashCommand cmd : SlashCommandRegistry.all()) {
            ui.printf("  %-20s - %s%n", cmd.name(), cmd.description());
        }
        
        ui.println();
    }
    
    private void handleInit() {
        // 创建 .core-ai/instructions.md 模板
        Path instructionsFile = Path.of(".core-ai/instructions.md");
        
        if (Files.exists(instructionsFile)) {
            ui.showError("instructions.md already exists");
            return;
        }
        
        try {
            Files.createDirectories(instructionsFile.getParent());
            Files.writeString(instructionsFile, """
                # Instructions
                
                Add your custom instructions here.
                These will be injected into the Agent's system prompt.
                
                ## Example
                
                - Always respond in Chinese
                - Use concise code style
                - Prefer Python over Java
                """);
            
            ui.println("Created instructions.md template");
            
            // 确保 MemoryTriggerService 目录存在
            MemoryTriggerService.getInstance().ensureDirectories();
        } catch (IOException e) {
            ui.showError("Failed to create instructions.md: " + e.getMessage());
        }
    }
    
    private void handleDebug() {
        // 切换调试日志
        boolean enabled = DebugLog.toggle();
        
        // 同步系统属性
        System.setProperty("core.ai.debug", String.valueOf(enabled));
        
        ui.println("Debug logging: " + (enabled ? "enabled" : "disabled"));
    }
}
```

💡 **说明**：
- 兜底处理器，处理 `/help`、`/init`、`/debug`
- `/exit` 不处理，由循环检测
- 未知命令显示警告

### 5.4.2 MemoryCommandHandler

**位置**: `command/MemoryCommandHandler.java`

```java
public class MemoryCommandHandler {
    private final TerminalUI ui;
    private final MdMemoryProvider memoryProvider;
    private final MemoryTriggerService triggerService;
    
    public MemoryCommandHandler(
        TerminalUI ui,
        MdMemoryProvider memoryProvider,
        MemoryTriggerService triggerService
    ) {
        this.ui = ui;
        this.memoryProvider = memoryProvider;
        this.triggerService = triggerService;
    }
    
    public void handle(String trimmed) {
        String[] parts = trimmed.split("\\s+");
        
        if (parts.length == 1) {
            // /memory - 显示菜单
            showMenu();
            return;
        }
        
        String subcommand = parts[1];
        
        switch (subcommand) {
            case "edit" -> handleEdit();
            case "search" -> handleSearch(parts);
            case "open" -> handleOpen();
            case "clear" -> handleClear();
            case "enable" -> handleEnable();
            case "disable" -> handleDisable();
            default -> ui.showError("Unknown subcommand: " + subcommand);
        }
    }
    
    private void showMenu() {
        ui.println();
        ui.println("Memory commands:");
        ui.println("  /memory edit    - Edit memory file");
        ui.println("  /memory search  - Search memories");
        ui.println("  /memory open    - Open memory directory");
        ui.println("  /memory clear   - Clear all memories");
        ui.println("  /memory enable  - Enable memory extraction");
        ui.println("  /memory disable - Disable memory extraction");
        ui.println();
    }
    
    private void handleEdit() {
        // 打开 $EDITOR 编辑 MEMORY.md
        Path memoryFile = memoryProvider.getMemoryFilePath();
        String editor = System.getenv("EDITOR");
        if (editor == null) editor = "vim";
        
        try {
            new ProcessBuilder(editor, memoryFile.toString())
                .inheritIO()
                .start()
                .waitFor();
        } catch (Exception e) {
            ui.showError("Failed to open editor: " + e.getMessage());
        }
    }
    
    private void handleSearch(String[] parts) {
        if (parts.length < 3) {
            ui.showError("Usage: /memory search <query>");
            return;
        }
        
        String query = String.join(" ", Arrays.copyOfRange(parts, 2, parts.length));
        List<MemoryEntry> results = memoryProvider.searchMemories(query);
        
        if (results.isEmpty()) {
            ui.println("No memories found matching: " + query);
            return;
        }
        
        ui.println("Memories matching '" + query + "':");
        ui.println();
        
        for (MemoryEntry entry : results) {
            ui.printf("  [%s] %s%n", entry.type(), entry.name());
            ui.println("    " + entry.description());
            ui.println();
        }
    }
    
    private void handleOpen() {
        // 打开记忆目录
        Path memoryDir = memoryProvider.getMemoryDirPath();
        String os = System.getProperty("os.name").toLowerCase();
        
        try {
            if (os.contains("mac")) {
                new ProcessBuilder("open", memoryDir.toString()).start();
            } else if (os.contains("win")) {
                new ProcessBuilder("explorer", memoryDir.toString()).start();
            } else {
                new ProcessBuilder("xdg-open", memoryDir.toString()).start();
            }
        } catch (IOException e) {
            ui.showError("Failed to open directory: " + e.getMessage());
        }
    }
    
    private void handleClear() {
        // 确认
        String confirm = ui.readLine("Are you sure? (y/n) ");
        if (!"y".equalsIgnoreCase(confirm)) return;
        
        triggerService.clearKnowledge();
        ui.println("All memories cleared");
    }
    
    private void handleEnable() {
        // 修改 agent.properties
        Path propsFile = Path.of(System.getProperty("user.home"))
            .resolve(".core-ai/agent.properties");
        
        try {
            Properties props = new Properties();
            props.load(Files.newBufferedReader(propsFile));
            props.setProperty("agent.memory.enabled", "true");
            props.store(Files.newBufferedWriter(propsFile), null);
            
            ui.println("Memory extraction enabled");
        } catch (IOException e) {
            ui.showError("Failed to enable memory: " + e.getMessage());
        }
    }
    
    private void handleDisable() {
        Path propsFile = Path.of(System.getProperty("user.home"))
            .resolve(".core-ai/agent.properties");
        
        try {
            Properties props = new Properties();
            props.load(Files.newBufferedReader(propsFile));
            props.setProperty("agent.memory.enabled", "false");
            props.store(Files.newBufferedWriter(propsFile), null);
            
            ui.println("Memory extraction disabled");
        } catch (IOException e) {
            ui.showError("Failed to disable memory: " + e.getMessage());
        }
    }
}
```

💡 **说明**：
- 6 个子命令：`edit`、`search`、`open`、`clear`、`enable`、`disable`
- `edit` 使用 `$EDITOR` 打开编辑
- `search` 调用 `MdMemoryProvider.searchMemories`
- `open` 使用系统命令打开目录
- `enable/disable` 修改 `agent.properties`

### 5.4.3 SkillCommandHandler

**位置**: `command/SkillCommandHandler.java`

```java
public class SkillCommandHandler {
    private final TerminalUI ui;
    
    public SkillCommandHandler(TerminalUI ui) {
        this.ui = ui;
    }
    
    public void handle(String trimmed) {
        String[] parts = trimmed.split("\\s+");
        
        if (parts.length == 1) {
            // /skill - 列出所有技能
            listSkills();
            return;
        }
        
        String skillName = parts[1];
        
        // 加载技能内容
        String content = loadSkill(skillName);
        if (content != null) {
            // 将技能内容作为消息发送给 Agent
            // 格式：<skill name=... base_dir=...>...</skill>
            queue.put(content);
        }
    }
    
    private void listSkills() {
        ui.println();
        ui.println("Available skills:");
        ui.println();
        
        // 扫描工作空间技能
        scanSkillDir(Path.of(".core-ai/skills"), "workspace");
        
        // 扫描用户技能
        Path userSkillDir = Path.of(System.getProperty("user.home"))
            .resolve(".core-ai/skills");
        scanSkillDir(userSkillDir, "user");
        
        // 服务器技能
        ui.println("  [server] core-ai-server");
        ui.println();
    }
    
    private void scanSkillDir(Path dir, String scope) {
        if (!Files.isDirectory(dir)) return;
        
        try (var stream = Files.list(dir)) {
            stream.filter(Files::isDirectory)
                .forEach(skillDir -> {
                    Path skillFile = skillDir.resolve("SKILL.md");
                    if (Files.exists(skillFile)) {
                        String name = skillDir.getFileName().toString();
                        ui.printf("  [%s] %s%n", scope, name);
                    }
                });
        } catch (IOException e) {
            // 忽略
        }
    }
    
    private String loadSkill(String name) {
        // 尝试从工作空间加载
        Path skillFile = Path.of(".core-ai/skills/" + name + "/SKILL.md");
        if (Files.exists(skillFile)) {
            try {
                return Files.readString(skillFile);
            } catch (IOException e) {
                return null;
            }
        }
        
        // 尝试从用户目录加载
        skillFile = Path.of(System.getProperty("user.home"))
            .resolve(".core-ai/skills/" + name + "/SKILL.md");
        if (Files.exists(skillFile)) {
            try {
                return Files.readString(skillFile);
            } catch (IOException e) {
                return null;
            }
        }
        
        ui.showError("Skill not found: " + name);
        return null;
    }
}
```

💡 **说明**：
- 扫描工作空间和用户目录的技能
- 技能以 `SKILL.md` 文件标识
- 加载后作为消息发送给 Agent

## 5.5 自动补全

### 5.5.1 SlashCommandCompleter

**位置**: `ui/SlashCommandCompleter.java`

```java
public class SlashCommandCompleter implements Completer {
    
    @Override
    public void complete(LineReader reader, ParsedLine line, List<Candidate> candidates) {
        String buffer = line.line();
        int wordIndex = line.wordIndex();
        
        if (wordIndex == 0) {
            // 顶层命令补全
            completeTopLevel(buffer, candidates);
        } else {
            // 子命令补全
            completeSubCommand(buffer, line, candidates);
        }
    }
    
    private void completeTopLevel(String buffer, List<Candidate> candidates) {
        // 只补全以 / 开头的命令
        if (!buffer.startsWith("/")) return;
        
        for (SlashCommand cmd : SlashCommandRegistry.all()) {
            if (cmd.name().startsWith(buffer)) {
                candidates.add(new Candidate(
                    cmd.name(),
                    cmd.description(),
                    null,  // group
                    null,  // descr
                    null,  // suffix
                    null,  // key
                    true   // complete
                ));
            }
        }
    }
    
    private void completeSubCommand(
        String buffer, ParsedLine line, List<Candidate> candidates
    ) {
        String parent = line.words().get(0);
        String sub = line.word();
        
        switch (parent) {
            case "/agents" -> {
                // /agents create, /agents delete
                for (String subCmd : List.of("create", "delete")) {
                    if (subCmd.startsWith(sub)) {
                        candidates.add(new Candidate(subCmd));
                    }
                }
            }
            case "/memory" -> {
                // /memory edit, search, open, clear, enable, disable
                for (String subCmd : List.of(
                    "edit", "search", "open", "clear", "enable", "disable"
                )) {
                    if (subCmd.startsWith(sub)) {
                        candidates.add(new Candidate(subCmd));
                    }
                }
            }
            case "/thinking" -> {
                // /thinking low, none, high, off
                for (String level : List.of("low", "none", "high", "off")) {
                    if (level.startsWith(sub)) {
                        candidates.add(new Candidate(level));
                    }
                }
            }
            case "/plugins" -> {
                // /plugins list, install, uninstall, enable, disable, ...
                for (String subCmd : List.of(
                    "list", "install", "uninstall", "enable", 
                    "disable", "validate", "info", "reload"
                )) {
                    if (subCmd.startsWith(sub)) {
                        candidates.add(new Candidate(subCmd));
                    }
                }
                
                // 特殊处理：--local, --global 标志
                if (sub.startsWith("--")) {
                    for (String flag : List.of("--local", "--global")) {
                        if (flag.startsWith(sub)) {
                            candidates.add(new Candidate(flag));
                        }
                    }
                }
            }
        }
    }
}
```

💡 **说明**：
- 实现 JLine 的 `Completer` 接口
- 顶层补全：所有以 `/` 开头的命令
- 子命令补全：根据父命令提供子命令
- 支持标志补全（`--local`、`--global`）

### 5.5.2 AgentNameCompleter

**位置**: `ui/AgentNameCompleter.java`

```java
public class AgentNameCompleter implements Completer {
    private List<String> agentNames = List.of();
    
    public void setAgentNames(List<String> names) {
        this.agentNames = names;
    }
    
    @Override
    public void complete(LineReader reader, ParsedLine line, List<Candidate> candidates) {
        String buffer = line.word();
        
        // 只在 @ 触发时补全
        if (!buffer.startsWith("@")) return;
        
        String prefix = buffer.substring(1);
        
        for (String name : agentNames) {
            if (name.startsWith(prefix)) {
                candidates.add(new Candidate("@" + name));
            }
        }
    }
}
```

💡 **说明**：
- 补全 Agent 名称（`@name`）
- 用于引用特定 Agent
- 动态更新 Agent 列表

### 5.5.3 FileReferenceCompleter

**位置**: `ui/FileReferenceCompleter.java`

```java
public class FileReferenceCompleter implements Completer {
    
    @Override
    public void complete(LineReader reader, ParsedLine line, List<Candidate> candidates) {
        String buffer = line.word();
        
        // 只在 @ 触发时补全文件路径
        if (!buffer.startsWith("@")) return;
        
        String path = buffer.substring(1);
        Path dir = Path.of(path).getParent();
        if (dir == null) dir = Path.of(".");
        
        try (var stream = Files.list(dir)) {
            stream.forEach(file -> {
                String name = file.getFileName().toString();
                candidates.add(new Candidate("@" + dir.resolve(name)));
            });
        } catch (IOException e) {
            // 忽略错误
        }
    }
}
```

💡 **说明**：
- 补全文件引用（`@path/to/file`）
- 列出目录内容
- 用于引用文件内容

## 5.6 命令系统设计模式

### 5.6.1 命令模式（Command Pattern）

```
┌─────────────────┐
│  SlashCommand   │  ← 命令描述（record）
└─────────────────┘
         │
         ▼
┌─────────────────┐
│ CommandDispatcher│  ← 命令分发器
└─────────────────┘
         │
         ├──────────────┬──────────────┬──────────────┐
         ▼              ▼              ▼              ▼
┌─────────────┐  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│   Session   │  │   Config    │  │    Agent    │  │   Plugin    │
│   Handler   │  │   Handler   │  │   Handler   │  │   Handler   │
└─────────────┘  └─────────────┘  └─────────────┘  └─────────────┘
```

💡 **说明**：
- 命令与处理器分离
- 分发器负责路由
- 处理器负责执行

### 5.6.2 策略模式（Strategy Pattern）

```java
// 不同的命令分发策略
private boolean dispatchSessionCommand(String trimmed) { ... }
private boolean dispatchConfigCommand(String trimmed) { ... }
private boolean dispatchAgentCommand(String trimmed) { ... }
private boolean dispatchPluginCommand(String trimmed) { ... }
```

💡 **说明**：
- 每种命令类型有独立的分发策略
- 按优先级尝试
- 可以扩展新的分发策略

### 5.6.3 责任链模式（Chain of Responsibility）

```java
public boolean dispatch(String trimmed) {
    // 链式处理
    if (dispatchSessionCommand(trimmed)) return true;
    if (dispatchConfigCommand(trimmed)) return true;
    if (dispatchAgentCommand(trimmed)) return true;
    if (dispatchPluginCommand(trimmed)) return true;
    
    // 兜底
    return handlers.commands().handle(trimmed);
}
```

💡 **说明**：
- 每个处理器决定是否处理
- 返回 `true` 表示已处理，停止传播
- 返回 `false` 表示未处理，继续传播

## 5.7 扩展新命令

### 5.7.1 添加新命令的步骤

1. **注册命令** - 在 `SlashCommandRegistry` 中添加
2. **分发命令** - 在 `CommandDispatcher` 中添加分发逻辑
3. **实现处理器** - 创建 Handler 或在现有 Handler 中添加
4. **补全支持** - 在 `SlashCommandCompleter` 中添加补全规则

### 5.7.2 示例：添加 /bookmark 命令

**步骤 1：注册命令**

```java
// SlashCommandRegistry.java
public static final List<SlashCommand> COMMANDS = List.of(
    // ... 现有命令
    new SlashCommand("/bookmark", "Bookmark current conversation")
);
```

**步骤 2：分发命令**

```java
// CommandDispatcher.java
private boolean dispatchSessionCommand(String trimmed) {
    String command = trimmed.split("\\s+")[0];
    
    return switch (command) {
        // ... 现有命令
        case "/bookmark" -> {
            handleBookmark(trimmed);
            yield true;
        }
        default -> false;
    };
}

private void handleBookmark(String trimmed) {
    String name = trimmed.length() > 10 
        ? trimmed.substring(10).trim() 
        : "bookmark-" + System.currentTimeMillis();
    
    // 保存书签
    BookmarkManager.save(name, session.getCurrentState());
    
    ui.println("Bookmarked: " + name);
}
```

**步骤 3：补全支持**

```java
// SlashCommandCompleter.java
case "/bookmark" -> {
    // 不需要子命令补全
}
```

💡 **说明**：
- 遵循现有模式
- 命令名、分发、处理器、补全四个步骤
- 可以创建独立的 Handler 类（如果逻辑复杂）
