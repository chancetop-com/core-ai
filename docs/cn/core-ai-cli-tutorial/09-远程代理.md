## 9.1 远程代理概述

### 9.1.1 远程代理的角色

远程代理系统负责连接和管理远程 Agent，包括：

- A2A（Agent-to-Agent）协议实现
- 远程连接管理
- SSE（Server-Sent Events）事件流
- 远程 Agent 发现
- 远程工具调用

💡 **设计意图**：支持分布式 Agent 协作，允许本地 CLI 连接远程 Agent 执行任务。

### 9.1.2 核心组件

| 组件 | 位置 | 职责 |
|------|------|------|
| `A2ARemoteConnector` | `remote/` | A2A 连接器 |
| `RemoteApiClient` | `remote/` | HTTP 客户端 |
| `HttpAgentSession` | `remote/` | HTTP 会话实现 |
| `RemoteSessionRunner` | `remote/` | 远程会话运行器 |
| `RemoteAgentToolProvider` | `remote/` | 远程 Agent 工具提供器 |
| `A2ARemoteAgentDiscovery` | `remote/` | Agent 发现服务 |

### 9.1.3 A2A 协议

```
┌──────────────┐
│   Local CLI  │
│              │
│  1. 发现     │ GET /api/agents
│  2. 连接     │ POST /api/sessions
│  3. 通信     │ SSE /api/sessions/events
│  4. 控制     │ POST /api/sessions/{id}/approve
│              │ POST /api/sessions/{id}/cancel
│  5. 关闭     │ DELETE /api/sessions/{id}
└──────────────┘
       │
       │ HTTP + SSE
       ▼
┌──────────────┐
│  Remote Agent│
│  Server      │
└──────────────┘
```

💡 **说明**：
- 基于 HTTP/JSON 的协议
- SSE 用于实时事件流
- 支持会话管理和工具审批

## 9.4 RemoteApiClient

### 9.4.1 类定义

**位置**: `remote/RemoteApiClient.java`

```java
public class RemoteApiClient {
    private final HttpClient httpClient;
    private final String baseUrl;
    private final String apiKey;
    
    public RemoteApiClient(String baseUrl, String apiKey) {
        this.baseUrl = baseUrl;
        this.apiKey = apiKey;
        
        this.httpClient = HttpClient.newBuilder()
            .version(HttpClient.Version.HTTP_1_1)
            .build();
    }
    
    // GET 请求
    public String get(String path) throws RemoteApiException {
        return send(buildRequest(path, "GET", null));
    }
    
    public String getRequired(String path) throws RemoteApiException {
        String result = get(path);
        if (result == null) {
            throw new RemoteApiException(404, "Not found");
        }
        return result;
    }
    
    // POST 请求
    public String post(String path, String body) throws RemoteApiException {
        return send(buildRequest(path, "POST", body));
    }
    
    // PUT 请求
    public String put(String path, String body) throws RemoteApiException {
        return send(buildRequest(path, "PUT", body));
    }
    
    // DELETE 请求
    public void delete(String path) throws RemoteApiException {
        send(buildRequest(path, "DELETE", null));
    }
    
    // POST 空请求体
    public String postEmpty(String path) throws RemoteApiException {
        return post(path, "");
    }
    
    // Multipart 上传
    public String postMultipart(
        String path, 
        Map<String, String> fields,
        Map<String, byte[]> files
    ) throws RemoteApiException {
        String boundary = UUID.randomUUID().toString();
        
        ByteArrayOutputStream baos = new ByteArrayOutputStream();
        
        // 写入字段
        for (var entry : fields.entrySet()) {
            writeField(baos, boundary, entry.getKey(), entry.getValue());
        }
        
        // 写入文件
        for (var entry : files.entrySet()) {
            writeFile(baos, boundary, entry.getKey(), entry.getValue());
        }
        
        // 结束标记
        writeEnd(baos, boundary);
        
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create(baseUrl + path))
            .header("Authorization", "Bearer " + apiKey)
            .header("Content-Type", "multipart/form-data; boundary=" + boundary)
            .POST(HttpRequest.BodyPublishers.ofByteArray(baos.toByteArray()))
            .build();
        
        return send(request);
    }
    
    private HttpRequest buildRequest(String path, String method, String body) {
        HttpRequest.Builder builder = HttpRequest.newBuilder()
            .uri(URI.create(baseUrl + path))
            .header("Authorization", "Bearer " + apiKey)
            .header("Content-Type", "application/json");
        
        switch (method) {
            case "GET" -> builder.GET();
            case "POST" -> builder.POST(
                body != null 
                    ? HttpRequest.BodyPublishers.ofString(body)
                    : HttpRequest.BodyPublishers.noBody()
            );
            case "PUT" -> builder.PUT(
                body != null
                    ? HttpRequest.BodyPublishers.ofString(body)
                    : HttpRequest.BodyPublishers.noBody()
            );
            case "DELETE" -> builder.DELETE();
        }
        
        return builder.build();
    }
    
    private String send(HttpRequest request) throws RemoteApiException {
        try {
            HttpResponse<String> response = httpClient.send(
                request,
                HttpResponse.BodyHandlers.ofString()
            );
            
            if (response.statusCode() >= 400) {
                String message = mapErrorMessage(response.statusCode(), response.body());
                throw new RemoteApiException(response.statusCode(), message);
            }
            
            return response.body();
        } catch (IOException | InterruptedException e) {
            throw new RemoteApiException(500, "Request failed: " + e.getMessage());
        }
    }
    
    private String mapErrorMessage(int statusCode, String body) {
        return switch (statusCode) {
            case 401 -> "Authentication failed. Please login again.";
            case 403 -> "Access denied.";
            case 404 -> "Not found.";
            case 429 -> "Rate limit exceeded. Please wait.";
            case 500 -> "Server error.";
            case 503 -> "Service unavailable.";
            default -> "HTTP " + statusCode + ": " + body;
        };
    }
    
    // 获取 HTTP 客户端（用于 SSE）
    public HttpClient httpClient() {
        return httpClient;
    }
}

public class RemoteApiException extends RuntimeException {
    private final int statusCode;
    
    public RemoteApiException(int statusCode, String message) {
        super(message);
        this.statusCode = statusCode;
    }
    
    public int getStatusCode() {
        return statusCode;
    }
}
```

💡 **说明**：
- 基于 `java.net.http.HttpClient`
- 支持 GET、POST、PUT、DELETE
- 支持 Multipart 上传
- 友好的错误消息映射

## 9.5 HttpAgentSession

### 9.5.1 类定义

**位置**: `remote/HttpAgentSession.java`

```java
public class HttpAgentSession implements AgentSession {
    private final RemoteApiClient api;
    private final String sessionId;
    private final List<AgentEventListener> listeners;
    private Thread sseThread;
    private final CountDownLatch connectionLatch;
    
    // 连接到远程会话
    public static HttpAgentSession connect(RemoteApiClient api, String agentId) {
        // 1. 创建会话
        String response = api.post("/api/sessions", 
            Json.createObject().add("agent_id", agentId).toString()
        );
        
        JsonObject json = Json.parse(response);
        String sessionId = json.getString("id");
        
        // 2. 创建会话对象
        HttpAgentSession session = new HttpAgentSession(api, sessionId);
        
        // 3. 启动 SSE 连接
        session.connectSSE();
        
        return session;
    }
    
    private HttpAgentSession(RemoteApiClient api, String sessionId) {
        this.api = api;
        this.sessionId = sessionId;
        this.listeners = new CopyOnWriteArrayList<>();
        this.connectionLatch = new CountDownLatch(1);
    }
    
    private void connectSSE() {
        sseThread = new Thread(() -> {
            try {
                // PUT 请求，Accept: text/event-stream
                HttpRequest request = HttpRequest.newBuilder()
                    .uri(URI.create(api.baseUrl() + "/api/sessions/events"
                        + "?agent-session-id=" + sessionId))
                    .header("Authorization", "Bearer " + api.apiKey())
                    .header("Accept", "text/event-stream")
                    .PUT(HttpRequest.BodyPublishers.noBody())
                    .build();
                
                // 发送请求
                HttpResponse<Stream<String>> response = api.httpClient().send(
                    request,
                    HttpResponse.BodyHandlers.ofLines()
                );
                
                // 标记连接成功
                connectionLatch.countDown();
                
                // 处理 SSE 事件
                response.body().forEach(line -> {
                    if (line.startsWith("data: ")) {
                        String data = line.substring(6);
                        handleSSEEvent(data);
                    }
                });
                
            } catch (Exception e) {
                // 连接失败
                connectionLatch.countDown();
            }
        }, "sse-reader");
        
        sseThread.setDaemon(true);
        sseThread.start();
        
        // 等待连接（10 秒超时）
        try {
            if (!connectionLatch.await(10, TimeUnit.SECONDS)) {
                throw new RuntimeException("SSE connection timeout");
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    }
    
    private void handleSSEEvent(String data) {
        try {
            JsonObject json = Json.parse(data);
            String type = json.getString("type");
            
            AgentEvent event = deserializeEvent(type, json);
            
            // 分发给监听器
            for (AgentEventListener listener : listeners) {
                dispatchEvent(listener, event);
            }
        } catch (Exception e) {
            // 忽略解析错误
        }
    }
    
    private AgentEvent deserializeEvent(String type, JsonObject json) {
        return switch (type) {
            case "text_chunk" -> new AgentEvent.TextChunk(
                json.getString("content")
            );
            case "reasoning_chunk" -> new AgentEvent.ReasoningChunk(
                json.getString("content")
            );
            case "tool_start" -> new AgentEvent.ToolStart(
                json.getString("tool_call_id"),
                json.getString("tool_name"),
                json.getObject("arguments")
            );
            case "tool_result" -> new AgentEvent.ToolResult(
                json.getString("tool_call_id"),
                json.getString("tool_name"),
                json.getString("result")
            );
            case "turn_complete" -> new AgentEvent.TurnComplete(
                json.getLong("elapsed_ms"),
                json.getInt("input_tokens"),
                json.getInt("output_tokens"),
                json.getInt("cached_tokens"),
                json.getDouble("cost_usd")
            );
            case "error" -> new AgentEvent.Error(
                json.getString("message")
            );
            case "tool_approval_request" -> new AgentEvent.ToolApprovalRequest(
                this,
                json.getString("tool_call_id"),
                json.getString("tool_name"),
                json.getObject("arguments"),
                json.getString("suggested_pattern")
            );
            default -> null;
        };
    }
    
    private void dispatchEvent(AgentEventListener listener, AgentEvent event) {
        if (event instanceof AgentEvent.TextChunk e) {
            listener.onTextChunk(e);
        } else if (event instanceof AgentEvent.ReasoningChunk e) {
            listener.onReasoningChunk(e);
        } else if (event instanceof AgentEvent.ToolStart e) {
            listener.onToolStart(e);
        } else if (event instanceof AgentEvent.ToolResult e) {
            listener.onToolResult(e);
        } else if (event instanceof AgentEvent.TurnComplete e) {
            listener.onTurnComplete(e);
        } else if (event instanceof AgentEvent.Error e) {
            listener.onError(e);
        } else if (event instanceof AgentEvent.ToolApprovalRequest e) {
            listener.onToolApprovalRequest(e);
        }
    }
    
    @Override
    public String id() {
        return sessionId;
    }
    
    @Override
    public void sendMessage(String message) {
        api.post("/api/sessions/" + sessionId + "/messages",
            Json.createObject().add("content", message).toString()
        );
    }
    
    @Override
    public void onEvent(AgentEventListener listener) {
        listeners.add(listener);
    }
    
    @Override
    public void approveToolCall(String toolCallId, ApprovalDecision decision) {
        api.post("/api/sessions/" + sessionId + "/approve",
            Json.createObject()
                .add("tool_call_id", toolCallId)
                .add("decision", decision.name())
                .toString()
        );
    }
    
    @Override
    public void cancelTurn() {
        api.postEmpty("/api/sessions/" + sessionId + "/cancel");
    }
    
    @Override
    public void close() {
        // 关闭 SSE 线程
        if (sseThread != null) {
            sseThread.interrupt();
        }
        
        // 删除会话
        try {
            api.delete("/api/sessions/" + sessionId);
        } catch (Exception e) {
            // 忽略
        }
    }
}
```

💡 **说明**：
- 实现 `AgentSession` 接口
- 使用 SSE 接收事件
- 支持工具审批和 Turn 取消

```java
public class RemoteSessionRunner {
    private final TerminalUI ui;
    private final Connection connection;
    private HttpAgentSession session;
    
    public RemoteSessionRunner(TerminalUI ui, Connection connection) {
        this.ui = ui;
        this.connection = connection;
    }
    
    public void run() {
        // 1. 连接到远程会话
        session = HttpAgentSession.connect(
            connection.client(),
            connection.agentId()
        );
        
        // 2. 设置远程斜杠命令
        ui.setSlashCommands(getRemoteSlashCommands());
        
        // 3. 创建事件监听器
        RemoteEventListener listener = new RemoteEventListener(ui);
        session.onEvent(listener);
        
        // 4. 启动发送线程
        BlockingQueue<String> queue = new LinkedBlockingQueue<>();
        startSenderThread(queue);
        
        // 5. 运行输入循环
        readInputLoop(queue);
        
        // 6. 关闭会话
        session.close();
    }
    
    private List<SlashCommand> getRemoteSlashCommands() {
        return List.of(
            new SlashCommand("/help", "Show help"),
            new SlashCommand("/build-agent", "Build agent from conversation"),
            new SlashCommand("/agents", "Manage agents"),
            new SlashCommand("/tools", "List tools"),
            new SlashCommand("/skill", "Manage skills"),
            new SlashCommand("/mcp", "Manage MCP servers"),
            new SlashCommand("/debug", "Toggle debug"),
            new SlashCommand("/clear", "Clear screen"),
            new SlashCommand("/exit", "Exit")
        );
    }
    
    private void startSenderThread(BlockingQueue<String> queue) {
        Thread senderThread = new Thread(() -> {
            while (true) {
                try {
                    String message = queue.take();
                    
                    if (CommandDispatcher.POISON_PILL.equals(message)) {
                        break;
                    }
                    
                    listener.prepareTurn();
                    session.sendMessage(message);
                    listener.waitForTurn();
                    
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    break;
                }
            }
        }, "remote-sender-thread");
        
        senderThread.setDaemon(true);
        senderThread.start();
    }
    
    private void readInputLoop(BlockingQueue<String> queue) {
        while (true) {
            String input = ui.readInput();
            
            if (input == null || "/exit".equals(input)) {
                break;
            }
            
            if (input.startsWith("/")) {
                // 处理远程命令
                handleCommand(input, queue);
                continue;
            }
            
            // 发送消息
            queue.put(input);
        }
    }
    
    private void handleCommand(String trimmed, BlockingQueue<String> queue) {
        String command = trimmed.split("\\s+")[0];
        
        switch (command) {
            case "/help" -> showHelp();
            case "/tools" -> handleTools();
            case "/skill" -> handleSkill();
            case "/mcp" -> handleMcp();
            case "/agents" -> handleAgents();
            case "/build-agent" -> handleBuildAgent();
            case "/debug" -> handleDebug();
            case "/clear" -> {
                queue.put(CommandDispatcher.POISON_PILL);
            }
            default -> ui.showError("Unknown command: " + command);
        }
    }
    
    private void handleTools() {
        // 从服务器获取工具列表
        String response = connection.client().get("/api/tools");
        // 解析并显示
        // ...
    }
    
    private void handleSkill() {
        // 远程技能管理
        new RemoteSessionCommandHandler(ui, session).handleSkill();
    }
    
    private void handleMcp() {
        // 远程 MCP 管理
        new McpServerCommandHandler(ui, connection.client()).handle();
    }
    
    private void handleAgents() {
        // 远程 Agent 管理
        new AgentCommandHandler(ui, connection.client()).handle();
    }
    
    private void handleBuildAgent() {
        // 从当前对话构建 Agent
        new CreateAgentCommandHandler(ui, connection.client()).handle();
    }
}
```

```java
public class A2ARemoteAgentDiscovery {
    
    // 发现远程 Agent
    public static RemoteAgentCatalog discoverCatalog(
        List<A2ARemoteAgentConfig> configs,
        List<A2ARemoteServerConfig> servers
    ) {
        List<RemoteAgentCatalogEntry> entries = new ArrayList<>();
        
        // 1. 从配置加载
        for (A2ARemoteAgentConfig config : configs) {
            if (!config.enabled()) continue;
            
            entries.add(new RemoteAgentCatalogEntry(
                config.id(),
                null,  // serverId
                config.agentId(),
                config.name(),
                config.description(),
                "available",
                config
            ));
        }
        
        // 2. 从服务器发现
        for (A2ARemoteServerConfig server : servers) {
            if (!server.discoveryEnabled()) continue;
            
            try {
                List<RemoteAgentCatalogEntry> serverEntries = 
                    discoverFromServer(server);
                entries.addAll(serverEntries);
            } catch (Exception e) {
                // 服务器不可用
                if (server.discoveryRequired()) {
                    throw new RuntimeException(
                        "Required server unavailable: " + server.url()
                    );
                }
            }
        }
        
        // 3. 去重
        entries = deduplicateEntries(entries);
        
        return new RemoteAgentCatalog(entries);
    }
    
    private static List<RemoteAgentCatalogEntry> discoverFromServer(
        A2ARemoteServerConfig server
    ) {
        // GET /api/agents
        String url = server.url() + "/api/agents";
        HttpClient client = HttpClient.newHttpClient();
        
        HttpRequest request = HttpRequest.newBuilder()
            .uri(URI.create(url))
            .header("Authorization", "Bearer " + server.apiKey())
            .GET()
            .build();
        
        try {
            HttpResponse<String> response = client.send(
                request,
                HttpResponse.BodyHandlers.ofString()
            );
            
            if (response.statusCode() != 200) {
                return List.of();
            }
            
            // 解析响应
            JsonObject json = Json.parse(response.body());
            JsonArray agents = json.getArray("agents");
            
            List<RemoteAgentCatalogEntry> entries = new ArrayList<>();
            
            for (JsonValue value : agents) {
                JsonObject agent = value.asObject();
                
                String type = agent.getString("type");
                if (!"AGENT".equals(type)) continue;
                
                String agentId = agent.getString("id");
                String name = agent.getString("name");
                String description = agent.getString("description", "");
                String status = agent.getString("status", "available");
                
                // 应用 include/exclude 过滤
                if (!matchesFilter(name, server)) continue;
                
                // 构建配置
                A2ARemoteAgentConfig config = new A2ARemoteAgentConfig(
                    server.id() + "-" + agentId,
                    true,
                    server.url(),
                    agentId,
                    server.apiKey(),
                    null,
                    server.id(),
                    name,
                    description,
                    true,
                    Duration.ofMinutes(30),
                    null,
                    null,
                    100000,
                    100000
                );
                
                entries.add(new RemoteAgentCatalogEntry(
                    config.id(),
                    server.id(),
                    agentId,
                    name,
                    description,
                    status,
                    config
                ));
            }
            
            return entries;
        } catch (Exception e) {
            return List.of();
        }
    }
    
    private static boolean matchesFilter(
        String name, 
        A2ARemoteServerConfig server
    ) {
        // 检查 exclude
        for (String pattern : server.excludeAgents()) {
            if (name.matches(pattern)) {
                return false;
            }
        }
        
        // 检查 include
        if (server.includeAgents().isEmpty()) {
            return true;  // 无 include 则全部包含
        }
        
        for (String pattern : server.includeAgents()) {
            if (name.matches(pattern)) {
                return true;
            }
        }
        
        return false;
    }
    
    private static List<RemoteAgentCatalogEntry> deduplicateEntries(
        List<RemoteAgentCatalogEntry> entries
    ) {
        Map<String, RemoteAgentCatalogEntry> map = new LinkedHashMap<>();
        
        for (RemoteAgentCatalogEntry entry : entries) {
            map.putIfAbsent(entry.agentId(), entry);
        }
        
        return new ArrayList<>(map.values());
    }
}

record RemoteAgentCatalog(List<RemoteAgentCatalogEntry> entries) {
    public Optional<RemoteAgentCatalogEntry> find(String agentId) {
        return entries.stream()
            .filter(e -> e.agentId().equals(agentId))
            .findFirst();
    }
    
    public List<RemoteAgentCatalogEntry> search(String query) {
        return entries.stream()
            .filter(e -> e.searchableText().contains(query.toLowerCase()))
            .toList();
    }
}

record RemoteAgentCatalogEntry(
    String id,
    String serverId,
    String agentId,
    String name,
    String description,
    String status,
    A2ARemoteAgentConfig config
) {
    public String searchableText() {
        return (name + " " + description).toLowerCase();
    }
}
```

💡 **说明**：
- 从配置和服务器发现 Agent
- 支持 include/exclude 过滤
- 去重（按 agentId）
- 1 分钟缓存

```java
public class SearchRemoteAgentsToolCall extends ToolCall {
    private final RemoteAgentCatalog catalog;
    
    public SearchRemoteAgentsToolCall(RemoteAgentCatalog catalog) {
        super("search_remote_agents", "Search for remote agents");
        this.catalog = catalog;
    }
    
    @Override
    public String execute(Map<String, Object> arguments, ToolContext context) {
        String query = (String) arguments.get("query");
        
        List<RemoteAgentCatalogEntry> results;
        if (query == null || query.isEmpty()) {
            results = catalog.entries();
        } else {
            results = catalog.search(query);
        }
        
        if (results.isEmpty()) {
            return "No agents found";
        }
        
        StringBuilder sb = new StringBuilder();
        sb.append("Found ").append(results.size()).append(" agents:\n\n");
        
        for (RemoteAgentCatalogEntry entry : results) {
            sb.append("- ").append(entry.name());
            if (!entry.description().isEmpty()) {
                sb.append(": ").append(entry.description());
            }
            sb.append(" (ID: ").append(entry.agentId()).append(")\n");
        }
        
        return sb.toString();
    }
}
```

💡 **说明**：
- 搜索远程 Agent
- 支持查询参数
- 返回格式化的列表

### 9.7.4 DelegateToRemoteAgentToolCall

```java
public class DelegateToRemoteAgentToolCall extends ToolCall {
    private final RemoteAgentCatalog catalog;
    private final Map<String, A2ARemoteAgentToolCall> delegates;
    
    public DelegateToRemoteAgentToolCall(RemoteAgentCatalog catalog) {
        super("delegate_to_remote_agent", "Delegate task to remote agent");
        this.catalog = catalog;
        this.delegates = new ConcurrentHashMap<>();
    }
    
    @Override
    public String execute(Map<String, Object> arguments, ToolContext context) {
        String agentId = (String) arguments.get("agent_id");
        String task = (String) arguments.get("task");
        
        // 验证参数
        if (agentId == null || task == null) {
            return "Error: agent_id and task are required";
        }
        
        // 查找 Agent
        Optional<RemoteAgentCatalogEntry> entry = catalog.find(agentId);
        if (entry.isEmpty()) {
            return "Error: Agent not found: " + agentId;
        }
        
        // 获取或创建委托
        A2ARemoteAgentToolCall delegate = delegates.computeIfAbsent(
            agentId,
            id -> new A2ARemoteAgentToolCall(entry.get().config())
        );
        
        // 执行任务
        try {
            return delegate.execute(Map.of("query", task), context);
        } catch (Exception e) {
            return "Error: " + e.getMessage();
        }
    }
}
```

💡 **说明**：
- 委托任务给远程 Agent
- 缓存委托对象
- 错误处理

```java
public class RemoteSessionCommandHandler {
    private final TerminalUI ui;
    private final HttpAgentSession session;
    private final Set<String> loadedToolIds;
    private final Set<String> loadedSkillIds;
    
    public RemoteSessionCommandHandler(
        TerminalUI ui, 
        HttpAgentSession session
    ) {
        this.ui = ui;
        this.session = session;
        this.loadedToolIds = new HashSet<>();
        this.loadedSkillIds = new HashSet<>();
    }
    
    // /tools - 加载远程工具
    public void handleTools() {
        // 获取工具列表
        String response = session.api().get("/api/tools");
        JsonArray tools = Json.parse(response).getArray("tools");
        
        ui.println();
        ui.println("Remote Tools:");
        ui.println();
        
        for (JsonValue value : tools) {
            JsonObject tool = value.asObject();
            String id = tool.getString("id");
            String name = tool.getString("name");
            String description = tool.getString("description", "");
            
            ui.printf("  %-20s - %s%n", name, description);
            
            // 标记为已加载
            loadedToolIds.add(id);
        }
        
        ui.println();
    }
    
    // /skill - 加载远程技能
    public void handleSkill() {
        // 获取技能列表
        String response = session.api().get("/api/skills");
        JsonArray skills = Json.parse(response).getArray("skills");
        
        ui.println();
        ui.println("Remote Skills:");
        ui.println();
        
        for (JsonValue value : skills) {
            JsonObject skill = value.asObject();
            String id = skill.getString("id");
            String name = skill.getString("name");
            String description = skill.getString("description", "");
            
            ui.printf("  %-20s - %s%n", name, description);
        }
        
        ui.println();
        
        // 选择技能
        String choice = ui.readLine("Select skill to load: ");
        
        // 下载技能
        String skillId = findSkillId(choice, skills);
        if (skillId != null) {
            String downloadUrl = "/api/skills/" + skillId + "/download";
            String content = session.api().get(downloadUrl);
            
            // 发送技能内容给 Agent
            session.sendMessage("<skill>\n" + content + "\n</skill>");
            
            loadedSkillIds.add(skillId);
            
            ui.println("Skill loaded: " + choice);
        }
    }
    
    private String findSkillId(String name, JsonArray skills) {
        for (JsonValue value : skills) {
            JsonObject skill = value.asObject();
            if (skill.getString("name").equals(name)) {
                return skill.getString("id");
            }
        }
        return null;
    }
}
```

💡 **说明**：
- 加载远程工具和技能
- 跟踪已加载的 ID
