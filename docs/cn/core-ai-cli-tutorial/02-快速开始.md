## 2.1 编译和运行

### 2.1.1 编译 CLI

```bash
# 进入项目根目录
cd core-ai

# 编译 CLI 模块
./gradlew :core-ai-cli:build

# 编译产物位于
ls -lh core-ai-cli/build/libs/
# core-ai-cli-1.0.0.jar
```

### 2.1.2 运行方式

#### 方式 1：使用 Gradle 运行（开发模式）

```bash
./gradlew :core-ai-cli:run
```

💡 **优势**：自动编译，适合开发调试

#### 方式 2：直接运行 JAR

```bash
java -jar core-ai-cli/build/libs/core-ai-cli-1.0.0.jar
```

💡 **优势**：独立运行，适合生产环境

#### 方式 3：创建可执行脚本

```bash
# 创建启动脚本
cat > core-ai-cli.sh << 'EOF'
#!/bin/bash
java -jar $(dirname $0)/core-ai-cli/build/libs/core-ai-cli-1.0.0.jar "$@"
EOF

chmod +x core-ai-cli.sh

# 运行
./core-ai-cli.sh
```

💡 **优势**：方便传递参数

### 2.1.3 首次运行

```bash
./gradlew :core-ai-cli:run

# 首次运行会提示配置
╔════════════════════════════════════════╗
║       Welcome to Core AI CLI          ║
╚════════════════════════════════════════╝

First time setup required.
Please configure your LLM provider:

? Select provider: (Use arrow keys)
❯ OpenAI
  Anthropic
  Local (Ollama)
```

💡 **说明**：首次运行需要配置 LLM 提供商和 API Key。

## 2.2 基本使用

### 2.2.1 简单对话

```bash
> Hello, how are you?

I'm doing well, thank you for asking! I'm an AI assistant ready to help you 
with various tasks. How can I assist you today?

> Can you help me write a Python function to calculate fibonacci numbers?

Sure! Here's a Python function to calculate fibonacci numbers:

```python
def fibonacci(n):
    """Calculate the nth fibonacci number."""
    if n <= 1:
        return n
    return fibonacci(n-1) + fibonacci(n-2)

# Example usage
for i in range(10):
    print(f"fibonacci({i}) = {fibonacci(i)}")
```

This implementation uses recursion. For better performance with large numbers, 
you might want to use memoization or an iterative approach.
```

💡 **说明**：CLI 支持 Markdown 渲染，代码会自动高亮显示。

### 2.2.2 文件操作

```bash
> Read the file README.md and summarize it

[Agent reads the file and provides a summary]

> Create a new file called test.py with a simple hello world program

[Agent creates the file]

> Run the test.py file

[Agent executes the file and shows output]
Hello, World!
```

💡 **说明**：CLI 可以通过工具读取、创建和执行文件。

### 2.2.3 代码分析

```bash
> Analyze the code in src/main/java/Main.java

[Agent analyzes the code and provides insights]

The Main.java file is the entry point of the CLI application. Key points:

1. Uses picocli for command-line argument parsing
2. Initializes SLF4J logging
3. Creates a CliApp instance and starts it
4. Supports multiple run modes (local, remote, serve)
5. Includes upgrade functionality
```

💡 **说明**：CLI 可以分析代码并提供建议。

## 2.4 会话管理

### 2.4.1 自动保存会话

CLI 会自动保存每个会话到本地文件：

```
~/.core-ai/sessions/
├── 2024-01-15_10-30-00.json
├── 2024-01-14_15-20-00.json
└── 2024-01-13_09-15-00.json
```

💡 **说明**：会话自动保存，可以随时恢复。

### 2.4.2 恢复会话

```bash
# 恢复最近的会话
./gradlew :core-ai-cli:run --args="--continue"

# 或者在 CLI 中
> /session resume
```

💡 **说明**：`--continue` 参数自动恢复最近的会话。

### 2.4.3 列出会话

```bash
> /session list

Recent sessions:
  1. 2024-01-15 10:30 - "Help with Python code"
  2. 2024-01-14 15:20 - "Analyze Java code"
  3. 2024-01-13 09:15 - "Write documentation"

Select session to resume (1-3): 
```

### 2.4.4 会话文件结构

```json
{
  "id": "2024-01-15_10-30-00",
  "created": "2024-01-15T10:30:00",
  "model": "gpt-4",
  "messages": [
    {
      "role": "user",
      "content": "Hello"
    },
    {
      "role": "assistant",
      "content": "Hi there!"
    }
  ],
  "memory": [
    "User prefers concise responses"
  ]
}
```

💡 **说明**：会话文件包含完整的对话历史和记忆。

## 2.5 配置 LLM

### 2.5.1 首次配置

首次运行时，CLI 会引导你完成配置：

```bash
? Select provider: OpenAI
? Enter API key: sk-...
? Select model: gpt-4

Configuration saved to ~/.core-ai/config.json
```

### 2.5.2 配置文件

配置文件位于 `~/.core-ai/config.json`：

```json
{
  "provider": "openai",
  "apiKey": "sk-...",
  "model": "gpt-4",
  "temperature": 0.7,
  "maxTokens": 4096
}
```

💡 **说明**：可以手动编辑配置文件。

### 2.5.3 运行时切换模型

```bash
> /model

Available models:
  1. gpt-4
  2. gpt-4-turbo
  3. gpt-3.5-turbo

Select model: 2

Switched to model: gpt-4-turbo
```

### 2.5.4 命令行指定模型

```bash
# 使用命令行参数指定模型
./gradlew :core-ai-cli:run --args="--model gpt-4-turbo"

# 或者直接运行 JAR
java -jar core-ai-cli-1.0.0.jar --model gpt-4-turbo
```

💡 **说明**：可以通过命令行参数覆盖配置文件中的模型设置。

### 2.5.5 支持的 LLM 提供商

| 提供商 | 配置方式 | 说明 |
|--------|---------|------|
| **OpenAI** | API Key | GPT-4, GPT-3.5 |
| **Anthropic** | API Key | Claude 3 |
| **Local (Ollama)** | 本地部署 | 无需 API Key |
| **Custom** | Base URL + API Key | 自定义端点 |

💡 **说明**：支持多种 LLM 提供商，可以轻松切换。

## 2.6 常见问题

### 2.6.1 API Key 错误

**问题**：
```
Error: Invalid API key
```

**解决方案**：
```bash
# 重新配置
> /config

# 或者手动编辑配置文件
vim ~/.core-ai/config.json
```

### 2.6.2 网络连接错误

**问题**：
```
Error: Connection timeout
```

**解决方案**：
```bash
# 检查网络连接
ping api.openai.com

# 如果使用代理，配置环境变量
export HTTP_PROXY=http://proxy:port
export HTTPS_PROXY=http://proxy:port

# 或者在配置文件中设置
{
  "proxy": "http://proxy:port"
}
```

### 2.6.3 模型不可用

**问题**：
```
Error: Model not available
```

**解决方案**：
```bash
# 切换到可用模型
> /model

# 或者在配置文件中修改
{
  "model": "gpt-3.5-turbo"
}
```

### 2.6.4 内存不足

**问题**：
```
Error: Out of memory
```

**解决方案**：
```bash
# 增加 JVM 内存
java -Xmx4g -jar core-ai-cli-1.0.0.jar

# 或者减少对话历史
> /session clear
```

### 2.6.5 终端显示异常

**问题**：Markdown 渲染不正确，代码没有高亮

**解决方案**：
```bash
# 检查终端是否支持 ANSI
echo -e "\033[31mRed text\033[0m"

# 如果不支持，使用不支持颜色的终端
export NO_COLOR=1

# 或者使用支持的终端（iTerm2、Windows Terminal）
```
