## 4.1 终端 UI 概述

### 4.1.1 终端 UI 的角色

终端 UI 是用户与 CLI 交互的核心组件，位于 `ui/` 包下，负责：

- 终端初始化与兼容
- Markdown 流式渲染
- 代码语法高亮
- 思考动画
- 用户输入（自动补全、粘贴处理）
- 表格渲染
- 输入选择器（Picker）

💡 **设计意图**：提供丰富的终端交互体验，媲美现代 IDE。

### 4.1.2 技术栈

| 组件 | 技术 | 说明 |
|------|------|------|
| **终端交互** | JLine 3 (`LineReader`, `Terminal`) | 命令行编辑、历史、自动补全 |
| **Markdown** | `StreamingMarkdownRenderer` + `MarkdownLineRenderer` | 流式增量渲染 |
| **代码高亮** | `CodeHighlighter` | 基于正则的语法高亮，ANSI 着色 |
| **动画** | `ThinkingSpinner` | Braille 字符动画 |
| **输出面板** | `OutputPanel` | 高层渲染协调器 |
| **ANSI 主题** | `AnsiTheme` | 颜色常量、显示宽度计算 |

## 4.2 TerminalUI 核心类

### 4.2.1 类定义

**位置**: `ui/TerminalUI.java`

```java
public class TerminalUI implements AutoCloseable {
    private final Terminal terminal;
    private final LineReader lineReader;
    private final SlashCommandCompleter slashCompleter;
    private final AgentNameCompleter agentNameCompleter;
    private final boolean simpleMode;  // dumb 终端降级
    
    public TerminalUI() {
        // 1. 构建终端
        this.terminal = buildTerminal();
        
        // 2. 检测 dumb 终端，降级为简单模式
        if (terminal.getType() == Terminal.TYPE_DUMB) {
            this.simpleMode = true;
            this.lineReader = null;
            this.slashCompleter = null;
            this.agentNameCompleter = null;
        } else {
            this.simpleMode = false;
            // 3. 创建补全器
            this.slashCompleter = new SlashCommandCompleter();
            this.agentNameCompleter = new AgentNameCompleter();
            
            // 4. 构建 JLine LineReader
            this.lineReader = buildLineReader();
        }
    }
}
```

💡 **说明**：
- 实现 `AutoCloseable`，支持 try-with-resources
- 支持 "dumb 终端" 降级为简单模式（`BufferedReader`）
- 使用 JLine 3 管理终端交互

### 4.2.2 终端构建

```java
private Terminal buildTerminal() {
    // 按优先级尝试不同 provider
    for (String provider : List.of("ffm", "jni", "jansi")) {
        try {
            Terminal term = TerminalBuilder.builder()
                .provider(provider)
                .build();
            
            // 拒绝 dumb 终端
            if (term.getType() != Terminal.TYPE_DUMB) {
                return term;
            }
        } catch (Exception e) {
            // 尝试下一个 provider
        }
    }
    
    // 尝试直接打开 /dev/tty
    return tryTtyTerminal();
}

private Terminal tryTtyTerminal() {
    try {
        // 直接打开 /dev/tty
        InputStream tty = new FileInputStream("/dev/tty");
        return TerminalBuilder.builder()
            .streams(tty, System.out)
            .build();
    } catch (Exception e) {
        // 最终降级
        return TerminalBuilder.builder()
            .dumb(true)
            .build();
    }
}
```

💡 **说明**：
- 按优先级尝试 `ffm`（Java 22+ Foreign Memory）、`jni`、`jansi`
- 如果都失败，尝试直接打开 `/dev/tty`
- 最终降级为 dumb 终端

}

private String readWithJLine() {
    try {
        String prompt = AnsiTheme.colorize("> ", AnsiTheme.Color.PROMPT);
        return lineReader.readLine(prompt);
    } catch (UserInterruptException e) {
        // Ctrl+C → 退出
        return "/exit";
    } catch (EndOfFileException e) {
        // Ctrl+D → 关闭
        return null;
    }
}

## 4.3 ANSI 主题系统

### 4.3.1 AnsiTheme

**位置**: `ui/AnsiTheme.java`

```java
public class AnsiTheme {
    // 检查 NO_COLOR 环境变量
    private static final boolean NO_COLOR = 
        System.getenv("NO_COLOR") != null;
    
    // 颜色常量
    public static final String PROMPT = "[36m";        // 青色
    public static final String ERROR = "[31m";         // 红色
    public static final String WARNING = "[33m";       // 黄色
    public static final String MUTED = "[90m";         // 灰色
    public static final String CMD_NAME = "[36m";      // 青色
    public static final String CMD_DESC = "[37m";      // 白色
    
    // Markdown 颜色
    public static final String MD_H1 = "[1;34m";       // 蓝色粗体
    public static final String MD_H2 = "[1;34m";       // 蓝色粗体
    public static final String MD_H3 = "[1m";          // 粗体
    public static final String MD_H4 = "[1m";          // 粗体
    public static final String MD_CODE_BLOCK = "[36m"; // 青色
    public static final String MD_INLINE_CODE = "[36m";// 青色
    public static final String MD_BOLD = "[1m";        // 粗体
    public static final String MD_ITALIC = "[3m";      // 斜体
    public static final String MD_BULLET = "[33m";     // 黄色
    
    // 语法高亮颜色
    public static final String SYN_KEYWORD = "[35m";   // 品红
    public static final String SYN_STRING = "[32m";    // 绿色
    public static final String SYN_COMMENT = "[90m";   // 灰色
    public static final String SYN_NUMBER = "[36m";    // 青色
    public static final String SYN_TYPE = "[33m";      // 黄色
    public static final String SYN_ANNOTATION = "[33m";// 黄色
    
    // 重置
    public static final String RESET = "[0m";
    
    // 着色辅助方法
    public static String colorize(String text, String color) {
        if (NO_COLOR) return text;
        return color + text + RESET;
    }
    
    // 计算显示宽度（忽略 ANSI 转义序列）
    public static int displayWidth(String text) {
        // 去除 ANSI 转义序列
        String clean = text.replaceAll("\\[[;\\d]*m", "");
        int width = 0;
        for (int i = 0; i < clean.length(); i++) {
            char c = clean.charAt(i);
            if (isWideChar(c)) {
                width += 2;  // CJK 字符占 2 列
            } else if (!isZeroWidth(c)) {
                width += 1;
            }
        }
        return width;
    }
    
    // 检测宽字符（CJK、Emoji）
    public static boolean isWideChar(char c) {
        // Unicode 范围检测
        return (c >= 0x4E00 && c <= 0x9FFF)   // CJK 统一汉字
            || (c >= 0x3000 && c <= 0x303F)   // CJK 符号和标点
            || (c >= 0xFF00 && c <= 0xFFEF);  // 全角 ASCII、半角片假名
    }
}
```

💡 **说明**：
- 支持 `NO_COLOR` 环境变量
- 颜色映射为 16 色（Windows 兼容）
- `displayWidth` 计算显示宽度（CJK 字符占 2 列）
- `isWideChar` 检测宽字符

## 4.4 Markdown 渲染

### 4.4.1 StreamingMarkdownRenderer

**位置**: `ui/StreamingMarkdownRenderer.java`

```java
public class StreamingMarkdownRenderer {
    private final Writer writer;
    private final StringBuilder lineBuffer;
    private boolean inCodeBlock;
    private String codeBlockLanguage;
    private int printedLength;
    private int printedDisplayWidth;
    
    public StreamingMarkdownRenderer(Writer writer) {
        this.writer = writer;
        this.lineBuffer = new StringBuilder();
        this.inCodeBlock = false;
        this.printedLength = 0;
    }
    
    // 处理流式文本块
    public void processChunk(String chunk) {
        for (char c : chunk.toCharArray()) {
            if (c == '\n') {
                completeLine();
                lineBuffer.setLength(0);
            } else {
                lineBuffer.append(c);
            }
        }
    }
    
    // 完成一行
    private void completeLine() {
        String line = lineBuffer.toString();
        
        // 检测代码块开始/结束
        if (line.startsWith("```")) {
            if (inCodeBlock) {
                // 代码块结束
                inCodeBlock = false;
                codeBlockLanguage = null;
            } else {
                // 代码块开始
                inCodeBlock = true;
                codeBlockLanguage = line.substring(3).trim();
            }
            writer.println(AnsiTheme.colorize(line, AnsiTheme.MD_CODE_BLOCK));
            return;
        }
        
        // 在代码块内 → 代码高亮
        if (inCodeBlock) {
            String highlighted = CodeHighlighter.highlight(
                codeBlockLanguage, line
            );
            writer.println(highlighted);
            return;
        }
        
        // 检测 Markdown 表格
        if (line.contains("|")) {
            // 缓冲表格行，委托给 TableRenderer
            bufferTableRow(line);
            return;
        }
        
        // 普通 Markdown 行
        renderSmartLine(line);
    }
    
    // 智能行渲染
    private void renderSmartLine(String line) {
        if (line.startsWith("#")) {
            // 标题
            renderHeading(line);
        } else if (line.startsWith("- ") || line.startsWith("* ")) {
            // 无序列表
            renderBullet(line);
        } else {
            // 普通文本 + 内联渲染
            String rendered = MarkdownLineRenderer.renderLine(line);
            writer.println(rendered);
        }
    }
    
    // 刷新部分输出
    public void flushPartial() {
        String partial = lineBuffer.toString();
        String rendered = MarkdownLineRenderer.renderInline(partial);
        writer.print(rendered);
        writer.flush();
    }
    
    // 清除部分输出（用于重绘）
    public void clearPartialOutput() {
        // ANSI 转义序列：清除当前行
        writer.print("[2K");
        writer.flush();
    }
    
    // 重置状态
    public void reset() {
        lineBuffer.setLength(0);
        inCodeBlock = false;
        codeBlockLanguage = null;
        printedLength = 0;
    }
}
```

💡 **说明**：
- 增量渲染：逐字符缓冲，按行渲染
- 检测代码块（```）和表格（|）
- 代码块内使用代码高亮
- 支持部分输出和清除（用于重绘）

### 4.4.2 MarkdownLineRenderer

**位置**: `ui/MarkdownLineRenderer.java`

```java
public class MarkdownLineRenderer {
    
    // 渲染单行 Markdown
    public static String renderLine(String line) {
        // ATX 标题 # - ######
        if (line.startsWith("#")) {
            return renderHeading(line);
        }
        
        // 无序列表 - *
        if (line.startsWith("- ") || line.startsWith("* ")) {
            String bullet = AnsiTheme.colorize("  • ", AnsiTheme.MD_BULLET);
            return bullet + renderInline(line.substring(2));
        }
        
        // 主题分隔符 --- *** ___
        if (line.matches("^(-{3,}|\\*{3,}|_{3,})$")) {
            return AnsiTheme.colorize("─".repeat(40), AnsiTheme.MUTED);
        }
        
        // 块引用 >
        if (line.startsWith("> ")) {
            return AnsiTheme.colorize("│ ", AnsiTheme.MUTED) 
                 + renderInline(line.substring(2));
        }
        
        // 普通文本
        return renderInline(line);
    }
    
    // 渲染标题
    private static String renderHeading(String line) {
        int level = 0;
        while (level < line.length() && line.charAt(level) == '#') {
            level++;
        }
        String text = line.substring(level).trim();
        
        return switch (level) {
            case 1 -> AnsiTheme.colorize(text, AnsiTheme.MD_H1);
            case 2 -> AnsiTheme.colorize(text, AnsiTheme.MD_H2);
            case 3 -> AnsiTheme.colorize(text, AnsiTheme.MD_H3);
            default -> AnsiTheme.colorize(text, AnsiTheme.MD_H4);
        };
    }
    
    // 内联渲染（代码、粗体、斜体）
    public static String renderInline(String text) {
        StringBuilder result = new StringBuilder();
        int i = 0;
        
        while (i < text.length()) {
            // 行内代码 `code`
            if (text.charAt(i) == '`') {
                int end = text.indexOf('`', i + 1);
                if (end > 0) {
                    String code = text.substring(i + 1, end);
                    result.append(
                        AnsiTheme.colorize(code, AnsiTheme.MD_INLINE_CODE)
                    );
                    i = end + 1;
                    continue;
                }
            }
            
            // 粗体 **text**
            if (i + 1 < text.length() 
                && text.charAt(i) == '*' 
                && text.charAt(i + 1) == '*') {
                int end = text.indexOf("**", i + 2);
                if (end > 0) {
                    String bold = text.substring(i + 2, end);
                    result.append(
                        AnsiTheme.colorize(bold, AnsiTheme.MD_BOLD)
                    );
                    i = end + 2;
                    continue;
                }
            }
            
            // 斜体 *text*
            if (text.charAt(i) == '*') {
                int end = text.indexOf('*', i + 1);
                if (end > 0) {
                    String italic = text.substring(i + 1, end);
                    result.append(
                        AnsiTheme.colorize(italic, AnsiTheme.MD_ITALIC)
                    );
                    i = end + 1;
                    continue;
                }
            }
            
            // 普通字符
            result.append(text.charAt(i));
            i++;
        }
        
        return result.toString();
    }
}
```

💡 **说明**：
- 支持 ATX 标题（`#` 到 `######`）
- 支持无序列表（`-`、`*`）
- 支持主题分隔符（`---`、`***`、`___`）
- 支持块引用（`>`）
- 内联渲染：代码（`` ` ``）、粗体（`**`）、斜体（`*`）

### 4.5.1 CodeHighlighter

**位置**: `ui/CodeHighlighter.java`

```java
public class CodeHighlighter {
    
    // 语言别名映射
    private static final Map<String, String> LANGUAGE_ALIASES = Map.of(
        "js", "javascript",
        "ts", "javascript",
        "py", "python",
        "rb", "python",
        "sh", "shell",
        "bash", "shell",
        "cpp", "c",
        "kt", "java",
        "kotlin", "java"
    );
    
    // 关键字映射
    private static final Map<String, Set<String>> KEYWORDS = Map.of(
        "java", Set.of("public", "private", "protected", "class", 
                       "interface", "void", "int", "String", "return"),
        "python", Set.of("def", "class", "import", "from", "return", 
                        "if", "else", "for", "while"),
        "javascript", Set.of("function", "const", "let", "var", 
                            "return", "if", "else", "for")
    );
    
    // 高亮入口
    public static String highlight(String language, String line) {
        if (language == null || language.isEmpty()) {
            return line;
        }
        
        // 解析语言别名
        String lang = LANGUAGE_ALIASES.getOrDefault(
            language.toLowerCase(), 
            language.toLowerCase()
        );
        
        // 特殊处理
        return switch (lang) {
            case "diff" -> highlightDiff(line);
            case "json" -> highlightJson(line);
            case "yaml" -> highlightYaml(line);
            default -> highlightGeneric(lang, line);
        };
    }
    
    // 通用高亮
    private static String highlightGeneric(String lang, String line) {
        // 1. 收集字符串
        List<Span> spans = collectStrings(line);
        
        // 2. 收集注释
        spans.addAll(collectComments(line));
        
        // 3. 收集注解 @Annotation
        spans.addAll(collectAnnotations(line));
        
        // 4. 收集数字
        spans.addAll(collectNumbers(line));
        
        // 5. 收集关键字和类型
        Set<String> keywords = KEYWORDS.getOrDefault(lang, Set.of());
        spans.addAll(collectKeywordsAndTypes(line, keywords));
        
        // 6. 应用颜色（避免重叠）
        return applySpans(line, spans);
    }
    
    // Diff 高亮
    private static String highlightDiff(String line) {
        if (line.startsWith("+")) {
            return AnsiTheme.colorize(line, "[32m");  // 绿色
        } else if (line.startsWith("-")) {
            return AnsiTheme.colorize(line, "[31m");  // 红色
        }
        return line;
    }
    
    // 收集字符串（双引号、单引号）
    private static List<Span> collectStrings(String line) {
        List<Span> spans = new ArrayList<>();
        // 匹配 "..." 和 '...'
        Pattern pattern = Pattern.compile("\"[^\"]*\"|'[^']*'");
        Matcher matcher = pattern.matcher(line);
        while (matcher.find()) {
            spans.add(new Span(
                matcher.start(), 
                matcher.end(), 
                AnsiTheme.SYN_STRING
            ));
        }
        return spans;
    }
    
    // 收集注释（// 和 #）
    private static List<Span> collectComments(String line) {
        List<Span> spans = new ArrayList<>();
        // C 风格注释 //
        int idx = line.indexOf("//");
        if (idx >= 0) {
            spans.add(new Span(idx, line.length(), AnsiTheme.SYN_COMMENT));
        }
        // Shell/Python 注释 #
        idx = line.indexOf("#");
        if (idx >= 0) {
            spans.add(new Span(idx, line.length(), AnsiTheme.SYN_COMMENT));
        }
        return spans;
    }
    
    // 收集注解 @Annotation
    private static List<Span> collectAnnotations(String line) {
        List<Span> spans = new ArrayList<>();
        Pattern pattern = Pattern.compile("@\\w+");
        Matcher matcher = pattern.matcher(line);
        while (matcher.find()) {
            spans.add(new Span(
                matcher.start(), 
                matcher.end(), 
                AnsiTheme.SYN_ANNOTATION
            ));
        }
        return spans;
    }
    
    // 收集数字
    private static List<Span> collectNumbers(String line) {
        List<Span> spans = new ArrayList<>();
        Pattern pattern = Pattern.compile("\\b\\d+\\b");
        Matcher matcher = pattern.matcher(line);
        while (matcher.find()) {
            spans.add(new Span(
                matcher.start(), 
                matcher.end(), 
                AnsiTheme.SYN_NUMBER
            ));
        }
        return spans;
    }
    
    // 收集关键字和类型
    private static List<Span> collectKeywordsAndTypes(
        String line, Set<String> keywords
    ) {
        List<Span> spans = new ArrayList<>();
        Pattern pattern = Pattern.compile("\\b\\w+\\b");
        Matcher matcher = pattern.matcher(line);
        while (matcher.find()) {
            String word = matcher.group();
            if (keywords.contains(word)) {
                // 关键字
                spans.add(new Span(
                    matcher.start(), 
                    matcher.end(), 
                    AnsiTheme.SYN_KEYWORD
                ));
            } else if (Character.isUpperCase(word.charAt(0))) {
                // 类型名（大写开头）
                spans.add(new Span(
                    matcher.start(), 
                    matcher.end(), 
                    AnsiTheme.SYN_TYPE
                ));
            }
        }
        return spans;
    }
    
    // 应用颜色（避免重叠）
    private static String applySpans(String line, List<Span> spans) {
        // 按位置排序
        spans.sort(Comparator.comparingInt(Span::start));
        
        StringBuilder result = new StringBuilder();
        int lastEnd = 0;
        
        for (Span span : spans) {
            // 添加未着色部分
            if (span.start() > lastEnd) {
                result.append(line, lastEnd, span.start());
            }
            // 添加着色部分
            String text = line.substring(span.start(), span.end());
            result.append(AnsiTheme.colorize(text, span.color()));
            lastEnd = span.end();
        }
        
        // 添加剩余部分
        if (lastEnd < line.length()) {
            result.append(line.substring(lastEnd));
        }
        
        return result.toString();
    }
}

record Span(int start, int end, String color) {}
```

💡 **说明**：
- 基于正则表达式的语法高亮
- 先收集所有 span（字符串、注释、注解、数字、关键字、类型）

```java
public class ThinkingSpinner {
    private final Writer writer;
    private volatile boolean running;
    private Thread spinnerThread;
    private long startTime;
    
    // Braille 字符动画帧
    private static final String[] FRAMES = {
        "⠋", "⠙", "⠹", "⠸", "⠼", "⠴", "⠦", "⠧", "⠇", "⠏"
    };
    
    // 轮播消息
    private static final String[] MESSAGES = {
        "Thinking...",
        "Charging the laser...",
        "Consulting the oracle...",
        "Reticulating splines..."
    };
    
    // 统计信息供应商（可选）
    private Supplier<String> statsSupplier;
    
    public ThinkingSpinner(Writer writer) {
        this.writer = writer;
        this.running = false;
    }
    
    public void start() {
        if (running) return;
        
        running = true;
        startTime = System.currentTimeMillis();
        
        // 守护线程运行动画
        spinnerThread = new Thread(() -> {
            int frame = 0;
            int messageIdx = 0;
            
            while (running) {
                // 构建显示文本
                StringBuilder sb = new StringBuilder();
                sb.append("\r");  // 回到行首
                sb.append(AnsiTheme.colorize(
                    FRAMES[frame], AnsiTheme.PROMPT
                ));
                sb.append(" ");
                sb.append(MESSAGES[messageIdx]);
                
                // 显示经过时间
                long elapsed = System.currentTimeMillis() - startTime;
                sb.append(" (");
                sb.append(formatElapsed(elapsed));
                sb.append(")");
                
                // 显示统计信息（如果有）
                if (statsSupplier != null) {
                    sb.append(" ");
                    sb.append(statsSupplier.get());
                }
                
                // 输出并刷新
                try {
                    writer.write(sb.toString());
                    writer.flush();
                } catch (IOException e) {
                    break;
                }
                
                // 更新帧和消息
                frame = (frame + 1) % FRAMES.length;
                if (frame == 0) {
                    messageIdx = (messageIdx + 1) % MESSAGES.length;
                }
                
                // 80ms 间隔
                try {
                    Thread.sleep(80);
                } catch (InterruptedException e) {
                    Thread.currentThread().interrupt();
                    break;
                }
            }
            
            // 清除动画
            try {
                writer.write("\r" + " ".repeat(60) + "\r");
                writer.flush();
            } catch (IOException e) {
                // 忽略
            }
        }, "thinking-spinner");
        
        spinnerThread.setDaemon(true);
        spinnerThread.start();
    }
    
    public void stop() {
        running = false;
        if (spinnerThread != null) {
            try {
                spinnerThread.join(1000);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }
    }
    
    public void resetTimer() {
        startTime = System.currentTimeMillis();
    }
    
    public long getElapsedMs() {
        return System.currentTimeMillis() - startTime;
    }
    
    // 格式化经过时间
    private String formatElapsed(long ms) {
        long seconds = ms / 1000;
        long minutes = seconds / 60;
        seconds = seconds % 60;
        
        if (minutes > 0) {
            return String.format("%d:%02d", minutes, seconds);
        }
        return String.format("%ds", seconds);
    }
}
```

💡 **说明**：
- 使用 Braille 字符（⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏）实现动画
- 80ms 间隔，轮播消息
- 显示经过时间（秒或分钟:秒）
- 支持统计信息供应商（token 使用量等）
- 守护线程运行，自动清理

### 4.7.2 PasteBuffer

**位置**: `ui/PasteBuffer.java`

```java
public class PasteBuffer {
    private final Map<String, String> buffer;
    private int nextId;
    
    // 阈值：大于 1000 字符或 10 行
    private static final int CHAR_THRESHOLD = 1000;
    private static final int LINE_THRESHOLD = 10;
    
    public PasteBuffer() {
        this.buffer = new HashMap<>();
        this.nextId = 1;
    }
    
    // 存储大粘贴
    public String store(String content) {
        if (content.length() < CHAR_THRESHOLD 
            && content.split("\n").length < LINE_THRESHOLD) {
            return content;  // 太小，直接返回
        }
        
        // 生成占位符
        String id = "#" + nextId++;
        String placeholder = String.format(
            "[Pasted %d chars, %d lines %s]",
            content.length(),
            content.split("\n").length,
            id
        );
        
        buffer.put(id, content);
        return placeholder;
    }
    
    // 展开占位符
    public String expand(String text) {
        // 正则匹配 [Pasted N chars, M lines #id]
        Pattern pattern = Pattern.compile(
            "\\[Pasted \\d+ chars, \\d+ lines #(\\d+)\\]"
        );
        Matcher matcher = pattern.matcher(text);
        StringBuilder result = new StringBuilder();
        
        while (matcher.find()) {
            String id = "#" + matcher.group(1);
            String content = buffer.getOrDefault(id, "");
            matcher.appendReplacement(result, content);
        }
        matcher.appendTail(result);
        
        return result.toString();
    }
}
```

💡 **说明**：
- 大粘贴（>1000 字符或 ≥10 行）存储为占位符
- 显示 `[Pasted N chars, M lines #id]`
- 提交前展开占位符
- 避免大粘贴干扰输入体验

```java
public class FileReferenceExpander {
    
    // 正则匹配 @path/file.ext
    private static final Pattern FILE_REF_PATTERN = Pattern.compile(
        "@[-\\w./_~]+(/\\S+|\\.\\w{1,10})"
    );
    
    // 最大文件大小 100 KB
    private static final int MAX_FILE_SIZE = 100 * 1024;
    
    // 展开 @file 引用
    public static String expand(String text, Path cwd) {
        Matcher matcher = FILE_REF_PATTERN.matcher(text);
        StringBuilder result = new StringBuilder();
        
        while (matcher.find()) {
            String ref = matcher.group();
            String path = ref.substring(1);  // 去掉 @
            
            // 解析路径
            Path file = cwd.resolve(path).normalize();
            
            // 安全检查：确保在 cwd 内
            if (!file.startsWith(cwd)) {
                matcher.appendReplacement(result, ref);
                continue;
            }
            
            // 读取文件内容
            try {
                if (Files.size(file) > MAX_FILE_SIZE) {
                    matcher.appendReplacement(
                        result, 
                        "[File too large: " + path + "]"
                    );
                    continue;
                }
                
                String content = Files.readString(file);
                String ext = getExtension(path);
                
                // 构建代码块
                String codeBlock = String.format(
                    "\n```%s\n// File: %s\n%s\n```\n",
                    ext, path, content
                );
                
                matcher.appendReplacement(
                    result, 
                    Matcher.quoteReplacement(codeBlock)
                );
            } catch (IOException e) {
                matcher.appendReplacement(
                    result, 
                    "[File not found: " + path + "]"
                );
            }
        }
        
        matcher.appendTail(result);
        return result.toString();
    }
    
    private static String getExtension(String path) {
        int dot = path.lastIndexOf('.');
        return dot > 0 ? path.substring(dot + 1) : "";
    }
}

💡 **说明**：
- 展开 `@file` 引用为代码块
- 正则匹配 `@path/file.ext`
- 安全检查：确保文件在 cwd 内
- 大小限制：100 KB
- 自动检测文件扩展名（用于代码高亮）

```java
public class TableRenderer {
    
    // 渲染 Markdown 表格
    public static String render(List<String> rows) {
        if (rows.isEmpty()) return "";
        
        // 1. 解析表格行
        List<String[]> parsedRows = new ArrayList<>();
        List<Boolean> separatorRows = new ArrayList<>();
        
        for (String row : rows) {
            if (row.matches("^\\|[\\s:-]+\\|$")) {
                // 分隔行 |---|---|
                separatorRows.add(true);
            } else {
                // 数据行 |col1|col2|
                String[] cells = row.split("\\|");
                // 去掉首尾空元素
                cells = Arrays.copyOfRange(cells, 1, cells.length - 1);
                parsedRows.add(cells);
                separatorRows.add(false);
            }
        }
        
        // 2. 计算列宽
        int numCols = parsedRows.stream()
            .mapToInt(r -> r.length)
            .max()
            .orElse(0);
        
        int[] colWidths = new int[numCols];
        for (String[] row : parsedRows) {
            for (int i = 0; i < row.length; i++) {
                int width = AnsiTheme.displayWidth(row[i].trim());
                colWidths[i] = Math.max(colWidths[i], width);
            }
        }
        
        // 3. 构建表格
        StringBuilder sb = new StringBuilder();
        
        // 顶部边框 ┌───┬───┐
        sb.append(drawBorder(colWidths, "┌", "┬", "┐"));
        
        for (int i = 0; i < parsedRows.size(); i++) {
            String[] row = parsedRows.get(i);
            
            // 数据行 │col1│col2│
            sb.append("│");
            for (int j = 0; j < numCols; j++) {
                String cell = j < row.length ? row[j].trim() : "";
                int padding = colWidths[j] - AnsiTheme.displayWidth(cell);
                sb.append(" ");
                sb.append(cell);
                sb.append(" ".repeat(Math.max(0, padding)));
                sb.append(" │");
            }
            sb.append("\n");
            
            // 分隔行 ├───┼───┤
            if (i < separatorRows.size() && separatorRows.get(i)) {
                sb.append(drawBorder(colWidths, "├", "┼", "┤"));
            }
        }
        
        // 底部边框 └───┴───┘
        sb.append(drawBorder(colWidths, "└", "┴", "┘"));
        
        return sb.toString();
    }
    
    // 绘制边框
    private static String drawBorder(
        int[] widths, String left, String mid, String right
    ) {
        StringBuilder sb = new StringBuilder();
        sb.append(left);
        for (int i = 0; i < widths.length; i++) {
            sb.append("─".repeat(widths[i] + 2));
            if (i < widths.length - 1) {
                sb.append(mid);
            }
        }
        sb.append(right);
        sb.append("\n");
        return sb.toString();
    }
}
```

💡 **说明**：
- 解析 Markdown 表格（`|col1|col2|`）
- 自动计算列宽（考虑 CJK 字符宽度）
- 使用 Unicode box-drawing 字符绘制边框
- 支持分隔行（`|---|---|`）

### 4.9.3 思考题

1. **如何实现更好的代码高亮？**
   
   **提示**：
   - 使用 ANTLR 或 Tree-sitter 进行真正的语法分析
   - 支持更多语言
   - 上下文感知高亮

2. **如何实现流式 Markdown 渲染的优化？**
   
   **提示**：
   - 增量解析（只渲染新增部分）
   - 缓存已渲染的行
   - 使用 ANSI 转义序列重绘

3. **如何实现跨平台终端兼容？**
   
   **提示**：
   - 检测终端类型（dumb、ansi、xterm）
   - 降级策略（无颜色、无动画）
   - Windows 特殊处理（CrLfFilterWriter）

4. **如何实现更智能的粘贴处理？**
   
   **提示**：
   - 检测粘贴内容的语言
   - 自动格式化
   - 语法检查
