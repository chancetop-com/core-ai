## 8.1 记忆系统概述

### 8.1.1 记忆系统的角色

记忆系统负责管理 Agent 的长期记忆，包括：

- 知识提取（从对话中提取关键信息）
- 本地存储（文件系统存储）
- 记忆注入（将记忆注入到 Prompt）
- 后台提取（使用 fork Agent 异步提取）
- 会话关闭提取（会话结束时提取）

💡 **设计意图**：让 Agent 能够记住用户偏好、项目上下文、历史经验，提供更个性化的帮助。

### 8.1.2 核心组件

| 组件 | 位置 | 职责 |
|------|------|------|
| `MdMemoryProvider` | `memory/` | 主要记忆存储提供者 |
| `LocalFileMemoryProvider` | `memory/` | 遗留/全局记忆提供者 |
| `MemoryTriggerService` | `memory/` | 后台提取服务 |
| `MemoryExtractionTool` | `memory/` | 提取规范工具 |
| `KnowledgeLogTool` | `memory/` | 知识日志工具 |
| `ExtractionCursorTool` | `memory/` | 提取游标工具 |
| `CliMemoryLifecycle` | `memory/` | 记忆生命周期 |
| `MemorySectionManager` | `memory/` | 记忆部分管理 |
| `MemorySystemPrompt` | `memory/` | 记忆 Prompt 注入 |
| `SessionCloseExtractor` | `memory/` | 会话关闭提取 |

## 8.2 存储提供者

### 8.2.1 MdMemoryProvider

**位置**: `memory/MdMemoryProvider.java`

```java
public class MdMemoryProvider {
    private final Path workspace;
    private final Path knowledgeDir;
    private final Path episodesDir;
    
    // 目录结构
    // .core-ai/knowledge/
    //   ├── MEMORY.md (索引)
    //   ├── project/
    //   ├── user/
    //   ├── feedback/
    //   └── reference/
    // .core-ai/episodes/
    //   └── *.md (情景记忆)
    
    public MdMemoryProvider(Path workspace) {
        this.workspace = workspace;
        this.knowledgeDir = workspace.resolve(".core-ai/knowledge");
        this.episodesDir = workspace.resolve(".core-ai/episodes");
        
        // 确保目录存在
        ensureDirectories();
    }
    
    private void ensureDirectories() {
        try {
            Files.createDirectories(knowledgeDir);
            Files.createDirectories(knowledgeDir.resolve("project"));
            Files.createDirectories(knowledgeDir.resolve("user"));
            Files.createDirectories(knowledgeDir.resolve("feedback"));
            Files.createDirectories(knowledgeDir.resolve("reference"));
            Files.createDirectories(episodesDir);
            
            // 创建索引文件
            Path indexFile = knowledgeDir.resolve("MEMORY.md");
            if (!Files.exists(indexFile)) {
                Files.writeString(indexFile, "# Memory Index\n\n");
            }
        } catch (IOException e) {
            // 忽略
        }
    }
    
    // 加载记忆
    public String load() {
        StringBuilder sb = new StringBuilder();
        
        // 1. 加载索引
        Path indexFile = knowledgeDir.resolve("MEMORY.md");
        if (Files.exists(indexFile)) {
            try {
                sb.append(Files.readString(indexFile));
                sb.append("\n\n");
            } catch (IOException e) {
                // 忽略
            }
        }
        
        // 2. 加载用户类型记忆
        loadTypeMemories("user", sb);
        
        // 3. 加载最新 2 个情景记忆（2 KB 预算）
        loadRecentEpisodes(sb, 2, 2048);
        
        return sb.toString();
    }
    
    private void loadTypeMemories(String type, StringBuilder sb) {
        Path typeDir = knowledgeDir.resolve(type);
        if (!Files.isDirectory(typeDir)) return;
        
        try (var stream = Files.list(typeDir)) {
            stream.filter(p -> p.toString().endsWith(".md"))
                .forEach(p -> {
                    try {
                        sb.append(Files.readString(p));
                        sb.append("\n\n");
                    } catch (IOException e) {
                        // 忽略
                    }
                });
        } catch (IOException e) {
            // 忽略
        }
    }
    
    private void loadRecentEpisodes(StringBuilder sb, int limit, int budget) {
        if (!Files.isDirectory(episodesDir)) return;
        
        try (var stream = Files.list(episodesDir)) {
            List<Path> episodes = stream
                .filter(p -> p.toString().endsWith(".md"))
                .sorted(Comparator.comparing(
                    p -> {
                        try {
                            return Files.getLastModifiedTime((Path) p);
                        } catch (IOException e) {
                            return FileTime.from(Instant.EPOCH);
                        }
                    },
                    Comparator.reverseOrder()
                ))
                .limit(limit)
                .toList();
            
            int totalSize = 0;
            for (Path episode : episodes) {
                String content = Files.readString(episode);
                if (totalSize + content.length() > budget) {
                    break;
                }
                sb.append(content);
                sb.append("\n\n");
                totalSize += content.length();
            }
        } catch (IOException e) {
            // 忽略
        }
    }
    
    // 列出所有记忆
    public List<MemoryEntry> listMemories() {
        List<MemoryEntry> entries = new ArrayList<>();
        
        // 扫描所有类型目录
        for (String type : List.of("project", "user", "feedback", "reference")) {
            Path typeDir = knowledgeDir.resolve(type);
            if (!Files.isDirectory(typeDir)) continue;
            
            try (var stream = Files.list(typeDir)) {
                stream.filter(p -> p.toString().endsWith(".md"))
                    .forEach(p -> {
                        MemoryEntry entry = parseMemoryFile(p, type);
                        if (entry != null) {
                            entries.add(entry);
                        }
                    });
            } catch (IOException e) {
                // 忽略
            }
        }
        
        return entries;
    }
    
    // 搜索记忆
    public List<MemoryEntry> searchMemories(String query) {
        return listMemories().stream()
            .filter(entry -> entry.matches(query))
            .toList();
    }
    
    private MemoryEntry parseMemoryFile(Path file, String type) {
        try {
            String content = Files.readString(file);
            
            // 解析 YAML frontmatter
            if (content.startsWith("---")) {
                int end = content.indexOf("---", 3);
                if (end > 0) {
                    String frontmatter = content.substring(3, end).trim();
                    String body = content.substring(end + 3).trim();
                    
                    // 简单解析（实际使用 SnakeYAML）
                    Map<String, String> metadata = parseFrontmatter(frontmatter);
                    
                    return new MemoryEntry(
                        file.getFileName().toString(),
                        metadata.getOrDefault("name", ""),
                        metadata.getOrDefault("description", ""),
                        type,
                        body,
                        file.toAbsolutePath()
                    );
                }
            }
            
            // 无 frontmatter，使用文件名
            return new MemoryEntry(
                file.getFileName().toString(),
                file.getFileName().toString().replace(".md", ""),
                "",
                type,
                content,
                file.toAbsolutePath()
            );
        } catch (IOException e) {
            return null;
        }
    }
    
    private Map<String, String> parseFrontmatter(String frontmatter) {
        Map<String, String> metadata = new HashMap<>();
        for (String line : frontmatter.split("\n")) {
            String[] parts = line.split(":", 2);
            if (parts.length == 2) {
                metadata.put(parts[0].trim(), parts[1].trim());
            }
        }
        return metadata;
    }
    
    public Path getMemoryFilePath() {
        return knowledgeDir.resolve("MEMORY.md");
    }
    
    public Path getMemoryDirPath() {
        return knowledgeDir;
    }
}

record MemoryEntry(
    String fileName,
    String name,
    String description,
    String type,
    String body,
    Path absolutePath
) {
    public boolean matches(String query) {
        String lowerQuery = query.toLowerCase();
        return name.toLowerCase().contains(lowerQuery)
            || description.toLowerCase().contains(lowerQuery)
            || body.toLowerCase().contains(lowerQuery);
    }
    
    public String toSummary() {
        return String.format("[%s] %s - %s", type, name, description);
    }
}
```

- 主要的记忆存储提供者
- 工作空间级别：`.core-ai/knowledge/` 和 `.core-ai/episodes/`
- 4 种类型：project、user、feedback、reference
- 支持 YAML frontmatter
- 搜索功能

### 8.2.2 LocalFileMemoryProvider

**位置**: `memory/LocalFileMemoryProvider.java`

```java
public class LocalFileMemoryProvider implements MemoryProvider {
    private final Path globalMemoryFile;
    private final Path projectMemoryFile;
    
    // 大小限制
    private static final int GLOBAL_MAX_SIZE = 5 * 1024;   // 5 KB
    private static final int PROJECT_MAX_SIZE = 10 * 1024; // 10 KB
    
    public LocalFileMemoryProvider(Path workspace) {
        this.globalMemoryFile = Path.of(System.getProperty("user.home"))
            .resolve(".core-ai/MEMORY.md");
        this.projectMemoryFile = workspace.resolve(".core-ai/MEMORY.md");
    }
    
    @Override
    public String load() {
        StringBuilder sb = new StringBuilder();
        
        // 1. 加载全局记忆
        if (Files.exists(globalMemoryFile)) {
            try {
                sb.append("--- Global Memory ---\n\n");
                sb.append(Files.readString(globalMemoryFile));
                sb.append("\n\n");
            } catch (IOException e) {
                // 忽略
            }
        }
        
        // 2. 加载项目记忆
        if (Files.exists(projectMemoryFile)) {
            try {
                sb.append("--- Project Memory ---\n\n");
                sb.append(Files.readString(projectMemoryFile));
            } catch (IOException e) {
                // 忽略
            }
        }
        
        return sb.toString();
    }
    
    @Override
    public void save(String content) {
        // 追加到项目记忆
        try {
            if (!Files.exists(projectMemoryFile.getParent())) {
                Files.createDirectories(projectMemoryFile.getParent());
            }
            
            String line = "- " + content + "\n";
            Files.write(
                projectMemoryFile,
                line.getBytes(StandardCharsets.UTF_8),
                StandardOpenOption.CREATE,
                StandardOpenOption.APPEND
            );
            
            // 检查大小
            enforceSizeLimit(projectMemoryFile, PROJECT_MAX_SIZE);
        } catch (IOException e) {
            // 忽略
        }
    }
    
    public void remove(String keyword) {
        try {
            if (Files.exists(projectMemoryFile)) {
                String content = Files.readString(projectMemoryFile);
                String updated = Arrays.stream(content.split("\n"))
                    .filter(line -> !line.contains(keyword))
                    .collect(Collectors.joining("\n"));
                Files.writeString(projectMemoryFile, updated);
            }
        } catch (IOException e) {
            // 忽略
        }
    }
    
    public void saveToScope(String scope, String content) {
        Path file = switch (scope) {
            case "global" -> globalMemoryFile;
            case "project" -> projectMemoryFile;
            default -> throw new IllegalArgumentException("Unknown scope: " + scope);
        };
        
        try {
            if (!Files.exists(file.getParent())) {
                Files.createDirectories(file.getParent());
            }
            
            String line = "- " + content + "\n";
            Files.write(
                file,
                line.getBytes(StandardCharsets.UTF_8),
                StandardOpenOption.CREATE,
                StandardOpenOption.APPEND
            );
            
            // 检查大小
            int maxSize = "global".equals(scope) ? GLOBAL_MAX_SIZE : PROJECT_MAX_SIZE;
            enforceSizeLimit(file, maxSize);
        } catch (IOException e) {
            // 忽略
        }
    }
    
    private void enforceSizeLimit(Path file, int maxSize) {
        try {
            long size = Files.size(file);
            if (size > maxSize) {
                // 截断旧内容
                String content = Files.readString(file);
                String[] lines = content.split("\n");
                
                // 保留最新的行
                List<String> kept = new ArrayList<>();
                int currentSize = 0;
                for (int i = lines.length - 1; i >= 0; i--) {
                    String line = lines[i];
                    if (currentSize + line.length() > maxSize) {
                        break;
                    }
                    kept.add(0, line);
                    currentSize += line.length();
                }
                
                Files.writeString(file, String.join("\n", kept));
            }
        } catch (IOException e) {
            // 忽略
        }
    }
}
```

- 遗留/全局记忆提供者
- 全局记忆：`~/.core-ai/MEMORY.md`（5 KB 限制）
- 项目记忆：`.core-ai/MEMORY.md`（10 KB 限制）
- 自动截断旧内容

### 8.3.1 类定义

**位置**: `memory/MemoryTriggerService.java`

```java
public class MemoryTriggerService {
    // 单例
    private static final MemoryTriggerService INSTANCE = new MemoryTriggerService();
    
    // 常量
    private static final int EXTRACTION_TURN_TRIGGER = 5;       // 5 轮触发
    private static final int EXTRACTION_IDLE_SECONDS = 180;     // 3 分钟空闲触发
    private static final int EXTRACTION_MAX_TURNS = 20;         // 最大 20 轮
    private static final int LOCK_PROCESSING_MAX_TURNS = 15;    // 锁处理最大 15 轮
    private static final int IDLE_CHECK_INTERVAL_SECONDS = 30;  // 30 秒检查间隔
    private static final float EXTRACTION_TEMPERATURE = 0.3f;   // 低温（确定性）
    
    private Agent mainAgent;
    private ScheduledExecutorService scheduler;
    private long lastActivityTime;
    private int turnCount;
    private CountDownLatch lockProcessingLatch;
    
    public static MemoryTriggerService getInstance() {
        return INSTANCE;
    }
    
    // 初始化
    public void init(Agent agent) {
        this.mainAgent = agent;
        this.lastActivityTime = System.currentTimeMillis();
        this.turnCount = 0;
        
        // 启动空闲检查调度器
        scheduler = Executors.newSingleThreadScheduledExecutor();
        scheduler.scheduleAtFixedRate(
            this::checkIdleTrigger,
            IDLE_CHECK_INTERVAL_SECONDS,
            IDLE_CHECK_INTERVAL_SECONDS,
            TimeUnit.SECONDS
        );
        
        // 异步处理锁文件
        CompletableFuture.runAsync(() -> {
            // 清理旧日志
            KnowledgeLogTool.pruneOldEntries();
            
            // 处理锁文件
            processLockFiles();
        });
        
        // 附加压缩监听器
        attachCompressionListener();
    }
    
    // Turn 完成时调用
    public void onTurnComplete() {
        turnCount++;
        lastActivityTime = System.currentTimeMillis();
        
        // 检查是否达到触发阈值
        if (turnCount >= EXTRACTION_TURN_TRIGGER) {
            runIncrementalExtraction();
            turnCount = 0;
        }
    }
    
    // 用户活动时调用
    public void onUserActivity() {
        lastActivityTime = System.currentTimeMillis();
    }
    
    // Agent 结束时调用
    public void onAgentEnd() {
        // 保存当前时间
        lastActivityTime = System.currentTimeMillis();
    }
    
    // 检查空闲触发
    private void checkIdleTrigger() {
        long idleSeconds = (System.currentTimeMillis() - lastActivityTime) / 1000;
        
        if (idleSeconds >= EXTRACTION_IDLE_SECONDS) {
            runIncrementalExtraction();
        }
    }
    
    // 运行增量提取（异步）
    private void runIncrementalExtraction() {
        CompletableFuture.runAsync(() -> {
            runIncrementalExtractionAndWait();
        });
    }
    
    // 运行增量提取（阻塞）
    public void runIncrementalExtractionAndWait() {
        if (mainAgent == null) return;
        
        // 获取提取规范
        String spec = MemoryExtractionTool.getCurrentSpec();
        
        // 构建提取 Prompt
        String prompt = ExtractionPrompt.format(
            mainAgent.getExecutionContext().getWorkspace(),
            getCursorInfo(),
            LocalDateTime.now(),
            EXTRACTION_MAX_TURNS,
            List.of("get_memory_extraction_spec", "save_memory", "read_memory")
        );
        
        // 运行提取 Agent
        runExtractionAgent(prompt, EXTRACTION_MAX_TURNS);
    }
    
    // 处理锁文件
    private void processLockFiles() {
        Path dailyLogsDir = mainAgent.getExecutionContext()
            .getWorkspace()
            .resolve(".core-ai/knowledge/daily-logs");
        
        if (!Files.isDirectory(dailyLogsDir)) return;
        
        try (var stream = Files.list(dailyLogsDir)) {
            List<Path> lockFiles = stream
                .filter(p -> p.toString().endsWith(".lock"))
                .toList();
            
            if (lockFiles.isEmpty()) return;
            
            lockProcessingLatch = new CountDownLatch(lockFiles.size());
            
            for (Path lockFile : lockFiles) {
                // 构建锁处理 Prompt
                String prompt = LockProcessingPrompt.format(
                    lockFile,
                    LOCK_PROCESSING_MAX_TURNS
                );
                
                // 运行锁处理 Agent
                runExtractionAgent(prompt, LOCK_PROCESSING_MAX_TURNS);
                
                // 重新加载记忆部分
                MemorySectionManager.reloadAgentMemorySection(
                    mainAgent,
                    memoryProvider
                );
                
                lockProcessingLatch.countDown();
            }
        } catch (IOException e) {
            // 忽略
        }
    }
    
    // 运行提取 Agent
    private void runExtractionAgent(String prompt, int maxTurns) {
        // Fork 主 Agent
        Agent forkedAgent = AgentFork.fork(mainAgent)
            .maxTurnNumber(maxTurns)
            .temperature(EXTRACTION_TEMPERATURE)
            .tools(List.of(
                new MemoryExtractionTool(),
                KnowledgeLogTool.addBuilder(),
                new ExtractionCursorTool()
            ))
            .build();
        
        // 注入提取 Prompt
        forkedAgent.continueWithInjectedMessage(prompt);
    }
    
    // 构建记忆工具
    public List<ToolCall> buildMemoryTools(Agent agent) {
        return List.of(
            new MemoryExtractionTool(),
            KnowledgeLogTool.addBuilder(),
            new ExtractionCursorTool()
        );
    }
    
    // 清空知识
    public void clearKnowledge() {
        Path workspace = mainAgent.getExecutionContext().getWorkspace();
        
        try {
            // 删除 knowledge 目录
            Path knowledgeDir = workspace.resolve(".core-ai/knowledge");
            deleteDirectory(knowledgeDir);
            
            // 删除 MEMORY.md
            Path memoryFile = workspace.resolve(".core-ai/MEMORY.md");
            Files.deleteIfExists(memoryFile);
            
            // 删除遗留 memory 目录
            Path legacyMemoryDir = workspace.resolve(".core-ai/memory");
            deleteDirectory(legacyMemoryDir);
            
            // 重新创建结构
            ensureDirectories();
        } catch (IOException e) {
            // 忽略
        }
    }
    
    // 设置日志模式
    public void setDailyLogsEnabled(boolean enabled) {
        MemoryExtractionTool.setDirectMode(!enabled);
    }
    
    private void deleteDirectory(Path dir) throws IOException {
        if (!Files.exists(dir)) return;
        
        try (var stream = Files.walk(dir)) {
            stream.sorted(Comparator.reverseOrder())
                .forEach(p -> {
                    try {
                        Files.delete(p);
                    } catch (IOException e) {
                        // 忽略
                    }
                });
        }
    }
    
    private void ensureDirectories() {
        Path workspace = mainAgent.getExecutionContext().getWorkspace();
        new MdMemoryProvider(workspace);  // 构造函数会创建目录
    }
    
    private String getCursorInfo() {
        // 获取提取游标信息
        return "cursor: " + mainAgent.getExecutionContext()
            .getCustomVariable("extraction_cursor");
    }
    
    private void attachCompressionListener() {
        mainAgent.getCompression().setListener(status -> {
            // 显示压缩状态
            ConsoleWriter.clearLineAndPrint(
                "Compressing conversation... " + status
            );
        });
    }
}
```

💡 **说明**：
- 单例模式
- 5 轮或 3 分钟空闲触发提取
- 使用 fork Agent 异步提取
- 处理锁文件（会话关闭时创建）
- 低温（0.3）保证确定性

### 8.3.2 触发条件

| 触发条件 | 阈值 | 说明 |
|---------|------|------|
| **Turn 计数** | 5 轮 | 每 5 轮对话触发一次 |
| **空闲时间** | 180 秒 | 3 分钟无活动触发 |
| **会话关闭** | - | 会话结束时提取 |

💡 **说明**：
- 双重触发机制
- 避免频繁提取
- 确保及时更新

### 8.4.2 ExtractionCursorTool

public class ExtractionCursorTool {
    
    // 内存游标

### 8.4.3 KnowledgeLogTool

```java
public class KnowledgeLogTool {
    
    public KnowledgeLogTool() {
        super("add_knowledge_log", "Add a knowledge log entry");
    }
    
    @Override
    public String execute(Map<String, Object> arguments, ToolContext context) {
        String entry = (String) arguments.get("entry");
        
        Path logFile = context.getWorkspace()
            .resolve(".core-ai/knowledge/log.md");
        
        try {
            // 追加到日志
            String line = String.format(
                "## %s\n\n%s\n\n",
                LocalDateTime.now().format(DateTimeFormatter.ISO_LOCAL_DATE_TIME),
                entry
            );
            
            Files.write(
                logFile,
                line.getBytes(StandardCharsets.UTF_8),
                StandardOpenOption.CREATE,
                StandardOpenOption.APPEND
            );
            
            return "Knowledge log added";
        } catch (IOException e) {
            return "Failed to add knowledge log: " + e.getMessage();
        }
    }
    
    // 清理旧日志（>30 天）
    public static void pruneOldEntries() {
        Path workspace = Path.of(System.getProperty("user.home"))
            .resolve(".core-ai");
        
        Path logFile = workspace.resolve("knowledge/log.md");
        if (!Files.exists(logFile)) return;
        
        try {
            String content = Files.readString(logFile);
            String[] sections = content.split("\n## ");
            
            LocalDateTime cutoff = LocalDateTime.now().minusDays(30);
            
            StringBuilder kept = new StringBuilder();
            for (String section : sections) {
                if (section.isEmpty()) continue;
                
                // 解析日期
                String dateStr = section.split("\n")[0];
                try {
                    LocalDateTime date = LocalDateTime.parse(dateStr);
                    if (date.isAfter(cutoff)) {
                        kept.append("## ").append(section);
                    }
                } catch (DateTimeParseException e) {
                    // 保留无法解析的
                    kept.append("## ").append(section);
                }
            }
            
            Files.writeString(logFile, kept.toString());
        } catch (IOException e) {
            // 忽略
        }
    }
}
```

💡 **说明**：
- 添加知识日志条目
- 自动清理 >30 天的旧日志
- 用于跟踪记忆提取历史

## 8.6 会话关闭提取

### 8.6.1 SessionCloseExtractor

**位置**: `memory/SessionCloseExtractor.java`

```java
public class SessionCloseExtractor {
    
    // 会话关闭时调用
    public static void onSessionClose(Agent agent, Session session) {
        // 跳过如果少于 2 轮
        if (session.getMessageCount() < 4) {  // 2 轮 = 4 条消息
            return;
        }
        
        // 等待待处理的锁文件
        MemoryTriggerService service = MemoryTriggerService.getInstance();
        service.awaitPendingLockProcessing();
        
        // 或运行增量提取
        service.runIncrementalExtractionAndWait();
        
        // 运行会话关闭提取 Agent
        runSessionCloseAgent(agent, session);
    }
    
    private static void runSessionCloseAgent(Agent agent, Session session) {
        // Fork 主 Agent
        Agent forkedAgent = AgentFork.fork(agent)
            .maxTurnNumber(7)  // 最多 7 轮
            .temperature(0.3f)
            .tools(List.of(
                new MemoryExtractionTool(),
                KnowledgeLogTool.addBuilder()
            ))
            .build();
        
        // 构建会话摘要
        String summary = buildSessionSummary(session);
        
        // 构建 Prompt
        String prompt = String.format("""
            The session is closing. Please extract important information 
            from this session and save them as memories.
            
            Session summary:
            %s
            
            Important:
            - Focus on user preferences and project context
            - Save to appropriate memory types (project/user/feedback/reference)
            - Be concise and actionable
            """, summary);
        
        // 运行提取
        forkedAgent.continueWithInjectedMessage(prompt);
        
        // 写入日志
        writeDailyLog(session);
        
        // 写入锁文件（下次启动时处理）
        writeLockFile(session);
    }
    
    private static String buildSessionSummary(Session session) {
        StringBuilder sb = new StringBuilder();
        
        List<Message> messages = session.getMessages();
        for (int i = 0; i < Math.min(messages.size(), 20); i++) {
            Message msg = messages.get(i);
            sb.append(msg.role()).append(": ").append(msg.content()).append("\n");
        }
        
        return sb.toString();
    }
    
    private static void writeDailyLog(Session session) {
        Path workspace = session.getWorkspace();
        Path dailyLogsDir = workspace.resolve(".core-ai/knowledge/daily-logs");
        
        try {
            Files.createDirectories(dailyLogsDir);
            
            String date = LocalDate.now().toString();
            Path logFile = dailyLogsDir.resolve(date + ".md");
            
            StringBuilder sb = new StringBuilder();
            sb.append("# Session Log - ").append(date).append("\n\n");
            sb.append("## Messages\n\n");
            
            for (Message msg : session.getMessages()) {
                sb.append("### ").append(msg.role()).append("\n\n");
                sb.append(msg.content()).append("\n\n");
            }
            
            Files.writeString(logFile, sb.toString());
        } catch (IOException e) {
            // 忽略
        }
    }
    
    private static void writeLockFile(Session session) {
        Path workspace = session.getWorkspace();
        Path dailyLogsDir = workspace.resolve(".core-ai/knowledge/daily-logs");
        
        try {
            Files.createDirectories(dailyLogsDir);
            
            String timestamp = LocalDateTime.now()
                .format(DateTimeFormatter.ofPattern("yyyyMMdd-HHmmss"));
            Path lockFile = dailyLogsDir.resolve(timestamp + ".lock");
            
            // 锁文件内容为日志文件路径
            Files.writeString(lockFile, timestamp + ".md");
        } catch (IOException e) {
            // 忽略
        }
    }
}
```

💡 **说明**：
- 会话关闭时提取记忆
- 写入日志文件（`.core-ai/knowledge/daily-logs/`）
- 写入锁文件（下次启动时处理）
- 使用 fork Agent 异步提取
