## 1.1 整体架构

### 1.1.1 分层架构

```
┌─────────────────────────────────────────┐
│         应用层 (Application Layer)      │
│  ┌─────────────────────────────────┐   │
│  │      Main / CliApp              │   │
│  │      (CLI 应用入口)              │   │
│  └─────────────────────────────────┘   │
└─────────────────────────────────────────┘
                  ↓
┌─────────────────────────────────────────┐
│         交互层 (Interaction Layer)      │
│  ┌──────────────┐  ┌────────────────┐  │
│  │ TerminalUI   │  │CommandDispatcher│  │
│  │(终端 UI)     │  │(命令分发)      │  │
│  └──────────────┘  └────────────────┘  │
└─────────────────────────────────────────┘
                  ↓
┌─────────────────────────────────────────┐
│         Agent 层 (Agent Layer)          │
│  ┌──────────────┐  ┌────────────────┐  │
│  │AgentSession  │  │  CliAgent      │  │
│  │  Runner      │  │  (CLI Agent)   │  │
│  │(会话运行器)  │  │                │  │
│  └──────────────┘  └────────────────┘  │
└─────────────────────────────────────────┘
                  ↓
┌─────────────────────────────────────────┐
│         功能层 (Feature Layer)          │
│  ┌────────┐ ┌──────┐ ┌──────┐ ┌─────┐ │
│  │ Memory │ │ Auth │ │Remote│ │Plugin│ │
│  │(记忆)  │ │(认证)│ │(远程)│ │(插件)│ │
│  └────────┘ └──────┘ └──────┘ └─────┘ │
└─────────────────────────────────────────┘
                  ↓
┌─────────────────────────────────────────┐
│         基础层 (Core Layer)             │
│  ┌─────────────────────────────────┐   │
│  │      core-ai / core-ai-api      │   │
│  │      (核心框架)                  │   │
│  └─────────────────────────────────┘   │
└─────────────────────────────────────────┘
```

💡 **设计意图**：清晰的分层架构，每层职责明确，便于维护和扩展。

### 1.1.2 架构特点

| 特点 | 说明 |
|------|------|
| **分层清晰** | 应用层、交互层、Agent 层、功能层、基础层 |
| **模块化** | 每个功能模块独立，可插拔 |
| **事件驱动** | 通过事件监听器实现模块间通信 |
| **可扩展** | 通过插件系统支持功能扩展 |
| **配置化** | 通过配置文件控制行为 |

### 1.2.2 核心组件说明

#### Main - 主入口

**位置**: `Main.java`

**职责**: 
- 解析命令行参数（使用 picocli）
- 初始化日志系统
- 启动 CliApp
- 处理升级命令

**核心方法**:
```java
public static void main(String[] args) {
    initSlf4j();
    System.exit(new CommandLine(new Main()).execute(args));
}
```

💡 **说明**：使用 picocli 库解析命令行参数，支持丰富的命令行选项。

#### CliApp - 应用主类

**位置**: `ai/core/cli/CliApp.java`

**职责**:
- 初始化核心组件
- 配置 Agent
- 启动不同的运行模式（本地/远程/服务）
- 管理生命周期

**核心方法**:
```java
public void start() {
    // 1. 引导核心组件
    var core = bootstrapCore();
    
    // 2. 初始化终端 UI
    var terminalUI = new TerminalUI();
    
    // 3. 创建 Agent
    var agent = createAgent(core);
    
    // 4. 启动会话
    var runner = new AgentSessionRunner(terminalUI, agent);
    runner.run();
}
```

#### TerminalUI - 终端 UI

**位置**: `ui/TerminalUI.java`

**职责**:
- 管理终端交互
- 渲染 Markdown
- 代码高亮
- 显示思考动画
- 处理用户输入

**核心功能**:
- 使用 JLine 3 实现交互式终端
- 使用 flexmark 渲染 Markdown
- 支持 ANSI 转义序列实现代码高亮
- 支持流式输出

💡 **说明**：TerminalUI 是用户与 CLI 交互的核心组件，提供丰富的终端体验。

#### AgentSessionRunner - 会话运行器

**位置**: `agent/AgentSessionRunner.java`

**职责**:
- 管理 Agent 会话
- 处理用户输入
- 调用 Agent
- 显示输出
- 处理命令

**核心方法**:
```java
public void run() {
    while (true) {
        // 1. 读取用户输入
        var input = terminalUI.readInput();
        
        // 2. 检查是否为命令
        if (input.startsWith("/")) {
            commandDispatcher.dispatch(input);
        } else {
            // 3. 调用 Agent
            var response = agent.process(input);
            
            // 4. 显示输出
            terminalUI.display(response);
        }
    }
}
```

#### CommandDispatcher - 命令分发器

**位置**: `agent/CommandDispatcher.java`

**职责**:
- 注册斜杠命令
- 解析命令
- 分发命令到处理器

**核心方法**:
```java
public void dispatch(String input) {
    var parts = input.split(" ");
    var command = parts[0];
    var args = Arrays.copyOfRange(parts, 1, parts.length);
    
    var handler = registry.getHandler(command);
    if (handler != null) {
        handler.handle(args);
    } else {
        terminalUI.error("Unknown command: " + command);
    }
}
```

#### SlashCommandRegistry - 命令注册表

**位置**: `command/SlashCommandRegistry.java`

**职责**:
- 注册所有斜杠命令
- 提供命令查找
- 支持命令自动补全

**内置命令**:
- `/help` - 显示帮助
- `/clear` - 清屏
- `/session` - 会话管理
- `/model` - 切换模型
- `/memory` - 记忆管理
- `/plugin` - 插件管理
- `/exit` - 退出

💡 **说明**：命令系统采用注册表模式，易于扩展新命令。

### 1.2.3 功能层组件

#### AuthManager - 认证管理

**位置**: `auth/AuthManager.java`

**职责**:
- 管理用户认证
- 支持 OAuth 认证
- 管理 API Key
- 自动刷新 Token

**认证流程**:
```
1. 检查本地是否有有效 Token
2. 如果没有，启动 OAuth 流程
3. 打开浏览器进行认证
4. 本地服务器接收回调
5. 保存 Token 到本地
6. 自动刷新 Token
```

#### MemorySystem - 记忆系统

**位置**: `memory/` 包

**职责**:
- 提取对话记忆
- 存储到本地文件
- 在对话中注入相关记忆
- 支持记忆搜索

**核心组件**:
- `MemoryExtractionTool` - 使用 LLM 提取记忆
- `LocalFileMemoryProvider` - 本地文件存储
- `MemoryTriggerService` - 触发记忆提取

💡 **说明**：记忆系统让 Agent 能够记住用户的偏好和历史对话。

#### PluginManager - 插件管理

**位置**: `plugin/PluginManager.java`

**职责**:
- 发现可用插件
- 安装插件
- 卸载插件
- 管理插件状态

**插件类型**:
- 命令插件 - 添加新的斜杠命令
- 工具插件 - 添加新的工具
- 技能插件 - 添加新的技能

💡 **说明**：插件系统让 CLI 可以通过插件扩展功能。

#### UpgradeChecker - 升级检查

**位置**: `upgrade/UpgradeChecker.java`

**职责**:
- 检查新版本
- 下载新版本
- 自动升级

**升级流程**:
```
1. 检查 GitHub Release API
2. 比较版本号
3. 如果有新版本，提示用户
4. 下载新版本二进制文件
5. 替换当前二进制文件
6. 提示用户重启
```

## 1.3 数据流

### 1.3.1 用户交互流程

```
用户输入
    ↓
TerminalUI.readInput()
    ↓
检查是否为命令
    ├─ 是 → CommandDispatcher.dispatch()
    │        ↓
    │     SlashCommandRegistry.getHandler()
    │        ↓
    │     CommandHandler.handle()
    │        ↓
    │     TerminalUI.display()
    │
    └─ 否 → AgentSessionRunner.process()
             ↓
          CliAgent.process()
             ↓
          LLM API 调用
             ↓
          流式响应
             ↓
          TerminalUI.display()
```

### 1.3.2 Agent 调用流程

```
AgentSessionRunner.run()
    ↓
读取用户输入
    ↓
构建消息列表
    ↓
调用 LLM API（流式）
    ├─ 接收流式响应
    ├─ 实时渲染 Markdown
    ├─ 检测工具调用
    └─ 执行工具（如果需要）
    ↓
显示完整响应
    ↓
检查是否需要提取记忆
    ├─ 是 → MemoryExtractionTool.extract()
    │        ↓
    │     保存到本地文件
    │
    └─ 否 → 继续
    ↓
等待下一次输入
```

### 1.3.3 插件加载流程

```
CliApp.start()
    ↓
PluginManager.discover()
    ↓
扫描插件目录
    ↓
加载插件配置
    ↓
验证插件
    ↓
注册插件命令/工具/技能
    ↓
插件就绪
```

## 1.4 设计模式

### 1.4.1 命令模式 (Command Pattern)

**应用**: 斜杠命令系统

```java
// 命令接口
public interface CommandHandler {
    void handle(String[] args);
}

// 具体命令
public class HelpCommandHandler implements CommandHandler {
    @Override
    public void handle(String[] args) {
        terminalUI.display("Available commands: ...");
    }
}

// 命令分发器
public class CommandDispatcher {
    private final Map<String, CommandHandler> handlers = new HashMap<>();
    
    public void register(String command, CommandHandler handler) {
        handlers.put(command, handler);
    }
    
    public void dispatch(String input) {
        var handler = handlers.get(command);
        handler.handle(args);
    }
}
```

💡 **优势**：命令的添加和分发解耦，易于扩展新命令。

### 1.4.2 观察者模式 (Observer Pattern)

**应用**: 事件监听系统

```java
// 事件监听器接口
public interface EventListener {
    void onEvent(AgentEvent event);
}

// 事件发布者
public class AgentSessionRunner {
    private final List<EventListener> listeners = new ArrayList<>();
    
    public void addListener(EventListener listener) {
        listeners.add(listener);
    }
    
    private void fireEvent(AgentEvent event) {
        for (var listener : listeners) {
            listener.onEvent(event);
        }
    }
}

// 具体监听器
public class CliEventListener implements EventListener {
    @Override
    public void onEvent(AgentEvent event) {
        if (event instanceof AgentResponseEvent) {
            terminalUI.display(event.getResponse());
        }
    }
}
```

💡 **优势**：模块间松耦合，支持多个监听器。

### 1.4.3 策略模式 (Strategy Pattern)

**应用**: 认证策略

```java
// 认证策略接口
public interface AuthStrategy {
    AuthResult authenticate();
}

// OAuth 策略
public class OAuthAuthStrategy implements AuthStrategy {
    @Override
    public AuthResult authenticate() {
        // OAuth 认证流程
    }
}

// API Key 策略
public class ApiKeyAuthStrategy implements AuthStrategy {
    @Override
    public AuthResult authenticate() {
        // API Key 认证流程
    }
}

// 认证管理器
public class AuthManager {
    private AuthStrategy strategy;
    
    public void setStrategy(AuthStrategy strategy) {
        this.strategy = strategy;
    }
    
    public AuthResult authenticate() {
        return strategy.authenticate();
    }
}
```

💡 **优势**：支持多种认证方式，易于切换和扩展。

### 1.4.4 工厂模式 (Factory Pattern)

**应用**: Agent 创建

```java
// Agent 工厂
public class CliAgentFactory {
    public static CliAgent create(CliAppOptions options, BootstrapResult core) {
        var agent = new CliAgent();
        agent.setModel(options.modelOverride());
        agent.setWorkspace(options.workspace());
        agent.setMemoryProvider(core.memoryProvider);
        // ... 配置其他属性
        return agent;
    }
}
```

💡 **优势**：集中管理 Agent 创建逻辑，便于维护和测试。
