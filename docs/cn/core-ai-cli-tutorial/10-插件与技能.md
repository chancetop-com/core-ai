## 10.1 插件系统概述

### 10.1.1 插件系统的角色

插件系统负责扩展 CLI 的功能，包括：

- 插件发现（本地、全局、JAR 内置）
- 插件安装（本地、Git、npm）
- 插件管理（启用/禁用）
- 插件验证
- 技能 provision

💡 **设计意图**：提供可扩展的插件架构，允许第三方扩展 CLI 功能。

### 10.1.2 核心组件

| 组件 | 位置 | 职责 |
|------|------|------|
| `PluginManager` | `plugin/` | 插件管理器（单例） |
| `PluginDiscovery` | `command/plugins/` | 插件发现 |
| `PluginInstaller` | `command/plugins/` | 插件安装 |
| `PluginStateManager` | `command/plugins/` | 插件状态管理 |
| `PluginValidator` | `command/plugins/` | 插件验证 |
| `PluginCommandHandler` | `command/plugins/` | 插件命令处理 |
| `ManagedSkillProvisioner` | `skill/` | 技能 provision |

### 10.1.3 插件结构

```
my-plugin/
├── .claude-plugin/
│   └── plugin.json          # 插件清单
├── skills/                   # 技能目录
│   └── my-skill/
│       └── SKILL.md
├── commands/                 # 命令目录
│   └── my-command.md
├── hooks/                    # 钩子目录
│   └── pre-commit.sh
├── agents/                   # Agent 配置目录
│   └── my-agent.md
├── .mcp.json                # MCP 服务器配置
└── .lsp.json                # LSP 服务器配置
```

💡 **说明**：
- 插件清单必需
- 支持 6 种组件：skills、commands、hooks、agents、mcp、lsp
- 每个组件可选

## 10.2 PluginManager 核心类

### 10.2.1 类定义

**位置**: `plugin/PluginManager.java`

```java
public class PluginManager {
    // 单例
    private static volatile PluginManager instance;
    
    private final Path configDir;
    private final Path globalPluginsDir;
    private final Path localPluginsDir;
    private List<Plugin> plugins;
    
    // 组件目录常量
    private static final String SKILLS_DIR = "skills";
    private static final String COMMANDS_DIR = "commands";
    private static final String HOOKS_DIR = "hooks";
    private static final String AGENTS_DIR = "agents";
    private static final String MCP_CONFIG = ".mcp.json";
    private static final String LSP_CONFIG = ".lsp.json";
    
    private PluginManager(Path configDir) {
        this.configDir = configDir;
        this.globalPluginsDir = configDir.resolve("plugins");
        this.localPluginsDir = Path.of(".core-ai/plugins");
        this.plugins = List.of();
    }
    
    public static PluginManager getInstance(Path configDir) {
        if (instance == null) {
            synchronized (PluginManager.class) {
                if (instance == null) {
                    instance = new PluginManager(configDir);
                }
            }
        }
        return instance;
    }
    
    // 初始化（提取内置插件 + 加载所有插件）
    public void initializeIfNeeded(Path jarPath) {
        // 1. 提取内置插件
        extractBundledPlugins(jarPath);
        
        // 2. 加载所有插件
        loadAllPlugins();
    }
    
    // 提取内置插件
    private void extractBundledPlugins(Path jarPath) {
        if (jarPath == null || !Files.exists(jarPath)) return;
        
        try (JarFile jar = new JarFile(jarPath.toFile())) {
            var entries = jar.entries();
            
            while (entries.hasMoreElements()) {
                JarEntry entry = entries.nextElement();
                String name = entry.getName();
                
                // 查找 plugins/ 目录下的文件
                if (name.startsWith("plugins/") && !entry.isDirectory()) {
                    // 解析路径：plugins/<plugin-name>/<file>
                    String relativePath = name.substring("plugins/".length());
                    Path targetPath = globalPluginsDir.resolve(relativePath);
                    
                    // 检查版本
                    if (shouldExtract(entry, targetPath)) {
                        Files.createDirectories(targetPath.getParent());
                        try (InputStream is = jar.getInputStream(entry)) {
                            Files.copy(is, targetPath, StandardCopyOption.REPLACE_EXISTING);
                        }
                    }
                }
            }
        } catch (IOException e) {
            // 忽略
        }
    }
    
    // 检查是否应该提取
    private boolean shouldExtract(JarEntry entry, Path targetPath) {
        if (!Files.exists(targetPath)) {
            return true;  // 目标不存在
        }
        
        // 比较版本
        try {
            // 从 JAR 读取清单
            String pluginName = extractPluginName(entry.getName());
            String jarVersion = readVersionFromJar(entry, pluginName);
            
            // 从目标读取清单
            String localVersion = readVersionFromLocal(targetPath, pluginName);
            
            // 比较版本
            return VersionComparator.compare(jarVersion, localVersion) > 0;
        } catch (Exception e) {
            return true;  // 出错则提取
        }
    }
    
    // 加载所有插件
    public void loadAllPlugins() {
        List<Plugin> loaded = new ArrayList<>();
        
        // 1. 加载本地插件（优先级高）
        loaded.addAll(discoverPlugins(localPluginsDir));
        
        // 2. 加载全局插件
        loaded.addAll(discoverPlugins(globalPluginsDir));
        
        // 3. 去重（按名称）
        Map<String, Plugin> deduped = new LinkedHashMap<>();
        for (Plugin plugin : loaded) {
            deduped.putIfAbsent(plugin.manifest().name(), plugin);
        }
        
        this.plugins = new ArrayList<>(deduped.values());
    }
    
    // 发现插件
    private List<Plugin> discoverPlugins(Path dir) {
        List<Plugin> plugins = new ArrayList<>();
        
        if (!Files.isDirectory(dir)) return plugins;
        
        try (var stream = Files.list(dir)) {
            stream.filter(Files::isDirectory)
                .forEach(pluginDir -> {
                    Plugin plugin = loadPlugin(pluginDir);
                    if (plugin != null) {
                        plugins.add(plugin);
                    }
                });
        } catch (IOException e) {
            // 忽略
        }
        
        return plugins;
    }
    
    // 加载单个插件
    private Plugin loadPlugin(Path pluginDir) {
        // 查找清单文件
        Path manifestFile = pluginDir.resolve(".claude-plugin/plugin.json");
        if (!Files.exists(manifestFile)) {
            manifestFile = pluginDir.resolve("plugin.json");
        }
        
        if (!Files.exists(manifestFile)) {
            return null;  // 无清单
        }
        
        try {
            // 读取清单
            String json = Files.readString(manifestFile);
            PluginManifest manifest = parseManifest(json);
            
            // 检测组件
            Set<PluginComponent> components = detectComponents(pluginDir);
            
            return new Plugin(pluginDir, manifest, components);
        } catch (IOException e) {
            return null;
        }
    }
    
    private PluginManifest parseManifest(String json) {
        JsonObject obj = Json.parse(json);
        return new PluginManifest(
            obj.getString("name"),
            obj.getString("version", "1.0.0"),
            obj.getString("description", ""),
            obj.getString("author", ""),
            obj.getString("license", "")
        );
    }
    
    private Set<PluginComponent> detectComponents(Path pluginDir) {
        Set<PluginComponent> components = EnumSet.noneOf(PluginComponent.class);
        
        if (Files.isDirectory(pluginDir.resolve(SKILLS_DIR))) {
            components.add(PluginComponent.SKILLS);
        }
        if (Files.isDirectory(pluginDir.resolve(COMMANDS_DIR))) {
            components.add(PluginComponent.COMMANDS);
        }
        if (Files.isDirectory(pluginDir.resolve(HOOKS_DIR))) {
            components.add(PluginComponent.HOOKS);
        }
        if (Files.isDirectory(pluginDir.resolve(AGENTS_DIR))) {
            components.add(PluginComponent.AGENTS);
        }
        if (Files.exists(pluginDir.resolve(MCP_CONFIG))) {
            components.add(PluginComponent.MCP);
        }
        if (Files.exists(pluginDir.resolve(LSP_CONFIG))) {
            components.add(PluginComponent.LSP);
        }
        
        return components;
    }
    
    // 获取启用的插件技能源
    public List<PluginSkillSource> getEnabledPluginSkillSources() {
        return plugins.stream()
            .filter(p -> !isDisabled(p.manifest().name()))
            .filter(p -> p.components().contains(PluginComponent.SKILLS))
            .map(p -> new PluginSkillSource(
                p.manifest().name(),
                p.dir().resolve(SKILLS_DIR)
            ))
            .toList();
    }
    
    // 检查插件是否禁用
    public boolean isDisabled(String name) {
        Path propsFile = configDir.resolve("agent.properties");
        
        if (!Files.exists(propsFile)) return false;
        
        try {
            Properties props = new Properties();
            props.load(Files.newBufferedReader(propsFile));
            
            String disabled = props.getProperty("plugin.disabled", "");
            Set<String> disabledSet = Set.of(disabled.split(","));
            
            return disabledSet.contains(name);
        } catch (IOException e) {
            return false;
        }
    }
}

record Plugin(
    Path dir,
    PluginManifest manifest,
    Set<PluginComponent> components
) {}

record PluginManifest(
    String name,
    String version,
    String description,
    String author,
    String license
) {}

enum PluginComponent {
    SKILLS, COMMANDS, HOOKS, AGENTS, MCP, LSP
}

record PluginSkillSource(
    String pluginName,
    Path skillsDir
) {}
```

💡 **说明**：
- 单例模式
- 支持本地和全局插件
- 自动提取内置插件
- 版本比较（避免降级）
- 6 种组件类型

### 10.2.2 VersionComparator

```java
public class VersionComparator {
    
    // 比较版本号
    public static int compare(String v1, String v2) {
        // 分割主版本和预发布版本
        String[] parts1 = v1.split("-", 2);
        String[] parts2 = v2.split("-", 2);
        
        // 比较主版本
        int mainCompare = compareMain(parts1[0], parts2[0]);
        if (mainCompare != 0) return mainCompare;
        
        // 比较预发布版本
        String pre1 = parts1.length > 1 ? parts1[1] : null;
        String pre2 = parts2.length > 1 ? parts2[1] : null;
        
        return comparePreRelease(pre1, pre2);
    }
    
    private static int compareMain(String v1, String v2) {
        String[] segments1 = v1.split("\\.");
        String[] segments2 = v2.split("\\.");
        
        int length = Math.max(segments1.length, segments2.length);
        
        for (int i = 0; i < length; i++) {
            int s1 = i < segments1.length ? parseSegment(segments1[i]) : 0;
            int s2 = i < segments2.length ? parseSegment(segments2[i]) : 0;
            
            if (s1 != s2) {
                return Integer.compare(s1, s2);
            }
        }
        
        return 0;
    }
    
    private static int parseSegment(String segment) {
        try {
            return Integer.parseInt(segment);
        } catch (NumberFormatException e) {
            return 0;
        }
    }
    
    private static int comparePreRelease(String pre1, String pre2) {
        // 无预发布 > 有预发布
        if (pre1 == null && pre2 == null) return 0;
        if (pre1 == null) return 1;   // v1 是正式版
        if (pre2 == null) return -1;  // v2 是正式版
        
        // 比较预发布标识符
        String[] ids1 = pre1.split("\\.");
        String[] ids2 = pre2.split("\\.");
        
        int length = Math.max(ids1.length, ids2.length);
        
        for (int i = 0; i < length; i++) {
            if (i >= ids1.length) return -1;  // v1 短
            if (i >= ids2.length) return 1;   // v2 短
            
            String id1 = ids1[i];
            String id2 = ids2[i];
            
            // 尝试作为数字比较
            try {
                int num1 = Integer.parseInt(id1);
                int num2 = Integer.parseInt(id2);
                if (num1 != num2) {
                    return Integer.compare(num1, num2);
                }
            } catch (NumberFormatException e) {
                // 作为字符串比较
                int cmp = id1.compareTo(id2);
                if (cmp != 0) return cmp;
            }
        }
        
        return 0;
    }
}
```

💡 **说明**：
- 语义化版本比较
- 支持预发布版本（`-alpha`、`-beta`）
- 数字和字符串标识符

```java
public class PluginDiscovery {
    
    // 扫描插件目录
    public static List<PluginEntry> scan(Path pluginDir) {
        List<PluginEntry> entries = new ArrayList<>();
        
        if (!Files.isDirectory(pluginDir)) return entries;
        
        try (var stream = Files.list(pluginDir)) {
            stream.filter(Files::isDirectory)
                .forEach(dir -> {
                    PluginEntry entry = loadEntry(dir);
                    if (entry != null) {
                        entries.add(entry);
                    }
                });
        } catch (IOException e) {
            // 忽略
        }
        
        return entries;
    }
    
    private static PluginEntry loadEntry(Path dir) {
        // 查找清单
        Path manifestFile = dir.resolve(".claude-plugin/plugin.json");
        if (!Files.exists(manifestFile)) {
            manifestFile = dir.resolve("plugin.json");
        }
        
        if (!Files.exists(manifestFile)) {
            return null;
        }
        
        try {
            String json = Files.readString(manifestFile);
            JsonObject obj = Json.parse(json);
            
            return new PluginEntry(
                obj.getString("name"),
                dir.toString(),
                obj.getString("version", "1.0.0"),
                obj.getString("description", "")
            );
        } catch (IOException e) {
            return null;
        }
    }
}

record PluginEntry(
    String name,
    String path,
    String version,
    String description
) {}
```

💡 **说明**：
- 扫描插件目录
- 加载清单信息

### 10.4.1 PluginInstaller

**位置**: `command/plugins/PluginInstaller.java`

```java
public class PluginInstaller {
    
    // 安装插件
    public static void install(String args, String scope) {
        // 解析参数
        InstallSource source = parseInstallSource(args);
        
        Path targetDir = getTargetDir(scope);
        
        try {
            switch (source.type()) {
                case LOCAL -> installFromLocal(source.path(), targetDir);
                case GIT -> installFromGit(source.url(), targetDir);
                case NPM -> installFromNpm(source.packageName(), targetDir);
            }
            
            System.out.println("Plugin installed: " + source.name());
        } catch (Exception e) {
            System.err.println("Failed to install: " + e.getMessage());
        }
    }
    
    private static InstallSource parseInstallSource(String args) {
        if (args.startsWith("git:") || args.startsWith("github:") || args.startsWith("https:")) {
            // Git 安装
            String url = args.substring(args.indexOf(":") + 1);
            if (args.startsWith("github:")) {
                url = "https://github.com/" + url;
            }
            return new InstallSource(InstallType.GIT, url, extractName(url));
        } else if (args.startsWith("npm:")) {
            // npm 安装
            String packageName = args.substring(4);
            return new InstallSource(InstallType.NPM, packageName, packageName);
        } else {
            // 本地安装
            return new InstallSource(InstallType.LOCAL, args, Path.of(args).getFileName().toString());
        }
    }
    
    private static void installFromLocal(String sourcePath, Path targetDir) {
        Path source = Path.of(sourcePath);
        Path target = targetDir.resolve(source.getFileName());
        
        try {
            copyDirectory(source, target);
        } catch (IOException e) {
            throw new RuntimeException("Failed to copy: " + e.getMessage());
        }
    }
    
    private static void installFromGit(String url, Path targetDir) {
        // 浅克隆
        String name = extractName(url);
        Path target = targetDir.resolve(name);
        
        try {
            new ProcessBuilder("git", "clone", "--depth", "1", url, target.toString())
                .inheritIO()
                .start()
                .waitFor();
        } catch (Exception e) {
            throw new RuntimeException("Git clone failed: " + e.getMessage());
        }
    }
    
    private static void installFromNpm(String packageName, Path targetDir) {
        // 使用 npm install
        Path tempDir = Files.createTempDirectory("npm-plugin-");
        
        try {
            // npm install
            new ProcessBuilder("npm", "install", packageName)
                .directory(tempDir.toFile())
                .inheritIO()
                .start()
                .waitFor();
            
            // 复制到目标
            Path source = tempDir.resolve("node_modules").resolve(packageName);
            Path target = targetDir.resolve(packageName);
            copyDirectory(source, target);
            
        } catch (Exception e) {
            throw new RuntimeException("npm install failed: " + e.getMessage());
        } finally {
            // 清理临时目录
            deleteDirectory(tempDir);
        }
    }
    
    // 卸载插件
    public static void uninstall(String name, String scope) {
        Path targetDir = getTargetDir(scope);
        Path pluginDir = targetDir.resolve(name);
        
        if (!Files.exists(pluginDir)) {
            System.err.println("Plugin not found: " + name);
            return;
        }
        
        try {
            deleteDirectory(pluginDir);
            System.out.println("Plugin uninstalled: " + name);
        } catch (IOException e) {
            System.err.println("Failed to uninstall: " + e.getMessage());
        }
    }
    
    private static Path getTargetDir(String scope) {
        if ("local".equals(scope)) {
            return Path.of(".core-ai/plugins");
        } else {
            return Path.of(System.getProperty("user.home"))
                .resolve(".core-ai/plugins");
        }
    }
    
    private static String extractName(String url) {
        // 从 URL 提取名称
        String name = url.replaceAll(".git$", "");
        int lastSlash = name.lastIndexOf("/");
        if (lastSlash >= 0) {
            name = name.substring(lastSlash + 1);
        }
        return name;
    }
}

record InstallSource(InstallType type, String path, String name) {}

enum InstallType {
    LOCAL, GIT, NPM
}
```

💡 **说明**：
- 支持 3 种安装方式：本地、Git、npm
- 支持 local 和 global 两种作用域
- 自动提取插件名称

### 10.4.2 PluginStateManager

```java
public class PluginStateManager {
    
    // 启用插件
    public static void enable(String name, Path configDir) {
        updateDisabledList(name, configDir, false);
    }
    
    // 禁用插件
    public static void disable(String name, Path configDir) {
        updateDisabledList(name, configDir, true);
    }
    
    private static void updateDisabledList(
        String name, 
        Path configDir, 
        boolean disable
    ) {
        Path propsFile = configDir.resolve("agent.properties");
        
        try {
            Properties props = new Properties();
            if (Files.exists(propsFile)) {
                props.load(Files.newBufferedReader(propsFile));
            }
            
            String disabled = props.getProperty("plugin.disabled", "");
            Set<String> disabledSet = new HashSet<>(Arrays.asList(disabled.split(",")));
            disabledSet.remove("");  // 移除空字符串
            
            if (disable) {
                disabledSet.add(name);
            } else {
                disabledSet.remove(name);
            }
            
            String newDisabled = String.join(",", disabledSet);
            props.setProperty("plugin.disabled", newDisabled);
            
            props.store(Files.newBufferedWriter(propsFile), null);
            
        } catch (IOException e) {
            System.err.println("Failed to update plugin state: " + e.getMessage());
        }
    }
    
    // 交互式选择器
    public static void showPicker(TerminalUI ui, Path configDir) {
        List<PluginEntry> plugins = PluginDiscovery.scan(
            configDir.resolve("plugins")
        );
        
        if (plugins.isEmpty()) {
            ui.println("No plugins installed");
            return;
        }
        
        List<String> options = new ArrayList<>();
        for (PluginEntry plugin : plugins) {
            boolean isDisabled = isDisabled(plugin.name(), configDir);
            String status = isDisabled ? "[disabled]" : "[enabled]";
            options.add(String.format("%s %s - %s", status, plugin.name(), plugin.description()));
        }
        
        int selected = ui.pickIndex(options);
        
        if (selected >= 0) {
            PluginEntry plugin = plugins.get(selected);
            boolean isDisabled = isDisabled(plugin.name(), configDir);
            
            if (isDisabled) {
                enable(plugin.name(), configDir);
                ui.println("Enabled: " + plugin.name());
            } else {
                disable(plugin.name(), configDir);
                ui.println("Disabled: " + plugin.name());
            }
        }
    }
    
    private static boolean isDisabled(String name, Path configDir) {
        Path propsFile = configDir.resolve("agent.properties");
        
        if (!Files.exists(propsFile)) return false;
        
        try {
            Properties props = new Properties();
            props.load(Files.newBufferedReader(propsFile));
            
            String disabled = props.getProperty("plugin.disabled", "");
            Set<String> disabledSet = Set.of(disabled.split(","));
            
            return disabledSet.contains(name);
        } catch (IOException e) {
            return false;
        }
    }
}
```

- 启用/禁用插件
- 持久化到 `agent.properties`

### 10.4.3 PluginValidator

```java
public class PluginValidator {
    
    // 验证插件
    public static ValidationResult validate(Path pluginDir) {
        List<String> errors = new ArrayList<>();
        List<String> warnings = new ArrayList<>();
        
        // 1. 检查清单
        Path manifestFile = pluginDir.resolve(".claude-plugin/plugin.json");
        if (!Files.exists(manifestFile)) {
            manifestFile = pluginDir.resolve("plugin.json");
        }
        
        if (!Files.exists(manifestFile)) {
            errors.add("Missing plugin.json manifest");
            return new ValidationResult(false, errors, warnings);
        }
        
        try {
            String json = Files.readString(manifestFile);
            JsonObject obj = Json.parse(json);
            
            // 检查必需字段
            if (!obj.containsKey("name")) {
                errors.add("Missing 'name' field in manifest");
            }
            
        } catch (IOException e) {
            errors.add("Failed to read manifest: " + e.getMessage());
        }
        
        // 2. 检查组件目录
        checkComponentDir(pluginDir, "skills", errors, warnings);
        checkComponentDir(pluginDir, "commands", errors, warnings);
        checkComponentDir(pluginDir, "hooks", errors, warnings);
        checkComponentDir(pluginDir, "agents", errors, warnings);
        
        // 3. 检查 MCP/LSP 配置
        checkJsonConfig(pluginDir, ".mcp.json", errors, warnings);
        checkJsonConfig(pluginDir, ".lsp.json", errors, warnings);
        
        return new ValidationResult(errors.isEmpty(), errors, warnings);
    }
    
    private static void checkComponentDir(
        Path pluginDir, 
        String dirName, 
        List<String> errors, 
        List<String> warnings
    ) {
        Path dir = pluginDir.resolve(dirName);
        if (!Files.isDirectory(dir)) return;
        
        try (var stream = Files.list(dir)) {
            long count = stream.count();
            if (count == 0) {
                warnings.add("Empty " + dirName + " directory");
            }
        } catch (IOException e) {
            warnings.add("Failed to check " + dirName + " directory");
        }
    }
    
    private static void checkJsonConfig(
        Path pluginDir, 
        String fileName, 
        List<String> errors, 
        List<String> warnings
    ) {
        Path file = pluginDir.resolve(fileName);
        if (!Files.exists(file)) return;
        
        try {
            String json = Files.readString(file);
            Json.parse(json);  // 验证 JSON 格式
        } catch (IOException e) {
            errors.add("Failed to read " + fileName);
        } catch (Exception e) {
            errors.add("Invalid JSON in " + fileName);
        }
    }
}

record ValidationResult(boolean valid, List<String> errors, List<String> warnings) {
    public void print(TerminalUI ui) {
        if (valid) {
            ui.println("✓ Plugin is valid");
        } else {
            ui.println("✗ Plugin is invalid");
        }
        
        if (!errors.isEmpty()) {
            ui.println("\nErrors:");
            for (String error : errors) {
                ui.println("  - " + error);
            }
        }
        
        if (!warnings.isEmpty()) {
            ui.println("\nWarnings:");
            for (String warning : warnings) {
                ui.println("  - " + warning);
            }
        }
    }
}
```

```java
public class PluginCommandHandler {
    private final TerminalUI ui;
    private final Path configDir;
    
    public PluginCommandHandler(TerminalUI ui, Path configDir) {
        this.ui = ui;
        this.configDir = configDir;
    }
    
    public void handle(String trimmed) {
        String[] parts = trimmed.split("\\s+");
        
        if (parts.length == 1) {
            // /plugins - 交互式浏览器
            showBrowser();
            return;
        }
        
        String subcommand = parts[1];
        
        switch (subcommand) {
            case "list" -> handleList();
            case "install" -> handleInstall(parts);
            case "uninstall" -> handleUninstall(parts);
            case "enable" -> handleEnable(parts);
            case "disable" -> handleDisable(parts);
            case "validate" -> handleValidate(parts);
            case "info" -> handleInfo(parts);
            case "reload" -> handleReload();
            case "help" -> handleHelp();
            default -> ui.showError("Unknown subcommand: " + subcommand);
        }
    }
    
    private void showBrowser() {
        ui.println();
        ui.println("Plugin Browser:");
        ui.println();
        
        List<PluginEntry> plugins = PluginDiscovery.scan(
            configDir.resolve("plugins")
        );
        
        if (plugins.isEmpty()) {
            ui.println("No plugins installed");
            ui.println();
            ui.println("Install a plugin:");
            ui.println("  /plugins install <path|git:url|npm:package>");
            ui.println();
            return;
        }
        
        for (PluginEntry plugin : plugins) {
            boolean isDisabled = PluginStateManager.isDisabled(
                plugin.name(), configDir
            );
            String status = isDisabled ? "[disabled]" : "[enabled]";
            
            ui.printf("  %s %s%n", status, plugin.name());
            ui.println("    " + plugin.description());
            ui.println("    Version: " + plugin.version());
            ui.println();
        }
        
        ui.println("Commands:");
        ui.println("  /plugins list              - List all plugins");
        ui.println("  /plugins install <source>  - Install plugin");
        ui.println("  /plugins uninstall <name>  - Uninstall plugin");
        ui.println("  /plugins enable <name>     - Enable plugin");
        ui.println("  /plugins disable <name>    - Disable plugin");
        ui.println("  /plugins validate <path>   - Validate plugin");
        ui.println("  /plugins info <name>       - Show plugin info");
        ui.println("  /plugins reload            - Reload all plugins");
        ui.println();
    }
    
    private void handleList() {
        List<PluginEntry> plugins = PluginDiscovery.scan(
            configDir.resolve("plugins")
        );
        
        if (plugins.isEmpty()) {
            ui.println("No plugins installed");
            return;
        }
        
        ui.println();
        ui.println("Installed Plugins:");
        ui.println();
        
        for (PluginEntry plugin : plugins) {
            boolean isDisabled = PluginStateManager.isDisabled(
                plugin.name(), configDir
            );
            String status = isDisabled ? "[disabled]" : "[enabled]";
            
            ui.printf("  %s %-20s %s%n", status, plugin.name(), plugin.version());
        }
        
        ui.println();
    }
    
    private void handleInstall(String[] parts) {
        if (parts.length < 3) {
            ui.showError("Usage: /plugins install <path|git:url|npm:package> [--local|--global]");
            return;
        }
        
        String source = parts[2];
        String scope = findFlag(parts, "--scope", "global");
        
        PluginInstaller.install(source, scope);
    }
    
    private void handleUninstall(String[] parts) {
        if (parts.length < 3) {
            ui.showError("Usage: /plugins uninstall <name> [--local|--global]");
            return;
        }
        
        String name = parts[2];
        String scope = findFlag(parts, "--scope", "global");
        
        PluginInstaller.uninstall(name, scope);
    }
    
    private void handleEnable(String[] parts) {
        if (parts.length < 3) {
            // 交互式选择
            PluginStateManager.showPicker(ui, configDir);
            return;
        }
        
        String name = parts[2];
        PluginStateManager.enable(name, configDir);
        ui.println("Enabled: " + name);
    }
    
    private void handleDisable(String[] parts) {
        if (parts.length < 3) {
            PluginStateManager.showPicker(ui, configDir);
            return;
        }
        
        String name = parts[2];
        PluginStateManager.disable(name, configDir);
        ui.println("Disabled: " + name);
    }
    
    private void handleValidate(String[] parts) {
        if (parts.length < 3) {
            ui.showError("Usage: /plugins validate <path>");
            return;
        }
        
        String path = parts[2];
        ValidationResult result = PluginValidator.validate(Path.of(path));
        result.print(ui);
    }
    
    private void handleInfo(String[] parts) {
        if (parts.length < 3) {
            ui.showError("Usage: /plugins info <name>");
            return;
        }
        
        String name = parts[2];
        
        // 查找插件
        List<PluginEntry> plugins = PluginDiscovery.scan(
            configDir.resolve("plugins")
        );
        
        Optional<PluginEntry> plugin = plugins.stream()
            .filter(p -> p.name().equals(name))
            .findFirst();
        
        if (plugin.isEmpty()) {
            ui.showError("Plugin not found: " + name);
            return;
        }
        
        PluginEntry p = plugin.get();
        
        ui.println();
        ui.println("Plugin: " + p.name());
        ui.println("  Version: " + p.version());
        ui.println("  Path: " + p.path());
        ui.println("  Description: " + p.description());
        ui.println();
    }
    
    private void handleReload() {
        PluginManager.getInstance(configDir).loadAllPlugins();
        ui.println("Plugins reloaded");
    }
    
    private void handleHelp() {
        ui.println();
        ui.println("Plugin Commands:");
        ui.println();
        ui.println("  /plugins list              - List all plugins");
        ui.println("  /plugins install <source>  - Install plugin");
        ui.println("    Sources:");
        ui.println("      - Local path: /plugins install ./my-plugin");
        ui.println("      - Git URL: /plugins install git:https://github.com/user/plugin");
        ui.println("      - GitHub: /plugins install github:user/plugin");
        ui.println("      - npm: /plugins install npm:my-plugin");
        ui.println("  /plugins uninstall <name>  - Uninstall plugin");
        ui.println("  /plugins enable <name>     - Enable plugin");
        ui.println("  /plugins disable <name>    - Disable plugin");
        ui.println("  /plugins validate <path>   - Validate plugin");
        ui.println("  /plugins info <name>       - Show plugin info");
        ui.println("  /plugins reload            - Reload all plugins");
        ui.println();
    }
    
    private String findFlag(String[] parts, String flag, String defaultValue) {
        for (int i = 0; i < parts.length - 1; i++) {
            if (flag.equals(parts[i])) {
                return parts[i + 1];
            }
        }
        return defaultValue;
    }
}
```

```java
public class SkillToolProvider implements ToolProvider {
    private final SkillConfig config;
    
    @Override
    public String id() {
        return "skill";
    }
    
    @Override
    public int priority() {
        return 50;  // 工作空间 100，用户 50，插件 75
    }
    
    @Override
    public RefreshPolicy refreshPolicy() {
        return RefreshPolicy.ON_DEMAND;
    }
    
    @Override
    public List<ToolCall> discover(ToolProviderContext context) {
        List<ToolCall> tools = new ArrayList<>();
        
        // 1. 工作空间技能（优先级 100）
        Path workspaceSkills = context.workspace().resolve(".core-ai/skills");
        tools.addAll(loadSkills(workspaceSkills, 100));
        
        // 2. 用户技能（优先级 50）
        Path userSkills = Path.of(System.getProperty("user.home"))
            .resolve(".core-ai/skills");
        tools.addAll(loadSkills(userSkills, 50));
        
        // 3. 插件技能（优先级 75）
        for (PluginSkillSource source : config.pluginSkillSources()) {
            tools.addAll(loadSkills(source.skillsDir(), 75));
        }
        
        return tools;
    }
    
    private List<ToolCall> loadSkills(Path skillsDir, int priority) {
        List<ToolCall> tools = new ArrayList<>();
        
        if (!Files.isDirectory(skillsDir)) return tools;
        
        try (var stream = Files.list(skillsDir)) {
            stream.filter(Files::isDirectory)
                .forEach(skillDir -> {
                    Path skillFile = skillDir.resolve("SKILL.md");
                    if (Files.exists(skillFile)) {
                        try {
                            String content = Files.readString(skillFile);
                            SkillMetadata metadata = parseSkillMetadata(content);
                            
                            tools.add(new SkillToolCall(
                                metadata.name(),
                                metadata.description(),
                                content,
                                skillDir,
                                priority
                            ));
                        } catch (IOException e) {
                            // 忽略
                        }
                    }
                });
        } catch (IOException e) {
            // 忽略
        }
        
        return tools;
    }
    
    private SkillMetadata parseSkillMetadata(String content) {
        // 解析 YAML frontmatter
        if (content.startsWith("---")) {
            int end = content.indexOf("---", 3);
            if (end > 0) {
                String frontmatter = content.substring(3, end).trim();
                // 解析 YAML（简化版）
                Map<String, String> metadata = parseFrontmatter(frontmatter);
                
                return new SkillMetadata(
                    metadata.getOrDefault("name", "unknown"),
                    metadata.getOrDefault("description", ""),
                    metadata.getOrDefault("version", "1.0.0")
                );
            }
        }
        
        return new SkillMetadata("unknown", "", "1.0.0");
    }
    
    private Map<String, String> parseFrontmatter(String frontmatter) {
        Map<String, String> metadata = new HashMap<>();
        for (String line : frontmatter.split("\n")) {
            String[] parts = line.split(":", 2);
            if (parts.length == 2) {
                metadata.put(parts[0].trim(), parts[1].trim());
            }
        }
        return metadata;
    }
}

record SkillConfig(
    List<PluginSkillSource> pluginSkillSources
) {}

record SkillMetadata(
    String name,
    String description,
    String version
) {}
```

## 10.7 ManagedSkillProvisioner

### 10.7.1 类定义

**位置**: `skill/ManagedSkillProvisioner.java`

```java
public class ManagedSkillProvisioner {
    
    // 启动时 provision 管理技能
    public static void provision(Path workspace) {
        // 当前只 provision browser-use 技能
        provisionBrowserUse(workspace);
    }
    
    private static void provisionBrowserUse(Path workspace) {
        Path skillDir = workspace.resolve(".core-ai/skills/browser-use");
        
        // 已安装则跳过
        if (Files.isDirectory(skillDir)) {
            return;
        }
        
        // 1. 尝试从服务器安装
        if (AuthManager.isLoggedIn()) {
            if (installFromServer(skillDir)) {
                adaptForWindows(skillDir);
                return;
            }
        }
        
        // 2. 尝试从 GitHub 安装
        if (installFromGithub(skillDir)) {
            adaptForWindows(skillDir);
        }
    }
    
    private static boolean installFromServer(Path skillDir) {
        try {
            // GET /api/skills
            String serverUrl = AuthManager.getServerUrl().orElse(null);
            if (serverUrl == null) return false;
            
            String apiKey = AuthConfig.load()
                .map(AuthConfig::apiKey)
                .orElse(null);
            if (apiKey == null) return false;
            
            HttpClient client = HttpClient.newHttpClient();
            
            HttpRequest request = HttpRequest.newBuilder()
                .uri(URI.create(serverUrl + "/api/skills"))
                .header("Authorization", "Bearer " + apiKey)
                .GET()
                .build();
            
            HttpResponse<String> response = client.send(
                request,
                HttpResponse.BodyHandlers.ofString()
            );
            
            if (response.statusCode() != 200) return false;
            
            // 查找 browser-use
            JsonObject json = Json.parse(response.body());
            JsonArray skills = json.getArray("skills");
            
            for (JsonValue value : skills) {
                JsonObject skill = value.asObject();
                if ("browser-use".equals(skill.getString("name"))) {
                    String skillId = skill.getString("id");
                    
                    // 下载
                    HttpRequest downloadRequest = HttpRequest.newBuilder()
                        .uri(URI.create(serverUrl + "/api/skills/" + skillId + "/download"))
                        .header("Authorization", "Bearer " + apiKey)
                        .GET()
                        .build();
                    
                    HttpResponse<String> downloadResponse = client.send(
                        downloadRequest,
                        HttpResponse.BodyHandlers.ofString()
                    );
                    
                    if (downloadResponse.statusCode() == 200) {
                        Files.createDirectories(skillDir);
                        Files.writeString(
                            skillDir.resolve("SKILL.md"),
                            downloadResponse.body()
                        );
                        return true;
                    }
                }
            }
            
            return false;
        } catch (Exception e) {
            return false;
        }
    }
    
    private static boolean installFromGithub(Path skillDir) {
        try {
            // 从 GitHub raw 下载
            String url = "https://raw.githubusercontent.com/core-ai/skills/main/browser-use/SKILL.md";
            
            HttpClient client = HttpClient.newHttpClient();
            HttpRequest request = HttpRequest.newBuilder()
                .uri(URI.create(url))
                .GET()
                .build();
            
            HttpResponse<String> response = client.send(
                request,
                HttpResponse.BodyHandlers.ofString()
            );
            
            if (response.statusCode() == 200) {
                Files.createDirectories(skillDir);
                Files.writeString(
                    skillDir.resolve("SKILL.md"),
                    response.body()
                );
                return true;
            }
            
            return false;
        } catch (Exception e) {
            return false;
        }
    }
    
    private static void adaptForWindows(Path skillDir) {
        String os = System.getProperty("os.name").toLowerCase();
        if (!os.contains("win")) return;
        
        Path skillFile = skillDir.resolve("SKILL.md");
        
        try {
            String content = Files.readString(skillFile);
            
            // 添加 Windows PowerShell 说明
            String windowsNote = """
                
                ## Windows Note
                
                On Windows, use PowerShell commands instead of bash:
                - Use `Get-Content` instead of `cat`
                - Use `Set-Content` instead of `echo >`
                - Use `Invoke-WebRequest` instead of `curl`
                """;
            
            Files.writeString(skillFile, content + windowsNote);
        } catch (IOException e) {
            // 忽略
        }
    }
}
```
