## 3.1 启动流程概述

### 3.1.1 完整启动流程

```
JVM 启动
    ↓
Main.main(args)
    ↓
初始化日志系统
    ↓
解析命令行参数（picocli）
    ↓
创建 CliApp 实例
    ↓
根据模式启动：
    ├─ 本地模式 → cliApp.start()
    ├─ 远程模式 → cliApp.startRemote()
    ├─ 服务模式 → cliApp.startServe()
    └─ ACP 模式 → cliApp.startAcpAgent()
    ↓
初始化核心组件
    ├─ BootstrapCore
    ├─ TerminalUI
    ├─ Agent
    └─ Plugins
    ↓
启动主循环
    ↓
等待用户输入
```

💡 **设计意图**：清晰的启动流程，支持多种运行模式。

### 3.1.2 启动时序图

```
JVM          Main        CliApp       BootstrapCore    TerminalUI
 │             │            │              │              │
 │─main()─────>│            │              │              │
 │             │─initSlf4j()│              │              │
 │             │─parseArgs()│              │              │
 │             │─new────────>│              │              │
 │             │            │─bootstrap()──>│              │
 │             │            │<─result──────│              │
 │             │            │─new────────────────────────>│
 │             │            │<─ui─────────────────────────│
 │             │            │─start()                     │
 │             │            │  ├─createAgent()            │
 │             │            │  └─run()                    │
```

## 3.2 Main 类详解

### 3.2.1 Main 类定义

**位置**: `Main.java`

```java
@Command(name = "core-ai-cli", versionProvider = VersionProvider.class, 
         description = "Core-AI CLI agent")
public class Main implements Callable<Integer> {
    
    public static void main(String[] args) {
        initSlf4j();
        System.exit(new CommandLine(new Main()).execute(args));
    }
    
    @Override
    public Integer call() {
        // 处理升级
        if (upgrade) {
            checkUpgrade();
            return 0;
        }
        
        // 启用调试
        if (debug) {
            DebugLog.enable();
            System.setProperty("core.ai.debug", "true");
        }
        
        // 创建选项
        var options = new CliAppOptions(
            configFile, model, prompt, skipPermissions, 
            continueSession, resume, workspace, timeLimitSeconds
        );
        
        // 根据模式启动
        if (acpAgent) {
            new CliApp(options).startAcpAgent();
        } else if (serve) {
            new CliApp(options).startServe(port, !headless, webDir);
        } else if (serverUrl != null) {
            new CliApp(options).startRemote(serverUrl, apiKey, agentId);
        } else {
            new CliApp(options).start();
        }
        
        return 0;
    }
}
```

💡 **说明**：
- 使用 picocli 库解析命令行参数
- 支持多种运行模式
- 实现 `Callable<Integer>` 接口

### 3.2.3 日志初始化

```java
private static void initSlf4j() {
    // 设置 SLF4J 提供者
    System.setProperty("slf4j.provider", "ai.core.cli.log.CliLoggerServiceProvider");
    
    // 重定向 System.err 到 null（避免日志库初始化时的输出）
    var stderr = System.err;
    System.setErr(new PrintStream(OutputStream.nullOutputStream(), false, stderr.charset()));
    
    // 初始化日志工厂
    LoggerFactory.getILoggerFactory();
    
    // 恢复 System.err
    System.setErr(stderr);
}
```

💡 **说明**：
- 使用自定义的日志提供者 `CliLoggerServiceProvider`
- 避免日志库初始化时的多余输出
- 支持调试模式

### 3.2.4 升级检查

```java
private void checkUpgrade() {
    var checker = new UpgradeChecker();
    var info = checker.check();
    
    if (info.latestVersion() == null) {
        System.out.println("Failed to check for updates.");
        System.exit(1);
        return;
    }
    
    if (!info.isNewer()) {
        System.out.println("You are up to date (v" + info.currentVersion() + ")");
        return;
    }
    
    System.out.println("New version available: v" + info.latestVersion());
    
    // 下载新版本
    Path installDir = upgradeDir != null ? upgradeDir : UpgradeDownloader.resolveInstallDir();
    Path downloaded = UpgradeDownloader.download(info.latestVersion(), installDir);
    
    // 替换当前二进制文件
    Path currentBinary = UpgradeDownloader.findCurrentBinary();
    if (currentBinary != null) {
        Path replaced = UpgradeDownloader.tryReplaceCurrent(downloaded, currentBinary);
        System.out.println("Replaced " + currentBinary.getFileName());
    }
}
```

💡 **说明**：
- 检查 GitHub Release API
- 下载新版本二进制文件
- 自动替换当前二进制文件

## 3.3 CliApp 初始化

### 3.3.1 CliApp 构造函数

**位置**: `ai/core/cli/CliApp.java`

```java
public class CliApp {
    private final Path configFile;
    private final String modelOverride;
    private final String prompt;
    private final boolean autoApproveAll;
    private final boolean continueSession;
    private final boolean resume;
    private final Path workspace;
    private final Integer timeLimitSeconds;

    public CliApp(CliAppOptions options) {
        this.configFile = options.configFile() != null 
            ? options.configFile() 
            : PathUtils.DEFAULT_CONFIG;
        this.modelOverride = options.modelOverride();
        this.prompt = options.prompt();
        this.autoApproveAll = options.autoApproveAll();
        this.continueSession = options.continueSession();
        this.resume = options.resume();
        this.workspace = options.workspace() != null 
            ? options.workspace().toAbsolutePath() 
            : Paths.get("").toAbsolutePath();
        this.timeLimitSeconds = options.timeLimitSeconds();
    }
}
```

💡 **说明**：
- 使用 `CliAppOptions` 记录传递所有选项
- 设置默认值（配置文件、工作目录）
- 转换相对路径为绝对路径

## 3.4 核心引导

### 3.4.1 BootstrapCore

**位置**: `ai/core/cli/BootstrapCore.java`

```java
public record BootstrapCore(
    BootstrapResult result,
    Path configFile,
    Properties properties
) {
    public static BootstrapCore load(Path configFile) {
        // 1. 加载配置文件
        var properties = loadProperties(configFile);
        
        // 2. 引导核心组件
        var bootstrap = new AgentBootstrap(new PropertiesFileSource(configFile));
        var result = bootstrap.initialize();
        
        return new BootstrapCore(result, configFile, properties);
    }
    
    private static Properties loadProperties(Path configFile) {
        var properties = new Properties();
        if (Files.exists(configFile)) {
            try (var reader = Files.newBufferedReader(configFile)) {
                properties.load(reader);
            }
        }
        return properties;
    }
}
```

💡 **说明**：
- 加载配置文件
- 引导核心组件（LLM、Memory 等）
- 返回引导结果

### 3.4.2 认证监听器

```java
private void registerAuthListener(BootstrapResult result) {
    // 从配置文件加载认证信息
    var auth = AuthConfig.load();
    if (auth != null && auth.apiKey() != null) {
        RuntimeAuthConfig.instance().update(
            auth.serverUrl() + "/api/litellm/v1", 
            auth.apiKey()
        );
    }
    
    // 注册监听器，当认证信息变化时更新 LLM 提供者
    if (result.liteLLMProvider != null) {
        RuntimeAuthConfig.instance().addListener(() -> {
            var rt = RuntimeAuthConfig.instance();
            if (rt.isConfigured()) {
                result.liteLLMProvider.updateCredentials(
                    rt.serverUrl(), 
                    rt.apiKey()
                );
            }
        });
    }
}
```

💡 **说明**：
- 加载保存的认证信息
- 注册监听器，支持动态更新认证信息
- 自动更新 LLM 提供者的凭证

## 3.5 组件初始化

### 3.5.1 本地模式启动

```java
public void start() {
    var shutdownResources = new ArrayList<AutoCloseable>();
    
    try {
        // 1. 引导核心组件
        var core = BootstrapCore.load(configFile);
        
        // 2. 注册认证监听器
        registerAuthListener(core.result);
        
        // 3. 初始化终端 UI
        var terminalUI = new TerminalUI();
        shutdownResources.add(terminalUI);
        
        // 4. 初始化插件管理器
        var pluginManager = new PluginManager();
        pluginManager.discover();
        
        // 5. 创建 Agent
        var agent = createAgent(core, terminalUI);
        
        // 6. 恢复会话（如果需要）
        if (continueSession || resume) {
            agent = restoreSession(agent, terminalUI);
        }
        
        // 7. 处理单次提示（如果有）
        if (prompt != null) {
            handleSinglePrompt(agent, terminalUI);
            return;
        }
        
        // 8. 创建会话运行器
        var runner = new AgentSessionRunner(terminalUI, agent, pluginManager);
        
        // 9. 注册关闭钩子
        Runtime.getRuntime().addShutdownHook(new Thread(() -> {
            closeShutdownResources(shutdownResources);
        }));
        
        // 10. 启动主循环
        runner.run();
        
    } catch (Exception e) {
        LOGGER.error("Failed to start CLI", e);
        System.exit(1);
    } finally {
        closeShutdownResources(shutdownResources);
    }
}
```

💡 **说明**：
- 按顺序初始化所有组件
- 支持会话恢复
- 支持单次提示模式
- 注册关闭钩子，确保资源正确释放

### 3.5.2 创建 Agent

```java
private CliAgent createAgent(BootstrapCore core, TerminalUI terminalUI) {
    var agent = new CliAgent();
    
    // 设置模型
    if (modelOverride != null) {
        agent.setModel(modelOverride);
    } else {
        var configModel = core.properties.getProperty("model");
        if (configModel != null) {
            agent.setModel(configModel);
        }
    }
    
    // 设置工作目录
    agent.setWorkspace(workspace);
    
    // 设置记忆提供者
    if (core.result.memoryProvider != null) {
        agent.setMemoryProvider(core.result.memoryProvider);
    }
    
    // 设置自动批准
    agent.setAutoApproveAll(autoApproveAll);
    
    // 设置时间限制
    if (timeLimitSeconds != null) {
        agent.setTimeLimitSeconds(timeLimitSeconds);
    }
    
    // 设置事件监听器
    agent.addListener(new CliEventListener(terminalUI));
    
    return agent;
}
```

💡 **说明**：
- 从配置或命令行参数设置模型
- 设置工作目录
- 注入记忆提供者
- 注册事件监听器

### 3.5.3 远程模式启动

```java
public void startRemote(String serverUrl, String apiKey, String agentId) {
    try {
        // 1. 初始化终端 UI
        var terminalUI = new TerminalUI();
        
        // 2. 创建远程连接器
        var connector = new A2ARemoteConnector(serverUrl, apiKey, agentId);
        
        // 3. 创建远程会话运行器
        var runner = new RemoteSessionRunner(terminalUI, connector);
        
        // 4. 启动主循环
        runner.run();
        
    } catch (Exception e) {
        LOGGER.error("Failed to start remote mode", e);
        System.exit(1);
    }
}
```

💡 **说明**：
- 使用 A2A 协议连接远程服务器
- 支持 API Key 认证
- 支持指定 Agent ID

### 3.5.4 服务模式启动

```java
public void startServe(int port, boolean openBrowser, Path webDir) {
    try {
        // 1. 引导核心组件
        var core = BootstrapCore.load(configFile);
        
        // 2. 创建 A2A 服务器
        var server = new A2AServer(port, core.result, webDir);
        
        // 3. 启动服务器
        server.start();
        
        // 4. 打开浏览器（如果需要）
        if (openBrowser) {
            BrowserLauncher.open("http://localhost:" + port);
        }
        
        // 5. 等待服务器关闭
        server.awaitTermination();
        
    } catch (Exception e) {
        LOGGER.error("Failed to start server mode", e);
        System.exit(1);
    }
}
```

💡 **说明**：
- 启动 A2A Web 服务器
- 可以指定端口
- 可以选择是否打开浏览器
- 可以指定前端目录（用于开发）

### 3.5.5 ACP 模式启动

```java
public void startAcpAgent() {
    try {
        // 1. 引导核心组件
        var core = BootstrapCore.load(configFile);
        
        // 2. 初始化终端 UI（用于日志）
        var terminalUI = new TerminalUI();
        
        // 3. 创建 Agent
        var agent = createAgent(core, terminalUI);
        
        // 4. 创建 ACP 运行器
        var runner = new AcpAgentRunner(agent);
        
        // 5. 启动 ACP 模式（stdin/stdout）
        runner.run();
        
    } catch (Exception e) {
        LOGGER.error("Failed to start ACP mode", e);
        System.exit(1);
    }
}
```

💡 **说明**：
- ACP = Agent Client Protocol
- 通过 stdin/stdout 与编辑器集成
- 用于 IDE 插件集成

## 3.6 启动模式

### 3.6.1 模式对比

| 模式 | 命令 | 说明 | 使用场景 |
|------|------|------|---------|
| **本地模式** | `core-ai-cli` | 本地运行 Agent | 日常使用 |
| **远程模式** | `core-ai-cli --server <url>` | 连接远程服务器 | 使用远程 Agent |
| **服务模式** | `core-ai-cli --serve` | 启动 Web 服务器 | 提供 A2A 服务 |
| **ACP 模式** | `core-ai-cli --acp-agent` | ACP stdio 模式 | IDE 集成 |

### 3.6.2 本地模式

```bash
# 基本启动
core-ai-cli

# 恢复最近的会话
core-ai-cli --continue

# 选择会话恢复
core-ai-cli --resume

# 指定模型
core-ai-cli --model gpt-4-turbo

# 单次提示
core-ai-cli --prompt "Hello"

# 跳过权限确认
core-ai-cli --dangerously-skip-permissions

# 设置工作目录
core-ai-cli --workspace /path/to/project

# 设置时间限制
core-ai-cli --time-limit-seconds 300
```

### 3.6.3 远程模式

```bash
# 连接远程服务器
core-ai-cli --server http://localhost:8080

# 使用 API Key
core-ai-cli --server http://localhost:8080 --api-key <token>

# 指定 Agent ID
core-ai-cli --server http://localhost:8080 --agent-id my-agent
```

### 3.6.4 服务模式

```bash
# 启动服务器（默认端口 8080）
core-ai-cli --serve

# 指定端口
core-ai-cli --serve --port 9000

# 无头模式（不打开浏览器）
core-ai-cli --serve --headless

# 指定前端目录（开发模式）
core-ai-cli --serve --web-dir /path/to/frontend
```

### 3.6.5 ACP 模式

```bash
# 启动 ACP 模式
core-ai-cli --acp-agent

# 通常由 IDE 插件调用
# 通过 stdin/stdout 通信
```

💡 **说明**：ACP 模式用于与 IDE 集成，通过标准输入输出通信。
