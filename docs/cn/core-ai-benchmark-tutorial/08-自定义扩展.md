## 8.1 扩展点概述

### 8.1.1 主要扩展点

benchmark 框架提供了多个扩展点：

```
┌─────────────────────────────────────────┐
│           Benchmark 框架                │
├─────────────────────────────────────────┤
│  扩展点 1: 推理处理器                   │
│  ├─ BFCLInferenceHandle (抽象类)        │
│  ├─ BFCLInferenceFCHandle (函数调用)    │
│  ├─ BFCLInferencePlanHandle (计划)      │
│  └─ 自定义推理处理器                    │
├─────────────────────────────────────────┤
│  扩展点 2: 数据集加载器                 │
│  ├─ BFCLDatasetLoader (BFCL)            │
│  └─ 自定义数据集加载器                  │
├─────────────────────────────────────────┤
│  扩展点 3: 批处理器                     │
│  ├─ BatchProcessor (通用批处理)         │
│  └─ 自定义批处理器                      │
├─────────────────────────────────────────┤
│  扩展点 4: 结果写入器                   │
│  ├─ ResultWriter (接口)                 │
│  └─ 自定义结果写入器                    │
└─────────────────────────────────────────┘
```

💡 **扩展原则**：
- **接口隔离**：通过接口定义扩展点
- **依赖倒置**：依赖抽象而非具体实现
- **开闭原则**：对扩展开放，对修改关闭

### 8.1.2 扩展场景

| 场景 | 扩展方式 | 示例 |
|------|---------|------|
| **支持新模型** | 自定义推理处理器 | 支持 Claude、Gemini 等 |
| **自定义评估** | 自定义评估指标 | 评估代码生成质量 |
| **新数据集** | 自定义数据集加载器 | 加载自定义测试集 |
| **新输出格式** | 自定义结果写入器 | 导出为 XML、Parquet 等 |

## 8.2 自定义推理处理器

### 8.2.1 创建自定义推理处理器

```java
package ai.core.benchmark.inference;

import ai.core.benchmark.domain.BFCLItemEvalResult;
import ai.core.llm.LLMProvider;
import ai.core.llm.domain.CompletionRequest;
import ai.core.llm.domain.CompletionResponse;
import ai.core.llm.domain.Message;
import ai.core.llm.domain.Tool;

import java.util.List;
import java.util.Map;

/**
 * 自定义推理处理器示例：支持多轮对话
 */
public class MultiTurnInferenceHandle extends BFCLInferenceHandle {
    private final LLMProvider llmProvider;
    private final int maxTurns;
    
    public MultiTurnInferenceHandle(LLMProvider llmProvider, int maxTurns) {
        this.llmProvider = llmProvider;
        this.maxTurns = maxTurns;
    }
    
    @Override
    protected BFCLItemEvalResult invoke(String id, List<Message> messages, List<Tool> tools) {
        long startTime = System.currentTimeMillis();
        
        List<Message> conversation = new ArrayList<>(messages);
        List<Map<String, Object>> allResults = new ArrayList<>();
        int totalInputTokens = 0;
        int totalOutputTokens = 0;
        
        // 多轮对话
        for (int turn = 0; turn < maxTurns; turn++) {
            // 构建请求
            var request = CompletionRequest.of(
                conversation, 
                tools, 
                llmProvider.config.getTemperature(), 
                llmProvider.config.getModel(), 
                "eval-req-" + turn
            );
            
            // 调用 LLM
            var response = llmProvider.completion(request);
            
            // 统计 Token
            totalInputTokens += response.usage.getPromptTokens();
            totalOutputTokens += response.usage.getCompletionTokens();
            
            // 提取结果
            if (response.choices.getFirst().finishReason == FinishReason.TOOL_CALLS) {
                var toolCalls = response.choices.getFirst().message.toolCalls;
                toolCalls.stream()
                    .map(tool -> Map.of(tool.function.name, (Object) tool.function.arguments))
                    .forEach(allResults::add);
                
                // 添加工具调用到对话历史
                conversation.add(response.choices.getFirst().message);
                
                // 模拟工具执行结果（实际应该执行真实工具）
                Message toolResult = Message.of(
                    RoleType.TOOL, 
                    "Tool executed successfully"
                );
                conversation.add(toolResult);
            } else {
                // 没有更多工具调用，结束对话
                allResults.add(Map.of("output", response.choices.getFirst().message.content));
                break;
            }
        }
        
        long endTime = System.currentTimeMillis();
        double latency = (endTime - startTime) / 1000.0;
        
        return BFCLItemEvalResult.of(
            id,
            allResults,
            totalInputTokens,
            totalOutputTokens,
            latency
        );
    }
}
```

💡 **扩展要点**：
- 继承 `BFCLInferenceHandle` 抽象类
- 实现 `invoke()` 方法
- 支持自定义逻辑（如多轮对话）

### 8.2.3 支持不同 LLM 提供商

```java
/**
 * Claude 推理处理器
 */
public class ClaudeInferenceHandle extends BFCLInferenceHandle {
    private final ClaudeClient claudeClient;
    
    public ClaudeInferenceHandle(ClaudeClient claudeClient) {
        this.claudeClient = claudeClient;
    }
    
    @Override
    protected BFCLItemEvalResult invoke(String id, List<Message> messages, List<Tool> tools) {
        long startTime = System.currentTimeMillis();
        
        // 转换为 Claude 格式
        var claudeMessages = convertToClaudeFormat(messages);
        var claudeTools = convertToolsToClaudeFormat(tools);
        
        // 调用 Claude API
        var response = claudeClient.createMessage(
            "claude-3-opus-20240229",
            claudeMessages,
            claudeTools
        );
        
        long endTime = System.currentTimeMillis();
        double latency = (endTime - startTime) / 1000.0;
        
        // 转换结果
        var result = convertClaudeResponse(response);
        
        return BFCLItemEvalResult.of(
            id,
            result.functionCalls,
            response.usage.inputTokens,
            response.usage.outputTokens,
            latency
        );
    }
    
    private List<ClaudeMessage> convertToClaudeFormat(List<Message> messages) {
        return messages.stream()
            .map(msg -> new ClaudeMessage(msg.role, msg.content))
            .toList();
    }
    
    private List<ClaudeTool> convertToolsToClaudeFormat(List<Tool> tools) {
        return tools.stream()
            .map(tool -> new ClaudeTool(
                tool.function.name,
                tool.function.description,
                tool.function.parameters
            ))
            .toList();
    }
    
    private ClaudeResult convertClaudeResponse(ClaudeResponse response) {
        List<Map<String, Object>> functionCalls = new ArrayList<>();
        
        for (var block : response.content) {
            if (block.type.equals("tool_use")) {
                functionCalls.add(Map.of(
                    block.name, 
                    block.input
                ));
            }
        }
        
        return new ClaudeResult(functionCalls);
    }
}
```

### 8.3.2 实现代码生成质量指标

```java
/**
 * 代码生成质量评估指标
 */
public class CodeQualityMetric implements EvaluationMetric {
    
    @Override
    public String getName() {
        return "code_quality";
    }
    
    @Override
    public MetricResult evaluate(BFCLItem item, BFCLItemEvalResult result) {
        // 提取生成的代码
        String code = extractGeneratedCode(result);
        
        if (code == null || code.isEmpty()) {
            return MetricResult.of(getName(), 0.0, Map.of("error", "No code generated"));
        }
        
        // 计算各项指标
        double syntaxScore = checkSyntax(code);
        double complexityScore = checkComplexity(code);
        double documentationScore = checkDocumentation(code);
        
        // 综合评分
        double overallScore = (syntaxScore * 0.4 + 
                              complexityScore * 0.3 + 
                              documentationScore * 0.3);
        
        Map<String, Object> details = Map.of(
            "syntax_score", syntaxScore,
            "complexity_score", complexityScore,
            "documentation_score", documentationScore,
            "code_length", code.length(),
            "line_count", code.split("\n").length
        );
        
        return MetricResult.of(getName(), overallScore, details);
    }
    
    private String extractGeneratedCode(BFCLItemEvalResult result) {
        // 从结果中提取代码
        for (var funcCall : result.result) {
            if (funcCall.containsKey("write_file")) {
                var args = (Map<String, Object>) funcCall.get("write_file");
                return (String) args.get("content");
            }
        }
        return null;
    }
    
    private double checkSyntax(String code) {
        // 简单的语法检查（实际应该使用 AST 解析）
        int braceCount = 0;
        int parenCount = 0;
        
        for (char c : code.toCharArray()) {
            if (c == '{') braceCount++;
            if (c == '}') braceCount--;
            if (c == '(') parenCount++;
            if (c == ')') parenCount--;
        }
        
        // 括号匹配得分
        double score = 1.0;
        if (braceCount != 0) score -= 0.3;
        if (parenCount != 0) score -= 0.3;
        
        return Math.max(0, score);
    }
    
    private double checkComplexity(String code) {
        // 简单的复杂度检查
        int lineCount = code.split("\n").length;
        
        // 代码行数适中得分高
        if (lineCount < 10) return 0.5;
        if (lineCount < 50) return 1.0;
        if (lineCount < 100) return 0.8;
        return 0.6;
    }
    
    private double checkDocumentation(String code) {
        // 检查是否有注释
        long commentLines = code.lines()
            .filter(line -> line.trim().startsWith("//") || line.trim().startsWith("*"))
            .count();
        
        int lineCount = code.split("\n").length;
        double commentRatio = (double) commentLines / lineCount;
        
        // 注释比例 10-30% 得分最高
        if (commentRatio < 0.05) return 0.3;
        if (commentRatio < 0.1) return 0.7;
        if (commentRatio < 0.3) return 1.0;
        return 0.8;
    }
}
```

### 8.3.3 使用自定义评估指标

```java
/**
 * 扩展的评估器，支持自定义指标
 */
public class ExtendedBFCLEvaluator extends BFCLEvaluator {
    private final List<EvaluationMetric> metrics;
    
    public ExtendedBFCLEvaluator(
        BFCLInferenceHandle inferenceHandle, 
        String resultDirName,
        List<EvaluationMetric> metrics
    ) {
        super(inferenceHandle, resultDirName);
        this.metrics = metrics;
    }
    
    @Override
    protected BFCLItemEvalResult processItem(ItemContext context) {
        // 调用基础处理
        BFCLItemEvalResult result = super.processItem(context);
        
        // 计算自定义指标
        Map<String, MetricResult> metricResults = new HashMap<>();
        for (EvaluationMetric metric : metrics) {
            MetricResult metricResult = metric.evaluate(context.item, result);
            metricResults.put(metric.getName(), metricResult);
        }
        
        // 将指标结果附加到评估结果
        result.metrics = metricResults;
        
        return result;
    }
}

@Test

        "extended-test",
        metrics
    );
    
    evaluator.eval(BFCLCategory.NON_LIVE, List.of());
}
```

```java
package ai.core.benchmark.loader;

/**
 * 自定义数据集加载器接口
 */
public interface CustomDatasetLoader {
    /**
     * 加载数据集
     */
    List<BFCLFileInfo> load(String category);
    
    /**
     * 获取数据集名称
     */
    String getName();
}

/**
 * HumanEval 数据集加载器
 */
public class HumanEvalDatasetLoader implements CustomDatasetLoader {
    private final String dataPath;
    
    public HumanEvalDatasetLoader(String dataPath) {
        this.dataPath = dataPath;
    }
    
    @Override
    public String getName() {
        return "humaneval";
    }
    
    @Override
    public List<BFCLFileInfo> load(String category) {
        // 加载 HumanEval 数据集
        // HumanEval 是一个代码生成基准测试数据集
        
        List<BFCLItem> items = new ArrayList<>();
        
        try (BufferedReader reader = Files.newBufferedReader(Path.of(dataPath))) {
            String line;
            int index = 0;
            
            while ((line = reader.readLine()) != null) {
                // HumanEval 格式：JSON Lines
                var json = JsonUtil.parseJson(line);
                
                BFCLItem item = new BFCLItem();
                item.id = "humaneval_" + index;
                
                // 转换 HumanEval 格式到 BFCL 格式
                item.question = List.of(List.of(
                    createMessage("user", json.getString("prompt"))
                ));
                
                // HumanEval 不使用函数定义，而是直接生成代码
                item.function = List.of(
                    createFunctionDefinition("generate_code", 
                        "Generate Python code to solve the problem",
                        createParameters("code", "string", "The generated Python code")
                    )
                );
                
                items.add(item);
                index++;
            }
        } catch (IOException e) {
            throw new RuntimeException("Failed to load HumanEval dataset", e);
        }
        
        BFCLFileInfo fileInfo = BFCLFileInfo.of(
            "humaneval.json",
            category,
            dataPath,
            items
        );
        
        return List.of(fileInfo);
    }
}
```

### 8.5.3 插件管理器

```java
/**
 * 插件管理器
 */
public class PluginManager {
    private final Map<String, BenchmarkPlugin> plugins = new HashMap<>();
    
    /**
     * 注册插件
     */
    public void registerPlugin(BenchmarkPlugin plugin) {
        plugins.put(plugin.getName(), plugin);
    }
    
    /**
     * 加载插件（使用 ServiceLoader）
     */
    public void loadPlugins(PluginContext context) {
        ServiceLoader<BenchmarkPlugin> loader = ServiceLoader.load(BenchmarkPlugin.class);
        
        for (BenchmarkPlugin plugin : loader) {
            plugin.initialize(context);
            registerPlugin(plugin);
        }
    }
    
    /**
     * 获取插件
     */
    public BenchmarkPlugin getPlugin(String name) {
        return plugins.get(name);
    }
    
    /**
     * 获取所有插件
     */
    public List<BenchmarkPlugin> getAllPlugins() {
        return new ArrayList<>(plugins.values());
    }
}
```

```java
            // 获取插件
            BenchmarkPlugin plugin = pluginManager.getPlugin(config.pluginName);
            BFCLInferenceHandle handle = plugin.getInferenceHandle();
            
            // 创建评估器
            BFCLEvaluator evaluator = new BFCLEvaluator(handle, config.name);
            
            // 运行测试
            evaluator.eval(config.category, List.of());
            
            // 加载结果
            List<BFCLItemEvalResult> results = loadResults(config.name, config.category);
            allResults.put(config.name, results);
        }
        
        // 4. 生成对比报告
        generateComparisonReport(allResults);
    }
    
    private void generateComparisonReport(Map<String, List<BFCLItemEvalResult>> allResults) {
        // 创建对比表格
        StringBuilder report = new StringBuilder();
        report.append("# Benchmark Comparison Report\n\n");
        
        report.append("| Model | Items | Avg Latency | P95 Latency | Total Tokens | Cost |\n");
        report.append("|-------|-------|-------------|-------------|--------------|------|\n");
        
        for (Map.Entry<String, List<BFCLItemEvalResult>> entry : allResults.entrySet()) {
            String modelName = entry.getKey();
            List<BFCLItemEvalResult> results = entry.getValue();
            
            double avgLatency = results.stream()
                .mapToDouble(r -> r.latency)
                .average()
                .orElse(0);
            
            double p95Latency = results.stream()
                .mapToDouble(r -> r.latency)
                .sorted()
                .skip((long) (results.size() * 0.95))
                .findFirst()
                .orElse(0);
            
            int totalTokens = results.stream()
                .mapToInt(r -> r.inputTokenCount + r.outputTokenCount)
                .sum();
            
            double cost = results.stream()
                .mapToDouble(r -> r.inputTokenCount * 0.03 + r.outputTokenCount * 0.06)
                .sum() / 1000;
            
            report.append(String.format("| %s | %d | %.2fs | %.2fs | %d | $%.2f |\n",
                modelName, results.size(), avgLatency, p95Latency, totalTokens, cost));
        }
        
        // 保存报告
        Files.writeString(Path.of("comparison_report.md"), report.toString());
        System.out.println("Report saved to: comparison_report.md");
    }
    
    private static class TestConfig {
        String name;
        String pluginName;
        BFCLCategory category;
        
        TestConfig(String name, String pluginName, BFCLCategory category) {
            this.name = name;
            this.pluginName = pluginName;
            this.category = category;
        }
    }
}
```

## 8.7 最佳实践

### 8.7.1 扩展开发最佳实践

✅ **推荐**：
- **遵循接口**：实现框架提供的接口
- **单一职责**：每个类只负责一个功能
- **依赖注入**：使用依赖注入而非硬编码
- **配置化**：通过配置文件控制行为
- **日志记录**：记录关键操作和错误

❌ **避免**：
- **修改核心代码**：通过扩展而非修改实现功能
- **硬编码配置**：使用配置文件而非硬编码
- **忽略异常**：捕获并处理所有异常
- **忽略日志**：记录关键操作日志

### 8.7.2 性能优化最佳实践

✅ **推荐**：
- **批量处理**：使用 BatchProcessor 批量处理
- **并发执行**：利用多核 CPU 并发执行
- **缓存结果**：缓存已完成的测试结果
- **流式处理**：使用流式处理避免内存溢出

❌ **避免**：
- **单条处理**：避免逐条处理大量数据
- **串行执行**：避免串行执行可并行的任务
- **重复计算**：避免重复计算相同结果
- **内存泄漏**：及时释放不需要的资源

### 8.7.3 测试最佳实践

✅ **推荐**：
- **单元测试**：为每个扩展编写单元测试
- **集成测试**：测试扩展与框架的集成
- **性能测试**：测试扩展的性能表现
- **文档测试**：确保示例代码可运行

❌ **避免**：
- **忽略测试**：不要跳过测试
- **只测正常情况**：测试边界情况和异常情况
- **忽略性能**：不要忽略性能测试
