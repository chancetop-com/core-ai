## 2.1 配置 LLM 提供商

### 2.1.1 配置 API 密钥

在 `application.yml` 中配置 LLM 提供商：

```yaml
# core-ai-benchmark/src/test/resources/application.yml
llm:
  providers:
    openai:
      api-key: ${OPENAI_API_KEY}
      base-url: https://api.openai.com/v1
      model: gpt-4
      temperature: 0.0
```

### 2.1.2 设置环境变量

```bash
# Linux/macOS
export OPENAI_API_KEY=sk-your-api-key-here

# Windows PowerShell
$env:OPENAI_API_KEY="sk-your-api-key-here"

# Windows CMD
set OPENAI_API_KEY=sk-your-api-key-here
```

💡 **提示**：也可以使用其他 LLM 提供商，如 Anthropic Claude、Google Gemini 等。

## 2.2 编写第一个测试

### 2.2.1 创建测试类

```java
package ai.core.benchmark;

import ai.core.benchmark.common.BFCLCategory;
import ai.core.benchmark.evaluator.BFCLEvaluator;
import ai.core.benchmark.inference.BFCLInferenceFCHandle;
import ai.core.llm.LLMProviders;
import core.framework.inject.Inject;
import org.junit.jupiter.api.Test;

class QuickStartTest extends IntegrationTest {
    @Inject
    LLMProviders llmProviders;

    @Test
    void testFirstBenchmark() {
        // 1. 创建推理处理器
        var inferenceHandle = new BFCLInferenceFCHandle(
            llmProviders.getProvider()
        );
        
        // 2. 创建评估器
        var evaluator = new BFCLEvaluator(
            inferenceHandle, 
            "quick-start-test"  // 结果目录名
        );
        
        // 3. 运行测试（只测试前 10 项）
        evaluator.eval(
            BFCLCategory.NON_LIVE, 
            List.of("simple_0", "simple_1", "simple_2")
        );
    }
}
```

💡 **说明**：
- `BFCLInferenceFCHandle`：函数调用推理处理器
- `BFCLEvaluator`：评估器主入口
- `BFCLCategory.NON_LIVE`：非实时测试类别
- 第三个参数是结果目录名，用于区分不同的测试运行

### 2.2.2 完整测试示例

```java
package ai.core.benchmark;

import ai.core.benchmark.common.BFCLCategory;
import ai.core.benchmark.evaluator.BFCLEvaluator;
import ai.core.benchmark.inference.BFCLInferenceFCHandle;
import ai.core.llm.LLMProviders;
import core.framework.inject.Inject;
import org.junit.jupiter.api.Test;

import java.util.List;

class QuickStartTest extends IntegrationTest {
    @Inject
    LLMProviders llmProviders;

    @Test
    void testSimpleCategory() {
        // 创建评估器
        var evaluator = new BFCLEvaluator(
            new BFCLInferenceFCHandle(llmProviders.getProvider()),
            "simple-test"
        );
        
        // 测试 NON_LIVE 类别的所有项
        evaluator.eval(BFCLCategory.NON_LIVE, List.of());
    }

    @Test
    void testSpecificItems() {
        // 只测试特定的测试项
        var evaluator = new BFCLEvaluator(
            new BFCLInferenceFCHandle(llmProviders.getProvider()),
            "specific-test"
        );
        
        // 只测试 simple_0 到 simple_9
        List<String> itemIds = List.of(
            "simple_0", "simple_1", "simple_2", "simple_3", "simple_4",
            "simple_5", "simple_6", "simple_7", "simple_8", "simple_9"
        );
        
        evaluator.eval(BFCLCategory.NON_LIVE, itemIds);
    }

    @Test
    void testWithSkipCompleted() {
        // 跳过已完成的项目（断点续传）
        var evaluator = new BFCLEvaluator(
            new BFCLInferenceFCHandle(llmProviders.getProvider()),
            "resumable-test"
        );
        
        // 第三个参数 true 表示跳过已完成项
        evaluator.eval(BFCLCategory.NON_LIVE, List.of(), true);
    }
}
```

## 2.4 查看结果

### 2.4.1 结果文件位置

测试结果保存在：

```
~/.cache/core-ai-benchmark/BFCL/result/<result-dir-name>/<category>/
```

例如：
```
~/.cache/core-ai-benchmark/BFCL/result/quick-start-test/non_live/
```

### 2.4.2 结果文件格式

结果文件使用 JSON Lines 格式，每行一个 JSON 对象：

```bash
# 查看结果文件
cat ~/.cache/core-ai-benchmark/BFCL/result/quick-start-test/non_live/simple_result.json
```

示例输出：
```json
{"id":"simple_0","result":[{"get_weather":{"location":"San Francisco, CA","unit":"celsius"}}],"input_token_count":150,"output_token_count":25,"latency":1.23}
{"id":"simple_1","result":[{"search_hotels":{"location":"New York","check_in":"2024-01-15","check_out":"2024-01-17"}}],"input_token_count":145,"output_token_count":30,"latency":1.15}
{"id":"simple_2","result":[{"book_flight":{"from":"SFO","to":"LAX","date":"2024-02-01"}}],"input_token_count":160,"output_token_count":28,"latency":1.30}
```

### 2.4.3 解析结果

使用 Python 脚本解析结果：

```python
import json

# 读取结果文件
results = []
with open('/Users/user/.cache/core-ai-benchmark/BFCL/result/quick-start-test/non_live/simple_result.json', 'r') as f:
    for line in f:
        results.append(json.loads(line))

# 统计信息
total = len(results)
total_input_tokens = sum(r['input_token_count'] for r in results)
total_output_tokens = sum(r['output_token_count'] for r in results)
avg_latency = sum(r['latency'] for r in results) / total

print(f"Total items: {total}")
print(f"Total input tokens: {total_input_tokens}")
print(f"Total output tokens: {total_output_tokens}")
print(f"Average latency: {avg_latency:.2f}s")
```

输出示例：
```
Total items: 100
Total input tokens: 15234
Total output tokens: 2876
Average latency: 1.23s
```

## 2.5 断点续传

### 2.5.1 什么是断点续传

断点续传允许你在测试中断后继续执行，避免重复测试已完成的项目。

### 2.5.2 使用断点续传

```java
@Test
void testWithResume() {
    var evaluator = new BFCLEvaluator(
        new BFCLInferenceFCHandle(llmProviders.getProvider()),
        "resumable-test"
    );
    
    // 第三个参数 true 表示跳过已完成项
    evaluator.eval(BFCLCategory.NON_LIVE, List.of(), true);
}
```

### 2.5.3 工作原理

1. **检查已完成项**：读取结果文件，提取已完成的 item ID
2. **过滤未完成项**：从数据集中过滤掉已完成的项目
3. **继续处理**：只处理未完成的项目
4. **追加写入**：结果追加到现有结果文件

💡 **优势**：
- 节省 API 调用费用
- 节省测试时间
- 避免重复工作

### 2.5.4 手动清理结果

如果需要重新测试所有项目：

```bash
# 删除结果目录
rm -rf ~/.cache/core-ai-benchmark/BFCL/result/quick-start-test/
```

或者在代码中指定新的结果目录名：

```java
var evaluator = new BFCLEvaluator(
    new BFCLInferenceFCHandle(llmProviders.getProvider()),
    "new-test-run"  // 新的结果目录
);
```

## 2.6 常见问题

### 2.6.1 API 密钥错误

**问题**：
```
java.lang.RuntimeException: API key not configured
```

**解决方案**：
```bash
# 设置环境变量
export OPENAI_API_KEY=sk-your-api-key-here

# 或者在 application.yml 中硬编码（不推荐）
llm:
  providers:
    openai:
      api-key: sk-your-api-key-here
```

### 2.6.2 数据集下载失败

**问题**：
```
java.io.IOException: Failed to download dataset
```

**解决方案**：
```bash
# 检查网络连接
ping gorilla.cs.berkeley.edu

# 手动下载数据集
cd ~/.cache/core-ai-benchmark/BFCL/
git clone https://github.com/ShishirPatil/gorilla.git
cd gorilla/berkeley-function-call-leaderboard/data/
cp -r * ../../

# 或者设置代理
export https_proxy=http://proxy.example.com:8080
```

### 2.6.3 速率限制

**问题**：
```
java.lang.RuntimeException: Rate limit exceeded
```

**解决方案**：
```java
// 降低并发数
var batchProcessor = new BatchProcessor<>(
    20,  // 减小批次大小
    4,   // 减少线程数
    this::processItem,
    this::writeResult
);

// 添加延迟
Thread.sleep(100);  // 每次请求后延迟 100ms
```

### 2.6.4 内存不足

**问题**：
```
java.lang.OutOfMemoryError: Java heap space
```

**解决方案**：
```bash
# 增加 JVM 堆内存
./gradlew :core-ai-benchmark:test -Dorg.gradle.jvmargs="-Xmx4g"
```
