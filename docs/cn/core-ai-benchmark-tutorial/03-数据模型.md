## 3.1 数据模型概述

### 3.1.1 核心数据模型

benchmark 框架包含以下核心数据模型：

```
┌─────────────────────────────────────────┐
│           数据模型层                     │
├─────────────────────────────────────────┤
│  BFCLItem         - 测试项（输入）       │
│  BFCLFileInfo     - 文件信息             │
│  BFCLItemEvalResult - 评估结果（输出）   │
│  BFCLCategory     - 测试类别（枚举）     │
└─────────────────────────────────────────┘
```

### 3.1.2 数据流向

```
数据集文件 (JSON Lines)
    ↓
BFCLDatasetLoader.readFile()
    ↓
List<BFCLItem>
    ↓
包装为 BFCLFileInfo
    ↓
BFCLEvaluator 处理
    ↓
InferenceHandle 推理
    ↓
BFCLItemEvalResult
    ↓
写入结果文件
```

💡 **设计意图**：清晰的数据模型定义了测试的输入和输出，便于追踪和分析。

## 3.4 BFCLItemEvalResult - 评估结果

### 3.4.1 类定义

**位置**: `domain/BFCLItemEvalResult.java`

```java
public class BFCLItemEvalResult {
    public static BFCLItemEvalResult of(String id,
                                        List<Map<String, Object>> result,
                                        Integer inputTokenCount, 
                                        Integer outputTokenCount,
                                        Double latency) {
        BFCLItemEvalResult agentResult = new BFCLItemEvalResult();
        agentResult.id = id;
        agentResult.result = result;
        agentResult.inputTokenCount = inputTokenCount;
        agentResult.outputTokenCount = outputTokenCount;
        agentResult.latency = latency;
        return agentResult;
    }

    @Property(name = "id")
    public String id;

    @Property(name = "result")
    public List<Map<String, Object>> result;

    @Property(name = "input_token_count")
    public Integer inputTokenCount;

    @Property(name = "output_token_count")
    public Integer outputTokenCount;

    @Property(name = "latency")
    public Double latency;
}
```

### 3.4.2 字段说明

| 字段 | 类型 | 说明 | 单位 |
|------|------|------|------|
| **id** | String | 测试项 ID（与 BFCLItem.id 对应） | - |
| **result** | List<Map<String, Object>> | LLM 推理结果 | - |
| **inputTokenCount** | Integer | 输入 Token 数量 | tokens |
| **outputTokenCount** | Integer | 输出 Token 数量 | tokens |
| **latency** | Double | 推理延迟 | 秒 |

### 3.4.3 result 字段详解

`result` 字段是一个列表，每个元素是一个 Map，表示一个函数调用：

```json
[
  {
    "get_weather": {
      "location": "San Francisco, CA",
      "unit": "celsius"
    }
  }
]
```

**结构说明**：
- 列表的每个元素对应一个函数调用
- Map 的 key 是函数名
- Map 的 value 是函数参数

💡 **示例**：
- 单个函数调用：`[{"get_weather": {"location": "SF"}}]`
- 多个并行调用：`[{"get_weather": {...}}, {"get_time": {...}}]`

### 3.4.4 创建结果示例

```java
// 创建评估结果
BFCLItemEvalResult result = BFCLItemEvalResult.of(
    "simple_0",  // 测试项 ID
    List.of(      // 推理结果
        Map.of("get_weather", Map.of("location", "San Francisco, CA", "unit", "celsius"))
    ),
    150,          // 输入 token 数
    25,           // 输出 token 数
    1.23          // 延迟（秒）
);

// 访问字段
System.out.println("ID: " + result.id);
System.out.println("Result: " + result.result);
System.out.println("Input tokens: " + result.inputTokenCount);
System.out.println("Output tokens: " + result.outputTokenCount);
System.out.println("Latency: " + result.latency + "s");
```

### 3.4.5 序列化为 JSON

```java
// 使用 JsonUtil 序列化
String json = JsonUtil.toJson(result);
System.out.println(json);

// 输出：
// {"id":"simple_0","result":[{"get_weather":{"location":"San Francisco, CA","unit":"celsius"}}],"input_token_count":150,"output_token_count":25,"latency":1.23}
```

## 3.5 BFCLCategory - 测试类别

### 3.5.1 枚举定义

**位置**: `common/BFCLCategory.java`

```java
public enum BFCLCategory {
    NON_LIVE(List.of(
            "simple_python",
            "simple_java",
            "simple_javascript",
            "multiple",
            "parallel",
            "parallel_multiple",
            "irrelevance"
    )),
    LIVE(List.of(
            "live_simple",
            "live_multiple",
            "live_parallel",
            "live_parallel_multiple",
            "live_irrelevance",
            "live_relevance"
    )),
    NON_PYTHON(List.of("simple_java", "simple_javascript")),
    PYTHON(List.of(
            "simple_python",
            "irrelevance",
            "parallel",
            "multiple",
            "parallel_multiple",
            "live_simple",
            "live_multiple",
            "live_parallel",
            "live_parallel_multiple",
            "live_irrelevance",
            "live_relevance"
    )),
    SINGLE_TURN(combine(NON_LIVE, LIVE));
    
    private final List<String> types;
    
    BFCLCategory(List<String> types) {
        this.types = types;
    }
    
    public List<String> getTypes() {
        return types;
    }
    
    private static List<String> combine(BFCLCategory... categories) {
        return Stream.of(categories)
                .flatMap(c -> c.types.stream())
                .toList();
    }
}
```

### 3.5.2 类别说明

| 类别 | 说明 | 包含类型 |
|------|------|---------|
| **NON_LIVE** | 非实时测试（静态数据集） | simple_python, simple_java, simple_javascript, multiple, parallel, parallel_multiple, irrelevance |
| **LIVE** | 实时测试（动态数据集） | live_simple, live_multiple, live_parallel, live_parallel_multiple, live_irrelevance, live_relevance |
| **NON_PYTHON** | 非 Python 语言测试 | simple_java, simple_javascript |
| **PYTHON** | Python 相关测试 | simple_python 和所有 live 测试 |
| **SINGLE_TURN** | 单轮对话测试 | NON_LIVE + LIVE 的所有类型 |

💡 **说明**：
- **NON_LIVE**：使用固定的测试数据集，结果可复现
- **LIVE**：使用动态生成的测试数据，更接近真实场景
- **SINGLE_TURN**：组合类别，包含所有单轮测试

### 3.5.3 使用示例

```java
// 测试特定类别
evaluator.eval(BFCLCategory.NON_LIVE, List.of());

// 测试所有单轮测试
evaluator.eval(BFCLCategory.SINGLE_TURN, List.of());

// 查看类别包含的类型
List<String> types = BFCLCategory.NON_LIVE.getTypes();
System.out.println("NON_LIVE types: " + types);
// 输出: [simple_python, simple_java, simple_javascript, multiple, parallel, parallel_multiple, irrelevance]
```

### 3.5.4 类别选择指南

| 场景 | 推荐类别 | 原因 |
|------|---------|------|
| **快速验证** | NON_LIVE | 数据量小，速度快 |
| **全面评估** | SINGLE_TURN | 覆盖所有单轮测试 |
| **生产环境测试** | LIVE | 更接近真实场景 |
| **多语言测试** | NON_PYTHON | 测试 Java/JavaScript 支持 |
| **Python 专项** | PYTHON | 专注 Python 函数调用 |

## 3.6 数据转换

### 3.6.1 BFCLItem 转换为 LLM 请求

```java
public class BFCLInferenceHandle {
    
    protected List<Message> prepareMessages(BFCLItem item) {
        List<Message> messages = new ArrayList<>();
        
        // 添加多轮对话
        for (List<BFCLItem.Message> turn : item.question) {
            for (BFCLItem.Message msg : turn) {
                Message llmMsg = new Message();
                llmMsg.role = msg.role;
                llmMsg.content = msg.content;
                messages.add(llmMsg);
            }
        }
        
        return messages;
    }
    
    protected List<Tool> prepareTools(BFCLItem item) {
        List<Tool> tools = new ArrayList<>();
        
        for (FunctionDefinition funcDef : item.function) {
            Tool tool = new Tool();
            tool.type = "function";
            
            Function function = new Function();
            function.name = funcDef.name;
            function.description = funcDef.description;
            function.parameters = convertParameters(funcDef.parameters);
            
            tool.function = function;
            tools.add(tool);
        }
        
        return tools;
    }
    
    private JsonSchema convertParameters(Parameters params) {
        JsonSchema schema = new JsonSchema();
        schema.type = params.type;
        schema.required = params.required;
        schema.properties = new LinkedHashMap<>();
        
        for (Map.Entry<String, JsonPropertyInfo> entry : params.properties.entrySet()) {
            schema.properties.put(entry.getKey(), convertProperty(entry.getValue()));
        }
        
        return schema;
    }
}
```

💡 **转换流程**：
1. 将 BFCLItem 的 question 转换为 LLM 的 Message 列表
2. 将 BFCLItem 的 function 转换为 LLM 的 Tool 列表
3. 递归转换参数定义为 JSON Schema

### 3.6.2 LLM 响应转换为 BFCLItemEvalResult

```java
public class BFCLInferenceFCHandle extends BFCLInferenceHandle {
    
    @Override
    protected BFCLItemEvalResult invoke(String id, List<Message> messages, List<Tool> tools) {
        // 1. 构建 LLM 请求
        var request = CompletionRequest.of(messages, tools, ...);
        
        // 2. 调用 LLM
        long startTime = System.currentTimeMillis();
        var response = llmProvider.completion(request);
        long endTime = System.currentTimeMillis();
        double latency = (endTime - startTime) / 1000.0;
        
        // 3. 转换响应
        return fromCompletionResponse(response, id, latency);
    }
    
    private BFCLItemEvalResult fromCompletionResponse(CompletionResponse response, String id, double latency) {
        List<Map<String, Object>> result = new ArrayList<>();
        
        // 提取工具调用
        if (response.choices.getFirst().finishReason == FinishReason.TOOL_CALLS) {
            var tools = response.choices.getFirst().message.toolCalls;
            tools.stream()
                .map(tool -> Map.of(tool.function.name, (Object) tool.function.arguments))
                .forEach(result::add);
        }
        
        // 如果没有工具调用，使用文本输出
        if (result.isEmpty()) {
            result.add(Map.of("output", response.choices.getFirst().message.content));
        }
        
        // 创建结果对象
        return BFCLItemEvalResult.of(
            id,
            result,
            response.usage.getPromptTokens(),
            response.usage.getCompletionTokens(),
            latency
        );
    }
}
```

💡 **转换逻辑**：
1. 调用 LLM API
2. 记录延迟时间
3. 提取工具调用或文本输出
4. 提取 Token 使用量
5. 创建 BFCLItemEvalResult 对象

## 3.7 实战示例

### 3.7.1 解析测试数据

```java
public class DataParser {
    
    public void parseBFCLItem(BFCLItem item) {
        System.out.println("=== Test Item: " + item.id + " ===");
        
        // 解析问题
        System.out.println("\nQuestion:");
        for (int i = 0; i < item.question.size(); i++) {
            System.out.println("Turn " + (i + 1) + ":");
            for (BFCLItem.Message msg : item.question.get(i)) {
                System.out.println("  [" + msg.role + "] " + msg.content);
            }
        }
        
        // 解析函数
        System.out.println("\nAvailable Functions:");
        for (FunctionDefinition func : item.function) {
            System.out.println("  - " + func.name + ": " + func.description);
            
            if (func.parameters != null && func.parameters.properties != null) {
                System.out.println("    Parameters:");
                for (Map.Entry<String, JsonPropertyInfo> entry : func.parameters.properties.entrySet()) {
                    String paramName = entry.getKey();
                    JsonPropertyInfo paramInfo = entry.getValue();
                    boolean required = func.parameters.required != null && 
                                     func.parameters.required.contains(paramName);
                    
                    System.out.println("      * " + paramName + " (" + paramInfo.type + ")" + 
                                     (required ? " [required]" : ""));
                    if (paramInfo.description != null) {
                        System.out.println("        " + paramInfo.description);
                    }
                    if (paramInfo.enumValues != null) {
                        System.out.println("        Values: " + String.join(", ", paramInfo.enumValues));
                    }
                }
            }
        }
    }
}
```

### 3.7.2 分析评估结果

```java
public class ResultAnalyzer {
    
    public void analyzeResults(List<BFCLItemEvalResult> results) {
        System.out.println("=== Evaluation Results ===\n");
        
        // 统计信息
        int totalItems = results.size();
        double totalLatency = 0;
        int totalInputTokens = 0;
        int totalOutputTokens = 0;
        
        for (BFCLItemEvalResult result : results) {
            totalLatency += result.latency;
            totalInputTokens += result.inputTokenCount;
            totalOutputTokens += result.outputTokenCount;
        }
        
        System.out.println("Total items: " + totalItems);
        System.out.println("Average latency: " + String.format("%.2f", totalLatency / totalItems) + "s");
        System.out.println("Total input tokens: " + totalInputTokens);
        System.out.println("Total output tokens: " + totalOutputTokens);
        System.out.println("Average input tokens per item: " + (totalInputTokens / totalItems));
        System.out.println("Average output tokens per item: " + (totalOutputTokens / totalItems));
        
        // 延迟分布
        System.out.println("\nLatency Distribution:");
        List<Double> latencies = results.stream()
            .map(r -> r.latency)
            .sorted()
            .toList();
        
        System.out.println("  Min: " + String.format("%.2f", latencies.get(0)) + "s");
        System.out.println("  P50: " + String.format("%.2f", latencies.get(latencies.size() / 2)) + "s");
        System.out.println("  P95: " + String.format("%.2f", latencies.get((int)(latencies.size() * 0.95))) + "s");
        System.out.println("  Max: " + String.format("%.2f", latencies.get(latencies.size() - 1)) + "s");
    }
}
```

public class ResultExporter {
    
    public void exportToCSV(List<BFCLItemEvalResult> results, String outputPath) throws IOException {

            // 写入表头

            }
        }

        return json.replace("\"", "\"\"");
    }
}

## 3.8 验证学习成果

### 3.8.1 自测题

1. **BFCLItem 的 question 字段是什么类型？**
   - A. List<Message>
   - B. List<List<Message>>
