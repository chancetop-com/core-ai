## 6.1 数据集管理概述

### 6.1.1 数据集管理的角色

数据集管理负责 BFCL 数据集的完整生命周期：

```
1. 下载数据集
   ↓
2. 加载数据
   ↓
3. 过滤已完成项
   ↓
4. 处理测试项
   ↓
5. 写入结果
   ↓
6. 断点续传（可选）
```

💡 **核心目标**：高效管理数据集，支持断点续传，避免重复处理。

### 6.1.2 数据集管理架构

```
┌─────────────────────────────────────────┐
│         数据集管理层                     │
├─────────────────────────────────────────┤
│  BFCLDatasetLoader                      │
│  ├─ load(category)                      │
│  ├─ loadUncompleted(category)           │
│  ├─ getCompletedItemIds(category)       │
│  └─ writeResultToFile(...)              │
├─────────────────────────────────────────┤
│  BFCLDownloader                         │
│  └─ download(workDir)                   │
├─────────────────────────────────────────┤
│  ResumableLoader<T, R>                  │
│  └─ 可恢复加载接口                      │
├─────────────────────────────────────────┤
│  ResultWriter<T>                        │
│  └─ 结果写入接口                        │
└─────────────────────────────────────────┘
```

💡 **设计意图**：分离下载、加载和写入逻辑，支持断点续传。

### 6.1.3 数据集目录结构

```
~/.cache/core-ai-benchmark/BFCL/
├── data/                          # 数据集文件
│   ├── BFCL_v4_simple.json
│   ├── BFCL_v4_multiple.json
│   ├── BFCL_v4_parallel.json
│   └── ...
└── result/                        # 结果文件
    └── <result-dir-name>/
        └── <category>/
            ├── simple_result.json
            ├── multiple_result.json
            └── ...
```

💡 **目录说明**：
- `data/`：原始数据集（JSON Lines 格式）
- `result/`：评估结果（按运行名称和类别组织）

## 6.3 数据集下载

### 6.3.1 BFCLDownloader 下载器

**位置**: `loader/BFCLDownloader.java`

```java
public class BFCLDownloader {
    private static final Logger LOGGER = LoggerFactory.getLogger(BFCLDownloader.class);
    
    public void download(String workDir) {
        LOGGER.info("Downloading BFCL dataset to: {}", workDir);
        
        // 1. 创建工作目录
        Path workPath = Paths.get(workDir);
        if (!Files.exists(workPath)) {
            Files.createDirectories(workPath);
        }
        
        // 2. 克隆数据集仓库
        Path dataPath = workPath.resolve("data");
        if (!Files.exists(dataPath)) {
            Files.createDirectories(dataPath);
        }
        
        // 3. 下载数据集文件
        // 实际实现可能使用 Git 或直接下载文件
        // 这里简化为从 GitHub 下载
        downloadFromGitHub(dataPath);
    }
    
    private void downloadFromGitHub(Path dataPath) {
        // 下载 BFCL v4 数据集
        String baseUrl = "https://raw.githubusercontent.com/ShishirPatil/gorilla/main/berkeley-function-call-leaderboard/data/";
        
        List<String> files = List.of(
            "BFCL_v4_simple.json",
            "BFCL_v4_multiple.json",
            "BFCL_v4_parallel.json",
            "BFCL_v4_parallel_multiple.json",
            "BFCL_v4_irrelevance.json",
            "BFCL_v4_live_simple.json",
            "BFCL_v4_live_multiple.json",
            "BFCL_v4_live_parallel.json",
            "BFCL_v4_live_parallel_multiple.json"
        );
        
        for (String file : files) {
            downloadFile(baseUrl + file, dataPath.resolve(file));
        }
    }
    
    private void downloadFile(String url, Path targetPath) {
        LOGGER.info("Downloading: {}", url);
        
        try {
            // 使用 HttpClient 下载
            HttpClient client = HttpClient.newHttpClient();
            HttpRequest request = HttpRequest.newBuilder()
                .uri(URI.create(url))
                .build();
            
            HttpResponse<InputStream> response = client.send(request, 
                HttpResponse.BodyHandlers.ofInputStream());
            
            // 写入文件
            try (InputStream is = response.body()) {
                Files.copy(is, targetPath, StandardCopyOption.REPLACE_EXISTING);
            }
            
            LOGGER.info("Downloaded: {}", targetPath);
        } catch (Exception e) {
            LOGGER.error("Failed to download: {}", url, e);
            throw new RuntimeException("Download failed: " + url, e);
        }
    }
}
```

💡 **下载策略**：
- 检查本地是否已存在
- 从 GitHub 下载 JSON Lines 文件
- 支持断点续传（如果实现）

💡 **数据集文件**：
- `BFCL_v4_simple.json`：简单函数调用
- `BFCL_v4_multiple.json`：多函数调用
- `BFCL_v4_parallel.json`：并行函数调用
- `BFCL_v4_live_*.json`：实时测试数据

## 6.4 数据加载

### 6.4.1 load() 方法

```java
@Override
public List<BFCLFileInfo> load(BFCLCategory category) {
    // 1. 下载数据集（如果不存在）
    downloadDataset();
    
    // 2. 读取文件
    return readFiles(category);
}

private void downloadDataset() {
    LOGGER.info("Using resource directory: {}", Paths.get(workDir).toAbsolutePath());

    if (isDatasetExist()) {
        LOGGER.info("BFCL dataset already available");
        return;
    }
    
    LOGGER.info("BFCL dataset not found, starting download...");
    datasetDownloader.download(workDir);
}

private boolean isDatasetExist() {
    if (!Files.exists(Paths.get(this.workDir))) {
        return false;
    }
    
    try (Stream<Path> stream = Files.list(Paths.get(this.workDir))) {
        return stream.findAny().isPresent();
    } catch (Exception e) {
        throw new RuntimeException(e);
    }
}
```

💡 **加载流程**：
1. 检查数据集是否存在
2. 如果不存在，自动下载
3. 读取指定类别的文件

### 6.4.2 readFiles() 方法

```java
private List<BFCLFileInfo> readFiles(BFCLCategory category) {
    LOGGER.info("Reading dataset files...");
    
    // 1. 查找数据集文件
    var files = findDatasetFiles();
    
    // 2. 过滤并读取
    return files.entrySet().stream()
        .filter(entry -> {
            var name = entry.getKey();
            return category.getTypes().stream()
                .anyMatch(partName -> name.startsWith("BFCL_v4_" + partName));
        })
        .peek(entry -> LOGGER.info("Reading file: {}", entry.getKey()))
        .map(entry -> {
            var path = entry.getValue();
            var name = entry.getKey();
            var items = readFile(path);
            return BFCLFileInfo.of(name, category.name().toLowerCase(Locale.ROOT), 
                                  path.toString(), items);
        })
        .toList();
}

private Map<String, Path> findDatasetFiles() {
    var files = new HashMap<String, Path>();
    
    try (Stream<Path> stream = Files.list(Paths.get(workDir).resolve("data"))) {
        for (Path path : stream.toList()) {
            Path fileName = path.getFileName();
            if (fileName != null && fileName.toString().startsWith("BFCL_v4_")) {
                files.put(fileName.toString(), path);
            }
        }
    } catch (IOException e) {
        throw new RuntimeException(e);
    }
    
    return files;
}

private List<BFCLItem> readFile(Path path) {
    var items = new ArrayList<BFCLItem>();
    
    try (BufferedReader reader = Files.newBufferedReader(path)) {
        while (reader.ready()) {
            var line = reader.readLine();
            var item = JsonUtil.fromJson(BFCLItem.class, line);
            items.add(item);
        }
    } catch (IOException e) {
        throw new RuntimeException(e);
    }
    
    return items;
}
```

💡 **加载逻辑**：
1. 列出 `data/` 目录下的所有文件
2. 过滤出 `BFCL_v4_*.json` 文件
3. 根据类别过滤文件（如 NON_LIVE 只加载 simple、multiple 等）
4. 逐行读取 JSON Lines 文件
5. 解析为 BFCLItem 对象
6. 包装为 BFCLFileInfo

💡 **JSON Lines 格式**：
```
{"id":"simple_0","question":[...],"function":[...]}
{"id":"simple_1","question":[...],"function":[...]}
{"id":"simple_2","question":[...],"function":[...]}
```

## 6.5 断点续传

### 6.5.1 loadUncompleted() 方法

```java
@Override
public List<BFCLFileInfo> loadUncompleted(BFCLCategory category) {
    LOGGER.info("Loading uncompleted items for category: {}", category);
    
    // 1. 加载所有数据
    var allFiles = load(category);
    
    // 2. 获取已完成项 ID
    var completedIds = getCompletedItemIds(category);

    if (completedIds.isEmpty()) {
        return allFiles;
    }

    // 3. 过滤掉已完成项
    return allFiles.stream()
            .map(fileInfo -> filterOutCompletedItems(fileInfo, completedIds))
            .filter(fileInfo -> !fileInfo.items.isEmpty())
            .toList();
}

private BFCLFileInfo filterOutCompletedItems(BFCLFileInfo fileInfo, List<String> completedIds) {
    var uncompletedItems = fileInfo.items.stream()
            .filter(item -> !completedIds.contains(item.id))
            .toList();
    return BFCLFileInfo.of(fileInfo.name, fileInfo.category, fileInfo.path, uncompletedItems);
}
```

💡 **断点续传流程**：
1. 加载所有测试数据
2. 读取已完成项的 ID
3. 过滤掉已完成项
4. 返回未完成项

💡 **优势**：
- 避免重复处理
- 节省 API 调用费用
- 支持中断后继续

### 6.5.2 getCompletedItemIds() 方法

```java
public List<String> getCompletedItemIds(BFCLCategory category) {
    var resultDir = Paths.get(this.workDir)
            .resolve("result")
            .resolve(this.resultDirName)
            .resolve(category.name().toLowerCase(Locale.ROOT));

    if (!Files.exists(resultDir)) {
        LOGGER.info("No result directory found, starting from scratch");
        return List.of();
    }

    var completedIds = new ArrayList<String>();
    
    try (Stream<Path> files = Files.list(resultDir)) {
        for (Path file : files.toList()) {
            Path fileName = file.getFileName();
            if (fileName != null && fileName.toString().endsWith("_result.json")) {
                completedIds.addAll(readCompletedIdsFromFile(file));
            }
        }
    } catch (IOException e) {
        LOGGER.warn("Error reading completed items, will process all items", e);
        return List.of();
    }

    LOGGER.info("Found {} completed items for category {}", completedIds.size(), category);
    return completedIds;
}

private List<String> readCompletedIdsFromFile(Path file) {
    var ids = new ArrayList<String>();
    
    try (BufferedReader reader = Files.newBufferedReader(file)) {
        while (reader.ready()) {
            var line = reader.readLine();
            var result = JsonUtil.fromJson(BFCLItemEvalResult.class, line);
            ids.add(result.id);
        }
    } catch (IOException e) {
        LOGGER.warn("Error reading file: {}", file, e);
    }
    
    return ids;
}
```

💡 **读取已完成项**：
1. 定位结果目录：`result/<result-dir-name>/<category>/`
2. 列出所有 `*_result.json` 文件
3. 逐行读取 JSON Lines
4. 解析 BFCLItemEvalResult，提取 ID
5. 返回 ID 列表

💡 **示例目录结构**：
```
result/
└── gpt-4-test/
    └── non_live/
        ├── simple_result.json
        ├── multiple_result.json
        └── parallel_result.json
```

### 6.5.3 断点续传示例

```java
// 第一次运行（处理所有项）
BFCLDatasetLoader loader = new BFCLDatasetLoader("test-run");
```

- 第一次运行处理 100 项

- 节省 50% 的 API 调用费用

## 6.6 结果写入

### 6.6.1 writeResultToFile() 方法

```java
@Override
public void writeResultToFile(Path filePath, BFCLItemEvalResult result) {
    LOGGER.debug("Writing result to file: {}", filePath);
    
    try (FileChannel channel = FileChannel.open(
            filePath,
            StandardOpenOption.CREATE,
            StandardOpenOption.WRITE,
            StandardOpenOption.APPEND
    )) {
        var json = JsonUtil.toJson(result);
        ByteBuffer buffer = StandardCharsets.UTF_8.encode(json + System.lineSeparator());
        var num = channel.write(buffer);
        LOGGER.debug("Wrote {} bytes to file", num);
    } catch (IOException e) {
        throw new RuntimeException(e);
    }
}

public void writeResultToFile(String fileName, String category, BFCLItemEvalResult result) {
    var filePath = getTargetFilePath(fileName, category);
    writeResultToFile(filePath, result);
}
```

💡 **写入逻辑**：
1. 打开文件通道（CREATE + WRITE + APPEND）
2. 将结果序列化为 JSON
3. 追加换行符
4. 写入文件
5. 自动关闭通道

💡 **文件模式**：
- `CREATE`：文件不存在则创建
- `WRITE`：写入模式
- `APPEND`：追加到文件末尾

### 6.6.2 getTargetFilePath() 方法

```java
public Path getTargetFilePath(String fileName, String category) {
    var path = Paths.get(this.workDir)
            .resolve("result")
            .resolve(this.resultDirName)
            .resolve(category);
    
    try {
        // 创建目录
        Files.createDirectories(path);
        
        // 转换文件名：BFCL_v4_simple.json -> simple_result.json
        var fileNameSplit = fileName.split("\\.");
        var targetFileName = fileNameSplit[0].replace("BFCL_v4_", "") + "_result." + fileNameSplit[1];
        var targetFilePath = path.resolve(targetFileName);
        
        // 创建文件（如果不存在）
        if (!Files.exists(targetFilePath)) {
            LOGGER.info("Creating file: {}", targetFilePath);
            Files.createFile(targetFilePath);
        }
        
        return targetFilePath;
    } catch (Exception e) {
        throw new RuntimeException(e);
    }
}
```

💡 **路径生成**：
```
输入: fileName = "BFCL_v4_simple.json", category = "non_live"
输出: ~/.cache/core-ai-benchmark/BFCL/result/test-run/non_live/simple_result.json
```

💡 **文件名转换**：
- `BFCL_v4_simple.json` → `simple_result.json`
- `BFCL_v4_multiple.json` → `multiple_result.json`

## 6.7 实战示例

### 6.7.1 完整的数据集管理流程

```java
public class DatasetManagementExample {
    
    public void runBenchmark() {
        // 1. 创建数据集加载器
        BFCLDatasetLoader loader = new BFCLDatasetLoader("gpt-4-test");
        
        // 2. 加载未完成的测试项
        List<BFCLFileInfo> files = loader.loadUncompleted(BFCLCategory.NON_LIVE);
        
        System.out.println("Loaded " + files.size() + " files");
        
        // 3. 统计总测试项数
        int totalItems = files.stream()
            .mapToInt(f -> f.items.size())
            .sum();
        
        System.out.println("Total items to process: " + totalItems);
        
        // 4. 创建推理处理器
        LLMProvider llmProvider = llmProviders.getProvider();
        BFCLInferenceFCHandle handle = new BFCLInferenceFCHandle(llmProvider);
        
        // 5. 创建批处理器
        BatchProcessor<BFCLItem, BFCLItemEvalResult> processor = new BatchProcessor<>(
            50,  // 批次大小
            8,   // 线程池大小
            item -> {
                // 处理单个测试项
                return handle.handle(item);
            },
            (item, result) -> {
                // 写入结果
                String fileName = findFileName(files, item);
                loader.writeResultToFile(fileName, "non_live", result);
            }
        );
        
        // 6. 展平所有测试项
        List<BFCLItem> allItems = files.stream()
            .flatMap(f -> f.items.stream())
            .toList();
        
        // 7. 执行批处理
        processor.process(allItems);
        
        System.out.println("Benchmark completed!");
    }
    
    private String findFileName(List<BFCLFileInfo> files, BFCLItem item) {
        return files.stream()
            .filter(f -> f.items.contains(item))
            .map(f -> f.name)
            .findFirst()
            .orElseThrow();
    }
}
```

💡 **完整流程**：
1. 创建加载器（指定结果目录名）
2. 加载未完成的测试项（支持断点续传）
3. 统计测试项数量
4. 创建推理处理器
5. 创建批处理器
6. 展平所有测试项

### 6.7.2 分析已完成的测试结果

```java
public class ResultAnalysisExample {
    
    public void analyzeResults() {
        // 1. 创建加载器
        BFCLDatasetLoader loader = new BFCLDatasetLoader("gpt-4-test");
        
        // 2. 获取已完成项 ID
        List<String> completedIds = loader.getCompletedItemIds(BFCLCategory.NON_LIVE);
        
        System.out.println("Completed items: " + completedIds.size());
        
        // 3. 读取结果文件
        Path resultDir = Paths.get(System.getProperty("user.home"))
            .resolve(".cache/core-ai-benchmark/BFCL/result/gpt-4-test/non_live");
        
        List<BFCLItemEvalResult> results = new ArrayList<>();
        
        try (Stream<Path> files = Files.list(resultDir)) {
            for (Path file : files.toList()) {
                if (file.toString().endsWith("_result.json")) {
                    results.addAll(readResults(file));
                }
            }
        } catch (IOException e) {
            throw new RuntimeException(e);
        }
        
        // 4. 统计分析
        System.out.println("\n=== Result Analysis ===");
        System.out.println("Total results: " + results.size());
        
        double avgLatency = results.stream()
            .mapToDouble(r -> r.latency)
            .average()
            .orElse(0);
        
        System.out.println("Average latency: " + String.format("%.2f", avgLatency) + "s");
        
        int totalInputTokens = results.stream()
            .mapToInt(r -> r.inputTokenCount)
            .sum();
        
        int totalOutputTokens = results.stream()
            .mapToInt(r -> r.outputTokenCount)
            .sum();
        
        System.out.println("Total input tokens: " + totalInputTokens);
        System.out.println("Total output tokens: " + totalOutputTokens);
    }
    
    private List<BFCLItemEvalResult> readResults(Path file) {
        List<BFCLItemEvalResult> results = new ArrayList<>();
        
        try (BufferedReader reader = Files.newBufferedReader(file)) {
            while (reader.ready()) {
                String line = reader.readLine();
                BFCLItemEvalResult result = JsonUtil.fromJson(BFCLItemEvalResult.class, line);
                results.add(result);
            }
        } catch (IOException e) {
            throw new RuntimeException(e);
        }
        
        return results;
    }
}
```

💡 **分析功能**：
- 统计已完成项数量
- 计算平均延迟

### 6.7.3 导出结果到 CSV

```java
public class ResultExporter {
    
    public void exportToCSV(String resultDirName, BFCLCategory category) throws IOException {
        // 1. 定位结果目录
        Path resultDir = Paths.get(System.getProperty("user.home"))
            .resolve(".cache/core-ai-benchmark/BFCL/result")
            .resolve(resultDirName)
            .resolve(category.name().toLowerCase(Locale.ROOT));
        
        // 2. 读取所有结果
        List<BFCLItemEvalResult> results = new ArrayList<>();
        
        try (Stream<Path> files = Files.list(resultDir)) {
            for (Path file : files.toList()) {
                if (file.toString().endsWith("_result.json")) {
                    try (BufferedReader reader = Files.newBufferedReader(file)) {
                        while (reader.ready()) {
                            String line = reader.readLine();
                            results.add(JsonUtil.fromJson(BFCLItemEvalResult.class, line));
                        }
                    }
                }
            }
        }
        
        // 3. 导出到 CSV
        Path csvPath = resultDir.resolve("results.csv");
        
        try (BufferedWriter writer = Files.newBufferedWriter(csvPath)) {
            // 写入表头
            writer.write("id,input_tokens,output_tokens,latency,result");
            writer.newLine();
            
            // 写入数据
            for (BFCLItemEvalResult result : results) {
                writer.write(String.format("%s,%d,%d,%.2f,\"%s\"",
                    result.id,
                    result.inputTokenCount,
                    result.outputTokenCount,
                    result.latency,
                    escapeJson(JsonUtil.toJson(result.result))
                ));
                writer.newLine();
            }
        }
        
        System.out.println("Exported to: " + csvPath);
    }
    
    private String escapeJson(String json) {
        return json.replace("\"", "\"\"");
    }
}
```

💡 **导出功能**：
- 读取所有结果文件
- 合并为单个 CSV 文件
- 便于在 Excel 中分析
