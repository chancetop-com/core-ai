## 📚 教程概览

core-ai-benchmark 是一个基于 BFCL（Berkeley Function Calling Leaderboard）的 AI Agent 基准测试框架，用于评估 AI 模型的函数调用能力。

### 核心能力

- 🧪 **标准化测试** - 基于 BFCL v4 基准测试标准
- ⚡ **并发执行** - 支持批量并发推理，提升测试效率
- 📊 **详细指标** - 记录延迟、Token 使用量等关键指标
- 💾 **断点续传** - 支持中断后继续执行，避免重复测试
- 🔄 **灵活扩展** - 支持自定义推理处理器

### 技术栈

- **语言**: Java 21+
- **框架**: core-ng (core-ai 框架)
- **构建**: Gradle
- **数据格式**: JSON Lines
