## 0.2 JDK 安装

### 0.2.1 检查现有 JDK

```bash
# 检查 Java 版本
java -version

# 如果已安装 JDK 21+，会显示类似：
# openjdk version "21.0.1" 2023-10-17
```

### 0.2.2 安装 JDK 21

#### macOS

```bash
# 使用 Homebrew 安装
brew install openjdk@21

# 设置环境变量
echo 'export PATH="/opt/homebrew/opt/openjdk@21/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

# 验证安装
java -version
```

#### Ubuntu/Debian

```bash
# 添加 OpenJDK 仓库
sudo add-apt-repository ppa:openjdk-21
sudo apt update

# 安装 JDK
sudo apt install openjdk-21-jdk

# 验证安装
java -version
```

#### Windows

1. 下载 [Oracle JDK 21](https://www.oracle.com/java/technologies/downloads/#java21)
2. 运行安装程序
3. 设置环境变量 `JAVA_HOME`
4. 将 `%JAVA_HOME%\bin` 添加到 `PATH`

## 0.4 IDE 配置

### 0.4.1 IntelliJ IDEA 配置

#### 导入项目

1. 打开 IntelliJ IDEA
2. 选择 `File → Open`
3. 选择 `core-ai` 项目根目录
4. 等待项目加载完成

#### 配置 JDK

1. 打开 `File → Project Structure`
2. 选择 `Project` 标签
3. 设置 `SDK` 为 JDK 21
4. 设置 `Language level` 为 21

#### 配置 Gradle

1. 打开 `File → Settings` (Windows/Linux) 或 `IntelliJ IDEA → Preferences` (macOS)
2. 导航到 `Build, Execution, Deployment → Build Tools → Gradle`
3. 设置 `Gradle JVM` 为 JDK 21
4. 勾选 `Delegate IDE build/run actions to Gradle`

#### 安装推荐插件

- **Lombok** - 简化代码
- **JSON** - JSON 文件支持
- **GitToolBox** - Git 增强

### 0.4.2 VS Code 配置

#### 安装扩展

```bash
# 安装 Java 扩展包
code --install-extension vscjava.vscode-java-pack

# 安装 Gradle 扩展
code --install-extension vscjava.vscode-gradle

# 安装 JSON 扩展
code --install-extension redhat.vscode-json
```

#### 配置 settings.json

```json
{
  "java.configuration.runtimes": [
    {
      "name": "JavaSE-21",
      "path": "/path/to/jdk-21",
      "default": true
    }
  ],
  "java.jdt.ls.java.home": "/path/to/jdk-21"
}
```

## 0.5 项目结构

### 0.5.1 benchmark 模块结构

```
core-ai-benchmark/
├── src/
│   ├── main/java/ai/core/benchmark/
│   │   ├── common/              # 通用组件
│   │   │   └── BFCLCategory.java
│   │   ├── domain/              # 数据模型
│   │   │   ├── BFCLItem.java
│   │   │   ├── BFCLFileInfo.java
│   │   │   └── BFCLItemEvalResult.java
│   │   ├── evaluator/           # 评估器
│   │   │   └── BFCLEvaluator.java
│   │   ├── executor/            # 执行器
│   │   │   └── ConcurrentBatchExecutor.java
│   │   ├── inference/           # 推理处理
│   │   │   ├── InferenceHandle.java
│   │   │   ├── BFCLInferenceHandle.java
│   │   │   ├── BFCLInferenceFCHandle.java
│   │   │   └── BFCLInferencePlanHandle.java
│   │   ├── loader/              # 数据加载
│   │   │   ├── DatasetLoader.java
│   │   │   ├── ResumableLoader.java
│   │   │   ├── ResultWriter.java
│   │   │   ├── BFCLDatasetLoader.java
│   │   │   └── BFCLDownloader.java
│   │   └── processor/           # 批处理
│   │       └── BatchProcessor.java
│   └── test/java/ai/core/benchmark/
│       ├── BFCLTest.java        # 测试用例
│       ├── IntegrationTest.java # 集成测试基类
│       └── TestModule.java      # 测试模块
├── build.gradle.kts             # 构建配置
└── README.md                    # 模块说明
```

### 0.5.2 核心包说明

| 包名 | 说明 |
|------|------|
| **common** | 通用组件和枚举 |
| **domain** | 数据模型定义 |
| **evaluator** | 评估器主逻辑 |
| **executor** | 并发执行器 |
| **inference** | LLM 推理处理 |
| **loader** | 数据集加载和结果写入 |
| **processor** | 批处理逻辑 |

## 0.6 依赖配置

### 0.6.1 查看依赖

```bash
# 进入项目根目录
cd core-ai

# 查看 benchmark 模块依赖
./gradlew :core-ai-benchmark:dependencies

# 输出示例：
# runtimeClasspath - Runtime classpath
# +--- project :core-ai
# +--- project :core-ai-api
# \--- core.framework:core-ng:9.4.2
```

### 0.6.2 主要依赖说明

| 依赖 | 版本 | 说明 |
|------|------|------|
| **core-ai** | - | core-ai 核心框架 |
| **core-ai-api** | - | core-ai API 定义 |
| **core-ng** | 9.4.2 | core-ng 框架 |

### 0.6.3 LLM 提供商配置

需要在配置文件中设置 LLM API 密钥：

```yaml
# application.yml
llm:
  providers:
    openai:
      api-key: ${OPENAI_API_KEY}
      base-url: https://api.openai.com/v1
      model: gpt-4
```
