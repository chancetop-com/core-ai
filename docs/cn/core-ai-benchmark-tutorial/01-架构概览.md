## 1.1 整体架构

### 1.1.1 分层架构

```
┌─────────────────────────────────────────┐
│         应用层 (Application Layer)      │
│  ┌─────────────────────────────────┐   │
│  │      BFCLEvaluator              │   │
│  │      (评估器主入口)              │   │
│  └─────────────────────────────────┘   │
└─────────────────────────────────────────┘
                  ↓
┌─────────────────────────────────────────┐
│         处理层 (Processing Layer)       │
│  ┌──────────────┐  ┌────────────────┐  │
│  │BatchProcessor│  │ConcurrentBatch │  │
│  │(批处理器)    │  │Executor(并发)  │  │
│  └──────────────┘  └────────────────┘  │
└─────────────────────────────────────────┘
                  ↓
┌─────────────────────────────────────────┐
│         推理层 (Inference Layer)        │
│  ┌──────────────┐  ┌────────────────┐  │
│  │InferenceHandle│  │BFCLInference   │  │
│  │(推理接口)    │  │FCHandle(实现)  │  │
│  └──────────────┘  └────────────────┘  │
└─────────────────────────────────────────┘
                  ↓
┌─────────────────────────────────────────┐
│         数据层 (Data Layer)             │
│  ┌──────────────┐  ┌────────────────┐  │
│  │DatasetLoader │  │ResultWriter    │  │
│  │(数据加载)    │  │(结果写入)      │  │
│  └──────────────┘  └────────────────┘  │
└─────────────────────────────────────────┘
                  ↓
┌─────────────────────────────────────────┐
│         模型层 (Domain Layer)           │
│  ┌──────────────┐  ┌────────────────┐  │
│  │BFCLItem      │  │BFCLItemEval    │  │
│  │(测试项)      │  │Result(结果)    │  │
│  └──────────────┘  └────────────────┘  │
└─────────────────────────────────────────┘
```

💡 **设计意图**：清晰的分层架构，每层职责明确，便于维护和扩展。

### 1.1.2 架构特点

| 特点 | 说明 |
|------|------|
| **分层清晰** | 应用层、处理层、推理层、数据层、模型层 |
| **接口抽象** | 通过接口定义核心行为，支持多种实现 |
| **并发处理** | 支持批量并发推理，提升测试效率 |
| **断点续传** | 支持中断后继续执行，避免重复测试 |
| **可扩展** | 易于添加新的推理处理器和评估策略 |

## 1.2 核心组件

### 1.2.1 组件关系图

```
BFCLEvaluator (评估器)
    ├─ BFCLDatasetLoader (数据加载器)
    │   ├─ BFCLDownloader (数据下载器)
    │   └─ ResultWriter (结果写入器)
    ├─ BatchProcessor (批处理器)
    │   └─ ConcurrentBatchExecutor (并发执行器)
    └─ InferenceHandle (推理处理器接口)
        ├─ BFCLInferenceFCHandle (函数调用处理)
        └─ BFCLInferencePlanHandle (计划处理)
```

### 1.2.2 核心组件说明

#### BFCLEvaluator - 评估器

**位置**: `evaluator/BFCLEvaluator.java`

**职责**: 
- 协调整个评估流程
- 加载数据集
- 分发推理任务
- 收集评估结果

**核心方法**:
```java
public class BFCLEvaluator {
    // 评估指定类别
    public void eval(BFCLCategory category, List<String> filterIds);
    
    // 评估（支持跳过已完成项）
    public void eval(BFCLCategory category, List<String> filterIds, boolean skipCompleted);
}
```

#### BFCLDatasetLoader - 数据加载器

**位置**: `loader/BFCLDatasetLoader.java`

**职责**:
- 下载 BFCL 数据集
- 加载测试数据
- 跟踪已完成项
- 写入评估结果

**核心方法**:
```java
public class BFCLDatasetLoader {
    // 加载全部数据
    public List<BFCLFileInfo> load(BFCLCategory category);
    
    // 加载未完成数据（断点续传）
    public List<BFCLFileInfo> loadUncompleted(BFCLCategory category);
    
    // 写入结果
    public void writeResultToFile(String fileName, String category, BFCLItemEvalResult result);
}
```

#### BatchProcessor - 批处理器

**位置**: `processor/BatchProcessor.java`

**职责**:
- 将数据分批处理
- 并发执行批次
- 跟踪处理进度
- 提供进度反馈

**核心方法**:
```java
public class BatchProcessor<T, R> {
    // 处理数据列表
    public void process(List<T> items);
}
```

#### InferenceHandle - 推理处理器

**位置**: `inference/InferenceHandle.java`

**职责**:
- 定义推理处理接口
- 支持多种推理策略

**核心接口**:
```java
public interface InferenceHandle<T, R> {
    R handle(T item);
}
```

### 1.2.3 数据模型组件

#### BFCLItem - 测试项

**位置**: `domain/BFCLItem.java`

**说明**: 表示一个 BFCL 测试项，包含问题和函数定义

```java
public class BFCLItem {
    public String id;                          // 测试项 ID
    public List<List<Message>> question;       // 问题（多轮对话）
    public List<FunctionDefinition> function;  // 函数定义
}
```

#### BFCLItemEvalResult - 评估结果

**位置**: `domain/BFCLItemEvalResult.java`

**说明**: 表示一个测试项的评估结果

```java
public class BFCLItemEvalResult {
    public String id;                          // 测试项 ID
    public List<Map<String, Object>> result;   // 推理结果
    public Integer inputTokenCount;            // 输入 Token 数
    public Integer outputTokenCount;           // 输出 Token 数
    public Double latency;                     // 延迟（秒）
}
```

#### BFCLCategory - 测试类别

**位置**: `common/BFCLCategory.java`

**说明**: 定义 BFCL 测试类别

```java
public enum BFCLCategory {
    NON_LIVE,      // 非实时测试
    LIVE,          // 实时测试
    NON_PYTHON,    // 非 Python 测试
    PYTHON,        // Python 测试
    SINGLE_TURN    // 单轮测试
}
```

## 1.3 数据流

### 1.3.1 评估流程

```
1. 初始化评估器
   ↓
2. 加载数据集
   ├─ 检查本地缓存
   ├─ 下载数据集（如需要）
   └─ 解析 JSON Lines 文件
   ↓
3. 过滤测试项
   ├─ 按类别过滤
   ├─ 按 ID 过滤（可选）
   └─ 跳过已完成项（可选）
   ↓
4. 分批处理
   ├─ 将测试项分成批次
   ├─ 并发处理每个批次
   └─ 每个测试项独立推理
   ↓
5. 推理处理
   ├─ 构建 LLM 请求
   ├─ 调用 LLM API
   └─ 解析响应结果
   ↓
6. 结果写入
   ├─ 序列化为 JSON
   └─ 追加写入结果文件
   ↓
7. 进度反馈
   ├─ 显示进度条
   └─ 记录处理统计
```

### 1.3.2 数据流向图

```
BFCL Dataset (JSON Lines)
    ↓
BFCLDatasetLoader.load()
    ↓
List<BFCLItem>
    ↓
BatchProcessor.process()
    ↓
┌─────────────┐
│   Batch 1   │ → InferenceHandle.handle() → BFCLItemEvalResult
├─────────────┤
│   Batch 2   │ → InferenceHandle.handle() → BFCLItemEvalResult
├─────────────┤
│   Batch N   │ → InferenceHandle.handle() → BFCLItemEvalResult
└─────────────┘
    ↓
ResultWriter.writeResultToFile()
    ↓
Result Files (JSON Lines)
```

### 1.3.3 并发处理流程

```
主线程
    ↓
创建批处理器
    ↓
分割数据为批次
    ↓
创建并发执行器
    ↓
提交批次任务 → ┌─ 线程1: 处理 Batch 1
               ├─ 线程2: 处理 Batch 2
               ├─ 线程3: 处理 Batch 3
               └─ 线程N: 处理 Batch N
    ↓
等待所有批次完成
    ↓
关闭执行器
```

## 1.4 设计模式

### 1.4.1 策略模式 (Strategy Pattern)

**应用**: `InferenceHandle` 接口

```java
// 策略接口
public interface InferenceHandle<T, R> {
    R handle(T item);
}

// 具体策略 1: 函数调用处理
public class BFCLInferenceFCHandle extends BFCLInferenceHandle {
    @Override
    protected BFCLItemEvalResult invoke(String id, List<Message> messages, List<Tool> tools) {
        // 函数调用推理实现
    }
}

// 具体策略 2: 计划处理
public class BFCLInferencePlanHandle extends BFCLInferenceHandle {
    @Override
    protected BFCLItemEvalResult invoke(String id, List<Message> messages, List<Tool> tools) {
        // 计划推理实现
    }
}
```

💡 **优势**: 支持灵活切换不同的推理策略，易于扩展新的推理方式。

### 1.4.2 模板方法模式 (Template Method Pattern)

**应用**: `BFCLInferenceHandle` 抽象类

```java
public abstract class BFCLInferenceHandle implements InferenceHandle<BFCLItem, BFCLItemEvalResult> {
    
    // 模板方法：定义算法骨架
    @Override
    public BFCLItemEvalResult handle(BFCLItem item) {
        // 1. 准备消息
        List<Message> messages = prepareMessages(item);
        
        // 2. 准备工具
        List<Tool> tools = prepareTools(item);
        
        // 3. 调用推理（由子类实现）
        BFCLItemEvalResult result = invoke(item.id, messages, tools);
        
        // 4. 后处理
        return postProcess(result);
    }
    
    // 抽象方法：由子类实现具体推理逻辑
    protected abstract BFCLItemEvalResult invoke(String id, List<Message> messages, List<Tool> tools);
}
```

💡 **优势**: 定义统一的推理流程，子类只需实现核心推理逻辑。

### 1.4.3 建造者模式 (Builder Pattern)

**应用**: `BFCLItemEvalResult.of()`

```java
public class BFCLItemEvalResult {
    public static BFCLItemEvalResult of(String id,
                                        List<Map<String, Object>> result,
                                        Integer inputTokenCount, 
                                        Integer outputTokenCount,
                                        Double latency) {
        BFCLItemEvalResult agentResult = new BFCLItemEvalResult();
        agentResult.id = id;
        agentResult.result = result;
        agentResult.inputTokenCount = inputTokenCount;
        agentResult.outputTokenCount = outputTokenCount;
        agentResult.latency = latency;
        return agentResult;
    }
}
```

💡 **优势**: 简化对象创建，提供清晰的构造接口。

### 1.4.4 生产者-消费者模式 (Producer-Consumer Pattern)

**应用**: `BatchProcessor` 和 `ConcurrentBatchExecutor`

```java
public class BatchProcessor<T, R> {
    public void process(List<T> items) {
        // 分割为批次（生产者）
        List<List<T>> batches = splitIntoBatches(items);
        
        // 创建任务
        List<Runnable> tasks = batches.stream()
            .map(batch -> () -> processBatch(batch))
            .toList();
        
        // 并发执行（消费者）
        ConcurrentBatchExecutor executor = ConcurrentBatchExecutor.create(threadPoolSize);
        executor.execute(tasks);
    }
}
```

💡 **优势**: 实现高效的并发处理，充分利用多核 CPU。

## 1.5 架构图解

### 1.5.1 组件交互图

```
┌─────────────────────────────────────────────────────────┐
│                    BFCLEvaluator                        │
│                                                         │
│  1. eval(category, filterIds)                          │
│     ↓                                                  │
│  2. datasetLoader.load(category)                       │
│     ↓                                                  │
│  3. batchProcessor.process(items)                      │
│     ↓                                                  │
│  4. For each item:                                     │
│     ├─ inferenceHandle.handle(item)                   │
│     └─ datasetLoader.writeResult(item, result)        │
└─────────────────────────────────────────────────────────┘
```

### 1.5.2 类图

```
┌─────────────────┐
│ BFCLEvaluator   │
├─────────────────┤
│ - datasetLoader │
│ - inferenceHandle│
│ - batchProcessor │
├─────────────────┤
│ + eval()        │
└────────┬────────┘
         │ uses
         ↓
┌─────────────────┐      ┌─────────────────┐
│BatchProcessor   │      │InferenceHandle  │
├─────────────────┤      ├─────────────────┤
│ - batchSize     │      ├─────────────────┤
│ - threadPoolSize│      │ + handle()      │
├─────────────────┤      └────────┬────────┘
│ + process()     │               │ implements
└────────┬────────┘               ↓
         │ uses          ┌─────────────────┐
         ↓               │BFCLInference    │
┌─────────────────┐      │Handle           │
│ConcurrentBatch  │      ├─────────────────┤
│Executor         │      │ + handle()      │
├─────────────────┤      │ # invoke()      │
│ - threadPoolSize│      └────────┬────────┘
├─────────────────┤               │ extends
│ + execute()     │               ↓
│ + shutdown()    │      ┌─────────────────┐
└─────────────────┘      │BFCLInferenceFC  │
                         │Handle           │
                         ├─────────────────┤
                         │ - llmProvider   │
                         ├─────────────────┤
                         │ # invoke()      │
                         └─────────────────┘
```

```
User          BFCLEvaluator    DatasetLoader    BatchProcessor    InferenceHandle
  │                │                │                │                │
```
