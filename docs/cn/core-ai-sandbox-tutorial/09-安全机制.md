## 9.1 安全架构概述

### 9.1.1 安全层次模型

```
┌─────────────────────────────────────────┐
│ Layer 4: 应用层安全                     │
│ - 路径验证                              │
│ - 输入验证                              │
│ - 大小限制                              │
├─────────────────────────────────────────┤
│ Layer 3: 进程层安全                     │
│ - 环境变量控制                          │
│ - 超时控制                              │
│ - 输出截断                              │
├─────────────────────────────────────────┤
│ Layer 2: 用户层安全                     │
│ - 非 root 用户 (UID 1001)              │
│ - 最小权限原则                          │
│ - 文件权限控制                          │
├─────────────────────────────────────────┤
│ Layer 1: 容器层安全                     │
│ - 容器隔离                              │
│ - 资源限制 (CPU/Memory)                │
│ - 网络隔离                              │
│ - 只读文件系统                          │
└─────────────────────────────────────────┘
```

💡 **深度防御**: 多层安全机制，即使一层被突破，其他层仍能提供保护。

### 9.1.2 安全原则

| 原则 | 说明 |
|------|------|
| **最小权限** | 只授予完成任务所需的最小权限 |
| **深度防御** | 多层安全机制，不依赖单一防护 |
| **默认拒绝** | 默认禁止所有操作，明确允许特定操作 |
| **隔离执行** | 在隔离环境中执行不可信代码 |
| **资源限制** | 限制资源使用，防止拒绝服务 |

## 9.4 路径安全

### 9.4.1 路径验证机制

**位置**: `main.go:879-914`

```go
// 基础路径清理
func resolvePath(requested string) string {
    if !filepath.IsAbs(requested) {
        requested = filepath.Join(workspaceDir, requested)
    }
    return filepath.Clean(requested)
}

// 下载路径验证（更严格）
func resolveDownloadPath(requested string) (string, error) {
    cleaned := resolvePath(requested)
    
    // 解析符号链接
    resolved, err := filepath.EvalSymlinks(cleaned)
    if err != nil {
        if os.IsNotExist(err) {
            return "", err
        }
        return "", fmt.Errorf("failed to resolve path: %w", err)
    }
    
    // 检查是否在允许的根目录内
    allowedRoots := []string{workspaceDir, os.TempDir()}
    for _, root := range allowedRoots {
        rootResolved, err := filepath.EvalSymlinks(root)
        if err != nil {
            rootResolved = filepath.Clean(root)
        }
        if isPathWithin(resolved, rootResolved) {
            return resolved, nil
        }
    }
    
    return "", fmt.Errorf("path is outside allowed directories")
}

// 检查路径是否在根目录内
func isPathWithin(path, root string) bool {
    rel, err := filepath.Rel(root, path)
    if err != nil {
        return false
    }
    return rel == "." || (rel != ".." && !strings.HasPrefix(rel, ".."+string(os.PathSeparator)))
}
```

💡 **安全检查**:
1. **路径清理**: 移除 `.`、`..`、多余的 `/`
2. **符号链接解析**: 防止通过符号链接逃逸
3. **根目录检查**: 确保路径在 `/workspace` 或 `/tmp` 内
4. **相对路径检查**: 防止 `../` 目录遍历

### 9.4.2 攻击向量防护

```bash

# 攻击 2: 编码绕过

# 攻击 3: 符号链接

# 400 Bad Request: path is outside allowed directories

# 攻击 4: 绝对路径

# 攻击 5: 双重编码

# 400 Bad Request: path is outside allowed directories
```

## 9.5 环境变量控制

### 9.5.1 最小化环境变量

**位置**: `main.go:1066-1090`

```go
func minimalEnv() []string {
    // 继承父进程环境
    parent := os.Environ()
    
    // 覆盖关键环境变量
    overrides := map[string]string{
        "PATH":                    "/usr/local/bin:/usr/bin:/bin",
        "HOME":                    "/tmp",
        "LANG":                    "en_US.UTF-8",
        "PYTHONIOENCODING":        "utf-8",
        "PYTHONDONTWRITEBYTECODE": "1",
        "PIP_USER":                "1",
    }
    
    result := make([]string, 0, len(parent)+len(overrides))
    for _, e := range parent {
        key, _, found := strings.Cut(e, "=")
        if found && overrides[key] != "" {
            continue  // 跳过将被覆盖的变量
        }
        result = append(result, e)
    }
    
    for k, v := range overrides {
        result = append(result, k+"="+v)
    }
    
    return result
}
```

💡 **环境变量策略**:
- **限制 PATH**: 只包含必要的系统目录
- **安全 HOME**: 设置为 `/tmp`，防止访问用户主目录
- **移除敏感变量**: 如 `API_KEY`、`SECRET` 等（如果父进程有）
- **Python 安全**: 禁用字节码缓存，使用用户级安装

```go
// POST /ocg/callback/*
func handleOcgCallbackProxy(w http.ResponseWriter, r *http.Request) {
    if r.Method != http.MethodPost {
        http.Error(w, "method not allowed", http.StatusMethodNotAllowed)
        return
    }
    
    // 代理到本地服务
    targetURL := "http://127.0.0.1:3457" + r.URL.RequestURI()
    
    // 限制请求体大小
    body, err := io.ReadAll(io.LimitReader(r.Body, 2<<20))  // 2MB
    if err != nil {
        http.Error(w, "failed to read callback body: "+err.Error(), http.StatusBadRequest)
        return
    }
    
    // 转发请求
    req, err := http.NewRequestWithContext(r.Context(), http.MethodPost, targetURL, bytes.NewReader(body))
    if err != nil {
        http.Error(w, "failed to create callback request: "+err.Error(), http.StatusInternalServerError)
        return
    }
    copyHeader(req.Header, r.Header)
    
    resp, err := http.DefaultClient.Do(req)
    if err != nil {
        http.Error(w, "failed to proxy OCG callback: "+err.Error(), http.StatusBadGateway)
        return
    }
    defer resp.Body.Close()
    
    copyHeader(w.Header(), resp.Header)
    w.WriteHeader(resp.StatusCode)
    io.Copy(w, resp.Body)
}
```

💡 **回调代理安全**:
- 只允许 POST 请求
- 限制请求体大小（2MB）
- 只能访问本地服务（127.0.0.1:3457）
- 转发请求头（但受控）

```go
        }
        log.Printf("request completed: method=%s path=%s remote=%s status=%d bytes=%d durationMs=%d", 
            r.Method, path, r.RemoteAddr, status, wrapped.bytes, time.Since(start).Milliseconds())
    })
}
```

💡 **审计日志**:
- 记录所有 HTTP 请求
- 记录请求方法、路径、来源
- 记录响应状态、大小、耗时
- 便于安全审计和问题排查

### 9.9.2 工具执行日志

```go
// 工具执行日志
log.Printf("tool executed: tool=%s duration=%dms status=%s", tool, duration, status)

// MCP 进程日志
log.Printf("[mcp:%s] started: command=%s args=%v pid=%d", id, command, args, pid)
log.Printf("[mcp:%s stderr] %s", id, line)

// 文件操作日志
log.Printf("file uploaded: path=%s, size=%d", safePath, len(body))
log.Printf("snapshot captured: files=%d", count)
```

💡 **操作日志**:
- 工具执行记录
- MCP 进程管理
- 文件上传/下载
- 快照操作

### 9.9.3 审计日志分析

```bash
# 查看失败请求
```

## 9.10 安全最佳实践

### 9.10.1 部署安全

✅ **推荐**:
```yaml
# Kubernetes 安全配置
securityContext:
  runAsNonRoot: true
  runAsUser: 1001
  readOnlyRootFilesystem: true
  allowPrivilegeEscalation: false
  capabilities:
    drop:
      - ALL

# 网络隔离
networkPolicy:
  ingress: []
  egress: []

# 资源限制
resources:
  limits:
    cpu: "2"
    memory: 2Gi
```

❌ **避免**:
```yaml
# ❌ 使用 root 用户
securityContext:
  runAsUser: 0

# ❌ 允许权限提升
securityContext:
  allowPrivilegeEscalation: true

# ❌ 不限制资源
resources: {}
```

### 9.10.2 代码安全

✅ **推荐**:
```bash
# 验证输入
if [ -z "$INPUT" ]; then
    echo "Error: Input required"
    exit 1
fi

# 使用安全路径
SAFE_PATH="/workspace/$INPUT"
if [[ "$SAFE_PATH" != /workspace/* ]]; then
    echo "Error: Invalid path"
    exit 1
fi

# 清理临时文件
trap "rm -f /tmp/tempfile" EXIT
```

❌ **避免**:
```bash
# ❌ 不验证输入
eval "$USER_INPUT"

# ❌ 使用用户输入构造命令
cat "/workspace/$USER_INPUT"

# ❌ 硬编码敏感信息
API_KEY="sk-xxx"
```

### 9.10.3 运行时安全

✅ **推荐**:
```bash
# 1. 定期检查容器状态
docker inspect sandbox | jq '.[0].State'

# 2. 监控资源使用
docker stats sandbox

# 3. 查看安全事件
docker logs sandbox | grep -i "error\|denied\|failed"

# 4. 定期更新镜像
docker pull core-ai-sandbox:latest
```

❌ **避免**:
```bash
# ❌ 不监控容器状态
# ❌ 不查看日志
# ❌ 使用过期镜像
```

## 9.11 常见安全漏洞

### 9.11.1 目录遍历

**漏洞**:
```bash
# 尝试访问 /etc/passwd
curl "http://localhost:8080/files/content?path=/workspace/../../../etc/passwd"
```

**防护**:
- 路径清理（`filepath.Clean`）
- 符号链接解析（`filepath.EvalSymlinks`）
- 根目录检查（`isPathWithin`）

**测试**:
```bash
# 所有目录遍历尝试都应该失败
curl -I "http://localhost:8080/files/content?path=/workspace/../etc/passwd"
# 400 Bad Request

curl -I "http://localhost:8080/files/content?path=/workspace/%2e%2e/etc/passwd"
# 400 Bad Request
```

### 9.11.2 命令注入

**漏洞**:
```bash
# 尝试执行恶意命令
curl -X POST http://localhost:8080/execute \
  -d '{"tool": "run_bash_command", "arguments": "{\"command\": \"ls; rm -rf /\"}"}'
```

**防护**:
- 超时控制
- 非 root 用户
- 资源限制
- 只读文件系统

**测试**:
```bash
# 命令会在受限环境中执行
# 即使包含恶意命令，也无法造成严重损害
```

### 9.11.3 符号链接攻击

**漏洞**:
```bash
# 创建指向敏感文件的符号链接
docker exec sandbox ln -s /etc/passwd /workspace/link
curl "http://localhost:8080/files/content?path=/workspace/link"
```

**防护**:
- 下载时解析符号链接（`filepath.EvalSymlinks`）
- 检查解析后的路径是否在允许范围内

**测试**:
```bash
docker exec sandbox ln -s /etc/passwd /workspace/link
curl -I "http://localhost:8080/files/content?path=/workspace/link"
# 400 Bad Request: path is outside allowed directories
```

### 9.11.4 资源耗尽

**漏洞**:
```bash
# Fork bomb
curl -X POST http://localhost:8080/execute \
  -d '{"tool": "run_bash_command", "arguments": "{\"command\": \":(){ :|:& };:\"}"}'

# 内存耗尽
curl -X POST http://localhost:8080/execute \
  -d '{"tool": "run_python_script", "arguments": "{\"code\": \"x = [1] * 10**10\"}"}'
```

**防护**:
- 超时控制
- 内存限制
- PID 限制
- 输出截断

**测试**:
```bash
# Fork bomb 会被 PID 限制阻止
# 内存耗尽会被 OOM killer 杀死
# 都不会影响宿主机
```
