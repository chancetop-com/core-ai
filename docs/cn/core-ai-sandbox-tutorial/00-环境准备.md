## 0.1 系统要求

### 硬件要求

| 配置 | 最低要求 | 推荐配置 |
|------|---------|---------|
| **CPU** | 2 核 | 4 核+ |
| **内存** | 4 GB | 8 GB+ |
| **磁盘** | 10 GB | 20 GB+ |

💡 **说明**: sandbox-runtime 本身很轻量，但需要运行 Docker 容器，建议预留足够资源。

### 操作系统

- ✅ Linux (Ubuntu 20.04+, CentOS 7+)
- ✅ macOS (10.15+)
- ✅ Windows 10/11 (需要 WSL2)

⚠️ **注意**: Windows 用户必须使用 WSL2，不支持原生 Windows 开发。

## 0.2 Go 环境安装

### 0.2.1 安装 Go 1.22+

#### macOS

```bash
# 使用 Homebrew
brew install go

# 验证版本
go version
# 应输出: go version go1.22.x darwin/amd64 或 darwin/arm64
```

#### Ubuntu/Debian

```bash
# 添加 Go 仓库
sudo add-apt-repository ppa:longsleep/golang-backports
sudo apt update
sudo apt install golang-go

# 验证版本
go version
```

#### CentOS/RHEL

```bash
# 下载 Go
wget https://go.dev/dl/go1.22.0.linux-amd64.tar.gz

# 解压到 /usr/local
sudo tar -C /usr/local -xzf go1.22.0.linux-amd64.tar.gz

# 配置环境变量
echo 'export PATH=$PATH:/usr/local/go/bin' >> ~/.bashrc
source ~/.bashrc

# 验证版本
go version
```

#### Windows (WSL2)

```bash
# 在 WSL2 中执行
# 参考 Ubuntu 安装步骤
```

### 0.2.2 配置 Go 环境

```bash
# 设置 GOPROXY（国内加速）
go env -w GOPROXY=https://goproxy.cn,direct

# 设置 GO111MODULE
go env -w GO111MODULE=on

# 查看配置
go env
```

### 0.2.3 安装 Go 工具

```bash
# 安装常用工具
go install golang.org/x/tools/gopls@latest
go install github.com/go-delve/delve/cmd/dlv@latest
go install honnef.co/go/tools/cmd/staticcheck@latest

# 验证安装
gopls version
dlv version
staticcheck --version
```

## 0.3 Docker 环境安装

### 0.3.1 安装 Docker

#### macOS

```bash
# 使用 Homebrew
brew install --cask docker

# 启动 Docker Desktop
open -a Docker
```

#### Ubuntu/Debian

```bash
# 安装依赖
sudo apt-get update
sudo apt-get install \
    ca-certificates \
    curl \
    gnupg \
    lsb-release

# 添加 Docker GPG key
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg

# 添加 Docker 仓库
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu \
  $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# 安装 Docker
sudo apt-get update
sudo apt-get install docker-ce docker-ce-cli containerd.io docker-compose-plugin

# 添加用户到 docker 组（避免每次 sudo）
sudo usermod -aG docker $USER
newgrp docker

# 验证安装
docker --version
docker-compose --version
```

#### CentOS/RHEL

```bash
# 安装依赖
sudo yum install -y yum-utils

# 添加 Docker 仓库
sudo yum-config-manager --add-repo https://download.docker.com/linux/centos/docker-ce.repo

# 安装 Docker
sudo yum install docker-ce docker-ce-cli containerd.io docker-compose-plugin

# 启动 Docker
sudo systemctl start docker
sudo systemctl enable docker

# 添加用户到 docker 组
sudo usermod -aG docker $USER
newgrp docker

# 验证安装
docker --version
```

### 0.3.2 验证 Docker

```bash
# 运行测试容器
docker run hello-world

# 应输出:
# Hello from Docker!
# This message shows that your installation appears to be working correctly.
```

### 0.3.3 配置 Docker 镜像加速（可选）

```bash
# 创建或编辑 daemon.json
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<-'EOF'
{
  "registry-mirrors": [
    "https://docker.mirrors.ustc.edu.cn",
    "https://hub-mirror.c.163.com"
  ]
}
EOF

# 重启 Docker
sudo systemctl daemon-reload
sudo systemctl restart docker
```

## 0.4 IDE 配置

### 0.4.1 VS Code 配置

#### 安装扩展

```bash
# 安装 Go 扩展
code --install-extension golang.go

# 安装 Docker 扩展
code --install-extension ms-azuretools.vscode-docker

# 安装 GitLens 扩展
code --install-extension eamodio.gitlens
```

#### 配置 settings.json

```json
{
  "go.useLanguageServer": true,
  "go.gopath": "/Users/username/go",
  "go.toolsManagement.autoUpdate": true,
  "go.lintTool": "golangci-lint",
  "go.lintFlags": [
    "--fast"
  ],
  "go.formatTool": "goimports",
  "go.docsTool": "gopls",
  "[go]": {
    "editor.formatOnSave": true,
    "editor.codeActionsOnSave": {
      "source.organizeImports": true
    }
  }
}
```

### 0.4.2 GoLand 配置

#### 安装插件

1. 打开 GoLand
2. Preferences → Plugins
3. 搜索并安装:
   - **Go** (内置)
   - **Docker**
   - **GitToolBox**

#### 配置 Go SDK

1. Preferences → Go → GOROOT
2. 选择 Go 1.22+ 安装路径
3. 点击 Apply

## 0.5 项目结构

### 0.5.1 源码结构

```
core-ai-sandbox-runtime/
├── main.go                 # HTTP 服务器主程序
├── mcp.go                  # MCP 进程管理器
├── snapshot.go             # 快照功能
├── async_test.go           # 异步任务测试
├── python_test.go          # Python 执行测试
├── snapshot_test.go        # 快照测试
├── Dockerfile              # Docker 镜像构建
├── go.mod                  # Go 模块定义
└── VERSION                 # 版本号
```

### 0.5.2 核心文件说明

| 文件 | 行数 | 说明 |
|------|------|------|
| **main.go** | ~1137 | HTTP 服务器、工具执行器、文件操作 |
| **mcp.go** | ~507 | MCP 进程管理、JSON-RPC 通信 |
| **snapshot.go** | ~367 | 快照捕获和恢复 |

💡 **提示**: 整个项目只有 3 个核心文件，代码结构清晰，易于理解。

## 0.6 验证环境

### 0.6.1 环境检查清单

```bash
# 创建检查脚本
cat > check-env.sh << 'EOF'
#!/bin/bash

echo "🔍 检查开发环境..."
echo

# 检查 Go
echo "1️⃣  Go 版本:"
go version || echo "❌ Go 未安装"

# 检查 Docker
echo
echo "2️⃣  Docker 版本:"
docker --version || echo "❌ Docker 未安装"

# 检查 Docker Compose
echo
echo "3️⃣  Docker Compose 版本:"
docker-compose --version || echo "❌ Docker Compose 未安装"

# 检查 Docker 运行状态
echo
echo "4️⃣  Docker 运行状态:"
docker ps > /dev/null 2>&1 && echo "✅ Docker 正在运行" || echo "❌ Docker 未运行"

# 检查 Go 工具
echo
echo "5️⃣  Go 工具:"
which gopls > /dev/null && echo "✅ gopls 已安装" || echo "❌ gopls 未安装"
which dlv > /dev/null && echo "✅ dlv 已安装" || echo "❌ dlv 未安装"
which staticcheck > /dev/null && echo "✅ staticcheck 已安装" || echo "❌ staticcheck 未安装"

echo
echo "✅ 环境检查完成!"
EOF

chmod +x check-env.sh
./check-env.sh
```
