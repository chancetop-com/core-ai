## 5.1 快照系统概述

### 5.1.1 什么是快照

**快照 (Snapshot)** 是沙箱在某一时刻的完整状态备份，包含：

- 📁 **文件系统**: `/workspace`、`/tmp`、`/skill` 目录的所有文件
- 📝 **元数据**: 创建时间、文件数量、运行时版本
- 🔒 **完整性**: SHA256 校验和确保数据完整

### 5.1.2 快照的用途

| 用途 | 说明 |
|------|------|
| **状态保存** | 保存工作进度，避免丢失 |
| **环境复制** | 快速复制相同的环境到另一个沙箱 |
| **故障恢复** | 从错误中恢复到之前的状态 |
| **版本管理** | 保存多个版本，随时切换 |
| **环境分享** | 将环境分享给其他人使用 |

## 5.2 捕获快照

### 5.2.1 HTTP API

**位置**: `snapshot.go:295-319`

```go
// POST /snapshot
func handleSnapshot(w http.ResponseWriter, r *http.Request) {
    if r.Method != http.MethodPost {
        http.Error(w, "method not allowed", http.StatusMethodNotAllowed)
        return
    }
    
    roots := liveSnapshotRoots()
    
    // 1. 预先检查容量限制
    entries, err := collectSnapshotEntries(roots)
    if err != nil {
        writeSnapshotError(w, http.StatusRequestEntityTooLarge, err.Error())
        return
    }
    
    // 2. 设置响应头
    w.Header().Set("Content-Type", "application/gzip")
    w.Header().Set("X-Snapshot-File-Count", strconv.Itoa(len(entries)))
    w.Header().Set("X-Snapshot-Runtime-Version", runtimeVersion)
    
    // 3. 构建并流式传输快照
    count, err := buildSnapshotArchive(w, roots)
    if err != nil {
        // 流式传输中断，中止连接
        panic(http.ErrAbortHandler)
    }
    
    log.Printf("snapshot captured: files=%d", count)
}
```

💡 **关键点**:
- **预检查**: 在开始传输前检查容量限制，避免传输到一半失败
- **流式传输**: 使用 `http.ResponseWriter` 直接流式写入，不缓存整个快照
- **中止机制**: 如果传输过程中出错，使用 `panic(http.ErrAbortHandler)` 中止连接

### 5.2.2 收集文件条目

**位置**: `snapshot.go:91-138`

```go
func collectSnapshotEntries(roots []snapshotRoot) ([]snapshotEntry, error) {
    var entries []snapshotEntry
    var totalSize int64
    
    for _, root := range roots {
        // 检查目录是否存在
        if _, err := os.Stat(root.Target); os.IsNotExist(err) {
            continue
        }
        
        // 遍历目录
        err := filepath.Walk(root.Target, func(path string, info os.FileInfo, err error) error {
            if err != nil {
                log.Printf("snapshot walk skip: path=%s err=%v", path, err)
                return nil
            }
            
            rel, relErr := filepath.Rel(root.Target, path)
            if relErr != nil || rel == "." {
                return nil
            }
            
            // 排除特殊路径
            if isSnapshotExcluded(rel) {
                if info.IsDir() {
                    return filepath.SkipDir
                }
                return nil
            }
            
            // 只处理目录和常规文件
            if info.IsDir() {
                return nil
            }
            if !info.Mode().IsRegular() {
                return nil  // 跳过符号链接、套接字等
            }
            
            // 检查单文件大小
            if info.Size() > maxSnapshotFileSize {
                log.Printf("snapshot skip oversized file: path=%s size=%d", path, info.Size())
                return nil
            }
            
            // 累加总大小
            totalSize += info.Size()
            if totalSize > maxSnapshotTotalSize {
                return fmt.Errorf("snapshot exceeds max total size (%d bytes)", maxSnapshotTotalSize)
            }
            
            // 添加到条目列表
            entries = append(entries, snapshotEntry{
                absPath: path,
                archiveName: root.ArchivePrefix + "/" + filepath.ToSlash(rel),
                info: info,
            })
            
            // 检查文件数量限制
            if len(entries) > maxSnapshotFiles {
                return fmt.Errorf("snapshot exceeds max file count (%d)", maxSnapshotFiles)
            }
            
            return nil
        })
        
        if err != nil {
            return nil, err
        }
    }
    
    return entries, nil
}
```

💡 **过滤规则**:
- **排除特殊路径**: `__pycache__`、`.X11-unix`、socket 文件等
- **只处理常规文件**: 跳过符号链接、套接字、设备文件
- **单文件大小限制**: 200 MB
- **总大小限制**: 2 GB
- **文件数量限制**: 10,000 个

### 5.2.3 构建归档

**位置**: `snapshot.go:142-197`

```go
func buildSnapshotArchive(w io.Writer, roots []snapshotRoot) (int, error) {
    entries, err := collectSnapshotEntries(roots)
    if err != nil {
        return 0, err
    }
    
    // 创建 gzip 压缩器
    gw := gzip.NewWriter(w)
    tw := tar.NewWriter(gw)
    
    // 1. 创建 manifest.json
    manifest := snapshotManifest{
        Format:         snapshotFormat,
        CreatedAt:      time.Now().UTC().Format(time.RFC3339),
        RuntimeVersion: runtimeVersion,
        FileCount:      len(entries),
        Roots:          roots,
    }
    manifestBytes, err := json.Marshal(manifest)
    if err != nil {
        return 0, err
    }
    
    // 写入 manifest
    if err := tw.WriteHeader(&tar.Header{
        Name: snapshotManifestName,
        Mode: 0644,
        Size: int64(len(manifestBytes)),
        Typeflag: tar.TypeReg,
    }); err != nil {
        return 0, err
    }
    if _, err := tw.Write(manifestBytes); err != nil {
        return 0, err
    }
    
    // 2. 写入所有文件
    for _, e := range entries {
        hdr := &tar.Header{
            Name:     e.archiveName,
            Mode:     int64(e.info.Mode().Perm()),
            Size:     e.info.Size(),
            ModTime:  e.info.ModTime(),
            Typeflag: tar.TypeReg,
        }
        if err := tw.WriteHeader(hdr); err != nil {
            return 0, err
        }
        
        f, err := os.Open(e.absPath)
        if err != nil {
            return 0, err
        }
        
        // 使用 CopyN 确保精确复制
        if _, err := io.CopyN(tw, f, e.info.Size()); err != nil {
            f.Close()
            return 0, fmt.Errorf("pack %s: %w", e.absPath, err)
        }
        f.Close()
    }
    
    // 3. 关闭写入器
    if err := tw.Close(); err != nil {
        return 0, err
    }
    if err := gw.Close(); err != nil {
        return 0, err
    }
    
    return len(entries), nil
}
```

💡 **归档结构**:
```
snapshot.tar.gz
├── manifest.json          # 元数据
├── roots/workspace/       # /workspace 目录的文件
│   ├── file1.txt
│   └── subdir/
│       └── file2.txt
├── roots/tmp/             # /tmp 目录的文件
│   └── temp.log
└── roots/skill/           # /skill 目录的文件
    └── my-skill/
        └── script.sh
```

## 5.3 恢复快照

### 5.3.1 HTTP API

**位置**: `snapshot.go:321-366`

```go
// POST /snapshot/restore
func handleSnapshotRestore(w http.ResponseWriter, r *http.Request) {
    if r.Method != http.MethodPost {
        http.Error(w, "method not allowed", http.StatusMethodNotAllowed)
        return
    }
    
    // 1. 获取期望的 SHA256
    expectedSha := strings.ToLower(strings.TrimSpace(r.Header.Get("X-Snapshot-Sha256")))
    if expectedSha == "" {
        writeSnapshotError(w, http.StatusBadRequest, "X-Snapshot-Sha256 header is required")
        return
    }
    
    // 2. 创建临时文件
    tmp, err := os.CreateTemp(os.TempDir(), "core-ai-snapshot-*.tmp")
    if err != nil {
        writeSnapshotError(w, http.StatusInternalServerError, 
            "failed to create staging file: "+err.Error())
        return
    }
    defer os.Remove(tmp.Name())
    defer tmp.Close()
    
    // 3. 流式接收并计算 SHA256
    hasher := sha256.New()
    n, err := io.Copy(io.MultiWriter(tmp, hasher), 
        io.LimitReader(r.Body, maxRestoreArchiveSize+1))
    if err != nil {
        writeSnapshotError(w, http.StatusBadRequest, "failed to read body: "+err.Error())
        return
    }
    
    // 4. 检查大小限制
    if n > maxRestoreArchiveSize {
        writeSnapshotError(w, http.StatusRequestEntityTooLarge, 
            fmt.Sprintf("archive exceeds max size (%d bytes)", maxRestoreArchiveSize))
        return
    }
    
    // 5. 验证 SHA256
    actualSha := hex.EncodeToString(hasher.Sum(nil))
    if actualSha != expectedSha {
        writeSnapshotError(w, http.StatusBadRequest, "sha256 mismatch")
        return
    }
    
    // 6. 解压恢复
    if _, err := tmp.Seek(0, io.SeekStart); err != nil {
        writeSnapshotError(w, http.StatusInternalServerError, err.Error())
        return
    }
    
    restored, err := restoreSnapshotArchive(tmp, liveSnapshotRoots())
    if err != nil {
        writeSnapshotError(w, http.StatusBadRequest, "restore failed: "+err.Error())
        return
    }
    
    log.Printf("snapshot restored: files=%d, size=%d", restored, n)
    w.Header().Set("Content-Type", "application/json")
    json.NewEncoder(w).Encode(map[string]any{
        "status": "ok",
        "files": restored,
    })
}
```

💡 **关键点**:
- **SHA256 验证**: 必须提供 `X-Snapshot-Sha256` Header，确保数据完整性
- **临时文件**: 先写入临时文件，验证后再解压
- **大小限制**: 压缩后最大 500 MB
- **流式处理**: 边接收边计算 SHA256，不缓存整个文件

### 5.3.2 解压恢复

**位置**: `snapshot.go:203-287`

```go
func restoreSnapshotArchive(r io.Reader, roots []snapshotRoot) (int, error) {
    gz, err := gzip.NewReader(r)
    if err != nil {
        return 0, fmt.Errorf("invalid gzip: %w", err)
    }
    defer gz.Close()
    
    tr := tar.NewReader(gz)
    restored := 0
    var totalWritten int64
    
    for {
        hdr, err := tr.Next()
        if err == io.EOF {
            break
        }
        if err != nil {
            return restored, fmt.Errorf("invalid tar: %w", err)
        }
        
        name := filepath.ToSlash(hdr.Name)
        
        // 1. 处理 manifest
        if name == snapshotManifestName {
            var manifest snapshotManifest
            if err := json.NewDecoder(io.LimitReader(tr, 1<<20)).Decode(&manifest); err != nil {
                return restored, fmt.Errorf("invalid manifest: %w", err)
            }
            if !strings.HasPrefix(manifest.Format, "core-ai-sandbox-snapshot/") {
                return restored, fmt.Errorf("unsupported snapshot format: %s", manifest.Format)
            }
            continue
        }
        
        // 2. 跳过符号链接
        if hdr.Typeflag == tar.TypeSymlink || hdr.Typeflag == tar.TypeLink {
            log.Printf("snapshot restore skip link entry: %s", name)
            continue
        }
        
        // 3. 确定目标路径
        var target string
        for _, root := range roots {
            prefix := root.ArchivePrefix + "/"
            if strings.HasPrefix(name, prefix) {
                target = filepath.Join(root.Target, 
                    filepath.FromSlash(strings.TrimPrefix(name, prefix)))
                
                // 安全检查：确保不逃逸
                if !isPathWithin(filepath.Clean(target), filepath.Clean(root.Target)) {
                    return restored, fmt.Errorf("entry escapes root: %s", name)
                }
                break
            }
        }
        
        if target == "" {
            return restored, fmt.Errorf("entry outside whitelisted roots: %s", name)
        }
        
        // 4. 恢复文件
        switch hdr.Typeflag {
        case tar.TypeDir:
            if err := os.MkdirAll(target, os.FileMode(hdr.Mode).Perm()|0700); err != nil {
                return restored, err
            }
        
        case tar.TypeReg:
            // 检查文件数量限制
            if restored >= maxSnapshotFiles {
                return restored, fmt.Errorf("archive exceeds max file count (%d)", maxSnapshotFiles)
            }
            
            // 创建目录
            if err := os.MkdirAll(filepath.Dir(target), 0755); err != nil {
                return restored, err
            }
            
            // 写入文件
            f, err := os.OpenFile(target, 
                os.O_CREATE|os.O_WRONLY|os.O_TRUNC, 
                os.FileMode(hdr.Mode).Perm())
            if err != nil {
                return restored, err
            }
            
            // 限制写入大小，防止 tar 炸弹
            remaining := maxSnapshotTotalSize - totalWritten
            written, err := io.Copy(f, io.LimitReader(tr, remaining+1))
            if err != nil {
                f.Close()
                return restored, err
            }
            f.Close()
            
            // 检查是否超出限制
            if written > remaining {
                return restored, fmt.Errorf("archive exceeds max uncompressed size (%d bytes)", 
                    maxSnapshotTotalSize)
            }
            
            totalWritten += written
            restored++
        
        default:
            log.Printf("snapshot restore skip entry type %d: %s", hdr.Typeflag, name)
        }
    }
    
    return restored, nil
}
```

💡 **安全措施**:
- **路径逃逸检查**: 确保文件不会写到白名单目录之外
- **符号链接跳过**: 不恢复符号链接，防止安全问题
- **大小限制**: 解压后最大 2 GB，防止 tar 炸弹
- **格式验证**: 只支持 `core-ai-sandbox-snapshot/` 格式

## 5.4 快照格式

### 5.4.1 Manifest 结构

```go
type snapshotManifest struct {
    Format         string         `json:"format"`           // 格式版本
    CreatedAt      string         `json:"created_at"`       // 创建时间
    RuntimeVersion string         `json:"runtime_version"`  // 运行时版本
    FileCount      int            `json:"file_count"`       // 文件数量
    Roots          []snapshotRoot `json:"roots"`            // 根目录列表
}

type snapshotRoot struct {
    Name          string `json:"name"`            // 名称
    Target        string `json:"target"`          // 实际路径
    ArchivePrefix string `json:"archive_prefix"`  // 归档前缀
}
```

**示例**:
```json
{
  "format": "core-ai-sandbox-snapshot/v1",
  "created_at": "2026-08-31T10:30:00Z",
  "runtime_version": "1.0.0",
  "file_count": 42,
  "roots": [
    {
      "name": "tmp",
      "target": "/tmp",
      "archive_prefix": "roots/tmp"
    },
    {
      "name": "skill",
      "target": "/skill",
      "archive_prefix": "roots/skill"
    },
    {
      "name": "workspace",
      "target": "/workspace",
      "archive_prefix": "roots/workspace"
    }
  ]
}
```

💡 **字段说明**:
- **format**: 快照格式版本，用于向后兼容
- **created_at**: UTC 时间戳，RFC3339 格式
- **runtime_version**: 创建快照的运行时版本
- **file_count**: 包含的文件总数（不含 manifest）
- **roots**: 捕获的根目录列表

### 5.4.2 归档路径映射

| 实际路径 | 归档路径 |
|---------|---------|
| `/workspace/file.txt` | `roots/workspace/file.txt` |
| `/workspace/subdir/file.txt` | `roots/workspace/subdir/file.txt` |
| `/tmp/temp.log` | `roots/tmp/temp.log` |
| `/skill/my-skill/script.sh` | `roots/skill/my-skill/script.sh` |

💡 **说明**: 
- 使用 `roots/` 前缀隔离不同根目录
- 保留原始目录结构
- 使用正斜杠 `/` 保证跨平台兼容

### 5.4.3 排除规则

**位置**: `snapshot.go:61-80`

```go
var snapshotExcludedSegments = map[string]bool{
    ".X11-unix":   true,
    ".ICE-unix":   true,
    "__pycache__": true,
}

func isSnapshotExcluded(relPath string) bool {
    // 排除 socket 文件
    if strings.HasSuffix(relPath, ".sock") {
        return true
    }
    
    // 排除快照临时文件
    if strings.HasPrefix(filepath.Base(relPath), "core-ai-snapshot-") {
        return true
    }
    
    // 排除特定目录
    for _, seg := range strings.Split(relPath, string(os.PathSeparator)) {
        if snapshotExcludedSegments[seg] {
            return true
        }
    }
    
    return false
}
```

💡 **排除内容**:
- `.X11-unix`、`.ICE-unix`: X11 套接字目录
- `__pycache__`: Python 缓存
- `.sock` 文件: Unix 套接字
- `core-ai-snapshot-*`: 快照临时文件

## 5.5 安全机制

### 5.5.1 SHA256 完整性验证

**恢复时必须提供 SHA256**:
```go
expectedSha := strings.ToLower(strings.TrimSpace(r.Header.Get("X-Snapshot-Sha256")))
if expectedSha == "" {
    writeSnapshotError(w, http.StatusBadRequest, "X-Snapshot-Sha256 header is required")
    return
}
```

**验证流程**:
```
1. 接收文件，同时计算 SHA256
2. 比较计算值和期望值
3. 不匹配则拒绝恢复
```

💡 **目的**:
- 防止传输过程中的数据损坏
- 防止恶意篡改快照
- 确保恢复的数据与捕获时一致

### 5.5.2 路径逃逸防护

**位置**: `snapshot.go:244-246`

```go
// 安全检查：确保不逃逸
if !isPathWithin(filepath.Clean(target), filepath.Clean(root.Target)) {
    return restored, fmt.Errorf("entry escapes root: %s", name)
}
```

**检查逻辑**:
```go
func isPathWithin(path, root string) bool {
    rel, err := filepath.Rel(root, path)
    if err != nil {
        return false
    }
    return rel == "." || (rel != ".." && !strings.HasPrefix(rel, ".."+string(os.PathSeparator)))
}
```

💡 **防护**:
- 防止通过 `../` 逃逸到白名单目录外
- 清理路径后再检查
- 拒绝所有逃逸尝试

### 5.5.3 大小限制

| 限制 | 值 | 说明 |
|------|-----|------|
| **单文件大小** | 200 MB | 跳过超过此大小的文件 |
| **总大小（压缩后）** | 500 MB | 拒绝恢复超过此大小的快照 |
| **总大小（解压后）** | 2 GB | 防止 tar 炸弹 |
| **文件数量** | 10,000 | 拒绝超过此数量的快照 |

💡 **目的**:
- 防止内存溢出
- 防止磁盘填满
- 防止 DoS 攻击

### 5.5.4 符号链接处理


💡 **原因**:

## 5.6 实战: 快照管理

### 5.6.1 版本管理脚本

```bash
#!/bin/bash
# snapshot-manager.sh - 快照版本管理工具

set -e

SNAPSHOT_DIR="./snapshots"
mkdir -p "$SNAPSHOT_DIR"

# 捕获快照并保存版本
capture_snapshot() {
    local version=$1
    local timestamp=$(date +%Y%m%d_%H%M%S)
    local filename="snapshot_v${version}_${timestamp}.tar.gz"
    
    echo "Capturing snapshot version $version..."
    curl -s -X POST http://localhost:8080/snapshot \
        -o "$SNAPSHOT_DIR/$filename"
    
    # 计算 SHA256
    local sha=$(shasum -a 256 "$SNAPSHOT_DIR/$filename" | cut -d' ' -f1)
    echo "$sha  $filename" >> "$SNAPSHOT_DIR/checksums.txt"
    
    echo "Saved: $filename"
    echo "SHA256: $sha"
}

# 恢复指定版本
restore_snapshot() {
    local version=$1
    
    # 查找最新版本
    local file=$(ls -t "$SNAPSHOT_DIR"/snapshot_v${version}_*.tar.gz 2>/dev/null | head -1)
    
    if [ -z "$file" ]; then
        echo "Error: Version $version not found"
        exit 1
    fi
    
    echo "Restoring from: $file"
    
    # 获取 SHA256
    local sha=$(grep "$(basename "$file")" "$SNAPSHOT_DIR/checksums.txt" | cut -d' ' -f1)
    
    # 恢复
    curl -s -X POST http://localhost:8080/snapshot/restore \
        -H "X-Snapshot-Sha256: $sha" \
        -H "Content-Type: application/gzip" \
        --data-binary "@$file"
    
    echo ""
    echo "Restored successfully!"
}

# 列出所有版本
list_snapshots() {
    echo "Available snapshots:"
    ls -lh "$SNAPSHOT_DIR"/snapshot_v*.tar.gz 2>/dev/null || echo "No snapshots found"
}

# 清理旧版本（保留最近 N 个）
cleanup_snapshots() {
    local keep=$1
    echo "Keeping last $keep snapshots..."
    
    ls -t "$SNAPSHOT_DIR"/snapshot_v*.tar.gz 2>/dev/null | tail -n +$((keep + 1)) | while read file; do
        echo "Removing: $(basename "$file")"
        rm -f "$file"
        # 从 checksums.txt 中移除
        sed -i '' "/$(basename "$file")/d" "$SNAPSHOT_DIR/checksums.txt" 2>/dev/null || true
    done
}

# 主命令
case "$1" in
    capture)
        capture_snapshot "${2:-latest}"
        ;;
    restore)
        restore_snapshot "$2"
        ;;
    list)
        list_snapshots
        ;;
    cleanup)
        cleanup_snapshots "${2:-5}"
        ;;
    *)
        echo "Usage: $0 {capture|restore|list|cleanup} [version|count]"
        exit 1
        ;;
esac
```

**使用示例**:
```bash
# 捕获快照
./snapshot-manager.sh capture v1
./snapshot-manager.sh capture v2

# 列出所有版本
./snapshot-manager.sh list

# 恢复到 v1
./snapshot-manager.sh restore v1

# 清理，保留最近 3 个
./snapshot-manager.sh cleanup 3
```

```bash
#!/bin/bash

echo "[$(date)] Cleaned up old backups (keeping $MAX_BACKUPS)"
```

```bash
#!/bin/bash
# migrate-environment.sh - 将一个沙箱的环境迁移到另一个

set -e

SOURCE_URL=$1
TARGET_URL=$2

if [ -z "$SOURCE_URL" ] || [ -z "$TARGET_URL" ]; then

    echo "Example: $0 http://sandbox1:8080 http://sandbox2:8080"

# 1. 从源沙箱捕获快照
echo "Step 1: Capturing snapshot from source..."
curl -s -X POST "$SOURCE_URL/snapshot" \
    -o migration.tar.gz

# 2. 计算 SHA256
sha=$(shasum -a 256 migration.tar.gz | cut -d' ' -f1)
echo "Step 2: SHA256: $sha"

# 3. 恢复到目标沙箱
echo "Step 3: Restoring to target..."
curl -s -X POST "$TARGET_URL/snapshot/restore" \
    -H "X-Snapshot-Sha256: $sha" \
    -H "Content-Type: application/gzip" \
    --data-binary @migration.tar.gz

echo ""
echo "Step 4: Migration completed!"

# 清理
rm -f migration.tar.gz
```

## 5.7 常见问题

### 5.7.1 快照过大

**症状**:
```
snapshot exceeds max total size (2147483648 bytes)
```

**原因**:
- 工作目录中有大量文件
- 包含大文件（日志、数据文件等）

**解决方案**:
```bash
# 1. 清理不必要的文件
curl -X POST http://localhost:8080/execute \
  -d '{"tool": "run_bash_command", "arguments": "{\"command\": \"rm -rf /workspace/*.log /workspace/node_modules\"}"}'

# 2. 压缩大文件
curl -X POST http://localhost:8080/execute \
  -d '{"tool": "run_bash_command", "arguments": "{\"command\": \"tar -czf /tmp/archive.tar.gz /workspace/large_dir\"}"}'

# 3. 删除原始文件
curl -X POST http://localhost:8080/execute \
  -d '{"tool": "run_bash_command", "arguments": "{\"command\": \"rm -rf /workspace/large_dir\"}"}'
```

### 5.7.2 SHA256 不匹配

**症状**:
```json
{
  "status": "error",
  "error": "sha256 mismatch"
}
```

**原因**:
- 文件在传输过程中被损坏
- 计算 SHA256 时使用了错误的文件
- 文件被篡改

**解决方案**:
```bash
# 1. 重新计算 SHA256
sha256sum snapshot.tar.gz
# a1b2c3d4e5f6...  snapshot.tar.gz

# 2. 确保使用正确的 SHA256
SHA=$(sha256sum snapshot.tar.gz | cut -d' ' -f1)

# 3. 重新恢复
curl -X POST http://localhost:8080/snapshot/restore \
  -H "X-Snapshot-Sha256: $SHA" \
  -H "Content-Type: application/gzip" \
  --data-binary @snapshot.tar.gz
```

### 5.7.3 恢复失败

**症状**:
```json
{
  "status": "error",
  "error": "entry escapes root: roots/workspace/../../etc/passwd"
}
```

**原因**:
- 快照文件被篡改
- 快照格式不兼容
- 包含恶意路径

**解决方案**:
```bash
# 1. 验证快照完整性
tar -tzf snapshot.tar.gz | grep -E '\.\.\/'
# 如果发现异常路径，快照可能已被篡改

# 2. 使用可信的快照
# 从可靠的来源获取快照

# 3. 检查 manifest
tar -xzf snapshot.tar.gz manifest.json
cat manifest.json | jq .format
# 应该是: "core-ai-sandbox-snapshot/v1"
```

### 5.7.4 恢复后文件权限错误

**症状**: 恢复后文件无法访问

**原因**: 文件权限未正确恢复

**解决方案**:
```bash
# 1. 修复权限
curl -X POST http://localhost:8080/execute \
  -d '{"tool": "run_bash_command", "arguments": "{\"command\": \"chmod -R 755 /workspace\"}"}'

# 2. 修复所有者
curl -X POST http://localhost:8080/execute \
  -d '{"tool": "run_bash_command", "arguments": "{\"command\": \"chown -R sandbox:sandbox /workspace\"}"}'
```

## 5.8 最佳实践

### 5.8.1 快照策略

✅ **推荐**:
- **定期备份**: 每小时/每天自动备份
- **版本管理**: 为重要状态创建版本快照
- **清理旧版本**: 保留最近 N 个版本
- **验证完整性**: 恢复前验证 SHA256

❌ **避免**:
- 频繁创建大快照（消耗资源）
- 不验证就恢复（可能损坏数据）
- 保留过多旧版本（浪费空间）

### 5.8.2 快照内容管理

✅ **推荐**:
```bash
# 1. 排除临时文件
curl -X POST http://localhost:8080/execute \
  -d '{"tool": "run_bash_command", "arguments": "{\"command\": \"rm -rf /workspace/*.tmp /workspace/*.log\"}"}'

# 2. 排除构建产物
curl -X POST http://localhost:8080/execute \
  -d '{"tool": "run_bash_command", "arguments": "{\"command\": \"rm -rf /workspace/node_modules /workspace/dist\"}"}'

# 3. 压缩大文件
curl -X POST http://localhost:8080/execute \
  -d '{"tool": "run_bash_command", "arguments": "{\"command\": \"tar -czf /tmp/data.tar.gz /workspace/data\"}"}'
```

❌ **避免**:
- 快照中包含敏感信息（密码、密钥）
- 快照中包含大文件（>100MB）
- 快照中包含临时文件（日志、缓存）

### 5.8.3 恢复策略

✅ **推荐**:
```bash
# 1. 恢复前备份当前状态
curl -X POST http://localhost:8080/snapshot \
  -o backup_before_restore.tar.gz

# 2. 验证快照完整性
sha256sum snapshot.tar.gz
# 与期望值对比

# 3. 恢复后验证
curl -X POST http://localhost:8080/execute \
  -d '{"tool": "run_bash_command", "arguments": "{\"command\": \"ls -la /workspace\"}"}'
```

❌ **避免**:
- 不备份就恢复（可能丢失数据）
- 不验证就恢复（可能使用损坏的快照）
- 恢复后不检查（可能恢复失败）

### 5.8.4 存储管理

✅ **推荐**:
```bash
# 1. 压缩快照
gzip snapshot.tar
# snapshot.tar.gz

# 2. 移动到外部存储
mv snapshot.tar.gz /backup/snapshots/

# 3. 定期清理
find /backup/snapshots/ -name "*.tar.gz" -mtime +30 -delete
```

❌ **避免**:
- 快照存储在工作目录（会被一起快照）
- 不压缩快照（浪费空间）
- 从不清理旧快照（磁盘满）
