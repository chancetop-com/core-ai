## 8.1 文件操作概述

### 8.1.1 为什么需要文件操作

**沙箱中的文件操作需求**:
- 📥 **下载结果**: 下载生成的报告、图表、数据文件
- 📤 **上传资源**: 上传数据集、配置文件、模型文件
- 📊 **数据交换**: 在沙箱和外部系统之间交换数据
- 📦 **制品管理**: 收集和管理生成的制品（artifacts）

**文件操作的优势**:
- ✅ **直接传输**: 无需 Base64 编码
- 🚀 **高效**: 流式传输，支持大文件
- 🔒 **安全**: 路径检查，防止目录遍历
- 📋 **完整**: 保留文件元数据（类型、大小、名称）

### 8.1.2 文件操作 API

| API | 方法 | 路径 | 用途 |
|-----|------|------|------|
| **文件下载** | GET | `/files/content` | 下载沙箱中的文件 |
| **文件上传** | POST | `/files/upload` | 上传文件到沙箱 |

### 8.1.3 文件操作限制

| 限制 | 值 | 说明 |
|------|-----|------|
| **下载大小** | 100 MB | 单个文件最大下载大小 |
| **上传大小** | 20 MB | 单个文件最大上传大小 |
| **允许目录** | `/workspace`, `/tmp` | 只能访问这些目录 |
| **禁止文件** | socket, device | 不能操作特殊文件 |

## 8.2 文件下载

### 8.2.1 HTTP API

**位置**: `main.go:372-433`

```go
// GET /files/content?path=/path/to/file
func handleFileContent(w http.ResponseWriter, r *http.Request) {
    if r.Method != http.MethodGet && r.Method != http.MethodHead {
        http.Error(w, "method not allowed", http.StatusMethodNotAllowed)
        return
    }

    // 1. 获取文件路径
    requested := r.URL.Query().Get("path")
    if requested == "" {
        http.Error(w, "path is required", http.StatusBadRequest)
        return
    }

    // 2. 解析和验证路径
    safePath, err := resolveDownloadPath(requested)
    if err != nil {
        http.Error(w, err.Error(), http.StatusBadRequest)
        return
    }

    // 3. 检查文件
    info, err := os.Stat(safePath)
    if err != nil {
        if os.IsNotExist(err) {
            http.Error(w, "file not found", http.StatusNotFound)
            return
        }
        http.Error(w, "failed to stat file: "+err.Error(), http.StatusInternalServerError)
        return
    }
    
    if info.IsDir() {
        http.Error(w, "path is a directory", http.StatusBadRequest)
        return
    }
    if !info.Mode().IsRegular() {
        http.Error(w, "path is not a regular file", http.StatusBadRequest)
        return
    }
    if info.Size() > maxDownloadFileSize {
        http.Error(w, fmt.Sprintf("file exceeds max size (%d bytes)", maxDownloadFileSize), 
            http.StatusRequestEntityTooLarge)
        return
    }

    // 4. 打开文件
    file, err := os.Open(safePath)
    if err != nil {
        http.Error(w, "failed to open file: "+err.Error(), http.StatusInternalServerError)
        return
    }
    defer file.Close()

    // 5. 设置响应头
    contentType := mimeType(safePath, file)
    w.Header().Set("Content-Type", contentType)
    w.Header().Set("Content-Length", strconv.FormatInt(info.Size(), 10))
    w.Header().Set("X-File-Name", filepath.Base(safePath))
    
    // 6. HEAD 请求只返回头
    if r.Method == http.MethodHead {
        return
    }
    
    // 7. 流式传输文件内容
    if _, err := file.Seek(0, io.SeekStart); err != nil {
        http.Error(w, "failed to read file: "+err.Error(), http.StatusInternalServerError)
        return
    }
    if _, err := io.Copy(w, file); err != nil {
        log.Printf("failed to stream file %s: %v", safePath, err)
    }
}
```

💡 **关键点**:
- **路径验证**: 使用 `resolveDownloadPath` 确保路径安全
- **文件检查**: 验证是常规文件，不是目录或特殊文件
- **大小限制**: 检查文件大小不超过 100 MB
- **内容类型**: 自动检测 MIME 类型
- **流式传输**: 使用 `io.Copy` 流式传输，不缓存整个文件

## 8.3 文件上传

### 8.3.1 HTTP API

```go
// POST /files/upload?path=/path/to/file
func handleFileUpload(w http.ResponseWriter, r *http.Request) {
    if r.Method != http.MethodPost {
        http.Error(w, "method not allowed", http.StatusMethodNotAllowed)
        return
    }

    // 1. 获取目标路径
    requested := r.URL.Query().Get("path")
    if requested == "" {
        writeFileUploadError(w, http.StatusBadRequest, "path is required")
        return
    }

    // 2. 解析和验证路径
    safePath, err := resolveUploadPath(requested)
    if err != nil {
        writeFileUploadError(w, http.StatusBadRequest, err.Error())
        return
    }

    // 3. 读取上传内容
    body, err := io.ReadAll(io.LimitReader(r.Body, maxUploadFileSize+1))
    if err != nil {
        writeFileUploadError(w, http.StatusBadRequest, "failed to read body: "+err.Error())
        return
    }
    if int64(len(body)) > maxUploadFileSize {
        writeFileUploadError(w, http.StatusRequestEntityTooLarge,
            fmt.Sprintf("file exceeds max size (%d bytes)", maxUploadFileSize))
        return
    }

    // 4. 创建目录
    if err := os.MkdirAll(filepath.Dir(safePath), 0755); err != nil {
        writeFileUploadError(w, http.StatusInternalServerError,
            "failed to create directory: "+err.Error())
        return
    }

    // 5. 写入文件
    if err := os.WriteFile(safePath, body, 0644); err != nil {
        writeFileUploadError(w, http.StatusInternalServerError,
            "failed to write file: "+err.Error())
        return
    }

    // 6. 返回成功响应
    log.Printf("file uploaded: path=%s, size=%d", safePath, len(body))
    w.Header().Set("Content-Type", "application/json")
    json.NewEncoder(w).Encode(FileUploadResponse{
        Status: "ok",
        Path:   safePath,
        Size:   int64(len(body)),
    })
}
```

💡 **关键点**:
- **路径验证**: 使用 `resolveUploadPath` 确保路径安全
- **大小限制**: 限制上传大小不超过 20 MB
- **自动创建目录**: 如果目录不存在会自动创建
- **覆盖写入**: 如果文件已存在会覆盖

## 8.4 路径安全

### 8.4.1 下载路径验证

**位置**: `main.go:886-906`

```go
func resolveDownloadPath(requested string) (string, error) {
    // 1. 清理路径
    cleaned := resolvePath(requested)
    
    // 2. 解析符号链接
    resolved, err := filepath.EvalSymlinks(cleaned)
    if err != nil {
        if os.IsNotExist(err) {
            return "", err
        }
        return "", fmt.Errorf("failed to resolve path: %w", err)
    }
    
    // 3. 检查是否在允许的根目录内
    allowedRoots := []string{workspaceDir, os.TempDir()}
    for _, root := range allowedRoots {
        rootResolved, err := filepath.EvalSymlinks(root)
        if err != nil {
            rootResolved = filepath.Clean(root)
        }
        if isPathWithin(resolved, rootResolved) {
            return resolved, nil
        }
    }
    
    return "", fmt.Errorf("path is outside allowed directories")
}
```

💡 **安全检查**:
- **路径清理**: 使用 `filepath.Clean` 清理路径
- **符号链接解析**: 使用 `filepath.EvalSymlinks` 解析所有符号链接
- **根目录检查**: 确保路径在 `/workspace` 或 `/tmp` 内
- **目录遍历防护**: 防止通过 `../` 逃逸

### 8.4.2 上传路径验证

**位置**: `main.go:489-502`

```go
func resolveUploadPath(requested string) (string, error) {
    cleaned := resolvePath(requested)
    allowedRoots := []string{workspaceDir, os.TempDir()}
    
    for _, root := range allowedRoots {

        }
```

💡 **下载 vs 上传**:
- **下载**: 先解析符号链接再检查（更安全）
- **上传**: 直接检查清理后的路径（文件可能不存在）

### 8.4.3 路径包含检查

**位置**: `main.go:908-914`

```go
func isPathWithin(path, root string) bool {
    rel, err := filepath.Rel(root, path)
    if err != nil {
        return false
    }
    return rel == "." || (rel != ".." && !strings.HasPrefix(rel, ".."+string(os.PathSeparator)))
}
```

💡 **检查逻辑**:
- 计算相对路径
- 如果是 `.` 表示在同一目录（允许）
- 如果不是 `..` 且不包含 `../` 前缀（允许）
- 否则拒绝（目录遍历）

## 8.5 内容类型检测

### 8.5.1 MIME 类型检测

**位置**: `main.go:916-937`

```go
func mimeType(path string, file *os.File) string {
    // 1. 根据扩展名检测
    switch strings.ToLower(filepath.Ext(path)) {
    case ".csv":
        return "text/csv; charset=utf-8"
    case ".json":
        return "application/json"
    case ".pdf":
        return "application/pdf"
    case ".png":
        return "image/png"
    case ".jpg", ".jpeg":
        return "image/jpeg"
    case ".svg":
        return "image/svg+xml"
    }
    
    // 2. 根据文件内容检测
    buffer := make([]byte, 512)
    n, err := file.Read(buffer)
    if err == nil && n > 0 {
        return http.DetectContentType(buffer[:n])
    }
    
    // 3. 默认类型
    return "application/octet-stream"
}
```

💡 **检测策略**:
1. **扩展名优先**: 根据文件扩展名返回已知的 MIME 类型
2. **内容检测**: 读取前 512 字节，使用 `http.DetectContentType` 检测
3. **默认类型**: 如果无法检测，返回 `application/octet-stream`

### 8.5.2 常见 MIME 类型

| 扩展名 | MIME 类型 |
|--------|----------|
| `.txt` | `text/plain; charset=utf-8` |
| `.csv` | `text/csv; charset=utf-8` |
| `.json` | `application/json` |
| `.pdf` | `application/pdf` |
| `.png` | `image/png` |
| `.jpg` | `image/jpeg` |
| `.svg` | `image/svg+xml` |
| `.html` | `text/html; charset=utf-8` |
| `.xml` | `application/xml` |
| `.zip` | `application/zip` |
| `.tar.gz` | `application/gzip` |

## 8.7 实战: 文件管理

### 8.7.1 文件管理脚本

```bash
#!/bin/bash
# file-manager.sh - 文件管理工具

SANDBOX_URL="http://localhost:8080"

# 列出文件
list_files() {
    local path=${1:-/workspace}
    curl -s -X POST "$SANDBOX_URL/execute" \
        -H "Content-Type: application/json" \
        -d "{\"tool\": \"run_bash_command\", \"arguments\": \"{\\\"command\\\": \\\"ls -lh $path\\\"}\"}" | \
        jq -r '.result'
}

# 下载文件
download_file() {
    local remote_path=$1
    local local_path=${2:-$(basename "$remote_path")}
    
    echo "Downloading $remote_path -> $local_path"
    curl -s "$SANDBOX_URL/files/content?path=$remote_path" -o "$local_path"
    
    if [ $? -eq 0 ]; then
        echo "Downloaded: $(ls -lh "$local_path" | awk '{print $5}')"
    else
        echo "Download failed"
        return 1
    fi
}

# 上传文件
upload_file() {
    local local_path=$1
    local remote_path=${2:-/workspace/$(basename "$local_path")}
    
    echo "Uploading $local_path -> $remote_path"
    result=$(curl -s -X POST "$SANDBOX_URL/files/upload?path=$remote_path" \
        --data-binary @"$local_path")
    
    status=$(echo "$result" | jq -r '.status')
    if [ "$status" = "ok" ]; then
        size=$(echo "$result" | jq -r '.size')
        echo "Uploaded: $size bytes"
    else
        error=$(echo "$result" | jq -r '.error')
        echo "Upload failed: $error"
        return 1
    fi
}

# 删除文件
delete_file() {
    local path=$1
    curl -s -X POST "$SANDBOX_URL/execute" \
        -H "Content-Type: application/json" \
        -d "{\"tool\": \"run_bash_command\", \"arguments\": \"{\\\"command\\\": \\\"rm -f $path\\\"}\"}" | \
        jq -r '.result'
    echo "Deleted: $path"
}

# 查看文件信息
file_info() {
    local path=$1
    curl -s -I "$SANDBOX_URL/files/content?path=$path" | grep -E "Content-|X-File"
}

# 同步目录
sync_directory() {
    local local_dir=$1
    local remote_dir=$2
    
    echo "Syncing $local_dir -> $remote_dir"
    
    # 上传所有文件
    find "$local_dir" -type f | while read file; do
        relative_path=${file#$local_dir/}
        remote_path="$remote_dir/$relative_path"
        upload_file "$file" "$remote_path"
    done
}

# 主命令
case "$1" in
    list)
        list_files "$2"
        ;;
    download)
        download_file "$2" "$3"
        ;;
    upload)
        upload_file "$2" "$3"
        ;;
    delete)
        delete_file "$2"
        ;;
    info)
        file_info "$2"
        ;;
    sync)
        sync_directory "$2" "$3"
        ;;
    *)
        echo "Usage: $0 {list|download|upload|delete|info|sync} [args...]"
        echo ""
        echo "Commands:"
        echo "  list [path]                    - List files"
        echo "  download <remote> [local]      - Download file"
        echo "  upload <local> [remote]        - Upload file"
        echo "  delete <path>                  - Delete file"
        echo "  info <path>                    - Show file info"
        echo "  sync <local_dir> <remote_dir>  - Sync directory"
        exit 1
        ;;
esac
```

**使用示例**:
```bash
# 列出文件
./file-manager.sh list /workspace

# 下载文件
./file-manager.sh download /workspace/report.txt ./local-report.txt

# 上传文件
./file-manager.sh upload ./data.json /workspace/data.json

# 查看文件信息
./file-manager.sh info /workspace/chart.png

# 同步目录
./file-manager.sh sync ./my-project /workspace/my-project
```

### 8.7.2 批量文件操作

```bash
#!/bin/bash
# batch-file-ops.sh - 批量文件操作

SANDBOX_URL="http://localhost:8080"

# 批量下载
batch_download() {
    local remote_dir=$1
    local local_dir=$2
    
    # 获取文件列表
    files=$(curl -s -X POST "$SANDBOX_URL/execute" \
        -H "Content-Type: application/json" \
        -d "{\"tool\": \"glob_file\", \"arguments\": \"{\\\"pattern\\\": \\\"*\\\", \\\"path\\\": \\\"$remote_dir\\\"}\"}" | \
        jq -r '.result' | tr '\n' ' ')
    
    # 下载每个文件
    for file in $files; do
        remote_path="$remote_dir/$file"
        local_path="$local_dir/$file"
        mkdir -p "$(dirname "$local_path")"
        
        echo "Downloading: $remote_path"
        curl -s "$SANDBOX_URL/files/content?path=$remote_path" -o "$local_path"
    done
    
    echo "Downloaded ${#files[@]} files"
}

# 批量上传
batch_upload() {
    local local_dir=$1
    local remote_dir=$2
    
    # 上传每个文件
    find "$local_dir" -type f | while read file; do
        relative_path=${file#$local_dir/}
        remote_path="$remote_dir/$relative_path"
        
        echo "Uploading: $file -> $remote_path"
        curl -s -X POST "$SANDBOX_URL/files/upload?path=$remote_path" \
            --data-binary @"$file" > /dev/null
    done
    
    echo "Upload complete"
}

# 批量删除
batch_delete() {
    local pattern=$1
    
    curl -s -X POST "$SANDBOX_URL/execute" \
        -H "Content-Type: application/json" \
        -d "{\"tool\": \"run_bash_command\", \"arguments\": \"{\\\"command\\\": \\\"rm -f $pattern\\\"}\"}"
    
    echo "Deleted: $pattern"
}

# 主命令
case "$1" in
    download)
        batch_download "$2" "$3"
        ;;
    upload)
        batch_upload "$2" "$3"
        ;;
    delete)
        batch_delete "$2"
        ;;
    *)
        echo "Usage: $0 {download|upload|delete} [args...]"
        exit 1
        ;;
esac
```

### 8.7.3 文件监控

```bash
#!/bin/bash
# file-watcher.sh - 监控文件变化

SANDBOX_URL="http://localhost:8080"
WATCH_DIR=${1:-/workspace}
INTERVAL=${2:-5}

echo "Watching $WATCH_DIR for changes (interval: ${INTERVAL}s)"
echo "Press Ctrl+C to stop"
echo ""

# 获取初始文件列表
get_file_list() {
    curl -s -X POST "$SANDBOX_URL/execute" \
        -H "Content-Type: application/json" \
        -d "{\"tool\": \"run_bash_command\", \"arguments\": \"{\\\"command\\\": \\\"find $WATCH_DIR -type f -printf '%T@ %p\\\\n' | sort -n\\\"}\"}" | \
        jq -r '.result'
}

prev_files=$(get_file_list)

while true; do
    sleep $INTERVAL
    
    curr_files=$(get_file_list)
    
    # 比较文件列表
    if [ "$prev_files" != "$curr_files" ]; then
        echo "[$(date)] Changes detected:"
        
        # 查找新增文件
        comm -13 <(echo "$prev_files" | awk '{print $2}' | sort) \
                 <(echo "$curr_files" | awk '{print $2}' | sort) | \
        while read file; do
            if [ -n "$file" ]; then
                echo "  + $file"
            fi
        done
        
        # 查找删除文件
        comm -23 <(echo "$prev_files" | awk '{print $2}' | sort) \
                 <(echo "$curr_files" | awk '{print $2}' | sort) | \
        while read file; do
            if [ -n "$file" ]; then
                echo "  - $file"
            fi
        done
        
        echo ""
        prev_files=$curr_files
    fi
done
```

**使用示例**:
```bash
# 监控 /workspace 目录
./file-watcher.sh /workspace 5

# 在另一个终端创建文件
curl -X POST http://localhost:8080/execute \
  -d '{"tool": "write_file", "arguments": "{\"file_path\": \"/workspace/test.txt\", \"content\": \"test\"}"}'

# 监控器会显示:
# [2026-08-31 15:30:00] Changes detected:
#   + /workspace/test.txt
```

## 8.8 常见问题

### 8.8.1 文件下载失败

**症状**:
```
file not found
```

**原因**: 文件路径错误或文件不存在

**解决方案**:
```bash
# 1. 检查文件是否存在
curl -X POST http://localhost:8080/execute \
  -d '{"tool": "run_bash_command", "arguments": "{\"command\": \"ls -la /workspace/file.txt\"}"}'

# 2. 使用绝对路径
curl "http://localhost:8080/files/content?path=/workspace/file.txt"

# 3. 检查路径安全
# ❌ 错误: path=../etc/passwd
# ✅ 正确: path=/workspace/file.txt
```

### 8.8.2 文件上传失败

**症状**:
```json
{
  "status": "error",
  "error": "failed to write file: permission denied"
}
```

**原因**: 目录权限不足

**解决方案**:
```bash
# 1. 检查目录权限
curl -X POST http://localhost:8080/execute \
  -d '{"tool": "run_bash_command", "arguments": "{\"command\": \"ls -la /workspace/\"}"}'

# 2. 修复权限
curl -X POST http://localhost:8080/execute \
  -d '{"tool": "run_bash_command", "arguments": "{\"command\": \"chmod 755 /workspace\"}"}'

# 3. 上传到 /tmp（通常有写权限）
curl -X POST "http://localhost:8080/files/upload?path=/tmp/file.txt" \
  --data-binary @"content"
```

### 8.8.3 大文件处理

**症状**:
```
file exceeds max size (104857600 bytes)
```

**原因**: 文件超过 100MB 限制

**解决方案**:
```bash
# 1. 压缩文件
curl -X POST http://localhost:8080/execute \
  -d '{"tool": "run_bash_command", "arguments": "{\"command\": \"tar -czf /tmp/archive.tar.gz /workspace/large_dir\"}"}'

# 2. 分块处理
curl -X POST http://localhost:8080/execute \
  -d '{"tool": "run_bash_command", "arguments": "{\"command\": \"split -b 50M /workspace/large.dat /tmp/part_\"}"}'

# 3. 使用外部存储
curl -X POST http://localhost:8080/execute \
  -d '{"tool": "run_bash_command", "arguments": "{\"command\": \"aws s3 cp /workspace/large.dat s3://bucket/\"}"}'
```

### 8.8.4 内容类型错误

**症状**: 下载文件时 Content-Type 不正确

**原因**: 扩展名无法识别或文件内容检测失败

**解决方案**:
```bash
# 1. 使用标准扩展名
# ✅ .json, .csv, .png, .pdf
# ❌ .txt1, .data, .bin

# 2. 手动设置 Content-Type（客户端处理）
curl "http://localhost:8080/files/content?path=/workspace/data.custom" \
  -H "Accept: application/json" \
  -o data.json

# 3. 在沙箱中重命名
curl -X POST http://localhost:8080/execute \
  -d '{"tool": "run_bash_command", "arguments": "{\"command\": \"mv /workspace/data.custom /workspace/data.json\"}"}'
```
