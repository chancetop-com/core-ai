## 📚 教程概览

core-ai-sandbox-runtime 是一个用 Go 编写的轻量级 HTTP 服务器，运行在隔离的容器环境中，提供安全的代码执行和文件操作能力。

### 核心能力

- 🔒 **安全执行** - 在非 root 用户的隔离容器中执行代码
- 🛠️ **工具执行** - 支持 bash、python 和多种文件操作工具
- 🔄 **异步任务** - 支持长时间运行的后台任务
- 📦 **MCP 集成** - 管理 Model Context Protocol 服务器进程
- 💾 **快照系统** - 捕获和恢复沙箱状态
- 🎨 **技能物化** - 动态加载和执行技能包

### 技术栈

- **语言**: Go 1.22+
- **容器**: Docker / Kubernetes
- **用户**: 非 root (UID 1001)
- **工作目录**: `/workspace` (可配置)

## ⚠️ 重要提示

1. **安全隔离** - sandbox-runtime 必须在容器中运行，不要在宿主机直接运行
2. **资源限制** - 生产环境必须配置 CPU/内存限制
3. **网络隔离** - 默认禁止网络访问，按需配置
4. **非 root 用户** - 容器以 UID 1001 运行，不要修改
