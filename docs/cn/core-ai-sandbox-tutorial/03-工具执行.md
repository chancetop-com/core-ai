## 3.1 工具注册机制

### 3.1.1 工具映射表

**位置**: `main.go:143-151`

```go

    "run_bash_command":  executeBash,
    "run_python_script": executePython,
    "read_file":         executeReadFile,
```

💡 **设计要点**:

  - 参数: JSON 字符串
  - 返回值: `(output, status)`
- **注册表模式**: 工具名 → 执行函数的映射
- **易于扩展**: 添加新工具只需在 map 中注册

### 3.1.2 请求处理流程

**位置**: `main.go:303-341`

```go
func handleExecute(w http.ResponseWriter, r *http.Request) {
    // 1. 解析请求
    var req ExecuteRequest
    if err := json.NewDecoder(r.Body).Decode(&req); err != nil {
        writeJSON(w, ExecuteResponse{Status: "failed", Result: "invalid request"})
        return
    }
    
    // 2. 查找工具
    executor, ok := toolMap[req.Tool]
    if !ok {
        writeJSON(w, ExecuteResponse{Status: "failed", Result: "unsupported tool"})
        return
    }
    
    // 3. 检查异步模式
    if isAsync(req.Arguments) {
        // 异步执行
        taskID, _ := taskRegistry.Submit(req.Tool, func() (string, string) {
            return executor(req.Arguments)
        })
        writeJSON(w, ExecuteResponse{Status: "pending", TaskID: taskID})
        return
    }
    
    // 4. 同步执行
    start := time.Now()
    result, status := executor(req.Arguments)
    
    // 5. 返回结果
    writeJSON(w, ExecuteResponse{
        Status:     status,
        Result:     truncateOutput(result),
        DurationMs: time.Since(start).Milliseconds(),
    })
}
```

💡 **流程说明**:
1. 解析 JSON 请求
2. 查找工具执行器
3. 判断同步/异步模式
4. 执行工具
5. 截断输出并返回

### 3.1.3 请求/响应结构

```go
// 请求结构
type ExecuteRequest struct {
    Tool      string `json:"tool"`       // 工具名称
    Arguments string `json:"arguments"`  // JSON 参数字符串
}

// 响应结构
type ExecuteResponse struct {
    Status     string `json:"status"`              // completed/failed/timeout/pending
    Result     string `json:"result"`              // 输出结果
    TaskID     string `json:"task_id,omitempty"`   // 异步任务 ID
    DurationMs int64  `json:"duration_ms,omitempty"` // 执行时长
}
```

💡 **状态说明**:
- `completed`: 执行成功
- `failed`: 执行失败
- `timeout`: 执行超时
- `pending`: 异步任务已提交

## 3.2 Bash 命令执行

### 3.2.1 实现代码

**位置**: `main.go:523-558`

```go
func executeBash(args string) (string, string) {
    // 1. 解析参数
    var parsed struct {
        Command      string `json:"command"`
        WorkspaceDir string `json:"workspace"`
        Timeout      int    `json:"timeout"`
    }
    if err := json.Unmarshal([]byte(args), &parsed); err != nil {
        return "failed to parse arguments: " + err.Error(), "failed"
    }
    
    // 2. 验证命令
    if parsed.Command == "" {
        return "command is empty", "failed"
    }
    
    // 3. 设置超时
    timeout := defaultBashTimeoutMs * time.Millisecond
    if parsed.Timeout > 0 {
        timeout = time.Duration(min(parsed.Timeout, maxBashTimeoutMs)) * time.Millisecond
    }
    
    // 4. 创建上下文
    ctx, cancel := context.WithTimeout(context.Background(), timeout)
    defer cancel()
    
    // 5. 创建命令
    cmd := exec.CommandContext(ctx, "bash", "-c", parsed.Command)
    cmd.Dir = sanitizePath(parsed.WorkspaceDir, workspaceDir)
    cmd.Env = minimalEnv()
    
    // 6. 执行命令
    output, err := cmd.CombinedOutput()
    result := string(output)
    
    // 7. 处理结果
    if ctx.Err() == context.DeadlineExceeded {
        return result + "\n... command timed out", "timeout"
    }
    if err != nil {
        return fmt.Sprintf("%s\nexit status: %v", result, err), "completed"
    }
    return result, "completed"
}
```

💡 **关键点**:
- **超时控制**: 使用 `context.WithTimeout`
- **工作目录**: 默认 `/workspace`
- **环境变量**: 使用 `minimalEnv()` 最小化
- **输出合并**: `CombinedOutput()` 合并 stdout 和 stderr

| `command` | string | (必填) | Bash 命令 |

## 3.3 Python 脚本执行

### 3.3.1 实现代码

**位置**: `main.go:560-615`

```go
func executePython(args string) (string, string) {
    // 1. 解析参数
    var parsed struct {
        Code         string `json:"code"`
        Script       string `json:"script"`        // 兼容旧版本
        ScriptPath   string `json:"script_path"`
        WorkspaceDir string `json:"workspace"`
        Timeout      int    `json:"timeout"`
    }
    if err := json.Unmarshal([]byte(args), &parsed); err != nil {
        return "failed to parse arguments: " + err.Error(), "failed"
    }
    
    // 2. 确定代码来源
    code := parsed.Code
    if code == "" {
        code = parsed.Script  // 兼容旧版本
    }
    
    // 3. 构建参数
    var pythonArgs []string
    switch {
    case code != "":
        // 内联代码
        pythonArgs = []string{"-u", "-c", code}
    case parsed.ScriptPath != "":
        // 脚本文件
        scriptPath := resolvePath(parsed.ScriptPath)
        if _, err := os.Stat(scriptPath); err != nil {
            return fmt.Sprintf("script file does not exist: %s", scriptPath), "failed"
        }
        pythonArgs = []string{"-u", scriptPath}
    default:
        return "either 'code' or 'script_path' is required", "failed"
    }
    
    // 4. 设置超时
    timeout := 60 * time.Second
    if parsed.Timeout > 0 {
        timeout = time.Duration(parsed.Timeout) * time.Second
    }
    
    // 5. 创建上下文
    ctx, cancel := context.WithTimeout(context.Background(), timeout)
    defer cancel()
    
    // 6. 创建命令
    cmd := exec.CommandContext(ctx, findPython(), pythonArgs...)
    cmd.Dir = sanitizePath(parsed.WorkspaceDir, workspaceDir)
    cmd.Env = minimalEnv()
    
    // 7. 执行命令
    output, err := cmd.CombinedOutput()
    result := string(output)
    
    // 8. 处理结果
    if ctx.Err() == context.DeadlineExceeded {
        return result + "\n... script timed out", "timeout"
    }
    if err != nil {
        return fmt.Sprintf("%s\nexit status: %v", result, err), "completed"
    }
    return result, "completed"
}
```

💡 **关键点**:
- **双模式**: 支持内联代码和脚本文件
- **向后兼容**: `script` 参数兼容旧版本
- **Python 查找**: 优先使用 `python3`
- **无缓冲**: `-u` 参数禁用输出缓冲

```go
func executeReadFile(args string) (string, string) {
    // 1. 解析参数
    var parsed struct {
        FilePath string `json:"file_path"`
        Offset   int    `json:"offset"`  // 起始行（1-based）
        Limit    int    `json:"limit"`   // 读取行数
    }
    if err := json.Unmarshal([]byte(args), &parsed); err != nil {
        return "failed to parse arguments: " + err.Error(), "failed"
    }
    if parsed.FilePath == "" {
        return "file_path is required", "failed"
    }
    
    // 2. 解析路径
    safePath := resolvePath(parsed.FilePath)
    
    // 3. 读取文件
    data, err := os.ReadFile(safePath)
    if err != nil {
        return fmt.Sprintf("error reading file: %v", err), "failed"
    }
    
    // 4. 按行分割
    lines := strings.Split(string(data), "\n")
    
    // 5. 应用偏移和限制
    startLine := 0
    if parsed.Offset > 0 {
        startLine = parsed.Offset - 1  // 1-based to 0-based
    }
    if startLine >= len(lines) {
        return "", "completed"
    }
    
    endLine := len(lines)
    if parsed.Limit > 0 {
        endLine = startLine + parsed.Limit
        if endLine > len(lines) {
            endLine = len(lines)
        }
    }
    
    // 6. 格式化输出（带行号）
    var sb strings.Builder
    for i := startLine; i < endLine; i++ {
        fmt.Fprintf(&sb, "%d | %s\n", i+1, lines[i])
    }
    return sb.String(), "completed"
}
```

💡 **特点**:
- **行号显示**: `行号 | 内容` 格式
- **分页支持**: `offset` 和 `limit` 参数
- **路径安全**: 自动解析和清理路径

**使用示例**:

```go
func executeWriteFile(args string) (string, string) {
    // 1. 解析参数
    var parsed struct {
        FilePath string `json:"file_path"`
        Content  string `json:"content"`
    }
    if err := json.Unmarshal([]byte(args), &parsed); err != nil {
        return "failed to parse arguments: " + err.Error(), "failed"
    }
    if parsed.FilePath == "" {
        return "file_path is required", "failed"
    }
    
    // 2. 解析路径
    safePath := resolvePath(parsed.FilePath)
    
    // 3. 创建目录
    if err := os.MkdirAll(filepath.Dir(safePath), 0755); err != nil {
        return fmt.Sprintf("failed to create directory: %v", err), "failed"
    }
    
    // 4. 写入文件
    f, err := os.OpenFile(safePath, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, 0644)
    if err != nil {
        return fmt.Sprintf("failed to open file for writing: %v", err), "failed"
    }
    defer f.Close()
    
    if _, err := io.WriteString(f, parsed.Content); err != nil {
        return fmt.Sprintf("failed to write file: %v", err), "failed"
    }
    
    return "file written: " + parsed.FilePath, "completed"
}
```

💡 **特点**:
- **自动创建目录**: 如果目录不存在会自动创建
- **覆盖写入**: 使用 `O_TRUNC` 标志

```go
func executeEditFile(args string) (string, string) {
    // 1. 解析参数
    var parsed struct {
        FilePath   string `json:"file_path"`
        OldString  string `json:"old_string"`
        NewString  string `json:"new_string"`
        ReplaceAll bool   `json:"replace_all"`
    }
    if err := json.Unmarshal([]byte(args), &parsed); err != nil {
        return "failed to parse arguments: " + err.Error(), "failed"
    }
    if parsed.FilePath == "" || parsed.OldString == "" {
        return "file_path and old_string are required", "failed"
    }
    
    // 2. 解析路径
    safePath := resolvePath(parsed.FilePath)
    
    // 3. 读取文件
    data, err := os.ReadFile(safePath)
    if err != nil {
        return fmt.Sprintf("error reading file: %v", err), "failed"
    }
    
    // 4. 替换文本
    content := string(data)
    if !strings.Contains(content, parsed.OldString) {
        return "old_string not found in file", "failed"
    }
    
    var newContent string
    if parsed.ReplaceAll {
        newContent = strings.ReplaceAll(content, parsed.OldString, parsed.NewString)
    } else {
        newContent = strings.Replace(content, parsed.OldString, parsed.NewString, 1)
    }
    
    // 5. 写回文件
    if err := os.WriteFile(safePath, []byte(newContent), 0644); err != nil {
        return fmt.Sprintf("failed to write file: %v", err), "failed"
    }
    
    return "file edited: " + parsed.FilePath, "completed"
}
```

💡 **特点**:
- **精确替换**: 查找并替换指定文本
- **批量替换**: `replace_all: true` 替换所有匹配

### 3.4.4 文件搜索 (glob_file)

**位置**: `main.go:733-767`

```go
func executeGlob(args string) (string, string) {
    // 1. 解析参数
    var parsed struct {
        Pattern string `json:"pattern"`
        Path    string `json:"path"`
    }
    if err := json.Unmarshal([]byte(args), &parsed); err != nil {
        return "failed to parse arguments: " + err.Error(), "failed"
    }
    if parsed.Pattern == "" {
        return "pattern is required", "failed"
    }
    
    // 2. 确定搜索目录
    baseDir := workspaceDir
    if parsed.Path != "" {
        baseDir = resolvePath(parsed.Path)
    }
    
    // 3. 遍历目录
    var results []string
    filepath.Walk(baseDir, func(path string, info os.FileInfo, err error) error {
        if err != nil {
            return nil
        }
        rel, _ := filepath.Rel(baseDir, path)
        matched, _ := filepath.Match(parsed.Pattern, filepath.Base(path))
        if matched {
            results = append(results, rel)
        }
        if len(results) >= 1000 {
            return io.EOF  // 限制结果数量
        }
        return nil
    })
    
    return strings.Join(results, "\n"), "completed"
}
```

💡 **特点**:
- **Glob 模式**: 支持 `*.txt`、`**/*.go` 等模式

### 3.4.5 内容搜索 (grep_file)

**位置**: `main.go:769-875`

```go
func executeGrep(args string) (string, string) {
    // 1. 解析参数
    var parsed struct {
        Pattern         string `json:"pattern"`
        Path            string `json:"path"`
        Glob            string `json:"glob"`
        OutputMode      string `json:"output_mode"`
        HeadLimit       int    `json:"head_limit"`
        CaseInsensitive bool   `json:"-i"`
    }
    // ... 解析逻辑
    
    // 2. 编译正则表达式
    pattern := parsed.Pattern
    if parsed.CaseInsensitive {
        pattern = "(?i)" + pattern
    }
    re, err := regexp.Compile(pattern)
    if err != nil {
        return fmt.Sprintf("invalid pattern: %v", err), "failed"
    }
    
    // 3. 遍历目录
    var results []string
    filepath.Walk(baseDir, func(path string, info os.FileInfo, err error) error {
        // 跳过大文件（>1MB）
        if info.Size() > 1024*1024 {
            return nil
        }
        
        // 应用 glob 过滤
        if parsed.Glob != "" {
            matched, _ := filepath.Match(parsed.Glob, filepath.Base(path))
            if !matched {
                return nil
            }
        }
        
        // 读取文件内容
        data, err := os.ReadFile(path)
        if err != nil {
            return nil
        }
        
        // 搜索匹配行
        lines := strings.Split(string(data), "\n")
        for i, line := range lines {
            if !re.MatchString(line) {
                continue
            }
            // 根据输出模式格式化结果
            switch parsed.OutputMode {
            case "content":
                results = append(results, fmt.Sprintf("%s:%d: %s", rel, i+1, line))
            case "count":
                // 计数模式
            default: // files_with_matches
                results = append(results, rel)
            }
        }
        return nil
    })
    
    return strings.Join(results, "\n"), "completed"
}
```

💡 **特点**:
- **正则表达式**: 支持完整的正则语法
- **多输出模式**: 
  - `files_with_matches`: 文件名（默认）
  - `content`: 文件内容（带行号）
  - `count`: 匹配数量
- **大小写敏感**: `-i` 参数控制
- **文件过滤**: `glob` 参数过滤文件类型
- **性能优化**: 跳过大文件（>1MB）

**使用示例**:

```bash
# 搜索包含 "Hello" 的文件

  -H "Content-Type: application/json" \
  -d '{
    "tool": "grep_file",
    "arguments": "{\"pattern\": \"Hello\"}"
  }'

# 响应（files_with_matches 模式）

  "status": "completed",
  "result": "test.txt\nsubdir/test.txt",
  "duration_ms": 25
}

# 显示匹配内容
```

## 3.9 常见问题

### 3.9.1 命令执行失败

**症状**:
```json
{
  "status": "completed",
  "result": "exit status: 127"
}
```

**原因**: 命令不存在

**解决方案**:
```bash
# 检查命令是否存在
docker exec sandbox which command_name

# 如果不存在，需要修改 Dockerfile 安装
# 然后重新构建镜像
docker build -t core-ai-sandbox:latest .
```

### 3.9.2 文件权限错误

**症状**:
```json
{
  "status": "failed",
  "result": "permission denied"
}
```

**原因**: 文件权限不足

**解决方案**:
```bash
# 检查文件权限
docker exec sandbox ls -la /workspace/file.txt

# 修改权限
docker exec sandbox chmod 644 /workspace/file.txt
```

### 3.9.3 超时问题

**症状**:
```json
{
  "status": "timeout",
  "result": "... command timed out"
}
```

**原因**: 命令执行时间超过限制

**解决方案**:
```bash
# 增加超时时间
curl -X POST http://localhost:8080/execute \
  -H "Content-Type: application/json" \
  -d '{
    "tool": "run_bash_command",
    "arguments": "{\"command\": \"long_running_command\", \"timeout\": 300000}"
  }'
```

### 3.9.4 输出被截断

**症状**:
```json
{
  "result": "... [output truncated at 30KB]"
}
```

**原因**: 输出超过 30KB

**解决方案**:
- 将输出写入文件，然后读取部分
- 使用分页参数（如 `read_file` 的 `offset` 和 `limit`）

### 3.10.1 命令编写

✅ **好的做法**:

❌ **避免的做法**:


### 3.10.2 文件操作

✅ **好的做法**:
```json
// 使用绝对路径
{"file_path": "/workspace/data.txt"}

// 先检查文件是否存在
{"tool": "read_file", "arguments": "{\"file_path\": \"/workspace/data.txt\"}"}

{"file_path": "/workspace/large.txt", "offset": 1, "limit": 100}
```

❌ **避免的做法**:
```json
// 相对路径（可能解析错误）
```
