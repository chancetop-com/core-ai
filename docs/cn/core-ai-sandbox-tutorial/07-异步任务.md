## 7.1 异步任务概述

### 7.1.1 为什么需要异步任务

**同步执行的限制**:
- ⏱️ **超时限制**: 默认 120 秒，最长 600 秒
- 🔒 **阻塞**: 占用 HTTP 连接
- 🚫 **不适合**: 长时间运行的任务（编译、训练、批处理）

**异步任务的优势**:
- ✅ **无超时限制**: 任务可以运行任意长时间
- 🚀 **非阻塞**: 立即返回，不占用连接
- 📊 **可追踪**: 随时查询任务状态
- 🔄 **可管理**: 支持取消和清理

## 7.2 任务注册表

### 7.2.1 核心结构

**位置**: `main.go:62-75`

```go
type AsyncTask struct {
    ID         string
    Tool       string
    Status     string    // pending, completed, failed, timeout
    Result     string
    DurationMs int64
    CreatedAt  time.Time
    DoneAt     time.Time
}

type TaskRegistry struct {
    mu            sync.Mutex
    tasks         map[string]*AsyncTask
    running       int32              // 当前运行中的任务数
    maxConcurrent int32              // 最大并发数
    nextID        atomic.Int64       // 任务 ID 生成器
}
```

💡 **设计要点**:
- **互斥锁**: 保护任务列表的并发访问
- **原子计数器**: 高效追踪运行中的任务数
- **原子 ID 生成器**: 生成唯一的任务 ID

### 7.2.2 初始化

**位置**: `main.go:77-85`

```go
}
```

**全局实例**:

### 7.2.3 提交任务

**位置**: `main.go:87-107`

```go
func (r *TaskRegistry) Submit(tool string, execFn func() (string, string)) (string, error) {
    // 1. 检查并发限制
    if atomic.LoadInt32(&r.running) >= r.maxConcurrent {
        return "", fmt.Errorf("max concurrent async tasks reached (%d)", r.maxConcurrent)
    }

    // 2. 生成任务 ID
    id := fmt.Sprintf("task-%d", r.nextID.Add(1))
    
    // 3. 创建任务对象
    task := &AsyncTask{
        ID:        id,
        Tool:      tool,
        Status:    "pending",
        CreatedAt: time.Now(),
    }

    // 4. 注册任务
    r.mu.Lock()
    r.tasks[id] = task
    r.mu.Unlock()

    // 5. 增加运行计数
    atomic.AddInt32(&r.running, 1)

    // 6. 启动后台 goroutine
    go func() {
        defer atomic.AddInt32(&r.running, -1)
        
        start := time.Now()
        result, status := execFn()
        
        task.Result = truncateOutput(result)
        task.Status = status
        task.DurationMs = time.Since(start).Milliseconds()
        task.DoneAt = time.Now()
    }()

    return id, nil
}
```

💡 **关键点**:
- **并发检查**: 超过限制立即返回错误
- **原子操作**: 高效且线程安全
- **后台执行**: goroutine 执行任务，不阻塞调用者
- **输出截断**: 防止内存溢出

### 7.2.5 清理任务

**位置**: `main.go:115-124`

```go
func (r *TaskRegistry) Cleanup(maxAge time.Duration) {
    r.mu.Lock()
    defer r.mu.Unlock()
    
    now := time.Now()
    for id, t := range r.tasks {
        // 只清理已完成的任务
        if t.Status != "pending" && now.Sub(t.DoneAt) > maxAge {
            delete(r.tasks, id)
        }
    }
}
```

💡 **清理策略**:
- 只清理已完成的任务（pending 状态的任务可能还在执行）
- 保留最近 N 分钟的任务（默认 30 分钟）
- 定期清理（默认 5 分钟一次）

### 7.3.2 异步标志检测

**位置**: `main.go:1109-1124`

```go
func isAsync(args string) bool {
    var raw map[string]interface{}
    if err := json.Unmarshal([]byte(args), &raw); err != nil {
        return false
    }
    return asyncFlag(raw, "async") || asyncFlag(raw, "run_in_background")
}

func asyncFlag(raw map[string]interface{}, key string) bool {
    v, ok := raw[key]
    if !ok {
        return false
    }
    b, ok := v.(bool)
    return ok && b
}
```

💡 **支持的标志**:
- `run_in_background`: 用于 bash 命令
- `async`: 用于 Python 脚本

## 7.4 查询任务状态

### 7.4.1 HTTP API

**位置**: `main.go:344-368`

```go
// GET /tasks/{taskId}
func handleTaskPoll(w http.ResponseWriter, r *http.Request) {
    if r.Method != http.MethodGet {
        http.Error(w, "method not allowed", http.StatusMethodNotAllowed)
        return
    }

    taskID := strings.TrimPrefix(r.URL.Path, "/tasks/")
    if taskID == "" {
        writeJSON(w, ExecuteResponse{Status: "failed", Result: "task_id is required"})
        return
    }

    task := taskRegistry.Get(taskID)
    if task == nil {
        writeJSON(w, ExecuteResponse{Status: "failed", Result: "task not found: " + taskID})
        return
    }

    writeJSON(w, ExecuteResponse{
        Status:     task.Status,
        Result:     task.Result,
        TaskID:     task.ID,
        DurationMs: task.DurationMs,
    })
}
```

💡 **返回字段**:
- `status`: 任务状态 (pending/completed/failed/timeout)
- `result`: 任务输出（执行中为空）
- `task_id`: 任务 ID
- `duration_ms`: 执行时长（毫秒）

### 7.4.2 轮询策略

```bash
#!/bin/bash

# 轮询任务状态
poll_task() {
    local task_id=$1
    local interval=${2:-5}  # 默认 5 秒
    
    echo "Polling task: $task_id (interval: ${interval}s)"
    
    while true; do
        result=$(curl -s http://localhost:8080/tasks/$task_id)
        status=$(echo $result | jq -r '.status')
        
        case "$status" in
            pending)
                echo "[$(date)] Task still running..."
                ;;
            completed)
                echo "[$(date)] Task completed!"
                echo "$result" | jq .
                return 0
                ;;
            failed)
                echo "[$(date)] Task failed!"
                echo "$result" | jq .
                return 1
                ;;
            timeout)
                echo "[$(date)] Task timeout!"
                echo "$result" | jq .
                return 1
                ;;
            *)
                echo "[$(date)] Unknown status: $status"
                return 1
                ;;
        esac
        
        sleep $interval
    done
}

# 使用示例
poll_task "task-1" 10  # 每 10 秒轮询一次
```

### 7.6.4 监控任务

```bash
#!/bin/bash

# 监控任务数量和状态
monitor_tasks() {
    echo "=== Task Monitor ==="
    echo ""
    
    pending=0
    completed=0
    failed=0
    timeout=0
    
    for i in {1..100}; do
        result=$(curl -s http://localhost:8080/tasks/task-$i 2>/dev/null)
        if [ -z "$result" ]; then
            continue
        fi
        
        status=$(echo $result | jq -r '.status')
        case "$status" in
            pending) ((pending++)) ;;
            completed) ((completed++)) ;;
            failed) ((failed++)) ;;
            timeout) ((timeout++)) ;;
        esac
    done
    
    total=$((pending + completed + failed + timeout))
    
    echo "Total tasks: $total"
    echo "  Pending:   $pending"
    echo "  Completed: $completed"
    echo "  Failed:    $failed"
    echo "  Timeout:   $timeout"
    echo ""
    
    if [ $pending -gt 0 ]; then
        echo "Running tasks:"
        for i in {1..100}; do
            result=$(curl -s http://localhost:8080/tasks/task-$i 2>/dev/null)
            if [ -z "$result" ]; then
                continue
            fi
            status=$(echo $result | jq -r '.status')
            if [ "$status" = "pending" ]; then
                tool=$(echo $result | jq -r '.tool')
                echo "  task-$i: $tool"
            fi
        done
    fi
}

# 持续监控
while true; do
    clear
    monitor_tasks
    sleep 5
done
```

## 7.7 实战: 异步任务管理

### 7.7.1 批量任务管理器

```bash
#!/bin/bash
# batch-task-manager.sh - 批量异步任务管理器

set -e

MAX_CONCURRENT=${MAX_CONCURRENT:-5}

# 提交任务并返回 ID
submit_task() {
    local tool=$1
    local args=$2
    
    result=$(curl -s -X POST http://localhost:8080/execute \
        -H "Content-Type: application/json" \
        -d "{
            \"tool\": \"$tool\",
            \"arguments\": \"$args\"
        }")
    
    status=$(echo $result | jq -r '.status')
    if [ "$status" = "failed" ]; then
        echo "ERROR: $(echo $result | jq -r '.result')" >&2
        return 1
    fi
    
    echo $result | jq -r '.task_id'
}

# 等待任务完成
wait_task() {
    local task_id=$1
    local interval=${2:-5}
    
    while true; do
        result=$(curl -s http://localhost:8080/tasks/$task_id)
        status=$(echo $result | jq -r '.status')
        
        if [ "$status" != "pending" ]; then
            echo "$result"
            return 0
        fi
        
        sleep $interval
    done
}

# 批量提交任务
batch_submit() {
    local task_file=$1
    local task_ids=()
    
    echo "Submitting tasks from $task_file..."
    
    while IFS= read -r line; do
        tool=$(echo $line | jq -r '.tool')
        args=$(echo $line | jq -c '.arguments')
        
        # 添加异步标志
        if echo "$args" | jq -e '.run_in_background' > /dev/null; then
            : # 已有标志
        else
            args=$(echo "$args" | jq -c '. + {"run_in_background": true}')
        fi
        
        task_id=$(submit_task "$tool" "$args")
        if [ $? -eq 0 ]; then
            task_ids+=("$task_id")
            echo "  Submitted: $task_id"
        else
            echo "  Failed to submit task"
        fi
        
        # 控制并发
        if [ ${#task_ids[@]} -ge $MAX_CONCURRENT ]; then
            echo "  Waiting for tasks to complete..."
            wait_task "${task_ids[0]}" > /dev/null
            task_ids=("${task_ids[@]:1}")
        fi
    done < "$task_file"
    
    echo ""
    echo "All tasks submitted! Task IDs:"
    printf '%s\n' "${task_ids[@]}"
}

# 批量等待任务
batch_wait() {
    local task_ids=("$@")
    
    echo "Waiting for ${#task_ids[@]} tasks..."
    
    for task_id in "${task_ids[@]}"; do
        result=$(wait_task "$task_id")
        status=$(echo $result | jq -r '.status')
        echo "  $task_id: $status"
    done
}

# 主命令
case "$1" in
    submit)
        batch_submit "$2"
        ;;
    wait)
        shift
        batch_wait "$@"
        ;;
    *)
        echo "Usage: $0 {submit|wait} [args...]"
        exit 1
        ;;
esac
```

### 7.7.2 任务队列

```bash
#!/bin/bash
# task-queue.sh - 简单的任务队列

QUEUE_FILE="/tmp/task-queue.json"
MAX_CONCURRENT=5

# 添加任务到队列
enqueue() {
    local tool=$1
    local args=$2
    
    # 创建队列文件（如果不存在）
    if [ ! -f "$QUEUE_FILE" ]; then
        echo "[]" > "$QUEUE_FILE"
    fi
    
    # 添加任务
    task=$(jq -n --arg tool "$tool" --argjson args "$args" '{tool: $tool, arguments: $args, status: "queued"}')
    jq ". += [$task]" "$QUEUE_FILE" > "$QUEUE_FILE.tmp" && mv "$QUEUE_FILE.tmp" "$QUEUE_FILE"
    
    echo "Task queued"
}

# 处理队列
process_queue() {
    while true; do
        # 检查当前运行中的任务数
        running=$(jq '[.[] | select(.status == "running")] | length' "$QUEUE_FILE")
        
        if [ "$running" -lt "$MAX_CONCURRENT" ]; then
            # 获取下一个排队的任务
            next_task=$(jq -r '.[] | select(.status == "queued") | @base64' "$QUEUE_FILE" | head -1)
            
            if [ -n "$next_task" ]; then
                # 解码任务
                task=$(echo "$next_task" | base64 --decode)
                tool=$(echo "$task" | jq -r '.tool')
                args=$(echo "$task" | jq -c '.arguments')
                
                # 标记为运行中
                jq "(.[] | select(.tool == \"$tool\" and .status == \"queued\")) |= .status = \"running\"" "$QUEUE_FILE" > "$QUEUE_FILE.tmp" && mv "$QUEUE_FILE.tmp" "$QUEUE_FILE"
                
                # 提交任务
                result=$(curl -s -X POST http://localhost:8080/execute \
                    -H "Content-Type: application/json" \
                    -d "{\"tool\": \"$tool\", \"arguments\": \"$args\"}")
                
                task_id=$(echo $result | jq -r '.task_id')
                echo "Started task: $task_id"
                
                # 后台监控任务
                (
                    while true; do
                        status=$(curl -s http://localhost:8080/tasks/$task_id | jq -r '.status')
                        if [ "$status" != "pending" ]; then
                            # 更新队列中的任务状态
                            jq "(.[] | select(.tool == \"$tool\" and .status == \"running\")) |= .status = \"$status\"" "$QUEUE_FILE" > "$QUEUE_FILE.tmp" && mv "$QUEUE_FILE.tmp" "$QUEUE_FILE"
                            break
                        fi
                        sleep 5
                    done
                ) &
            fi
        fi
        
        sleep 2
    done
}

# 主命令
case "$1" in
    enqueue)
        enqueue "$2" "$3"
        ;;
    process)
        process_queue
        ;;
    status)
        jq . "$QUEUE_FILE"
        ;;
    *)
        echo "Usage: $0 {enqueue|process|status} [args...]"
        exit 1
        ;;
esac
```

```bash
#!/bin/bash
# task-dashboard.sh - 简单的任务监控仪表板

watch_tasks() {
    while true; do
        clear
        echo "=== Async Task Dashboard ==="
        echo "Time: $(date)"
        echo ""
        
        # 统计任务状态
        pending=0
        completed=0
        failed=0
        timeout=0
        total_duration=0
        
        for i in {1..1000}; do
            result=$(curl -s --connect-timeout 1 http://localhost:8080/tasks/task-$i 2>/dev/null)
            if [ -z "$result" ]; then
                break
            fi
            
            status=$(echo $result | jq -r '.status')
            duration=$(echo $result | jq -r '.duration_ms // 0')
            
            case "$status" in
                pending) ((pending++)) ;;
                completed) 
                    ((completed++))
                    total_duration=$((total_duration + duration))
                    ;;
                failed) 
                    ((failed++))
                    total_duration=$((total_duration + duration))
                    ;;
                timeout) 
                    ((timeout++))
                    total_duration=$((total_duration + duration))
                    ;;
            esac
        done
        
        total=$((pending + completed + failed + timeout))
        avg_duration=0
        if [ $((completed + failed + timeout)) -gt 0 ]; then
            avg_duration=$((total_duration / (completed + failed + timeout)))
        fi
        
        echo "📊 Statistics"
        echo "  Total tasks:    $total"
        echo "  Pending:        $pending"
        echo "  Completed:      $completed"
        echo "  Failed:         $failed"
        echo "  Timeout:        $timeout"
        echo "  Avg duration:   ${avg_duration}ms"
        echo ""
        
        # 显示最近的任务
        echo "📋 Recent Tasks"
        for i in {1..10}; do
            result=$(curl -s http://localhost:8080/tasks/task-$i 2>/dev/null)
            if [ -n "$result" ]; then
                status=$(echo $result | jq -r '.status')
                tool=$(echo $result | jq -r '.tool // "N/A"')
                duration=$(echo $result | jq -r '.duration_ms // 0')
                
                case "$status" in
                    pending)   icon="🔄" ;;
                    completed) icon="✅" ;;
                    failed)    icon="❌" ;;
                    timeout)   icon="⏱️" ;;
                    *)         icon="❓" ;;
                esac
                
                printf "  %s task-%-3d %-20s %8dms\n" "$icon" "$i" "$tool" "$duration"
            fi
        done
        
        sleep 2
    done
}
```

## 7.8 常见问题

### 7.8.1 任务无法提交

**症状**:
```json
{
  "status": "failed",
  "result": "max concurrent async tasks reached (5)"
}
```

**原因**: 达到最大并发限制

**解决方案**:
```bash
# 1. 等待一些任务完成
sleep 10

# 2. 增加并发限制
docker run -d --name sandbox \
    -e MAX_ASYNC_TASKS=20 \
    -p 8080:8080 \
    core-ai-sandbox:latest

# 3. 优化任务，减少并发需求
# 使用批量处理而不是多个小任务
```

### 7.8.2 任务状态一直是 pending

**症状**: 任务状态一直是 pending，不变成 completed

**原因**:
- 任务执行时间过长
- 任务被阻塞（等待输入、死锁）
- 资源不足（CPU、内存）

**解决方案**:
```bash
# 1. 检查容器资源
docker stats sandbox

# 2. 检查任务日志
docker logs sandbox | grep "task-"

# 3. 进入容器检查进程
docker exec sandbox ps aux | grep "sleep\|python"

# 4. 终止卡住的任务
docker exec sandbox pkill -f "task-command"
```

### 7.8.3 任务输出丢失

**症状**: 任务完成后，result 字段为空

**原因**:
- 命令没有输出
- 输出被重定向
- 输出超过 30KB 被截断

**解决方案**:
```bash
# 1. 检查命令是否有输出
docker exec sandbox bash -c "your-command"

# 2. 避免重定向输出
# ❌ 错误: "command > /dev/null"
# ✅ 正确: "command"

# 3. 如果输出很大，写入文件
curl -X POST http://localhost:8080/execute \
  -d '{
    "tool": "run_bash_command",
    "arguments": "{\"command\": \"large-command > /workspace/output.txt && echo Done\", \"run_in_background\": true}"
  }'

# 然后读取文件
curl -X POST http://localhost:8080/execute \
  -d '{"tool": "read_file", "arguments": "{\"file_path\": \"/workspace/output.txt\"}"}'
```

### 7.8.4 任务 ID 冲突

**症状**: 提交任务时返回已存在的 task_id

**原因**: 任务 ID 生成器重置（容器重启）

**解决方案**:
```bash
# 1. 使用唯一的任务名称
curl -X POST http://localhost:8080/execute \
  -d '{
    "tool": "run_bash_command",
    "arguments": "{\"command\": \"echo test\", \"run_in_background\": true}"
  }'

# 2. 记录 task_id 到自己的存储
echo "task-1" >> /tmp/my-tasks.txt

# 3. 查询时使用记录的 ID
task_id=$(cat /tmp/my-tasks.txt | tail -1)
curl http://localhost:8080/tasks/$task_id
```

### 7.9.2 轮询策略

✅ **推荐**:
```bash
# 1. 指数退避轮询
poll_with_backoff() {
    local task_id=$1
    local interval=1
    local max_interval=30
    
    while true; do
        result=$(curl -s http://localhost:8080/tasks/$task_id)
        status=$(echo $result | jq -r '.status')
        
        if [ "$status" != "pending" ]; then
            echo "$result"
            return 0
        fi
        
        sleep $interval
        interval=$((interval * 2))
        if [ $interval -gt $max_interval ]; then
            interval=$max_interval
        fi
    done
}

# 2. 带超时的轮询
poll_with_timeout() {
    local task_id=$1
    local timeout=$2
    local start=$(date +%s)
    
    while true; do
        # 检查超时
        now=$(date +%s)
        if [ $((now - start)) -ge $timeout ]; then
            echo "Timeout waiting for task $task_id"
            return 1
        fi
        
        result=$(curl -s http://localhost:8080/tasks/$task_id)
        status=$(echo $result | jq -r '.status')
        
        if [ "$status" != "pending" ]; then
            echo "$result"
            return 0
        fi
        
        sleep 5
    done
}
```

### 7.9.4 错误处理

✅ **推荐**:
```bash
# 1. 重试失败的任务
retry_task() {
    local task_id=$1
    local max_retries=3
    
    for i in $(seq 1 $max_retries); do
        result=$(curl -s http://localhost:8080/tasks/$task_id)
        status=$(echo $result | jq -r '.status')
        
        if [ "$status" = "completed" ]; then
            echo "Task succeeded on attempt $i"
            return 0
        elif [ "$status" = "failed" ] || [ "$status" = "timeout" ]; then
            echo "Task failed on attempt $i, retrying..."
            sleep 5
        else
            echo "Task still running..."
            sleep 5
        fi
    done
    
    echo "Task failed after $max_retries attempts"
    return 1
}

# 2. 记录任务日志
log_task() {
    local task_id=$1
    local log_file="/tmp/task-$task_id.log"
    
    while true; do
        result=$(curl -s http://localhost:8080/tasks/$task_id)
        status=$(echo $result | jq -r '.status')
        
        echo "[$(date)] Status: $status" >> "$log_file"
        
        if [ "$status" != "pending" ]; then
            echo "[$(date)] Result: $(echo $result | jq -r '.result')" >> "$log_file"
            echo "[$(date)] Duration: $(echo $result | jq -r '.duration_ms')ms" >> "$log_file"
            break
        fi
        
        sleep 5
    done
}
```
