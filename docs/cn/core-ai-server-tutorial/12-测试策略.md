## 12.1 测试策略概述

### 12.1.1 测试金字塔

```
        ╱╲
       ╱  ╲
      ╱ E2E╲        ← 端到端测试（少量）
     ╱──────╲
    ╱        ╲
   ╱ 集成测试  ╲     ← 集成测试（中量）
  ╱────────────╲
 ╱              ╲
╱   单元测试     ╲   ← 单元测试（大量）
╱────────────────╲
```

### 12.1.2 测试类型

| 测试类型 | 目的 | 范围 | 速度 | 示例 |
|---------|------|------|------|------|
| **单元测试** | 验证单个类/方法 | 单个组件 | 快 | Service、Repository |
| **集成测试** | 验证组件间交互 | 多个组件 | 中 | API、数据库 |
| **端到端测试** | 验证完整流程 | 整个系统 | 慢 | 用户场景 |
| **性能测试** | 验证性能和稳定性 | 整个系统 | 慢 | 压力测试、负载测试 |

## 12.2 单元测试

### 12.2.1 Service 测试

```java
@Test
public class AgentServiceTest {
    
    @InjectMocks
    private AgentService agentService;
    
    @Mock
    private AgentRepository agentRepository;
    
    @Mock
    private UserService userService;
    
    @Test
    public void testCreateAgent_Success() {
        // Given
        var request = new CreateAgentRequest();
        request.setName("Test Agent");
        request.setDescription("Test Description");
        
        var user = new User();
        user.setId("user123");
        
        var agent = new Agent();
        agent.setId("agent123");
        agent.setName("Test Agent");
        agent.setOwnerId("user123");
        
        when(userService.getCurrentUser()).thenReturn(user);
        when(agentRepository.save(any(Agent.class))).thenReturn(agent);
        
        // When
        var result = agentService.createAgent(request);
        
        // Then
        assertNotNull(result);
        assertEquals("agent123", result.getId());
        assertEquals("Test Agent", result.getName());
        assertEquals("user123", result.getOwnerId());
        
        verify(userService).getCurrentUser();
        verify(agentRepository).save(any(Agent.class));
    }
    
    @Test
    public void testCreateAgent_InvalidName() {
        // Given
        var request = new CreateAgentRequest();
        request.setName("");  // 空名称
        
        // When & Then
        assertThrows(ValidationException.class, () -> {
            agentService.createAgent(request);
        });
        
        verify(agentRepository, never()).save(any());
    }
    
    @Test
    public void testGetAgent_NotFound() {
        // Given
        when(agentRepository.findById("nonexistent")).thenReturn(null);
        
        // When & Then
        assertThrows(ResourceNotFoundException.class, () -> {
            agentService.getAgent("nonexistent");
        });
    }
    
    @Test
    public void testDeleteAgent_Unauthorized() {
        // Given
        var agent = new Agent();
        agent.setId("agent123");
        agent.setOwnerId("user456");
        
        var currentUser = new User();
        currentUser.setId("user789");
        
        when(agentRepository.findById("agent123")).thenReturn(agent);
        when(userService.getCurrentUser()).thenReturn(currentUser);
        
        // When & Then
        assertThrows(ForbiddenException.class, () -> {
            agentService.deleteAgent("agent123");
        });
    }
}
```

```java
@Test
public class AgentRepositoryTest {
    
    @InjectMocks
    private AgentRepository agentRepository;
    
    @Mock
    private MongoCollection<Agent> agentCollection;
    
    @Test
    public void testFindById() {
        // Given
        var agent = new Agent();
        agent.setId("agent123");
        agent.setName("Test Agent");
        
        when(agentCollection.findById("agent123")).thenReturn(agent);
        
        // When
        var result = agentRepository.findById("agent123");
        
        // Then
        assertNotNull(result);
        assertEquals("agent123", result.getId());
    }
    
    @Test
    public void testFindByOwnerId() {
        // Given
        var agents = List.of(
            createAgent("agent1", "user123"),
            createAgent("agent2", "user123")
        );
        
        when(agentCollection.find(any()))
            .thenReturn(mockFindIterable(agents));
        
        // When
        var result = agentRepository.findByOwnerId("user123");
        
        // Then
        assertEquals(2, result.size());
    }
    
    @Test
    public void testSave_NewAgent() {
        // Given
        var agent = new Agent();
        agent.setName("New Agent");
        
        doAnswer(invocation -> {
            var arg = invocation.getArgument(0, Agent.class);
            arg.setId("generated-id");
            return null;
        }).when(agentCollection).insertOne(any());
        
        // When
        agentRepository.save(agent);
        
        // Then
        verify(agentCollection).insertOne(agent);
        assertEquals("generated-id", agent.getId());
    }
    
    private Agent createAgent(String id, String ownerId) {
        var agent = new Agent();
        agent.setId(id);
        agent.setOwnerId(ownerId);
        return agent;
    }
}
```

```java
        // When
        var encoded = passwordEncoder.encode(rawPassword);
```

```java
@Test
public class AgentRepositoryIntegrationTest extends BaseIntegrationTest {
    
    @Inject
    private AgentRepository agentRepository;
    
    @Inject
    private MongoCollection<Agent> agentCollection;
    
    @BeforeEach
    public void setUp() {
        // 清理测试数据
        agentCollection.deleteMany(Filters.empty());
    }
    
    @Test
    public void testSaveAndFind() {
        // Given
        var agent = new Agent();
        agent.setName("Test Agent");
        agent.setOwnerId("user123");
        
        // When
        agentRepository.save(agent);
        var found = agentRepository.findById(agent.getId());
        
        // Then
        assertNotNull(found);
        assertEquals("Test Agent", found.getName());
        assertEquals("user123", found.getOwnerId());
    }
    
    @Test
    public void testFindByOwnerId_WithMultipleAgents() {
        // Given
        agentRepository.save(createAgent("Agent 1", "user123"));
        agentRepository.save(createAgent("Agent 2", "user123"));
        agentRepository.save(createAgent("Agent 3", "user456"));
        
        // When
        var result = agentRepository.findByOwnerId("user123");
        
        // Then
        assertEquals(2, result.size());
        assertTrue(result.stream().allMatch(a -> a.getOwnerId().equals("user123")));
    }
    
    @Test
    public void testUpdate() {
        // Given
        var agent = createAgent("Original Name", "user123");
        agentRepository.save(agent);
        
        // When
        agent.setName("Updated Name");
        agentRepository.save(agent);
        
        // Then
        var found = agentRepository.findById(agent.getId());
        assertEquals("Updated Name", found.getName());
    }
    
    @Test
    public void testDelete() {
        // Given
        var agent = createAgent("Test Agent", "user123");
        agentRepository.save(agent);
        
        // When
        agentRepository.delete(agent.getId());
        
        // Then
        var found = agentRepository.findById(agent.getId());
        assertNull(found);
    }
    
    private Agent createAgent(String name, String ownerId) {
        var agent = new Agent();
        agent.setName(name);
        agent.setOwnerId(ownerId);
        return agent;
    }
}
```

### 12.3.2 基础测试类

```java
@SpringBootTest
@Testcontainers
public abstract class BaseIntegrationTest {
    
    @Container
    static MongoDBContainer mongoDB = new MongoDBContainer("mongo:6.0");
    
    @Container
    static GenericContainer<?> redis = new GenericContainer<>("redis:7-alpine")
        .withExposedPorts(6379);
    
    @DynamicPropertySource
    static void configureProperties(DynamicPropertyRegistry registry) {
        registry.add("mongodb.uri", mongoDB::getReplicaSetUrl);
        registry.add("redis.host", redis::getHost);
        registry.add("redis.port", () -> redis.getMappedPort(6379));
    }
    
    @BeforeAll
    static void startContainers() {
        mongoDB.start();
        redis.start();
    }
    
    @AfterAll
    static void stopContainers() {
        mongoDB.stop();
        redis.stop();
    }
}
```

```java
@Test
public class AgentApiTest extends BaseIntegrationTest {

    public void testCreateAgent() {
```

```java
public class ApiPerformanceTest extends Simulation {
    
    private final String baseUrl = "http://localhost:8080";
    
    private final FeederBuilder.Batch<String> userFeeder = csv("users.csv").random();
    
    private final ScenarioBuilder listAgentsScenario = scenario("List Agents")
        .feed(userFeeder)
        .exec(
            http("List Agents")
                .get("/api/agents")
                .header("Authorization", "Bearer #{token}")
                .check(status().is(200))
                .check(jsonPath("$.items[*]").count().saveAs("count"))
        );
    
    private final ScenarioBuilder createAgentScenario = scenario("Create Agent")
        .feed(userFeeder)
        .exec(
            http("Create Agent")
                .post("/api/agents")
                .header("Authorization", "Bearer #{token}")
                .body(StringBody("""
                    {
                        "name": "Agent #{userId}",
                        "description": "Test Agent"
                    }
                """))
                .check(status().is(201))
                .check(jsonPath("$.id").saveAs("agentId"))
        );
    
    {
        setUp(
            listAgentsScenario.injectOpen(
                rampUsersPerSec(10).to(100).during(60)
            ),
            createAgentScenario.injectOpen(
                rampUsersPerSec(5).to(50).during(60)
            )
        ).protocols(
            http.baseUrl(baseUrl)
                .acceptHeader("application/json")
                .contentTypeHeader("application/json")
        ).assertions(
            global().responseTime().max().lt(500),
            global().successfulRequests().percent().gt(99.0)
        );
    }
}
```

### 12.6.2 测试结构（AAA 模式）

```java
@Test
public void createAgent_Success() {
    // Arrange（准备）
    var request = new CreateAgentRequest();

    var user = new User();
```

## 12.9 常见问题

### 12.9.1 测试不稳定

**问题**: 测试时过时

**解决方案**:
```java
// ✅ 好的实践：使用 Wait 策略
@Test
public void testAsyncOperation() {
    // 触发异步操作
    service.startAsyncOperation();
    
    // 等待完成
    await().atMost(5, SECONDS)
        .until(() -> service.isOperationCompleted());
    
    // 验证结果
    assertTrue(service.isOperationSuccessful());
}

// ❌ 避免：硬编码等待
@Test
public void testAsyncOperation() {
    service.startAsyncOperation();
    Thread.sleep(5000);  // 不可靠
    assertTrue(service.isOperationCompleted());
}
```

### 12.9.2 测试数据污染

**问题**: 测试间数据相互影响

**解决方案**:
```java
@BeforeEach
public void setUp() {
    // 清理测试数据
    testDataService.cleanup();
}

@AfterEach
public void tearDown() {
    // 清理测试数据
    testDataService.cleanup();
}
```

### 12.9.3 Mock 过度使用

**问题**: 过度 Mock 导致测试失去意义

**解决方案**:
```java
// ✅ 好的实践：只 Mock 外部依赖
@Test
public void testCreateAgent() {
    // Mock 数据库
    when(agentRepository.save(any())).thenReturn(agent);
    
    // 使用真实的业务逻辑
    var result = agentService.createAgent(request);
    
    // 验证
    assertNotNull(result);
}

// ❌ 避免：Mock 所有东西
@Test
public void testCreateAgent() {
    when(agentService.createAgent(any())).thenReturn(agent);  // 没有意义
    var result = agentService.createAgent(request);
}
```
