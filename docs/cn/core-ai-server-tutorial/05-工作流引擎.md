## 5.1 工作流引擎概述

### 5.1.1 什么是工作流

工作流（Workflow）是一种将复杂任务分解为多个步骤，并按特定顺序执行的编排机制。

**核心概念**:

| 概念 | 说明 | 示例 |
|------|------|------|
| **节点（Node）** | 工作流中的一个执行步骤 | LLM 调用、工具执行、条件判断 |
| **边（Edge）** | 节点之间的连接，定义执行顺序 | 条件分支、并行执行 |
| **工作流（Workflow）** | 由节点和边组成的有向图 | 完整的业务流程 |

💡 **核心思想**: 将复杂的 AI 任务分解为可管理、可复用、可观测的步骤。

### 5.1.2 工作流引擎的职责

`WorkflowModule` 提供:

```
┌─────────────────────────────────────┐
│        工作流引擎核心能力            │
├─────────────────────────────────────┤
│ ✅ 工作流定义和解析                  │
│ ✅ 节点执行和调度                    │
│ ✅ 条件分支和并行执行                │
│ ✅ 状态管理和持久化                  │
│ ✅ 错误处理和重试                    │
│ ✅ 执行追踪和可观测性                │
└─────────────────────────────────────┘
```

### 5.1.3 工作流类型

```
┌─────────────────────────────────────┐
│         工作流类型                   │
├─────────────────────────────────────┤
│ 顺序工作流（Sequential）            │
│  - 节点按顺序执行                   │
│  - 适用于线性流程                   │
├─────────────────────────────────────┤
│ 条件工作流（Conditional）           │
│  - 根据条件选择执行路径             │
│  - 适用于决策流程                   │
├─────────────────────────────────────┤
│ 并行工作流（Parallel）              │
│  - 多个节点并行执行                 │
│  - 适用于独立任务                   │
├─────────────────────────────────────┤
│ 循环工作流（Loop）                  │
│  - 节点循环执行直到满足条件         │
│  - 适用于迭代优化                   │
└─────────────────────────────────────┘
```

💡 **设计意图**: 支持多种工作流模式，适应不同的业务场景。

## 5.2 WorkflowEngine 核心实现

### 5.2.1 核心类

```java
public class WorkflowEngine {
    @Inject
    private WorkflowRepository repository;
    
    @Inject
    private NodeExecutorFactory executorFactory;
    
    @Inject
    private WorkflowEventPublisher eventPublisher;
    
    /**
     * 执行工作流
     */
    public WorkflowResult execute(WorkflowDefinition workflow, 
                                  Map<String, Object> input) {
        // 1. 创建工作流实例
        var instance = createInstance(workflow, input);
        
        // 2. 执行工作流
        try {
            var result = doExecute(instance);
            instance.setStatus(WorkflowStatus.COMPLETED);
            return result;
        } catch (Exception e) {
            instance.setStatus(WorkflowStatus.FAILED);
            instance.setError(e.getMessage());
            throw e;
        } finally {
            // 3. 持久化状态
            repository.save(instance);
            
            // 4. 发布事件
            eventPublisher.publish(new WorkflowCompletedEvent(instance));
        }
    }
    
    /**
     * 恢复执行（从失败点继续）
     */
    public WorkflowResult resume(String instanceId) {
        var instance = repository.findById(instanceId);
        if (instance == null) {
            throw new WorkflowNotFoundException(instanceId);
        }
        
        return doExecute(instance);
    }
    
    /**
     * 核心执行逻辑
     */
    private WorkflowResult doExecute(WorkflowInstance instance) {
        var context = new WorkflowContext(instance.getInput());
        var currentNode = instance.getStartNode();
        
        while (currentNode != null) {
            // 1. 更新当前节点
            instance.setCurrentNode(currentNode.getId());
            currentNode.setStatus(NodeStatus.RUNNING);
            
            // 2. 执行节点
            var executor = executorFactory.create(currentNode.getType());
            var output = executor.execute(currentNode, context);
            
            // 3. 保存节点输出
            currentNode.setOutput(output);
            currentNode.setStatus(NodeStatus.COMPLETED);
            context.setNodeOutput(currentNode.getId(), output);
            
            // 4. 发布事件
            eventPublisher.publish(
                new NodeCompletedEvent(instance, currentNode, output)
            );
            
            // 5. 查找下一个节点
            currentNode = findNextNode(instance, currentNode, output);
        }
        
        return new WorkflowResult(context.getOutputs());
    }
    
    /**
     * 查找下一个节点
     */
    private WorkflowNode findNextNode(WorkflowInstance instance,
                                      WorkflowNode currentNode,
                                      Object output) {
        var edges = instance.getWorkflow().getEdges()
            .stream()
            .filter(e -> e.getFrom().equals(currentNode.getId()))
            .toList();
        
        for (var edge : edges) {
            // 检查条件是否满足
            if (edge.getCondition() == null || 
                evaluateCondition(edge.getCondition(), output)) {
                return instance.getNode(edge.getTo());
            }
        }
        
        return null;  // 没有下一个节点，工作流结束
    }
}
```

💡 **设计要点**:
- **状态驱动**: 每个节点有明确的状态（PENDING/RUNNING/COMPLETED/FAILED）
- **上下文传递**: 使用 `WorkflowContext` 在节点间传递数据
- **事件驱动**: 关键事件发布通知，便于扩展和监控
- **可恢复**: 支持从失败点恢复执行

        return type == NodeType.CONDITION;

### 5.4.2 条件表达式

```java
public class ConditionEvaluator {
    /**
     * 评估条件表达式
     */
    public boolean evaluate(String expression, Map<String, Object> variables) {
        // 支持简单的表达式语法
        // 示例: "output.status == 'success'"
        // 示例: "output.score > 0.8"
        // 示例: "output.tags contains 'important'"
        
        var engine = new SimpleExpressionEngine();
        return engine.evaluate(expression, variables);
    }
}

// 简单表达式引擎
public class SimpleExpressionEngine {
    public boolean evaluate(String expression, Map<String, Object> variables) {
        // 解析表达式
        var parts = expression.split("\\s+");
        if (parts.length != 3) {
            throw new IllegalArgumentException("Invalid expression: " + expression);
        }
        
        var left = resolveValue(parts[0], variables);
        var operator = parts[1];
        var right = resolveValue(parts[2], variables);
        
        return switch (operator) {
            case "==" -> Objects.equals(left, right);
            case "!=" -> !Objects.equals(left, right);
            case ">" -> compare(left, right) > 0;
            case "<" -> compare(left, right) < 0;
            case ">=" -> compare(left, right) >= 0;
            case "<=" -> compare(left, right) <= 0;
            case "contains" -> left.toString().contains(right.toString());
            default -> throw new IllegalArgumentException("Unknown operator: " + operator);
        };
    }
    
    private Object resolveValue(String expr, Map<String, Object> variables) {
        // 处理变量引用: output.status
        if (expr.contains(".")) {
            var parts = expr.split("\\.");
            var value = variables.get(parts[0]);
            for (int i = 1; i < parts.length; i++) {
                if (value instanceof Map) {
                    value = ((Map<?, ?>) value).get(parts[i]);
                } else {
                    return null;
                }
            }
            return value;
        }
        
        // 处理字面量
        if (expr.startsWith("'") && expr.endsWith("'")) {
            return expr.substring(1, expr.length() - 1);
        }
        
        if (expr.matches("-?\\d+")) {
            return Integer.parseInt(expr);
        }
        
        if (expr.matches("-?\\d+\\.\\d+")) {
            return Double.parseDouble(expr);
        }
        
        return variables.get(expr);
    }
}
```

💡 **设计意图**: 提供简单但强大的条件表达式，支持变量引用和基本运算。

### 5.4.3 并行执行

```java
public class ParallelNodeExecutor implements NodeExecutor {
    @Inject
    private NodeExecutorFactory executorFactory;
    
    @Override
    public Object execute(WorkflowNode node, WorkflowContext context) {
        var parallelNodes = (List<WorkflowNode>) node.getConfig().get("nodes");
        
        // 并行执行所有节点
        var futures = parallelNodes.stream()
            .map(n -> CompletableFuture.supplyAsync(() -> {
                var executor = executorFactory.create(n.getType());
                return executor.execute(n, context);
            }))
            .toList();
        
        // 等待所有完成
        var results = futures.stream()
            .map(CompletableFuture::join)
            .toList();
        
        // 聚合结果
        return aggregateResults(results);
    }
    
    private Object aggregateResults(List<Object> results) {
        // 根据业务需求聚合结果
        return Map.of("results", results);
    }
    
    @Override
    public boolean supports(NodeType type) {
        return type == NodeType.PARALLEL;
    }
}
```

💡 **优势**:
- 提高执行效率
- 充分利用资源
- 支持独立任务并行

## 5.7 错误处理和重试

### 5.7.1 重试策略

```java
public class RetryPolicy {
    private int maxRetries = 3;
    private Duration initialDelay = Duration.ofSeconds(1);
    private double multiplier = 2.0;
    private Duration maxDelay = Duration.ofMinutes(1);
    
    /**
     * 计算重试延迟
     */
    public Duration calculateDelay(int retryCount) {
        var delay = initialDelay.multipliedBy(
            (long) Math.pow(multiplier, retryCount)
        );
        return delay.compareTo(maxDelay) > 0 ? maxDelay : delay;
    }
    
    /**
     * 是否应该重试
     */
    public boolean shouldRetry(int retryCount, Exception error) {
        return retryCount < maxRetries && isRetryable(error);
    }
    
    private boolean isRetryable(Exception error) {
        // 网络错误、超时等可重试
        return error instanceof TimeoutException ||
               error instanceof IOException ||
               error instanceof TransientException;
    }
}
```

💡 **设计要点**:
- **指数退避**: 重试间隔指数增长，避免雪崩
- **最大延迟**: 限制最大重试间隔
- **可重试判断**: 区分可重试和不可重试错误

### 5.7.2 重试执行器

```java
public class RetryingNodeExecutor implements NodeExecutor {
    private final NodeExecutor delegate;
    private final RetryPolicy retryPolicy;
    
    @Override
    public Object execute(WorkflowNode node, WorkflowContext context) {
        int retryCount = 0;
        
        while (true) {
            try {
                return delegate.execute(node, context);
            } catch (Exception e) {
                retryCount++;
                
                if (!retryPolicy.shouldRetry(retryCount, e)) {
                    throw new NodeExecutionException(
                        "Node execution failed after " + retryCount + " retries",
                        e
                    );
                }
                
                var delay = retryPolicy.calculateDelay(retryCount);
                logger.warn("Node execution failed, retrying in {} (attempt {}/{})",
                    delay, retryCount, retryPolicy.getMaxRetries(), e);
                
                try {
                    Thread.sleep(delay.toMillis());
                } catch (InterruptedException ie) {
                    Thread.currentThread().interrupt();
                    throw new NodeExecutionException("Retry interrupted", ie);
                }
            }
        }
    }
}
```

💡 **优势**:
- 自动重试
- 可配置策略
- 详细的日志记录

### 5.7.3 错误处理策略

```java
public class WorkflowEngine {
    /**
     * 执行工作流（带错误处理）
     */
    public WorkflowResult execute(WorkflowDefinition workflow, 
                                  Map<String, Object> input) {
        var instance = createInstance(workflow, input);
        
        try {
            var result = doExecute(instance);
            instance.setStatus(WorkflowStatus.COMPLETED);
            return result;
        } catch (NodeExecutionException e) {
            // 节点执行失败
            instance.setStatus(WorkflowStatus.FAILED);
            instance.setError(e.getMessage());
            
            // 发布失败事件
            eventPublisher.publish(new WorkflowFailedEvent(instance, e));
            
            // 根据配置决定是否重试整个工作流
            if (workflow.isRetryable()) {
                return retryWorkflow(instance);
            }
            
            throw e;
        } catch (Exception e) {
            // 其他异常
            instance.setStatus(WorkflowStatus.FAILED);
            instance.setError(e.getMessage());
            throw new WorkflowExecutionException("Workflow execution failed", e);
        } finally {
            repository.save(instance);
        }
    }
}
```

💡 **原则**:
- 区分可恢复和不可恢复错误
- 提供详细的错误信息
- 支持降级和补偿机制

#### 2. 节点执行器

```java
public class DataTransformNodeExecutor implements NodeExecutor {
    @Inject
    private JsonTransformer transformer;
    
    @Override
    public Object execute(WorkflowNode node, WorkflowContext context) {
        var config = parseConfig(node.getConfig());
        var inputData = getInputData(node, context);
        
        // 1. 字段映射
        var mappedData = applyFieldMappings(inputData, config.getFieldMappings());
        
        // 2. 数据过滤
        var filteredData = applyFilter(mappedData, config.getFilterExpression());
        
        // 3. 格式转换
        return convertFormat(filteredData, config.getOutputFormat());
    }
    
    private Map<String, String> applyFieldMappings(
            Map<String, Object> data, 
            Map<String, String> mappings) {
        var result = new HashMap<String, Object>();
        
        for (var entry : mappings.entrySet()) {
            var sourceField = entry.getKey();
            var targetField = entry.getValue();
            
            if (data.containsKey(sourceField)) {
                result.put(targetField, data.get(sourceField));
            }
        }
        
        return result;
    }
    
    private List<Map<String, Object>> applyFilter(
            List<Map<String, Object>> data,
            String expression) {
        if (expression == null || expression.isEmpty()) {
            return data;
        }
        
        return data.stream()
            .filter(item -> evaluateFilter(expression, item))
            .toList();
    }
    
    private Object convertFormat(Object data, String format) {
        return switch (format.toLowerCase()) {
            case "json" -> toJson(data);
            case "csv" -> toCsv(data);
            case "xml" -> toXml(data);
            default -> throw new IllegalArgumentException("Unsupported format: " + format);
        };
    }
    
    @Override
    public boolean supports(NodeType type) {
        return type == NodeType.CUSTOM && 
               "data_transform".equals(type.name().toLowerCase());
    }
}
```

## 5.11 性能优化

### 5.11.1 并行执行

```java
public class WorkflowEngine {
    /**
     * 识别可并行执行的节点
     */
    private List<List<WorkflowNode>> identifyParallelExecution(
            WorkflowInstance instance) {
        var levels = new ArrayList<List<WorkflowNode>>();
        var visited = new HashSet<String>();
        var queue = new LinkedList<String>();
        
        queue.add(instance.getStartNode().getId());
        
        while (!queue.isEmpty()) {
            var level = new ArrayList<WorkflowNode>();
            var nextQueue = new LinkedList<String>();
            
            while (!queue.isEmpty()) {
                var nodeId = queue.poll();
                if (visited.contains(nodeId)) continue;
                
                var node = instance.getNode(nodeId);
                level.add(node);
                visited.add(nodeId);
                
                // 查找下一个节点
                var nextNodes = findNextNodes(instance, node);
                nextQueue.addAll(
                    nextNodes.stream()
                        .map(WorkflowNode::getId)
                        .toList()
                );
            }
            
            if (!level.isEmpty()) {
                levels.add(level);
            }
            queue = nextQueue;
        }
        
        return levels;
    }
    
    /**
     * 并行执行同一层的节点
     */
    private void executeLevel(List<WorkflowNode> level, 
                             WorkflowContext context) {
        var futures = level.stream()
            .map(node -> CompletableFuture.runAsync(() -> {
                var executor = executorFactory.create(node.getType());
                var output = executor.execute(node, context);
                context.setNodeOutput(node.getId(), output);
            }))
            .toList();
        
        // 等待所有节点完成
        CompletableFuture.allOf(
            futures.toArray(new CompletableFuture[0])
        ).join();
    }
}
```

💡 **优势**:
- 提高执行效率
- 充分利用多核 CPU
- 减少总执行时间
