## 0.1 硬件要求

### 最低配置

- **CPU**: 4 核
- **内存**: 8 GB
- **磁盘**: 10 GB 可用空间

### 推荐配置

- **CPU**: 8 核+
- **内存**: 16 GB+（运行多个服务和数据库）
- **磁盘**: 20 GB+ SSD

💡 **说明**: core-ai-server 需要同时运行应用、MongoDB、Redis，内存消耗较大。

### 0.2.1 安装 JDK 21

#### macOS (Homebrew)

```bash
# 安装 OpenJDK 21
brew install openjdk@21

# 配置环境变量
echo 'export JAVA_HOME=$(/usr/libexec/java_home -v 21)' >> ~/.zshrc
echo 'export PATH=$JAVA_HOME/bin:$PATH' >> ~/.zshrc
source ~/.zshrc

# 验证
java -version
# 应输出: java version "21.x.x"
```

#### Ubuntu/Debian

```bash
# 添加 OpenJDK 仓库
sudo add-apt-repository ppa:openjdk-21
sudo apt update

# 安装
sudo apt install openjdk-21-jdk

# 验证
java -version
```

#### Windows

1. 下载 [Adoptium JDK 21](https://adoptium.net/)
2. 运行安装程序
3. 配置环境变量:
   - `JAVA_HOME`: `C:\Program Files\Java\jdk-21`
   - 在 `PATH` 中添加: `%JAVA_HOME%\bin`

### 0.2.2 安装 Maven

#### macOS

```bash
brew install maven
mvn -version
```

#### Ubuntu/Debian

```bash
sudo apt install maven
mvn -version
```

#### Windows

1. 下载 [Maven](https://maven.apache.org/download.cgi)
2. 解压到 `C:\Program Files\Maven`
3. 配置环境变量:
   - `M2_HOME`: `C:\Program Files\Maven`
   - 在 `PATH` 中添加: `%M2_HOME%\bin`

### 0.2.3 安装 MongoDB

#### macOS (Homebrew)

```bash
# 安装 MongoDB
brew tap mongodb/brew
brew install mongodb-community@6.0

# 启动服务
brew services start mongodb-community@6.0

# 验证
mongosh
# 进入 MongoDB shell
```

#### Ubuntu/Debian

```bash
# 导入公钥
wget -qO - https://www.mongodb.org/static/pgp/server-6.0.asc | sudo apt-key add -

# 添加仓库
echo "deb [ arch=amd64,arm64 ] https://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/6.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-6.0.list

# 安装
sudo apt update
sudo apt install mongodb-org

# 启动
sudo systemctl start mongod
sudo systemctl enable mongod

# 验证
mongosh
```

#### Docker 方式

```bash
docker run -d \
  --name mongodb \
  -p 27017:27017 \
  -v mongodb_data:/data/db \
  mongo:6.0
```

### 0.2.4 安装 Redis

#### macOS (Homebrew)

```bash
brew install redis
brew services start redis
redis-cli ping
# 应输出: PONG
```

#### Ubuntu/Debian

```bash
sudo apt install redis-server
sudo systemctl start redis-server
sudo systemctl enable redis-server

```

#### Docker 方式

```bash
docker run -d \
  --name redis \
  -p 6379:6379 \
  -v redis_data:/data \
  redis:6-alpine
```

## 0.3 开发工具配置

### 0.3.1 IntelliJ IDEA 配置

#### 安装推荐插件

1. **Lombok** - 简化 Java 代码
2. **MongoDB** - MongoDB 支持
3. **Redis** - Redis 支持
4. **GitToolBox** - Git 增强
5. **JSON Parser** - JSON 格式化

#### 配置项目

1. **导入项目**: File → Open → 选择 `core-ai` 根目录
2. **配置 JDK**: File → Project Structure → Project SDK → 选择 JDK 21
3. **配置 Maven**: File → Settings → Build Tools → Maven
   - Maven home path: 自动检测
   - User settings file: 默认
   - Local repository: 默认

#### 代码风格配置

```
File → Settings → Editor → Code Style → Java
├── Tabs and Indents
│   ├── Tab size: 4
│   ├── Indent: 4
│   └── Continuation indent: 8
├── Spaces
│   └── Around Operators: 勾选所有
└── Imports
    ├── Class count to use import with '*': 999
    └── Names count to use import with '*': 999
```

### 0.3.2 VS Code 配置

#### 安装推荐扩展

```bash
# Java 扩展包
code --install-extension vscjava.vscode-java-pack

# MongoDB 扩展
code --install-extension mongodb.mongodb-vscode

# Redis 扩展
code --install-extension cweijan.vscode-redis-client

# Git 扩展
code --install-extension eamodio.gitlens
```

#### 配置文件

创建 `.vscode/settings.json`:

```json
{
  "java.configuration.runtimes": [
    {
      "name": "JavaSE-21",
      "path": "/path/to/jdk-21",
      "default": true
    }
  ],
  "java.jdt.ls.java.home": "/path/to/jdk-21",
  "maven.executable.path": "/path/to/mvn",
  "editor.formatOnSave": true,
  "editor.tabSize": 4,
  "editor.insertSpaces": true
}
```

## 0.4 项目导入

### 0.4.1 克隆项目

```bash
# 克隆仓库
git clone https://github.com/chancetop-com/core-ai.git
cd core-ai

# 查看项目结构
tree -L 2 -d
```

预期输出:

```
core-ai/
├── core-ai/              # 内核 SDK
├── core-ai-server/       # 服务端（本教程重点）
├── core-ai-cli/          # 命令行工具
├── core-ai-frontend/     # 前端应用
├── core-ai-sandbox/      # 沙箱环境
├── core-ai-benchmark/    # 性能测试
├── docs/                 # 文档
└── pom.xml              # Maven 配置
```

### 0.4.2 构建项目

```bash
# 首次构建（下载依赖）
./mvnw clean install -DskipTests

# 编译核心模块
./mvnw clean compile -pl core-ai,core-ai-server

# 运行测试
./mvnw test -pl core-ai-server
```

⚠️ **注意**: 首次构建可能需要 10-15 分钟下载依赖。

### 0.4.3 配置文件

创建 `core-ai-server/src/main/resources/application-local.yml`:

```yaml
server:
  port: 8080

mongodb:
  uri: mongodb://localhost:27017/core-ai

redis:
  host: localhost
  port: 6379
  password:

llm:
  default-provider: openai
  providers:
    openai:
      api-key: ${OPENAI_API_KEY}
      base-url: https://api.openai.com/v1
      model: gpt-4

auth:
  admin:
    email: admin@example.com
    password: admin123
    name: Admin

logging:
  level:
    root: INFO
    ai.core.server: DEBUG
```

## 0.7 常见问题

### Q1: Maven 下载依赖很慢

**解决方案**: 配置 Maven 镜像

编辑 `~/.m2/settings.xml`:

```xml
<mirrors>
  <mirror>
    <id>aliyunmaven</id>
    <mirrorOf>central</mirrorOf>
    <name>阿里云公共仓库</name>
    <url>https://maven.aliyun.com/repository/public</url>
  </mirror>
</mirrors>
```

### Q2: MongoDB 连接失败

**排查步骤**:

1. 检查 MongoDB 是否运行:
   ```bash
   systemctl status mongod
   ```

2. 检查端口是否被占用:
   ```bash
   lsof -i :27017
   ```

3. 检查连接字符串:
   ```bash
   mongosh mongodb://localhost:27017/core-ai
   ```

### Q3: Redis 连接失败

**排查步骤**:

1. 检查 Redis 是否运行:
   ```bash
   redis-cli ping
   ```

2. 检查端口:
   ```bash
   lsof -i :6379
   ```

3. 检查密码配置（如果有）

### Q4: 编译失败 "找不到符号"

**解决方案**:

```bash
# 清理并重新构建
./mvnw clean
./mvnw install -DskipTests

# 强制更新依赖
./mvnw dependency:resolve -U
```

### Q5: 测试失败

**解决方案**:

```bash
# 查看详细错误
./mvnw test -pl core-ai-server -X

# 跳过失败继续
./mvnw test -pl core-ai-server -Dmaven.test.failure.ignore=true

# 查看测试报告
cat core-ai-server/target/surefire-reports/*.txt
```
