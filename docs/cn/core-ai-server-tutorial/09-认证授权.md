## 9.1 认证授权概述

### 9.1.1 认证 vs 授权

| 概念 | 说明 | 示例 |
|------|------|------|
| **认证（Authentication）** | 验证用户身份 | 用户名/密码、JWT Token |
| **授权（Authorization）** | 验证用户权限 | RBAC、权限检查 |

```
┌─────────────────────────────────────────┐
│              认证授权流程                │
├─────────────────────────────────────────┤
│                                         │
│  1. 认证                                │
│     ├─ 用户名/密码 → 验证 → JWT Token   │
│     ├─ API Key → 验证 → 用户身份        │
│     └─ OAuth → 验证 → 用户身份          │
│                                         │
│  2. 授权                                │
│     ├─ 角色检查（ADMIN/USER/GUEST）     │
│     ├─ 权限检查（read/write/delete）    │
│     └─ 资源检查（所属关系）             │
│                                         │
└─────────────────────────────────────────┘
```

### 9.1.2 core-ai-server 的认证方式

core-ai-server 支持多种认证方式：

| 认证方式 | 适用场景 | 安全级别 |
|---------|---------|---------|
| **JWT Token** | Web 应用、移动应用 | 高 |
| **API Key** | 程序化访问、CLI | 中 |
| **Basic Auth** | 内部服务调用 | 低 |
| **OAuth 2.0** | 第三方集成 | 高 |

### 9.1.3 AuthModule 架构

```java
public class AuthModule extends Module {
    @Override
    protected void initialize() {
        // 1. 认证服务
        bind(UserService.class);
        bind(AuthService.class);

        http().route(POST, "/api/auth/logout", authController::logout);
        http().route(POST, "/api/auth/refresh", authController::refresh);
    }
}
```

## 9.2 认证机制

### 9.2.1 用户名/密码认证

```java
@RestController
public class AuthController {
    @Inject
    private AuthService authService;
    
    @POST("/api/auth/login")
    public LoginResponse login(@Body LoginRequest request) {
        // 1. 验证用户名和密码
        var user = authService.authenticate(
            request.getUsername(), 
            request.getPassword()
        );
        
        if (user == null) {
            throw new AuthenticationException("Invalid credentials");
        }
        
        // 2. 生成 JWT Token
        var token = authService.generateToken(user);
        
        // 3. 返回响应
        return new LoginResponse(
            token,
            user.getId(),
            user.getUsername(),
            user.getRole()
        );
    }
}

public class AuthService {
    @Inject
    private UserRepository userRepository;
    
    @Inject
    private JwtTokenProvider tokenProvider;
    
    public User authenticate(String username, String password) {
        var user = userRepository.findByUsername(username);
        
        if (user == null) {
            return null;
        }
        
        // 验证密码（使用 BCrypt）
        if (!passwordEncoder.matches(password, user.getPassword())) {
            return null;
        }
        
        // 检查账户状态
        if (!user.isEnabled()) {
            throw new AccountDisabledException("Account is disabled");
        }
        
        return user;
    }
    
    public String generateToken(User user) {
        return tokenProvider.generateToken(user);
    }
}
```

### 9.2.2 认证拦截器

```java
public class JwtAuthInterceptor implements Interceptor {
    @Inject
    private JwtTokenProvider tokenProvider;
    
    @Inject
    private UserService userService;
    
    @Override
    public void intercept(Request request, Response response, Chain chain) {
        // 1. 检查是否是公开端点
        if (isPublicEndpoint(request.path())) {
            chain.proceed(request, response);
            return;
        }
        
        // 2. 提取 Token
        var authHeader = request.header("Authorization");
        if (authHeader == null || !authHeader.startsWith("Bearer ")) {
            throw new UnauthorizedException("Missing or invalid Authorization header");
        }
        
        var token = authHeader.substring(7);
        
        // 3. 验证 Token
        var claims = tokenProvider.validateToken(token);
        if (claims == null) {
            throw new UnauthorizedException("Invalid or expired token");
        }
        
        // 4. 加载用户信息
        var userId = claims.getSubject();
        var user = userService.findById(userId);
        if (user == null) {
            throw new UnauthorizedException("User not found");
        }
        
        // 5. 设置请求上下文
        request.setAttribute("currentUser", user);
        request.setAttribute("userId", userId);
        
        // 6. 继续处理
        chain.proceed(request, response);
    }
    
    private boolean isPublicEndpoint(String path) {
        var publicPaths = List.of(
            "/api/auth/login",
            "/api/auth/register",
            "/health",
            "/metrics"
        );
        return publicPaths.stream().anyMatch(path::startsWith);
    }
}
```

### 9.2.3 API Key 认证

```java
public class ApiKeyAuthInterceptor implements Interceptor {
    @Inject
    private ApiKeyService apiKeyService;
    
    @Override
    public void intercept(Request request, Response response, Chain chain) {
        var apiKey = request.header("X-API-Key");
        
        if (apiKey == null) {
            // 尝试 JWT 认证
            chain.proceed(request, response);
            return;
        }
        
        // 验证 API Key
        var apiKeyEntity = apiKeyService.validateApiKey(apiKey);
        if (apiKeyEntity == null) {
            throw new UnauthorizedException("Invalid API Key");
        }
        
        // 检查权限
        var requiredPermission = getRequiredPermission(request);
        if (!apiKeyEntity.hasPermission(requiredPermission)) {
            throw new ForbiddenException("Insufficient permissions");
        }
        
        // 设置请求上下文
        request.setAttribute("apiKey", apiKeyEntity);
        request.setAttribute("userId", apiKeyEntity.getUserId());
        
        chain.proceed(request, response);
    }
}
```

## 9.3 JWT Token 管理

### 9.3.1 Token 结构

JWT Token 由三部分组成：

```
Header.Payload.Signature
```

**Header**:
```json
{
  "alg": "HS256",
  "typ": "JWT"
}
```

**Payload**:
```json
{
  "sub": "user123",
  "name": "John Doe",
  "role": "ADMIN",
  "iat": 1516239022,
  "exp": 1516242622
}
```

**Signature**:
```
HMACSHA256(
  base64UrlEncode(header) + "." +
  base64UrlEncode(payload),
  secret
)
```

### 9.3.2 Token Provider

```java
public class JwtTokenProvider {
    @Inject
    private JwtConfig config;
    
    /**
     * 生成 Token
     */
    public String generateToken(User user) {
        var now = new Date();
        var expiry = new Date(now.getTime() + config.getExpiration() * 1000);
        
        return Jwts.builder()
            .setSubject(user.getId())
            .claim("username", user.getUsername())
            .claim("role", user.getRole())
            .setIssuedAt(now)
            .setExpiration(expiry)
            .signWith(SignatureAlgorithm.HS256, config.getSecret())
            .compact();
    }
    
    /**
     * 验证 Token
     */
    public Claims validateToken(String token) {
        try {
            return Jwts.parser()
                .setSigningKey(config.getSecret())
                .parseClaimsJws(token)
                .getBody();
        } catch (ExpiredJwtException e) {
            throw new TokenExpiredException("Token has expired");
        } catch (JwtException e) {
            throw new InvalidTokenException("Invalid token");
        }
    }
    
    /**
     * 刷新 Token
     */
    public String refreshToken(String token) {
        var claims = validateToken(token);
        var userId = claims.getSubject();
        
        var user = userService.findById(userId);
        if (user == null) {
            throw new UserNotFoundException("User not found");
        }
        
        return generateToken(user);
    }
    
    /**
     * 解析 Token
     */
    public Claims parseToken(String token) {
        return Jwts.parser()
            .setSigningKey(config.getSecret())
            .parseClaimsJws(token)
            .getBody();
    }
}
```

### 9.3.3 Token 刷新机制

```java
public class TokenRefreshService {
    @Inject
    private JwtTokenProvider tokenProvider;
    
    @Inject
    private RedisClient redisClient;
    
    /**
     * 刷新 Token
     */
    public String refreshToken(String oldToken) {
        // 1. 验证旧 Token
        var claims = tokenProvider.validateToken(oldToken);
        
        // 2. 检查是否在黑名单中（已登出）
        if (isTokenBlacklisted(oldToken)) {
            throw new InvalidTokenException("Token has been revoked");
        }
        
        // 3. 生成新 Token
        var newToken = tokenProvider.refreshToken(oldToken);
        
        // 4. 将旧 Token 加入黑名单
        blacklistToken(oldToken, claims.getExpiration());
        
        return newToken;
    }
    
    /**
     * Token 黑名单
     */
    public void blacklistToken(String token, Date expiration) {
        var ttl = expiration.getTime() - System.currentTimeMillis();
        redisClient.setex("token:blacklist:" + token, ttl / 1000, "1");
    }
    
    public boolean isTokenBlacklisted(String token) {
        return redisClient.exists("token:blacklist:" + token);
    }
}
```

### 9.4.3 权限检查拦截器

```java
public class PermissionInterceptor implements Interceptor {
    @Override
    public void intercept(Request request, Response response, Chain chain) {
        var method = request.getAttribute("handlerMethod");
        if (method == null) {
            chain.proceed(request, response);
            return;
        }
        
        // 检查 @RequiresPermission
        var permissionAnnotation = method.getAnnotation(RequiresPermission.class);
        if (permissionAnnotation != null) {
            var requiredPermissions = permissionAnnotation.value();
            var user = (User) request.getAttribute("currentUser");
            
            if (!hasPermissions(user, requiredPermissions)) {
                throw new ForbiddenException("Insufficient permissions");
            }
        }
        
        // 检查 @RequiresRole
        var roleAnnotation = method.getAnnotation(RequiresRole.class);
        if (roleAnnotation != null) {
            var requiredRoles = roleAnnotation.value();
            var user = (User) request.getAttribute("currentUser");
            
            if (!hasRole(user, requiredRoles)) {
                throw new ForbiddenException("Insufficient role");
            }
        }
        
        chain.proceed(request, response);
    }
    
    private boolean hasPermissions(User user, Permission[] permissions) {
        var userPermissions = user.getPermissions();
        return Arrays.stream(permissions)
            .allMatch(userPermissions::contains);
    }
    
    private boolean hasRole(User user, Role[] roles) {
        return Arrays.stream(roles)
            .anyMatch(role -> role == user.getRole());
    }
}
```

### 9.5.1 API Key 实体

### 9.5.2 API Key 服务

```java
public class ApiKeyService {
    @Inject
    private MongoCollection<ApiKey> apiKeyCollection;
    
    /**
     * 创建 API Key
     */
    public ApiKey createApiKey(String userId, String name, String role) {
        var apiKey = new ApiKey();
        apiKey.id = UUID.randomUUID().toString();
        apiKey.key = generateKey();
        apiKey.name = name;
        apiKey.userId = userId;
        apiKey.role = role;
        apiKey.permissions = getPermissionsForRole(role);
        apiKey.enabled = true;
        apiKey.createdAt = ZonedDateTime.now();
        
        apiKeyCollection.insert(apiKey);
        
        return apiKey;
    }
    
    /**
     * 验证 API Key
     */
    public ApiKey validateApiKey(String key) {
        var apiKey = apiKeyCollection.find(Filters.eq("key", key)).first();
        
        if (apiKey == null) {
            return null;
        }
        
        if (!apiKey.enabled) {
            return null;
        }
        
        // 检查过期时间
        if (apiKey.expiresAt != null && 
            apiKey.expiresAt.isBefore(ZonedDateTime.now())) {
            return null;
        }
        
        // 更新最后使用时间
        apiKeyCollection.update(
            Filters.eq("_id", apiKey.id),
            Updates.set("lastUsedAt", ZonedDateTime.now())
        );
        
        return apiKey;
    }
    
    /**
     * 生成 API Key
     */
    private String generateKey() {
        return "cai_" + UUID.randomUUID().toString().replace("-", "");
    }
    
    /**
     * 撤销 API Key
     */
    public void revokeApiKey(String keyId) {
        apiKeyCollection.update(
            Filters.eq("_id", keyId),
            Updates.set("enabled", false)
        );
    }
}
```

### 9.6.2 OAuth 服务

```java
public class OAuthService {
    @Inject
    private OAuthConfig oauthConfig;
    
    @Inject
    private UserService userService;
    
    /**
     * 获取授权 URL
     */
    public String getAuthorizationUrl(String provider, String redirectUri) {
        var config = oauthConfig.getProvider(provider);
        
        return config.getAuthorizeUrl() +
            "?client_id=" + config.getClientId() +
            "&redirect_uri=" + URLEncoder.encode(redirectUri) +
            "&response_type=code" +
            "&scope=user:email";
    }
    
    /**
     * 处理授权回调
     */
    public User handleCallback(String provider, String code, String redirectUri) {
        var config = oauthConfig.getProvider(provider);
        
        // 1. 交换 Access Token
        var accessToken = exchangeCodeForToken(config, code, redirectUri);
        
        // 2. 获取用户信息
        var userInfo = getUserInfo(config, accessToken);
        
        // 3. 查找或创建用户
        var user = userService.findOrCreateByOAuth(provider, userInfo);
        
        return user;
    }
    
    private String exchangeCodeForToken(OAuthProviderConfig config, 
                                        String code, 
                                        String redirectUri) {
        var request = HttpRequest.newBuilder()
            .uri(URI.create(config.getTokenUrl()))
            .header("Accept", "application/json")
            .POST(HttpRequest.BodyPublishers.ofString(
                "client_id=" + config.getClientId() +
                "&client_secret=" + config.getClientSecret() +
                "&code=" + code +
                "&redirect_uri=" + URLEncoder.encode(redirectUri)
            ))
            .build();
        
        var response = httpClient.send(request, BodyHandlers.ofString());
        var json = JsonUtil.parseJson(response.body());
        
        return json.getString("access_token");
    }
}
```

### 9.6.3 OAuth 控制器

```java
@RestController
public class OAuthController {
    @Inject
    private OAuthService oauthService;
    
    @Inject
    private AuthService authService;
    
    @GET("/api/oauth/{provider}/authorize")
    public void authorize(@Path("provider") String provider,
                         @Param("redirect_uri") String redirectUri,

        response.redirect(authUrl);
    }
    
    @GET("/api/oauth/{provider}/callback")

                                 @Param("code") String code,
                                 @Param("redirect_uri") String redirectUri) {

        var token = authService.generateToken(user);
        
        return new LoginResponse(token, user.getId(), user.getUsername(), user.getRole());
    }
}
```

```java
public class RateLimitInterceptor implements Interceptor {
    @Inject
    private RedisClient redisClient;
    
    @Override
    public void intercept(Request request, Response response, Chain chain) {
        var userId = request.getAttribute("userId");
        var key = "rate_limit:" + userId;
        
        // 滑动窗口限流
        var count = redisClient.incr(key);
        if (count == 1) {
            redisClient.expire(key, 60);  // 1 分钟窗口
        }
        
        var limit = 100;  // 每分钟 100 次
        if (count > limit) {
            throw new RateLimitExceededException("Rate limit exceeded");
        }
        
        chain.proceed(request, response);
    }
}
```

### 9.8.1 需求

- 支持 IP 白名单

### 9.8.2 实现

#### 1. MFA 认证

```java
public class MfaAuthService {
    @Inject
    private RedisClient redisClient;
    
    /**
     * 发送验证码
     */
    public void sendVerificationCode(String userId, String method) {
        var code = generateCode();
        var key = "mfa:" + userId;
        
        redisClient.setex(key, 300, code);  // 5 分钟过期
        
        if ("email".equals(method)) {
            emailService.send(userId, "Verification Code", 
                "Your code is: " + code);
        } else if ("sms".equals(method)) {
            smsService.send(userId, "Your code is: " + code);
        }
    }
    
    /**
     * 验证验证码
     */
    public boolean verifyCode(String userId, String code) {
        var key = "mfa:" + userId;
        var storedCode = redisClient.get(key);
        
        if (storedCode == null) {
            return false;
        }
        
        if (!storedCode.equals(code)) {
            return false;
        }
        
        redisClient.del(key);
        return true;
    }
    
    private String generateCode() {
        return String.format("%06d", new Random().nextInt(999999));
    }
}
```

#### 2. IP 白名单

```java
public class IpWhitelistService {
    @Inject
    private MongoCollection<IpWhitelist> whitelistCollection;
    
    public boolean isAllowed(String userId, String ipAddress) {
        var whitelist = whitelistCollection.find(
            Filters.eq("userId", userId)
        ).first();
        
        if (whitelist == null) {
            return true;  // 未配置白名单，允许所有
        }
        
        return whitelist.getIps().contains(ipAddress);
    }
}

public class IpWhitelistInterceptor implements Interceptor {
    @Inject
    private IpWhitelistService whitelistService;
    
    @Override
    public void intercept(Request request, Response response, Chain chain) {
        var userId = request.getAttribute("userId");
        var ipAddress = request.header("X-Forwarded-For");
        
        if (!whitelistService.isAllowed(userId, ipAddress)) {
            throw new ForbiddenException("IP address not allowed");
        }
        
        chain.proceed(request, response);
    }
}
```

```java
public class DeviceFingerprintService {
    public String generateFingerprint(Request request) {
        var userAgent = request.header("User-Agent");
        var ip = request.header("X-Forwarded-For");
        var acceptLanguage = request.header("Accept-Language");
        
        var data = userAgent + ip + acceptLanguage;
        return DigestUtils.sha256Hex(data);
    }
    
    public boolean verifyFingerprint(String userId, String fingerprint) {
        var storedFingerprint = redisClient.get("device:" + userId);
        
        if (storedFingerprint == null) {
            // 首次登录，保存指纹
            redisClient.set("device:" + userId, fingerprint);
            return true;
        }
        
        return storedFingerprint.equals(fingerprint);
    }
}
```

### 9.9.1 Token 过期问题

**问题**: Token 频繁过期，用户体验差

**解决方案**:
```java
// 1. 实现自动刷新
public class TokenRefreshFilter implements Filter {
    @Override
    public void doFilter(Request request, Response response, Chain chain) {
        var token = extractToken(request);
        var claims = tokenProvider.parseToken(token);
        
        // 如果 Token 即将过期（< 5 分钟），自动刷新
        var expiration = claims.getExpiration();
        var timeLeft = expiration.getTime() - System.currentTimeMillis();
        
        if (timeLeft < 5 * 60 * 1000) {
            var newToken = tokenProvider.refreshToken(token);
            response.header("X-New-Token", newToken);
        }
        
        chain.doFilter(request, response);
    }
}
```
