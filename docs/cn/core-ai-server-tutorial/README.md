> 🎯 **面向初学者的 core-ai-server 完整学习教程**

## 📚 教程概览

core-ai-server 是 core-ai 框架的服务端实现，基于 **Java 21** 和 **core-ng 框架**，采用模块化架构设计，提供：

- 🤖 **Agent 会话管理** - 完整的对话生命周期管理
- 🔄 **工作流引擎** - 可视化工作流编排和执行
- 🌐 **LLM 网关** - 统一的 LLM 调用和负载均衡
- 📊 **可观测性** - 追踪、日志和监控
- 🔗 **A2A 协议** - Agent-to-Agent 通信协议
- 🛠️ **MCP 服务器** - Model Context Protocol 实现
- 🔐 **认证授权** - 完整的用户认证和权限管理
