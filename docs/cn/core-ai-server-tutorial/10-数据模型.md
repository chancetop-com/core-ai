## 10.1 数据模型概述

### 10.1.1 MongoDB vs 关系数据库

| 特性 | MongoDB | MySQL/PostgreSQL |
|------|---------|-----------------|
| **数据模型** | 文档模型（灵活） | 表格模型（严格） |
| **Schema** | 动态 Schema | 固定 Schema |
| **扩展性** | 水平扩展 | 垂直扩展 |
| **事务** | 多文档事务 | 强事务支持 |
| **查询** | 丰富的查询语言 | SQL 标准 |
| **适用场景** | 灵活结构、大数据量 | 复杂关系、强一致性 |

## 10.3 实体关系设计

### 10.3.1 关系类型

MongoDB 支持三种关系模式：

**1. 嵌入（Embedding）**
```java
@Document("users")
public class User {
    @Field("profile")
    private UserProfile profile;  // 嵌入存储
}

// 优点：查询快，一次读取
// 缺点：数据冗余，更新复杂
```

**2. 引用（Referencing）**
```java
@Document("sessions")
public class Session {
    @Field("user_id")
    private String userId;  // 引用用户 ID
    
    @Field("agent_id")
    private String agentId;  // 引用 Agent ID
}

// 优点：数据一致，易于更新
// 缺点：需要多次查询
```

**3. 混合（Mixed）**
```java
@Document("agents")
public class Agent {
    @Field("config")
    private AgentConfig config;  // 嵌入配置
    
    @Field("tool_ids")
    private List<String> toolIds;  // 引用工具 ID
}

// 结合嵌入和引用的优点
```

### 10.3.3 关联查询

```java
public class SessionService {
    @Inject
    private MongoCollection<Session> sessionCollection;
    
    @Inject
    private MongoCollection<User> userCollection;
    
    /**
     * 查询会话（包含用户信息）
     */
    public SessionDTO getSessionWithUser(String sessionId) {
        var session = sessionCollection.findById(sessionId);
        if (session == null) {
            return null;
        }
        
        var user = userCollection.findById(session.getUserId());
        
        return SessionDTO.builder()
            .id(session.getId())
            .title(session.getTitle())
            .user(UserDTO.from(user))
            .build();
    }
    
    /**
     * 使用聚合查询（更高效）
     */
    public List<SessionDTO> getSessionsWithUser(String userId) {
        var pipeline = List.of(
            Aggregates.match(Filters.eq("user_id", userId)),
            Aggregates.lookup("users", "user_id", "_id", "user"),
            Aggregates.unwind("$user"),
            Aggregates.project(Projections.fields(
                Projections.include("title", "status", "message_count"),
                Projections.computed("user", "$user")
            ))
        );
        
        return sessionCollection.aggregate(pipeline, SessionDTO.class);
    }
}
```

💡 **最佳实践**:
- 频繁查询的数据使用嵌入
- 独立更新的数据使用引用
- 使用聚合查询优化关联查询
- 避免过深的嵌套（最多 3 层）

### 10.4.2 索引策略

```java
@Component
public class IndexInitializer {
    @Inject
    private MongoCollection<User> userCollection;
    
    @Inject
    private MongoCollection<Agent> agentCollection;
    
    @Inject
    private MongoCollection<Session> sessionCollection;
    
    @Inject
    private MongoCollection<Message> messageCollection;
    
    @PostConstruct
    public void initializeIndexes() {
        // User 索引
        userCollection.createIndex(Indexes.ascending("username"));
        userCollection.createIndex(Indexes.ascending("email"));
        
        // Agent 索引
        agentCollection.createIndex(Indexes.ascending("owner_id"));
        agentCollection.createIndex(Indexes.ascending("status"));
        agentCollection.createIndex(Indexes.text("name", "description"));
        
        // Session 索引
        sessionCollection.createIndex(
            Indexes.compoundIndex(
                Indexes.ascending("user_id"),
                Indexes.descending("created_at")
            )
        );
        sessionCollection.createIndex(Indexes.ascending("agent_id"));
        sessionCollection.createIndex(Indexes.ascending("status"));
        
        // Message 索引
        messageCollection.createIndex(
            Indexes.compoundIndex(
                Indexes.ascending("session_id"),
                Indexes.ascending("created_at")
            )
        );
        
        LOGGER.info("Database indexes initialized");
    }
}
```

💡 **索引原则**:
- 为查询频繁的字段创建索引
- 为排序字段创建索引
- 使用复合索引优化多条件查询
- 避免过多索引（影响写入性能）
- 定期分析慢查询，优化索引

## 10.5 查询优化

### 10.5.1 基础查询

```java
public class UserRepository {
    @Inject
    private MongoCollection<User> userCollection;
    
    /**
     * 按 ID 查询
     */
    public User findById(String id) {
        return userCollection.findById(id);
    }
    
    /**
     * 按条件查询
     */
    public User findByEmail(String email) {
        return userCollection.find(
            Filters.eq("email", email)
        ).first();
    }
    
    /**
     * 分页查询
     */
    public List<User> findUsers(int page, int size) {
        return userCollection.find()
            .skip((page - 1) * size)
            .limit(size)
            .sort(Sorts.descending("created_at"))
            .into(new ArrayList<>());
    }
}
```

### 10.5.2 复杂查询

```java
public class SessionRepository {
    @Inject
    private MongoCollection<Session> sessionCollection;
    
    /**
     * 多条件查询
     */
    public List<Session> findSessions(String userId, SessionStatus status, 
                                      ZonedDateTime startDate, ZonedDateTime endDate) {
        var filters = new ArrayList<Bson>();
        
        if (userId != null) {
            filters.add(Filters.eq("user_id", userId));
        }
        
        if (status != null) {
            filters.add(Filters.eq("status", status));
        }
        
        if (startDate != null) {
            filters.add(Filters.gte("created_at", startDate));
        }
        
        if (endDate != null) {
            filters.add(Filters.lte("created_at", endDate));
        }
        
        var filter = filters.isEmpty() ? 
            Filters.empty() : Filters.and(filters);
        
        return sessionCollection.find(filter)
            .sort(Sorts.descending("created_at"))
            .into(new ArrayList<>());
    }
    
    /**
     * 聚合查询
     */
    public Map<String, Long> countSessionsByStatus(String userId) {
        var pipeline = List.of(
            Aggregates.match(Filters.eq("user_id", userId)),
            Aggregates.group("$status", Accumulators.sum("count", 1))
        );
        
        var results = sessionCollection.aggregate(pipeline).into(new ArrayList<>());
        
        return results.stream()
            .collect(Collectors.toMap(
                doc -> doc.getString("_id"),
                doc -> doc.getLong("count")
            ));
    }
}
```

### 10.5.3 批量操作

```java
public class MessageRepository {
    @Inject
    private MongoCollection<Message> messageCollection;
    
    /**
     * 批量插入
     */
    public void insertMessages(List<Message> messages) {
        messageCollection.insertMany(messages);
    }
    
    /**
     * 批量更新
     */
    public void updateMessages(List<Message> messages) {
        var bulkOps = messages.stream()
            .map(msg -> BulkOps.updateOne(
                Filters.eq("_id", msg.getId()),
                Updates.combine(
                    Updates.set("content", msg.getContent()),
                    Updates.set("updated_at", ZonedDateTime.now())
                )
            ))
            .toList();
        
        messageCollection.bulkWrite(bulkOps);
    }
    
    /**
     * 批量删除
     */
    public void deleteMessages(List<String> ids) {
        messageCollection.deleteMany(
            Filters.in("_id", ids)
        );
    }
}
```

💡 **查询优化技巧**:
- 使用投影减少数据传输
- 使用索引字段查询
- 使用批量操作提高性能
- 避免全表扫描
- 使用聚合管道处理复杂查询

## 10.6 数据迁移

### 10.6.1 迁移策略

**1. Schema 迁移**
```java
public class UserMigration {
    @Inject
    private MongoCollection<User> userCollection;
    
    /**
     * 迁移 1: 添加新字段
     */
    public void migrate1AddLastLoginAt() {
        userCollection.updateMany(
            Filters.exists("last_login_at", false),
            Updates.set("last_login_at", ZonedDateTime.now())
        );
    }
    
    /**
     * 迁移 2: 字段重命名
     */
    public void migrate2RenameField() {
        userCollection.updateMany(
            Filters.exists("name"),
            Updates.rename("name", "display_name")
        );
    }
    
    /**
     * 迁移 3: 数据类型转换
     */
    public void migrate3ConvertType() {
        var users = userCollection.find().into(new ArrayList<>());
        
        for (var user : users) {
            if (user.getLoginCount() instanceof String) {
                var count = Integer.parseInt((String) user.getLoginCount());
                userCollection.updateOne(
                    Filters.eq("_id", user.getId()),
                    Updates.set("login_count", count)
                );
            }
        }
    }
}
```

**2. 数据迁移服务**
```java
public class MigrationService {
    @Inject
    private MongoCollection<Migration> migrationCollection;
    
    /**
     * 执行迁移
     */
    public void runMigrations() {
        var migrations = List.of(
            new Migration("001", "Add last_login_at field", this::migrate001),
            new Migration("002", "Rename name to display_name", this::migrate002),
            new Migration("003", "Convert login_count to integer", this::migrate003)
        );
        
        for (var migration : migrations) {
            if (!isMigrationApplied(migration.getId())) {
                LOGGER.info("Applying migration: {}", migration.getId());
                
                try {
                    migration.getRunnable().run();
                    markMigrationApplied(migration.getId());
                    LOGGER.info("Migration {} applied successfully", migration.getId());
                } catch (Exception e) {
                    LOGGER.error("Migration {} failed", migration.getId(), e);
                    throw new MigrationException("Migration failed: " + migration.getId(), e);
                }
            }
        }
    }
    
    private boolean isMigrationApplied(String id) {
        return migrationCollection.find(
            Filters.eq("_id", id)
        ).first() != null;
    }
    
    private void markMigrationApplied(String id) {
        migrationCollection.insertOne(
            new Migration(id, ZonedDateTime.now())
        );
    }
}
```

#### 2. Repository

```java
public class DatasetRepository {
    @Inject
    private MongoCollection<Dataset> datasetCollection;
    
    public Dataset findById(String id) {
        return datasetCollection.findById(id);
    }
    
    public List<Dataset> findByOwnerId(String ownerId) {
        return datasetCollection.find(
            Filters.eq("owner_id", ownerId)
        ).into(new ArrayList<>());
    }
    
    public Dataset save(Dataset dataset) {
        if (dataset.getId() == null) {
            datasetCollection.insertOne(dataset);
        } else {
            datasetCollection.replaceOne(
                Filters.eq("_id", dataset.getId()),
                dataset
            );
        }
        return dataset;
    }
    
    public void delete(String id) {
        datasetCollection.deleteOne(Filters.eq("_id", id));
    }
    
    public List<Dataset> search(String keyword, int page, int size) {
        return datasetCollection.find(
            Filters.or(
                Filters.regex("name", keyword, "i"),
                Filters.regex("description", keyword, "i")
            )
        ).skip((page - 1) * size)
         .limit(size)
         .into(new ArrayList<>());
    }
}
```

```java
public class DatasetService {
    @Inject
    private DatasetRepository datasetRepository;
    
    @Inject
    private DatasetRecordRepository recordRepository;
    
    public Dataset createDataset(CreateDatasetRequest request, String userId) {
        var dataset = new Dataset();
        dataset.setName(request.getName());
        dataset.setDescription(request.getDescription());
        dataset.setType(request.getType());
        dataset.setOwnerId(userId);
        dataset.setSchema(request.getSchema());
        dataset.setRecordCount(0L);
        dataset.setStatus(DatasetStatus.DRAFT);
        
        return datasetRepository.save(dataset);
    }
    
    public Dataset getDataset(String id) {
        return datasetRepository.findById(id);
    }
    
    public List<Dataset> listDatasets(String userId, int page, int size) {
        return datasetRepository.findByOwnerId(userId);
    }
    
    public void updateDataset(String id, UpdateDatasetRequest request) {
        var dataset = datasetRepository.findById(id);
        if (dataset == null) {
            throw new DatasetNotFoundException("Dataset not found: " + id);
        }
        
        if (request.getName() != null) {
            dataset.setName(request.getName());
        }
        if (request.getDescription() != null) {
            dataset.setDescription(request.getDescription());
        }
        if (request.getSchema() != null) {
            dataset.setSchema(request.getSchema());
        }
        
        datasetRepository.save(dataset);
    }
    
    public void deleteDataset(String id) {
        // 先删除所有记录
        recordRepository.deleteByDatasetId(id);
        
        // 再删除数据集
        datasetRepository.delete(id);
    }
    
    public void addRecord(String datasetId, Map<String, Object> record) {
        var dataset = datasetRepository.findById(datasetId);
        if (dataset == null) {
            throw new DatasetNotFoundException("Dataset not found: " + datasetId);
        }
        
        // 验证记录
        validateRecord(dataset.getSchema(), record);
        
        // 保存记录
        recordRepository.save(datasetId, record);
        
        // 更新记录计数
        dataset.setRecordCount(dataset.getRecordCount() + 1);
        datasetRepository.save(dataset);
    }
    
    private void validateRecord(DatasetSchema schema, Map<String, Object> record) {
        for (var field : schema.getFields()) {
            var value = record.get(field.getName());
            
            if (field.getRequired() && value == null) {
                throw new ValidationException(
                    "Field '" + field.getName() + "' is required"
                );
            }
            
            if (value != null) {
                validateFieldValue(field, value);
            }
        }
    }
    
    private void validateFieldValue(FieldDefinition field, Object value) {
        // 根据字段类型验证
        switch (field.getType()) {
            case STRING:
                if (!(value instanceof String)) {
                    throw new ValidationException(
                        "Field '" + field.getName() + "' must be a string"
                    );
                }
                break;
            case NUMBER:
                if (!(value instanceof Number)) {
                    throw new ValidationException(
                        "Field '" + field.getName() + "' must be a number"
                    );
                }
                break;
            // ... 其他类型
        }
    }
}
```

**问题**: 并发更新导致数据不一致

**解决方案**:
```java
// 使用乐观锁
public class Agent {
    @Field("version")
    private Long version;

// 更新时检查版本
public void updateAgent(Agent agent) {
    var result = agentCollection.updateOne(
        Filters.and(
            Filters.eq("_id", agent.getId()),
            Filters.eq("version", agent.getVersion())
        ),
        Updates.combine(
            Updates.set("name", agent.getName()),
            Updates.inc("version", 1)
        )
    );
    
    if (result.getModifiedCount() == 0) {
        throw new OptimisticLockException("Agent has been modified");
    }
}
```
