## 2.1 启动入口

### 2.1.1 主类

core-ai-server 的启动入口是通过 core-ng 框架的 `App` 类:

```java
// core-ai-server/src/main/java/ai/core/server/ServerApp.java
public class ServerApp extends App {
    @Override
    protected void initialize() {
        // 启动逻辑
    }
}
```

💡 **设计意图**: 继承 `App` 类可以获得 core-ng 框架的完整生命周期管理。

### 2.1.2 启动命令

```bash
# 方式 1: Maven 启动
./mvnw spring-boot:run -pl core-ai-server -Dspring-boot.run.profiles=local

# 方式 2: Java 直接启动
java -jar core-ai-server/target/core-ai-server-1.0.0.jar \
  --spring.profiles.active=local

# 方式 3: Docker 启动
docker run -p 8080:8080 \
  -e SPRING_PROFILES_ACTIVE=local \
  -e MONGODB_URI=mongodb://host.docker.internal:27017/core-ai \
  core-ai-server:latest
```

### 2.1.3 启动参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `--spring.profiles.active` | 激活的配置 profile | `local`, `dev`, `prod` |
| `--server.port` | HTTP 端口 | `8080` |
| `--mongodb.uri` | MongoDB 连接串 | `mongodb://localhost:27017/core-ai` |
| `--redis.host` | Redis 主机 | `localhost` |
| `--logging.level.root` | 日志级别 | `DEBUG`, `INFO` |

## 2.2 应用启动流程

### 2.2.1 启动时序图

```
JVM 启动
    ↓
┌─────────────────────┐
│ ServerApp 实例化     │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│ initialize() 调用    │  ← 核心启动方法
└──────────┬──────────┘
           ↓
    ┌──────┴──────┐
    ↓              ↓
┌────────┐    ┌────────┐
│ 加载   │    │ 加载   │
│ 系统   │    │ 核心   │
│ 配置   │    │ SDK    │
└────────┘    └────────┘
    ↓              ↓
┌─────────────────────┐
│ 注册 MongoDB 集合   │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│ 加载平台基础设施     │  ← 17 个模块
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│ 加载领域模块        │  ← 13 个模块
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│ 加载传输模块        │  ← 1 个模块
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│ 执行启动钩子        │  ← onStartup()
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│ 应用就绪            │
└─────────────────────┘
```

### 2.2.2 启动阶段详解

#### 阶段 1: 系统配置加载 (1-2秒)

```java
// ServerApp.java:77-78
load(new SystemModule("sys.properties"));
loadProperties("agent.properties");
```

**操作**:
1. 加载 `sys.properties` - 系统级配置
2. 加载 `agent.properties` - Agent 相关配置
3. 初始化系统模块

**关键配置**:
```properties
# sys.properties
sys.mongo.uri=mongodb://localhost:27017/core-ai
sys.redis.host=localhost
sys.redis.port=6379
sys.admin.email=admin@example.com
sys.admin.password=admin123
```

#### 阶段 2: 核心 SDK 加载 (2-3秒)

```java
// ServerApp.java:82-85
load(new MultiAgentModule());
load(new ServiceApiModule());
load(new McpServerModule());
load(new McpModule());
```

**操作**:
1. 加载 `MultiAgentModule` - Agent SDK 核心
2. 加载 `ServiceApiModule` - API 定义
3. 加载 `McpServerModule` - MCP 服务器
4. 加载 `McpModule` - MCP 集成

#### 阶段 3: MongoDB 注册 (1-2秒)

```java
// ServerApp.java:87
registerMongo();
```

**操作**: 注册所有 MongoDB 集合和索引（详见 2.4 节）

#### 阶段 4: 平台基础设施加载 (5-8秒)

```java
// ServerApp.java:88
loadPlatformInfrastructure();
```

**操作**: 加载 17 个平台基础设施模块（详见 2.6 节）

#### 阶段 5: 领域模块加载 (3-5秒)

```java
// ServerApp.java:89
loadDomainModules();
```

**操作**: 加载 13 个领域模块（详见 2.7 节）

#### 阶段 6: 传输层加载 (1-2秒)

```java
// ServerApp.java:90
loadTransportModules();
```

**操作**: 加载 Web 模块，注册 HTTP 路由

#### 阶段 7: 启动钩子执行 (2-5秒)

**操作**: 执行所有 `onStartup()` 注册的钩子

#### 阶段 8: 应用就绪

**总启动时间**: 15-25 秒

## 2.3 配置加载机制

### 2.3.1 配置文件优先级

```
命令行参数 > 环境变量 > application-{profile}.yml > application.yml > 默认值
```

### 2.3.2 配置文件结构

```
core-ai-server/src/main/resources/
├── application.yml              # 默认配置
├── application-local.yml        # 本地开发配置
├── application-dev.yml          # 开发环境配置
├── application-prod.yml         # 生产环境配置
├── sys.properties               # 系统配置
└── agent.properties             # Agent 配置
```

### 2.3.3 配置示例

**application.yml** (默认配置):
```yaml
server:
  port: 8080
  
mongodb:
  uri: ${MONGODB_URI:mongodb://localhost:27017/core-ai}
  
redis:
  host: ${REDIS_HOST:localhost}
  port: ${REDIS_PORT:6379}

  admin:
```

```yaml
mongodb:
  uri: mongodb://localhost:27017/core-ai-local
  
logging:
  level:
    root: INFO
```

## 2.4 MongoDB 初始化

### 2.4.1 集合注册

`registerMongo()` 方法注册所有 MongoDB 集合:

```java
// ServerApp.java:148-225
private void registerMongo() {
    var mongo = config(MongoConfig.class);
    mongo.uri(requiredProperty("sys.mongo.uri"));
    
    // 核心集合
    registerCoreCollections(mongo);
    
    // 业务集合
    mongo.collection(SystemPrompt.class);
    mongo.collection(ChatSession.class);
    mongo.collection(ChatMessage.class);
    mongo.collection(AgentDefinition.class);
    // ... 更多集合
    
    // 工作流集合
    registerWorkflowCollections(mongo);
    
    // 追踪集合
    mongo.collection(Trace.class);
    mongo.collection(Span.class);
}
```

### 2.4.2 核心集合

| 集合 | 实体类 | 说明 |
|------|--------|------|
| `users` | `User` | 用户信息 |
| `api_keys` | `ApiKey` | API 密钥 |
| `agents` | `AgentDefinition` | Agent 定义 |
| `sessions` | `ChatSession` | 会话信息 |
| `messages` | `ChatMessage` | 会话消息 |
| `workflows` | `WorkflowDefinition` | 工作流定义 |
| `traces` | `Trace` | 追踪数据 |
| `skills` | `SkillDefinition` | 技能定义 |

### 2.4.3 索引创建

```java
// 自动创建索引
mongo.collection(ChatSession.class, collection -> {
    collection.createIndex(Indexes.ascending("userId", "createdAt"));
    collection.createIndex(Indexes.ascending("agentId"));
});

mongo.collection(Trace.class, collection -> {
    collection.createIndex(Indexes.ascending("traceId"), 
        new IndexOptions().unique(true));
    collection.createIndex(Indexes.ascending("timestamp"));
});
```

💡 **设计意图**: 在启动时创建索引，确保查询性能。


### 2.5.2 加载顺序原则

1. **基础设施优先** - 先加载基础设施模块
2. **被依赖优先** - 被其他模块依赖的先加载
3. **功能分组** - 相关模块按功能分组加载
4. **传输层最后** - 传输层依赖所有应用层模块

### 2.5.3 关键依赖链

```
AuthModule
    ↓
UserModule
    ↓
SessionModule (依赖 Auth, User, ToolRegistry, Skill, Sandbox)
    ↓
AgentRunnerModule (依赖 Session, Trace)
    ↓
WorkflowModule (依赖 AgentRunner, ToolRegistry, Sandbox)
    ↓
WebModule (依赖所有应用层模块)
```

## 2.8 传输层初始化

### 2.8.1 WebModule 初始化

```java
// WebModule.java
public class WebModule extends Module {
    private static final String[] ROOT_FILES = {
        "/favicon.svg", "/favicon.ico", "/icons.svg",
        "/logo-lockup.svg", "/logo-lockup-dark.svg"
    };
    
    @Override
    protected void initialize() {
        registerStaticFiles();
    }
    
    private void registerStaticFiles() {
        var webPath = System.getProperty("core.webPath");
        if (webPath == null) return;
        
        var webDir = Path.of(webPath);
        if (!webDir.toFile().exists()) return;
        
        var controller = new StaticFileController(webDir);
        registerWebAssetsUploader(webDir, controller);
        
        // 注册根文件路由
        for (var path : ROOT_FILES) {
            http().route(HTTPMethod.GET, path, controller::serve);
        }
        
        // 注册 SPA 路由
        var spaRoutes = new String[]{
            "/", "/login", "/chat", "/agents", "/sessions",
            "/workflows", "/traces", "/skills", "/settings"
        };
        for (var path : spaRoutes) {
            http().route(HTTPMethod.GET, path, controller::serve);
        }
    }
    
    private void registerWebAssetsUploader(Path webDir, StaticFileController controller) {
        var uploader = bind(WebAssetsUploader.class);
        onStartup(() -> uploader.upload(webDir, controller));
    }
}
```

**初始化操作**:
1. 创建静态文件控制器
2. 注册根文件路由（favicon 等）
3. 注册 SPA 路由（前端页面）
4. 启动时上传 Web 资源

## 2.9 启动钩子

### 2.9.1 onStartup() 机制

```java
// 注册启动钩子
onStartup(() -> {
    // 启动时执行的逻辑
    authService.initialize();
});

onStartup(() -> {
    // 另一个启动钩子
    workflowRunner.recoverPendingRuns();
});
```

### 2.9.2 常见启动钩子

| 钩子 | 模块 | 作用 |
|------|------|------|
| `authService::initialize` | AuthModule | 初始化管理员用户 |
| `uploader::upload` | WebModule | 上传 Web 资源 |
| `workflowRunner::recoverPendingRuns` | WorkflowModule | 恢复未完成的工作流 |
| `taskRunner::register` | TraceModule | 注册定时任务 |

### 2.9.3 onShutdown() 机制

```java
// 注册关闭钩子
onShutdown(() -> {
    // 关闭时执行的逻辑
    agentRunner.shutdown();
});

onShutdown(() -> {
    // 清理资源
    sandboxService.cleanup();
});
```

## 2.10 启动性能优化

### 2.10.1 并行加载

core-ng 框架支持模块并行加载:

```java
// 配置并行加载
System.setProperty("core.module.parallel", "true");
```

💡 **效果**: 启动时间可减少 30-50%

### 2.10.2 懒加载

某些组件可以延迟初始化:

```java
// 使用 Provider 延迟初始化
@Inject Provider<HeavyService> heavyServiceProvider;

public void doWork() {
    var service = heavyServiceProvider.get();  // 首次调用时才初始化
    service.process();
}
```

### 2.10.3 索引预热

启动时预热关键索引:

```java
onStartup(() -> {
    // 预热常用查询
    agentCollection.find().limit(100).into(new ArrayList<>());
    sessionCollection.find().limit(100).into(new ArrayList<>());
});
```

## 2.11 启动问题排查

### 2.11.1 常见问题

#### 问题 1: MongoDB 连接失败

**症状**:
```
ERROR - Failed to connect to MongoDB: mongodb://localhost:27017/core-ai
```

**排查**:
```bash
# 检查 MongoDB 是否运行
systemctl status mongod

# 检查连接
mongosh mongodb://localhost:27017/core-ai

# 检查端口
lsof -i :27017
```

**解决**:
```yaml
# 修改 application.yml
mongodb:
  uri: mongodb://correct-host:27017/core-ai
```

#### 问题 2: 端口被占用

**症状**:
```
ERROR - Port 8080 is already in use
```

**排查**:
```bash
# 查找占用端口的进程
lsof -i :8080

# 或查看进程
ps aux | grep java
```

**解决**:
```bash
# 杀掉占用进程
kill -9 <PID>

# 或修改端口
java -jar app.jar --server.port=8081
```

#### 问题 3: 模块初始化失败

**症状**:
```
ERROR - Failed to initialize module: SessionModule
Caused by: NullPointerException
```

**排查**:
```bash
# 启用 DEBUG 日志
java -jar app.jar --logging.level.ai.core.server=DEBUG

# 查看详细堆栈
```

**解决**:
- 检查依赖注入是否正确
- 检查配置是否完整
- 检查模块加载顺序
