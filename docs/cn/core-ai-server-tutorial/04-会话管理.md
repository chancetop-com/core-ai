## 4.1 会话管理概述

### 4.1.1 什么是 Agent 会话

Agent 会话是用户与 AI Agent 之间的一次交互过程，包含:

- **对话历史** - 用户消息和 Agent 回复的完整记录
- **上下文状态** - 当前对话的上下文信息
- **工具调用** - Agent 使用的工具及其结果
- **会话元数据** - 创建时间、用户信息、Agent 配置等

💡 **核心概念**: 会话是 Agent 运行的容器，管理着对话的完整生命周期。

### 4.1.2 会话管理的职责

`SessionModule` 负责:

| 职责 | 说明 | 核心类 |
|------|------|--------|
| **会话创建** | 创建新的会话实例 | `AgentSessionManager` |
| **会话存储** | 持久化会话数据 | `SessionRepository` |
| **会话检索** | 查询和加载会话 | `SessionService` |
| **会话清理** | 清理过期会话 | `SessionCleanupJob` |
| **会话事件** | 发布会话相关事件 | `SessionEventPublisher` |

### 4.1.3 会话类型

```
┌─────────────────────────────────┐
│         会话类型                 │
├─────────────────────────────────┤
│ InProcessAgentSession           │  ← 进程内会话（本章重点）
│  - 同一 JVM 进程内运行          │
│  - 低延迟，高吞吐              │
│  - 适合单机部署                │
├─────────────────────────────────┤
│ RemoteAgentSession              │  ← 远程会话
│  - 跨进程/跨机器运行           │
│  - 通过 A2A 协议通信           │
│  - 适合分布式部署              │
└─────────────────────────────────┘
```

💡 **设计意图**: `InProcessAgentSession` 是默认实现，性能最优；`RemoteAgentSession` 用于分布式场景。

## 4.2 AgentSessionManager 详解

### 4.2.1 核心职责

`AgentSessionManager` 是会话管理的核心类，负责:

```java
public class AgentSessionManager {
    @Inject
    private SessionRepository repository;
    
    @Inject
    private AgentFactory agentFactory;
    
    @Inject
    private SessionEventPublisher eventPublisher;
    
    // 会话注册表（内存缓存）
    private final Map<String, InProcessAgentSession> sessions = 
        new ConcurrentHashMap<>();
    
    /**
     * 创建新会话
     */
    public InProcessAgentSession createSession(CreateSessionRequest request) {
        // 1. 创建 Agent 实例
        var agent = agentFactory.create(request.getAgentId());
        
        // 2. 创建会话
        var session = new InProcessAgentSession(
            UUID.randomUUID().toString(),
            agent,
            request.getUserId()
        );
        
        // 3. 持久化
        repository.save(session);
        
        // 4. 注册到内存
        sessions.put(session.getId(), session);
        
        // 5. 发布事件
        eventPublisher.publish(new SessionCreatedEvent(session));
        
        return session;
    }
    
    /**
     * 获取会话
     */
    public InProcessAgentSession getSession(String sessionId) {
        // 先从内存缓存查找
        var session = sessions.get(sessionId);
        if (session != null) {
            return session;
        }
        
        // 从数据库加载
        session = repository.findById(sessionId);
        if (session != null) {
            sessions.put(sessionId, session);
        }
        
        return session;
    }
    
    /**
     * 关闭会话
     */
    public void closeSession(String sessionId) {
        var session = sessions.remove(sessionId);
        if (session != null) {
            session.close();
            repository.update(session);
            eventPublisher.publish(new SessionClosedEvent(session));
        }
    }
    
    /**
     * 清理过期会话
     */
    public void cleanupExpiredSessions(Duration maxIdleTime) {
        var expired = repository.findExpired(maxIdleTime);
        for (var session : expired) {
            closeSession(session.getId());
            logger.info("Cleaned up expired session: {}", session.getId());
        }
    }
}
```

💡 **设计要点**:
- **两级缓存**: 内存缓存 + 数据库，提高查询性能
- **事件驱动**: 会话状态变化发布事件，便于扩展
- **自动清理**: 定时任务清理过期会话，防止内存泄漏

### 4.2.2 会话注册表

```java
// 内存中的会话注册表

    new ConcurrentHashMap<>();

// 优势

// ✅ 线程安全（ConcurrentHashMap）
```

💡 **注意事项**:
- 内存缓存会占用内存，需要限制大小
- 多实例部署时需要分布式缓存（Redis）
- 需要定期清理过期会话

### 4.2.3 并发控制

```java
public class AgentSessionManager {
    // 使用 ConcurrentHashMap 保证线程安全
    private final Map<String, InProcessAgentSession> sessions = 
        new ConcurrentHashMap<>();
    
    public InProcessAgentSession getSession(String sessionId) {
        // 无锁读取
        return sessions.get(sessionId);
    }
    
    public void closeSession(String sessionId) {
        // 原子操作
        sessions.computeIfPresent(sessionId, (id, session) -> {
            session.close();
            return null;  // 移除
        });
    }
}
```

💡 **设计意图**: 使用 `ConcurrentHashMap` 的原子操作，避免显式锁，提高并发性能。

## 4.3 InProcessAgentSession 实现

### 4.3.1 类结构

```java
public class InProcessAgentSession {
    // 会话元数据
    private final String id;
    private final Agent agent;
    private final String userId;
    private final LocalDateTime createdAt;
    
    // 对话历史
    private final List<Message> messages = new ArrayList<>();
    
    // 会话状态
    private SessionStatus status = SessionStatus.ACTIVE;
    private LocalDateTime lastActivityAt;
    
    // 工具调用记录
    private final List<ToolCall> toolCalls = new ArrayList<>();
    
    // 会话上下文
    private final Map<String, Object> context = new HashMap<>();
    
    /**
     * 发送消息
     */
    public String sendMessage(String userMessage) {
        // 1. 添加用户消息
        var userMsg = Message.user(userMessage);
        messages.add(userMsg);
        
        // 2. 调用 Agent
        var response = agent.run(messages);
        
        // 3. 添加 Agent 回复
        var assistantMsg = Message.assistant(response);
        messages.add(assistantMsg);
        
        // 4. 更新活动时间
        lastActivityAt = LocalDateTime.now();
        
        // 5. 发布事件
        eventPublisher.publish(new MessageReceivedEvent(this, userMsg));
        eventPublisher.publish(new MessageSentEvent(this, assistantMsg));
        
        return response;
    }
    
    /**
     * 获取对话历史
     */
    public List<Message> getMessages() {
        return Collections.unmodifiableList(messages);
    }
    
    /**
     * 设置上下文
     */
    public void setContext(String key, Object value) {
        context.put(key, value);
    }
    
    /**
     * 获取上下文
     */
    public Object getContext(String key) {
        return context.get(key);
    }
    
    /**
     * 关闭会话
     */
    public void close() {
        status = SessionStatus.CLOSED;
        agent.close();
    }
}
```

💡 **设计要点**:
- **不可变列表**: `getMessages()` 返回不可变列表，防止外部修改
- **上下文管理**: 使用 Map 存储会话级别的上下文信息
- **状态管理**: 跟踪会话状态（ACTIVE/CLOSED/EXPIRED）

## 4.5 多轮对话机制

### 4.5.1 对话上下文

多轮对话的关键是维护对话上下文:

```java
public class InProcessAgentSession {
    // 对话历史
    private final List<Message> messages = new ArrayList<>();
    
    public String sendMessage(String userMessage) {
        // 1. 添加用户消息
        messages.add(Message.user(userMessage));
        
        // 2. 构建上下文（包含历史消息）
        var context = buildContext();
        
        // 3. 调用 Agent
        var response = agent.run(context);
        
        // 4. 添加 Agent 回复
        messages.add(Message.assistant(response));
        
        return response;
    }
    
    /**
     * 构建对话上下文
     */
    private List<Message> buildContext() {
        // 策略 1: 返回所有历史
        // return messages;
        
        // 策略 2: 只返回最近 N 条
        int maxMessages = 20;
        if (messages.size() > maxMessages) {
            return messages.subList(
                messages.size() - maxMessages, 
                messages.size()
            );
        }
        
        return messages;
    }
}
```

💡 **设计考虑**:
- **上下文窗口**: LLM 有 token 限制，不能传递所有历史
- **相关性**: 早期的消息可能不相关，应该截断
- **成本**: 传递更多 token 会增加成本

### 4.5.2 上下文压缩

```java
public class ContextCompressor {
    @Inject
    private LLMProvider llmProvider;
    
    /**
     * 压缩对话历史
     */
    public String compress(List<Message> messages) {
        // 1. 生成摘要
        var summary = generateSummary(messages);
        
        // 2. 保留最近的消息
        var recentMessages = messages.subList(
            Math.max(0, messages.size() - 5), 
            messages.size()
        );
        
        // 3. 组合
        return summary + "\n\n" + formatMessages(recentMessages);
    }
    
    private String generateSummary(List<Message> messages) {
        var prompt = "请总结以下对话的主要内容:\n\n" + 
            formatMessages(messages);
        
        return llmProvider.complete(prompt);
    }
}
```

💡 **优势**:
- 减少 token 消耗
- 保留关键信息
- 提高响应速度

### 4.5.3 对话分支

支持对话分支（如用户撤销操作）:

```java
public class InProcessAgentSession {
    // 对话树（支持分支）
    private final MessageTree messageTree = new MessageTree();
    
    public String sendMessage(String userMessage, String parentId) {
        // 在指定父消息下创建分支
        var userMsg = messageTree.addUserMessage(parentId, userMessage);
        
        var response = agent.run(messageTree.getPath(userMsg));
        
        messageTree.addAssistantMessage(userMsg.getId(), response);
        
        return response;
    }
}

// 消息树
public class MessageTree {
    private final Map<String, MessageNode> nodes = new HashMap<>();
    
    public MessageNode addUserMessage(String parentId, String content) {
        var node = new MessageNode(Message.user(content));
        node.setParentId(parentId);
        nodes.put(node.getId(), node);
        return node;
    }
    
    public List<Message> getPath(MessageNode node) {
        var path = new ArrayList<Message>();
        var current = node;
        while (current != null) {
            path.add(0, current.getMessage());
            current = nodes.get(current.getParentId());
        }
        return path;
    }
}
```

💡 **使用场景**:
- 用户撤销操作
- A/B 测试不同的回复
- 探索不同的对话路径

```java
public class SessionRepository {
    @Inject
    private MongoCollection<SessionDocument> collection;
    
    /**
     * 保存会话
     */
    public void save(InProcessAgentSession session) {
        var doc = toDocument(session);
        collection.insertOne(doc);
    }
    
    /**
     * 更新会话
     */
    public void update(InProcessAgentSession session) {
        var doc = toDocument(session);
        collection.replaceOne(
            Filters.eq("_id", session.getId()),
            doc
        );
    }
    
    /**
     * 查找会话
     */
    public InProcessAgentSession findById(String id) {
        var doc = collection.find(Filters.eq("_id", id)).first();
        return doc != null ? toSession(doc) : null;
    }
    
    /**
     * 查找用户的会话
     */
    public List<InProcessAgentSession> findByUserId(String userId) {
        return collection.find(Filters.eq("userId", userId))
            .sort(Sorts.descending("lastActivityAt"))
            .into(new ArrayList<>())
            .stream()
            .map(this::toSession)
            .toList();
    }
    
    /**
     * 查找过期会话
     */
    public List<InProcessAgentSession> findExpired(Duration maxIdleTime) {
        var threshold = LocalDateTime.now().minus(maxIdleTime);
        return collection.find(
            Filters.and(
                Filters.eq("status", SessionStatus.IDLE),
                Filters.lt("lastActivityAt", threshold)
            )
        ).into(new ArrayList<>())
         .stream()
         .map(this::toSession)
         .toList();
    }
}
```

### 4.6.3 增量保存

```java
public class InProcessAgentSession {

    public InProcessAgentSession createSubSession() {

        return new InProcessAgentSession(
            UUID.randomUUID().toString(),
            agent,
            context.getUserInfo().getId(),
            subContext
        );
    }
}
```

## 4.10 会话管理最佳实践

### 4.10.1 内存管理

```java
public class AgentSessionManager {
    // 限制内存中的会话数量
    private static final int MAX_SESSIONS = 10000;
    
    // 使用 LRU 缓存
    private final Map<String, InProcessAgentSession> sessions = 
        Collections.synchronizedMap(
            new LinkedHashMap<>(1000, 0.75f, true) {
                @Override
                protected boolean removeEldestEntry(Map.Entry eldest) {
                    if (size() > MAX_SESSIONS) {
                        // 淘汰最久未使用的会话
                        evictSession(eldest.getKey());
                        return true;
                    }
                    return false;
                }
            }
        );
    
    private void evictSession(String sessionId) {
        var session = sessions.get(sessionId);
        if (session != null) {
            // 持久化到数据库
            repository.update(session);
            // 从内存移除
            sessions.remove(sessionId);
            logger.info("Evicted session: {}", sessionId);
        }
    }
}
```

💡 **优势**:
- 防止内存溢出
- 自动淘汰不活跃会话
- 保证系统稳定性

### 4.10.2 并发安全

```java
public class InProcessAgentSession {
    // 使用读写锁保护消息历史
    private final ReadWriteLock lock = new ReentrantReadWriteLock();
    private final List<Message> messages = new ArrayList<>();
    
    public String sendMessage(String userMessage) {
        lock.writeLock().lock();
        try {
            messages.add(Message.user(userMessage));
            var response = agent.run(messages);
            messages.add(Message.assistant(response));
            return response;
        } finally {
            lock.writeLock().unlock();
        }
    }
    
    public List<Message> getMessages() {
        lock.readLock().lock();
        try {
            return new ArrayList<>(messages);
        } finally {
            lock.readLock().unlock();
        }
    }
}
```

💡 **优势**:
- 读写分离，提高并发性能
- 防止并发修改异常
- 保证数据一致性

### 4.10.3 错误处理

```java
public class InProcessAgentSession {
    public String sendMessage(String userMessage) {
        try {
            return doSendMessage(userMessage);
        } catch (LLMException e) {

        }
    }
}
```

💡 **原则**:
- 捕获具体异常，不要捕获 `Exception`
- 提供有意义的错误信息
- 记录详细日志
- 不要暴露内部实现细节

## 4.11 性能优化

### 4.11.1 批量操作

```java
public class SessionRepository {
    /**
     * 批量保存会话
     */
    public void saveAll(List<InProcessAgentSession> sessions) {
        var docs = sessions.stream()
            .map(this::toDocument)
            .toList();
        
        collection.insertMany(docs);
    }
    
    /**
     * 批量更新
     */
    public void updateAll(List<InProcessAgentSession> sessions) {
        var bulkOps = sessions.stream()
            .map(session -> BulkOps.replaceOne(
                Filters.eq("_id", session.getId()),
                toDocument(session)
            ))
            .toList();
        
        collection.bulkWrite(bulkOps);
    }
}
```

💡 **优势**:
