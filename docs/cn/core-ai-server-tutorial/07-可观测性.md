## 7.1 可观测性概述

### 7.1.1 什么是可观测性

可观测性（Observability）是指通过系统的外部输出来理解系统内部状态的能力。在 AI 应用中，可观测性尤为重要，因为：

| 挑战 | 说明 | 可观测性的作用 |
|------|------|---------------|
| **复杂流程** | Agent 执行涉及多步决策和工具调用 | 追踪完整的执行路径 |
| **LLM 调用** | 多次 LLM 调用，成本和延迟不确定 | 监控 token 使用和成本 |
| **性能问题** | 响应时间波动大 | 识别性能瓶颈 |
| **错误诊断** | 错误可能发生在任何环节 | 快速定位问题根因 |
| **成本优化** | LLM 调用成本高昂 | 分析和优化成本 |

💡 **核心价值**: 可观测性让我们能够理解、调试和优化 AI 应用的行为。

### 7.1.2 三大支柱

可观测性包含三大支柱：

```
┌─────────────────────────────────────────────────────────┐
│                   可观测性三大支柱                        │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐    │
│  │   Traces    │  │   Metrics   │  │    Logs     │    │
│  │   (追踪)    │  │   (指标)    │  │   (日志)    │    │
│  ├─────────────┤  ├─────────────┤  ├─────────────┤    │
│  │ 请求的完整  │  │ 系统的数值  │  │ 离散的事件  │    │
│  │ 执行路径    │  │ 度量        │  │ 记录        │    │
│  ├─────────────┤  ├─────────────┤  ├─────────────┤    │
│  │ - 调用链    │  │ - 延迟      │  │ - 错误信息  │    │
│  │ - 时间线    │  │ - 吞吐量    │  │ - 调试信息  │    │
│  │ - 上下文    │  │ - 错误率    │  │ - 审计记录  │    │
│  │             │  │ - 资源使用  │  │             │    │
│  └─────────────┘  └─────────────┘  └─────────────┘    │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 7.1.3 TraceModule 的职责

`TraceModule` 提供完整的可观测性能力：

```java
public class TraceModule extends Module {
    @Override
    protected void initialize() {
        // 1. 绑定追踪服务
        bind(TraceService.class);
        bind(IngestService.class);
        bind(ModelPricingService.class);
        
        // 2. 注册 OTLP 端点（接收 OpenTelemetry 数据）
        var otlpController = bind(OTLPController.class);
        http().route(POST, "/v1/traces", otlpController::receive);
        
        // 3. 注册追踪查询 API
        api().service(TraceWebService.class, bind(TraceWebServiceImpl.class));
        
        // 4. 注册维护任务
        schedule().fixedRate("trace-daily-maintenance",
            bind(TraceDailyMaintenanceJob.class), Duration.ofHours(1));
        schedule().fixedRate("trace-archive",
            bind(TraceArchivingJob.class), Duration.ofHours(1));
    }
}
```

- 支持 OpenTelemetry 标准协议
- 提供完整的追踪存储和查询能力
- 自动维护和归档历史数据
- 集成成本计算

## 7.3 Trace 数据模型

### 7.3.1 Trace 实体

```java
@Document("traces")
public class Trace {
    @Id
    public String id;                    // 内部 ID
    
    public String traceId;               // OpenTelemetry trace ID
    public String name;                  // 追踪名称（如 agent 名称）
    public String type;                  // 追踪类型（agent/llm_call/tool_call）
    
    // Agent 信息
    public String agentName;             // Agent 名称
    public String agentId;               // Agent ID
    public String model;                 // 使用的模型
    
    // 会话信息
    public String sessionId;             // 会话 ID
    public String userId;                // 用户 ID
    
    // 状态信息
    public TraceStatus status;           // 状态（SUCCESS/ERROR/CANCELLED）
    public String errorMessage;          // 错误信息
    
    // 输入输出
    public String input;                 // 输入内容
    public String output;                // 输出内容
    
    // Token 使用
    public Long inputTokens;             // 输入 token 数
    public Long outputTokens;            // 输出 token 数
    public Long totalTokens;             // 总 token 数
    public Long cachedTokens;            // 缓存 token 数
    
    // 成本
    public Double costUsd;               // 成本（美元）
    
    // 时间信息
    public Long durationMs;              // 持续时间（毫秒）
    public ZonedDateTime startedAt;      // 开始时间
    public ZonedDateTime completedAt;    // 完成时间
    public ZonedDateTime createdAt;      // 创建时间
    public ZonedDateTime updatedAt;      // 更新时间
    
    // 元数据
    public Map<String, Object> metadata; // 额外元数据
    public String source;                // 数据来源（cli/web/api）
}

public enum TraceStatus {
    SUCCESS,      // 成功
    ERROR,        // 错误
    CANCELLED,    // 已取消
    RUNNING       // 运行中
}
```

💡 **设计要点**:
- **traceId**: OpenTelemetry 标准 ID，用于关联所有 span
- **type**: 区分不同类型的追踪（agent 运行、LLM 调用、工具调用）
- **token 统计**: 精确记录 token 使用量
- **成本计算**: 实时计算 LLM 调用成本

### 7.3.2 Trace 类型

```java
public enum TraceType {
    AGENT_RUN,       // Agent 完整运行
    AGENT_TURN,      // Agent 单轮对话
    LLM_CALL,        // LLM 调用
    TOOL_CALL,       // 工具调用
    WORKFLOW_RUN,    // 工作流运行
    WORKFLOW_NODE    // 工作流节点
}
```

💡 **使用场景**:
- **AGENT_RUN**: 追踪完整的 agent 执行过程
- **LLM_CALL**: 追踪单次 LLM 调用
- **TOOL_CALL**: 追踪工具执行

```java
public class Span {

    public SpanStatus status;            // 状态

    public Long outputTokens;            // 输出 token
    public Long totalTokens;             // 总 token
    public Double costUsd;               // 成本
    
    // 属性
    public Map<String, String> attributes;  // 自定义属性
    
    // 事件

    // 元数据
    public ZonedDateTime createdAt;
    public ZonedDateTime updatedAt;
}

public enum SpanStatus {
    OK,           // 成功
    ERROR,        // 错误
    UNSET         // 未设置
}

    public String name;                  // 事件名称
    public ZonedDateTime timestamp;      // 时间戳
    public Map<String, String> attributes;  // 事件属性

```

💡 **设计要点**:
- **spanId/traceId**: OpenTelemetry 标准 ID
- **parentSpanId**: 支持 span 层级关系
- **attributes**: 灵活的自定义属性
- **events**: 记录 span 内的重要事件

### 7.4.2 Span 层级关系

```
Trace: agent.run
├── Span: agent.turn (第 1 轮)
│   ├── Span: llm_call (调用 LLM)
│   │   └── attributes: {model: "gpt-4", tokens: 150}
│   └── Span: tool_call (调用工具)
│       └── attributes: {tool: "search", query: "..."}
├── Span: agent.turn (第 2 轮)
│   ├── Span: llm_call
│   └── Span: tool_call
└── Span: agent.turn (第 3 轮)
    └── Span: llm_call
```

💡 **优势**:
- 清晰的调用链可视化
- 精确的性能分析
- 快速的问题定位

## 7.5 追踪采集服务

### 7.5.1 IngestService 核心逻辑

```java
public class IngestService {
    @Inject
    MongoCollection<Trace> traceCollection;
    @Inject
    MongoCollection<Span> spanCollection;
    @Inject
    ModelPricingService modelPricingService;
    
    /**
     * 采集追踪数据
     */
    public void ingest(IngestRequest request, String authUserId, String source) {
        if (request.spans == null || request.spans.isEmpty()) return;
        
        // 1. 识别根 span（parentSpanId == null）
        Map<String, IngestSpanRequest> rootByTrace = new LinkedHashMap<>();
        for (var spanReq : request.spans) {
            if (spanReq.parentSpanId == null) {
                rootByTrace.put(spanReq.traceId, spanReq);
            }
        }
        
        // 2. 确保 trace 文档存在（先创建 trace，再创建 span）
        Set<String> ensuredTraces = new HashSet<>();
        for (var spanReq : request.spans) {
            if (ensuredTraces.add(spanReq.traceId)) {
                var representative = rootByTrace.getOrDefault(spanReq.traceId, spanReq);
                ensureTrace(spanReq.traceId, representative, request, authUserId, source);
            }
        }
        
        // 3. 保存所有 span
        for (var spanReq : request.spans) {
            saveSpan(spanReq, authUserId);
        }
        
        LOGGER.debug("ingested {} spans for {} traces", 
            request.spans.size(), ensuredTraces.size());
    }
    
    /**
     * 确保 trace 文档存在
     */
    private void ensureTrace(String traceId, IngestSpanRequest rootSpan,
                             IngestRequest request, String authUserId, String source) {
        var existing = traceCollection.find(Filters.eq("trace_id", traceId));
        if (!existing.isEmpty()) {
            updateTrace(traceId, rootSpan);
            return;
        }
        
        var trace = new Trace();
        trace.id = UUID.randomUUID().toString();
        trace.traceId = traceId;
        trace.agentName = attr(rootSpan.attributes, "gen_ai.agent.name");
        trace.agentId = attr(rootSpan.attributes, "gen_ai.agent.id");
        trace.name = friendlyTraceName(rootSpan.name, trace.agentName);
        trace.model = rootSpan.model;
        trace.sessionId = rootSpan.attributes != null ? 
            rootSpan.attributes.get("session.id") : null;
        trace.userId = resolveUserId(authUserId, rootSpan.attributes);
        trace.source = source;
        trace.type = mapTraceType(rootSpan.type);
        trace.status = mapTraceStatus(rootSpan.status, rootSpan.attributes);
        
        // 初始化 token 和成本（必须为数值 0，不能为 null）
        trace.inputTokens = 0L;
        trace.outputTokens = 0L;
        trace.totalTokens = 0L;
        trace.cachedTokens = 0L;
        trace.costUsd = 0.0;
        
        trace.durationMs = rootSpan.durationMs;
        trace.startedAt = toZonedDateTime(rootSpan.startedAtEpochMs);
        trace.completedAt = toZonedDateTime(rootSpan.completedAtEpochMs);
        trace.createdAt = ZonedDateTime.now();
        trace.updatedAt = ZonedDateTime.now();
        
        // 使用 upsert 确保并发安全
        traceCollection.upsert(
            Filters.eq("trace_id", traceId),
            trace
        );
    }
    
    /**
     * 保存 span
     */
    private void saveSpan(IngestSpanRequest spanReq, String authUserId) {
        var span = new Span();
        span.id = UUID.randomUUID().toString();
        span.spanId = spanReq.spanId;
        span.traceId = spanReq.traceId;
        span.parentSpanId = spanReq.parentSpanId;
        span.name = spanReq.name;
        span.type = SpanType.valueOf(spanReq.type.name());
        span.status = SpanStatus.valueOf(spanReq.status.name());
        span.durationMs = spanReq.durationMs;
        span.startedAt = toZonedDateTime(spanReq.startedAtEpochMs);
        span.completedAt = toZonedDateTime(spanReq.completedAtEpochMs);
        span.input = spanReq.input;
        span.output = spanReq.output;
        span.model = spanReq.model;
        span.attributes = spanReq.attributes;
        
        // 计算 token 和成本
        if (spanReq.inputTokens != null || spanReq.outputTokens != null) {
            span.inputTokens = spanReq.inputTokens;
            span.outputTokens = spanReq.outputTokens;
            span.totalTokens = (spanReq.inputTokens != null ? spanReq.inputTokens : 0) +
                              (spanReq.outputTokens != null ? spanReq.outputTokens : 0);
            
            // 计算成本
            if (spanReq.model != null) {
                span.costUsd = modelPricingService.calculateCost(
                    spanReq.model,
                    span.inputTokens,
                    span.outputTokens
                );
                
                // 更新 trace 的 token 和成本
                updateTraceMetrics(spanReq.traceId, span);
            }
        }
        
        span.createdAt = ZonedDateTime.now();
        span.updatedAt = ZonedDateTime.now();
        
        spanCollection.insert(span);
    }
    
    /**
     * 更新 trace 的 token 和成本指标
     */
    private void updateTraceMetrics(String traceId, Span span) {
        traceCollection.update(
            Filters.eq("trace_id", traceId),
            Updates.combine(
                Updates.inc("input_tokens", span.inputTokens),
                Updates.inc("output_tokens", span.outputTokens),
                Updates.inc("total_tokens", span.totalTokens),
                Updates.inc("cost_usd", span.costUsd)
            )
        );
    }
}
```

💡 **设计要点**:
- **先创建 trace**: 确保 span 的 `$inc` 操作有目标
- **并发安全**: 使用 `upsert` 和唯一索引
- **增量更新**: span 的 token 和成本增量更新到 trace
- **成本计算**: 实时计算 LLM 调用成本

## 7.6 追踪查询服务

### 7.6.1 TraceService 核心方法

```java
public class TraceService {
    @Inject
    MongoCollection<Trace> traceCollection;
    @Inject
    MongoCollection<Span> spanCollection;
    
    /**
     * 查询追踪列表
     */
    public List<Trace> list(TraceListFilter filter) {
        if (requiresSearch(filter)) {
            return listWithSearch(filter);
        }
        
        var query = new Query();
        query.skip = filter.offset;
        query.limit = filter.limit;
        query.sort = Sorts.descending("created_at");
        
        var bsonFilters = buildFilters(filter);
        if (!bsonFilters.isEmpty()) {
            query.filter = bsonFilters.size() == 1 ? 
                bsonFilters.getFirst() : Filters.and(bsonFilters);
        }
        
        var traces = traceCollection.find(query);
        TraceServiceHelper.enrichMetricsInBatch(traces, spanCollection);
        return traces;
    }
    
    /**
     * 构建查询过滤器
     */
    private List<Bson> buildFilters(TraceListFilter filter) {
        List<Bson> bsonFilters = new ArrayList<>();
        
        // 搜索查询
        addQueryFilter(bsonFilters, filter.q);
        
        // 类型过滤
        if (filter.type != null && !filter.type.isEmpty()) {
            bsonFilters.add(Filters.eq("type", filter.type));
        }
        
        // Agent 名称过滤
        if (filter.agentName != null && !filter.agentName.isEmpty()) {
            bsonFilters.add(Filters.eq("agent_name", filter.agentName));
        }
        
        // 模型过滤
        if (filter.model != null && !filter.model.isEmpty()) {
            bsonFilters.add(Filters.eq("model", filter.model));
        }
        
        // 状态过滤
        if (filter.status != null && !filter.status.isEmpty()) {
            bsonFilters.add(Filters.eq("status", TraceStatus.valueOf(filter.status)));
        }
        
        // 会话 ID 过滤
        if (filter.sessionId != null && !filter.sessionId.isEmpty()) {
            bsonFilters.add(Filters.eq("session_id", filter.sessionId));
        }
        
        // 用户 ID 过滤
        if (filter.userId != null && !filter.userId.isEmpty()) {
            bsonFilters.add(Filters.eq("user_id", filter.userId));
        }
        
        // 时间范围过滤
        if (filter.startFrom != null) {
            bsonFilters.add(Filters.gte("started_at", filter.startFrom));
        }
        if (filter.startTo != null) {
            bsonFilters.add(Filters.lte("started_at", filter.startTo));
        }
        
        return bsonFilters;
    }
    
    /**
     * 获取追踪详情（包含所有 span）
     */
    public TraceDetail get(String traceId) {
        var trace = traceCollection.find(Filters.eq("trace_id", traceId)).first();
        if (trace == null) {
            throw new NotFoundException("Trace not found: " + traceId);
        }
        
        var spans = spanCollection.find(Filters.eq("trace_id", traceId));
        
        return new TraceDetail(trace, spans);
    }
    
    /**
     * 搜索追踪
     */
    public List<Trace> search(String query, TraceListFilter filter) {
        filter.q = query;
        return listWithSearch(filter);
    }
}
```

```java
public class TraceDailyMaintenanceJob implements Job {
    @Inject
    TraceDailyMaintenanceService maintenanceService;
    
    @Override
    public void execute() {
        LOGGER.info("Starting trace daily maintenance");
        
        try {
            // 1. 计算每日统计
            maintenanceService.calculateDailyStats();
            
            // 2. 清理过期数据
            maintenanceService.cleanupExpiredData();
            
            // 3. 优化索引
            maintenanceService.optimizeIndexes();
            
            LOGGER.info("Trace daily maintenance completed");
        } catch (Exception e) {
            LOGGER.error("Trace daily maintenance failed", e);
        }
    }

public class TraceDailyMaintenanceService {
    @Inject
    MongoCollection<Trace> traceCollection;
    @Inject
    MongoCollection<Span> spanCollection;
    @Inject
    MongoCollection<TraceDailyStats> statsCollection;
    
    /**
     * 计算每日统计
     */
    public void calculateDailyStats() {
        var yesterday = LocalDate.now().minusDays(1);
        var startOfDay = yesterday.atStartOfDay(ZoneId.systemDefault());
        var endOfDay = yesterday.plusDays(1).atStartOfDay(ZoneId.systemDefault());
        
        // 聚合统计
        var pipeline = List.of(
            Aggregates.match(Filters.and(
                Filters.gte("started_at", startOfDay),
                Filters.lt("started_at", endOfDay)
            )),
            Aggregates.group(null,
                Accumulators.sum("trace_count", 1),
                Accumulators.sum("total_tokens", "$total_tokens"),
                Accumulators.sum("total_cost", "$cost_usd"),
                Accumulators.avg("avg_duration", "$duration_ms")
            )
        );
        
        var results = traceCollection.aggregate(pipeline);
        
        if (!results.isEmpty()) {
            var stats = new TraceDailyStats();
            stats.date = yesterday;
            stats.traceCount = results.get(0).getLong("trace_count");
            stats.totalTokens = results.get(0).getLong("total_tokens");
            stats.totalCost = results.get(0).getDouble("total_cost");
            stats.avgDuration = results.get(0).getDouble("avg_duration");
            stats.createdAt = ZonedDateTime.now();
            
            statsCollection.upsert(
                Filters.eq("date", yesterday),
                stats
            );
        }
    }
    
    /**
     * 清理过期数据
     */
    public void cleanupExpiredData() {
        var retentionDays = 90;  // 保留 90 天
        var cutoffDate = LocalDate.now().minusDays(retentionDays)
            .atStartOfDay(ZoneId.systemDefault());
        
        // 删除过期的 trace
        var deletedTraces = traceCollection.delete(
            Filters.lt("started_at", cutoffDate)
        );
        
        // 删除过期的 span
        var deletedSpans = spanCollection.delete(
            Filters.lt("started_at", cutoffDate)
        );
        
        LOGGER.info("Cleaned up {} traces and {} spans older than {} days",
            deletedTraces, deletedSpans, retentionDays);
    }
}
```

### 7.7.2 归档服务

```java
public class TraceArchiveService {
    @Inject
    ObjectStorageService objectStorageService;
    @Inject
    MongoCollection<Trace> traceCollection;
    @Inject
    MongoCollection<Span> spanCollection;
    
    /**
     * 归档旧的追踪数据
     */
    public void archiveOldTraces(int olderThanDays) {
        var cutoffDate = LocalDate.now().minusDays(olderThanDays)
            .atStartOfDay(ZoneId.systemDefault());
        
        // 1. 查询要归档的 trace
        var traces = traceCollection.find(
            Filters.lt("started_at", cutoffDate)
        );
        
        for (var trace : traces) {
            try {
                // 2. 查询关联的 span
                var spans = spanCollection.find(
                    Filters.eq("trace_id", trace.traceId)
                );
                
                // 3. 打包成 JSON
                var archiveData = Map.of(
                    "trace", trace,
                    "spans", spans
                );
                var json = JsonUtil.toJson(archiveData);
                
                // 4. 上传到对象存储
                var key = buildArchiveKey(trace);
                objectStorageService.upload(key, json.getBytes());
                
                // 5. 从 MongoDB 删除
                traceCollection.delete(Filters.eq("_id", trace.id));
                spanCollection.delete(Filters.eq("trace_id", trace.traceId));
                
                LOGGER.debug("Archived trace: {}", trace.traceId);
                
            } catch (Exception e) {
                LOGGER.error("Failed to archive trace: {}", trace.traceId, e);
            }
        }
    }
    
    private String buildArchiveKey(Trace trace) {
        var date = trace.startedAt.toLocalDate();
        return String.format("traces/%d/%02d/%02d/%s.json",
            date.getYear(), date.getMonthValue(), date.getDayOfMonth(),
            trace.traceId);
    }
}
```

💡 **设计要点**:
- **定时维护**: 每小时运行一次维护任务
- **每日统计**: 计算每日的追踪数量、token 使用、成本等
- **数据清理**: 自动清理过期数据
- **归档存储**: 将旧数据归档到对象存储，节省数据库空间

#### 1. 创建追踪上下文

```java
public class CustomWorkflowTracer {
    @Inject
    private Tracer tracer;
    
    /**
     * 追踪工作流执行
     */
    public <T> T traceWorkflow(String workflowId, String workflowName,
                               Supplier<T> workflow) {
        var span = tracer.spanBuilder("workflow.run")
            .setAttribute("workflow.id", workflowId)
            .setAttribute("workflow.name", workflowName)
            .startSpan();
        
        try (var scope = span.makeCurrent()) {
            var result = workflow.get();
            span.setStatus(StatusCode.OK);
            return result;
        } catch (Exception e) {
            span.setStatus(StatusCode.ERROR, e.getMessage());
            span.recordException(e);
            throw e;
        } finally {
            span.end();
        }
    }
    
    /**
     * 追踪节点执行
     */
    public <T> T traceNode(String nodeId, String nodeName, String nodeType,
                           Supplier<T> nodeExecution) {
        var span = tracer.spanBuilder("workflow.node")
            .setAttribute("node.id", nodeId)
            .setAttribute("node.name", nodeName)
            .setAttribute("node.type", nodeType)
            .startSpan();
        
        try (var scope = span.makeCurrent()) {
            var startTime = System.currentTimeMillis();
            var result = nodeExecution.get();
            var duration = System.currentTimeMillis() - startTime;
            
            span.setAttribute("node.duration_ms", duration);
            span.setStatus(StatusCode.OK);
            
            return result;
        } catch (Exception e) {
            span.setStatus(StatusCode.ERROR, e.getMessage());
            span.recordException(e);
            throw e;
        } finally {
            span.end();
        }
    }
}
```

#### 2. 在工作流中使用

```java
public class CustomWorkflowEngine {
    @Inject
    private CustomWorkflowTracer workflowTracer;
    
    public WorkflowResult execute(WorkflowDefinition workflow, 
                                  Map<String, Object> input) {
        return workflowTracer.traceWorkflow(
            workflow.getId(),
            workflow.getName(),
            () -> doExecute(workflow, input)
        );
    }
    
    private WorkflowResult doExecute(WorkflowDefinition workflow,
                                     Map<String, Object> input) {
        var context = new WorkflowContext(input);
        
        for (var node : workflow.getNodes()) {
            var output = workflowTracer.traceNode(
                node.getId(),
                node.getName(),
                node.getType(),
                () -> executeNode(node, context)
            );
            
            context.setNodeOutput(node.getId(), output);
        }
        
        return new WorkflowResult(context.getOutputs());
    }
}
```

```java
// ✅ 好的实践: 完整的错误处理
public CompletionResponse callLLM(CompletionRequest request) {
    var span = tracer.spanBuilder("llm.call")
        .setAttribute("gen_ai.request.model", request.getModel())
        .startSpan();

        span.setAttribute("error.type", e.getClass().getSimpleName());
        span.recordException(e);
        throw e;
    } finally {
        span.end();
    }
}
```
