## 13.1 持久化系统总览

### 13.1.1 持久化的角色

持久化系统是 core-ai 的**状态管理基础设施**，负责：

- **会话持久化**：保存对话历史，支持会话恢复
- **Agent 状态持久化**：保存 Agent 的消息列表、系统变量
- **Flow 状态持久化**：保存 Flow 的执行进度，支持断点续传
- **工具权限持久化**：保存用户的工具审批决策

💡 **设计意图**：AI Agent 系统需要管理大量状态（对话历史、上下文、执行进度），完善的持久化机制可以保证系统可靠性、支持断点续传、跨进程共享。

### 13.1.2 核心类关系图

```
┌─────────────────────────────────────────────────────────────┐
│                PersistenceProvider (interface)              │
│                                                             │
│  + save(id, context)                                        │
│  + load(id): Optional<String>                               │
│  + delete(ids)                                              │
│  + clear()                                                  │
└──────────────────────┬──────────────────────────────────────┘
                       │ 实现
        ┌──────────────┼──────────────┬──────────────┐
        ▼              ▼              ▼              ▼
┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ Temporary    │ │ File         │ │ Redis        │ │ Custom       │
│ Provider     │ │ Provider     │ │ Provider     │ │ Provider     │
│              │ │              │ │              │ │ (用户自定义) │
│ 内存存储     │ │ 文件存储     │ │ Redis 存储   │ │              │
│ 重启丢失     │ │ 本地持久化   │ │ 分布式存储   │ │              │
└──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘
```

### 13.1.3 三种内置实现对比

| 实现 | 存储位置 | 持久性 | 性能 | 适用场景 |
|---|---|---|---|---|
| **Temporary** | 内存 | ❌ 重启丢失 | ⭐⭐⭐⭐⭐ 最快 | 测试、开发 |
| **File** | 本地文件 | ✅ 本地持久化 | ⭐⭐⭐ 中等 | 单机部署 |
| **Redis** | Redis 服务器 | ✅ 分布式持久化 | ⭐⭐⭐⭐ 快 | 分布式部署 |

💡 **设计意图**：
- **Temporary**：最快，但不持久，适合测试和开发
- **File**：简单可靠，适合单机部署
- **Redis**：分布式、高性能，适合生产环境

## 13.2 PersistenceProvider SPI

### 13.2.1 文件位置

```
core-ai/src/main/java/ai/core/persistence/PersistenceProvider.java
```

### 13.2.2 接口定义

```java
public interface PersistenceProvider {
    /**
     * 保存数据
     * @param id 唯一标识
     * @param context 数据内容（JSON 字符串）
     */
    void save(String id, String context);
    
    /**
     * 加载数据
     * @param id 唯一标识
     * @return 数据内容，如果不存在返回 empty
     */
    Optional<String> load(String id);
    
    /**
     * 删除数据
     * @param ids 要删除的 id 列表
     */
    void delete(List<String> ids);
    
    /**
     * 清空所有数据
     */
    void clear();
}
```

💡 **设计意图**：
- **简单接口**：只有 4 个方法，易于实现
- **JSON 字符串**：数据以 JSON 字符串形式存储，便于序列化和反序列化
- **Optional 返回**：load 返回 Optional，明确表达"可能不存在"的语义

### 13.2.3 PersistenceProviders 注册表

```java
public class PersistenceProviders {
    private final Map<String, PersistenceProvider> providers = new ConcurrentHashMap<>();
    
    public void register(String id, PersistenceProvider provider) {
        providers.put(id, provider);
    }
    
    public PersistenceProvider get(String id) {
        return providers.get(id);
    }
    
    public PersistenceProvider getDefault() {
        return providers.values().iterator().next();
    }
    
    public boolean has(String id) {
        return providers.containsKey(id);
    }
}
```

💡 **设计意图**：
- **多 provider 共存**：可以同时注册多个 provider（如 file + redis）
- **按 id 获取**：可以按名字选择 provider
- **默认 provider**：不指定时用第一个注册的

## 13.3 TemporaryPersistenceProvider

### 13.3.1 文件位置

```
core-ai/src/main/java/ai/core/persistence/providers/TemporaryPersistenceProvider.java
```

### 13.3.2 核心实现

```java
public class TemporaryPersistenceProvider implements PersistenceProvider {
    private final Map<String, String> store = new ConcurrentHashMap<>();
    
    @Override
    public void save(String id, String context) {
        store.put(id, context);
    }
    
    @Override
    public Optional<String> load(String id) {
        return Optional.ofNullable(store.get(id));
    }
    
    @Override
    public void delete(List<String> ids) {
        ids.forEach(store::remove);
    }
    
    @Override
    public void clear() {
        store.clear();
    }
}
```

💡 **设计意图**：
- **ConcurrentHashMap**：线程安全，支持并发访问
- **内存存储**：最快，但重启丢失
- **适用场景**：测试、开发、临时会话

| **存储位置** | 内存（JVM 堆） |
| **持久性** | ❌ 重启丢失 |

| **容量** | 受 JVM 内存限制 |

## 13.4 FilePersistenceProvider

### 13.4.1 文件位置

```
core-ai/src/main/java/ai/core/persistence/providers/FilePersistenceProvider.java
```

### 13.4.2 核心实现

```java
public class FilePersistenceProvider implements PersistenceProvider {
    private final Path baseDir;
    
    public FilePersistenceProvider(String basePath) {
        this.baseDir = Path.of(basePath);
        try {
            Files.createDirectories(baseDir);
        } catch (IOException e) {
            throw new RuntimeException("Failed to create persistence directory: " + basePath, e);
        }
    }
    
    @Override
    public void save(String id, String context) {
        var file = baseDir.resolve(id + ".json");
        try {
            Files.writeString(file, context, StandardCharsets.UTF_8);
        } catch (IOException e) {
            throw new RuntimeException("Failed to save persistence: " + id, e);
        }
    }
    
    @Override
    public Optional<String> load(String id) {
        var file = baseDir.resolve(id + ".json");
        if (!Files.exists(file)) {
            return Optional.empty();
        }
        
        try {
            return Optional.of(Files.readString(file, StandardCharsets.UTF_8));
        } catch (IOException e) {
            throw new RuntimeException("Failed to load persistence: " + id, e);
        }
    }
    
    @Override
    public void delete(List<String> ids) {
        for (var id : ids) {
            var file = baseDir.resolve(id + ".json");
            try {
                Files.deleteIfExists(file);
            } catch (IOException e) {
                throw new RuntimeException("Failed to delete persistence: " + id, e);
            }
        }
    }
    
    @Override
    public void clear() {
        try (var stream = Files.list(baseDir)) {
            stream.filter(p -> p.toString().endsWith(".json"))
                  .forEach(p -> {
                      try {
                          Files.delete(p);
                      } catch (IOException e) {
                          throw new RuntimeException("Failed to clear persistence", e);
                      }
                  });
        } catch (IOException e) {
            throw new RuntimeException("Failed to list persistence directory", e);
        }
    }
}
```

💡 **设计意图**：
- **文件存储**：每个 id 对应一个 JSON 文件（`{id}.json`）
- **UTF-8 编码**：支持中文等多字节字符
- **异常处理**：IO 异常转换为 RuntimeException，简化调用方代码
- **目录自动创建**：如果目录不存在，自动创建

### 13.4.3 特点

| 特性 | 说明 |
|---|---|
| **存储位置** | 本地文件系统 |
| **持久性** | ✅ 本地持久化 |
| **性能** | ⭐⭐⭐ 中等（毫秒级） |
| **容量** | 受磁盘空间限制 |
| **并发** | ✅ 线程安全（文件锁） |
| **分布式** | ❌ 不支持（单机） |

## 13.5 RedisPersistenceProvider

### 13.5.1 文件位置

```
core-ai/src/main/java/ai/core/persistence/providers/RedisPersistenceProvider.java
```

### 13.5.2 核心实现

```java
public class RedisPersistenceProvider implements PersistenceProvider {
    private final JedisPool jedisPool;
    private final String keyPrefix;
    
    public RedisPersistenceProvider(String redisUrl) {
        this(redisUrl, "core-ai:");
    }
    
    public RedisPersistenceProvider(String redisUrl, String keyPrefix) {
        this.jedisPool = new JedisPool(redisUrl);
        this.keyPrefix = keyPrefix;
    }
    
    @Override
    public void save(String id, String context) {
        try (var jedis = jedisPool.getResource()) {
            jedis.set(keyPrefix + id, context);
        }
    }
    
    @Override
    public Optional<String> load(String id) {
        try (var jedis = jedisPool.getResource()) {
            var value = jedis.get(keyPrefix + id);
            return Optional.ofNullable(value);
        }
    }
    
    @Override
    public void delete(List<String> ids) {
        try (var jedis = jedisPool.getResource()) {
            var keys = ids.stream()
                .map(id -> keyPrefix + id)
                .toArray(String[]::new);
            jedis.del(keys);
        }
    }
    
    @Override
    public void clear() {
        try (var jedis = jedisPool.getResource()) {
            var keys = jedis.keys(keyPrefix + "*");
            if (!keys.isEmpty()) {
                jedis.del(keys.toArray(new String[0]));
            }
        }
    }
}
```

💡 **设计意图**：
- **Jedis 客户端**：使用 Jedis（Redis 官方 Java 客户端）
- **keyPrefix**：key 前缀（默认 `core-ai:`），避免与其他应用冲突
- **连接池**：使用 JedisPool 管理连接，提高性能
- **try-with-resources**：自动释放连接

### 13.5.3 特点

| 特性 | 说明 |
|---|---|
| **存储位置** | Redis 服务器 |
| **持久性** | ✅ 分布式持久化 |
| **性能** | ⭐⭐⭐⭐ 快（亚毫秒级） |
| **容量** | 受 Redis 内存限制 |
| **并发** | ✅ 线程安全（Redis 单线程） |
| **分布式** | ✅ 支持（多进程共享） |

## 13.6 Persistence 抽象

### 13.6.1 文件位置

```
core-ai/src/main/java/ai/core/persistence/Persistence.java
```

### 13.6.2 接口定义

```java
public interface Persistence<T> {
    /**
     * 保存对象
     */
    void save(T object);
    
    /**
     * 加载对象
     */
    Optional<T> load(String id);
    
    /**
     * 删除对象
     */
    void delete(String id);
}
```

💡 **设计意图**：
- **泛型接口**：支持保存任意类型的对象
- **高层抽象**：封装了序列化和反序列化逻辑
- **与 PersistenceProvider 的关系**：Persistence 使用 PersistenceProvider 作为底层存储

### 13.6.3 实现示例

```java
public class AgentPersistence implements Persistence<Agent> {
    private final PersistenceProvider provider;
    
    public AgentPersistence(PersistenceProvider provider) {
        this.provider = provider;
    }
    
    @Override
    public void save(Agent agent) {
        var state = new AgentState(
            agent.getName(),
            agent.getMessages(),
            agent.getSystemVariables(),
            Instant.now()
        );
        provider.save(agent.getId(), JsonUtil.toJson(state));
    }
    
    @Override
    public Optional<Agent> load(String id) {
        return provider.load(id)
            .map(json -> {
                var state = JsonUtil.fromJson(json, AgentState.class);
                // 重建 Agent（需要从 Builder 重建）
                return rebuildAgent(state);
            });
    }
    
    @Override
    public void delete(String id) {
        provider.delete(List.of(id));
    }
    
    private Agent rebuildAgent(AgentState state) {
        var agent = Agent.builder()
            .name(state.name())
            .build();
        agent.restoreHistory(state.messages());
        agent.setSystemVariables(state.systemVariables());
        return agent;
    }
}
```

💡 **设计意图**：
- **序列化**：把 Agent 转换成 AgentState（可序列化的数据类）
- **反序列化**：从 AgentState 重建 Agent
- **状态类**：AgentState 只包含可序列化的字段（name、messages、variables）

## 13.7 会话持久化

### 13.7.1 SessionPersistence

```java
public class SessionPersistence {
    private final PersistenceProvider persistenceProvider;
    
    public SessionPersistence(PersistenceProvider persistenceProvider) {
        this.persistenceProvider = persistenceProvider;
    }
    
    /**
     * 保存会话状态
     */
    public void save(InProcessAgentSession session) {
        var state = new SessionState(
            session.id(),
            session.agent().getMessages(),
            session.agent().getSystemVariables(),
            Instant.now()
        );
        
        persistenceProvider.save(session.id(), JsonUtil.toJson(state));
    }
    
    /**
     * 加载会话状态
     */
    public Optional<SessionState> load(String sessionId) {
        return persistenceProvider.load(sessionId)
            .map(json -> JsonUtil.fromJson(json, SessionState.class));
    }
    
    /**
     * 删除会话
     */
    public void delete(String sessionId) {
        persistenceProvider.delete(List.of(sessionId));
    }
    
    /**
     * 恢复会话
     */
    public void restore(InProcessAgentSession session) {
        load(session.id()).ifPresent(state -> {
            session.agent().restoreHistory(state.messages());
            session.agent().setSystemVariables(state.systemVariables());
        });
    }
}
```

💡 **设计意图**：
- **SessionState**：封装会话状态（id、messages、variables、timestamp）
- **自动恢复**：restore 方法自动加载并恢复会话状态
- **时间戳**：记录保存时间，便于管理和清理

### 13.7.2 SessionState 数据类

## 13.9 自定义 PersistenceProvider

### 13.9.1 示例：MongoDB Provider

```java
public class MongoPersistenceProvider implements PersistenceProvider {
    private final MongoCollection<Document> collection;
    
    public MongoPersistenceProvider(MongoDatabase database, String collectionName) {
        this.collection = database.getCollection(collectionName);
    }
    
    @Override
    public void save(String id, String context) {
        var doc = new Document()
            .append("_id", id)
            .append("context", context)
            .append("updatedAt", Instant.now());
        
        collection.updateOne(
            Filters.eq("_id", id),
            new Document("$set", doc),
            new UpdateOptions().upsert(true)
        );
    }
    
    @Override
    public Optional<String> load(String id) {
        var doc = collection.find(Filters.eq("_id", id)).first();
        if (doc == null) {
            return Optional.empty();
        }
        return Optional.of(doc.getString("context"));
    }
    
    @Override
    public void delete(List<String> ids) {
        collection.deleteMany(Filters.in("_id", ids));
    }
    
    @Override
    public void clear() {
        collection.deleteMany(new Document());
    }
}
```

💡 **设计意图**：
- **MongoDB**：文档数据库，适合存储 JSON 数据
- **upsert**：如果不存在则插入，存在则更新
- **时间戳**：记录更新时间，便于审计

### 13.9.2 示例：数据库 Provider

```java
public class JdbcPersistenceProvider implements PersistenceProvider {
    private final DataSource dataSource;
    
    public JdbcPersistenceProvider(DataSource dataSource) {
        this.dataSource = dataSource;
    }
    
    @Override
    public void save(String id, String context) {
        try (var conn = dataSource.getConnection();
             var stmt = conn.prepareStatement(
                 "INSERT INTO persistence (id, context, updated_at) VALUES (?, ?, ?) " +
                 "ON CONFLICT (id) DO UPDATE SET context = ?, updated_at = ?"
             )) {
            var now = Instant.now();
            stmt.setString(1, id);
            stmt.setString(2, context);
            stmt.setTimestamp(3, Timestamp.from(now));
            stmt.setString(4, context);
            stmt.setTimestamp(5, Timestamp.from(now));
            stmt.executeUpdate();
        } catch (SQLException e) {
            throw new RuntimeException("Failed to save persistence: " + id, e);
        }
    }
    
    @Override
    public Optional<String> load(String id) {
        try (var conn = dataSource.getConnection();
             var stmt = conn.prepareStatement("SELECT context FROM persistence WHERE id = ?")) {
            stmt.setString(1, id);
            var rs = stmt.executeQuery();
            if (rs.next()) {
                return Optional.of(rs.getString("context"));
            }
            return Optional.empty();
        } catch (SQLException e) {
            throw new RuntimeException("Failed to load persistence: " + id, e);
        }
    }
    
    @Override
    public void delete(List<String> ids) {
        try (var conn = dataSource.getConnection();
             var stmt = conn.prepareStatement("DELETE FROM persistence WHERE id = ANY(?)")) {
            stmt.setArray(1, conn.createArrayOf("varchar", ids.toArray()));
            stmt.executeUpdate();
        } catch (SQLException e) {
            throw new RuntimeException("Failed to delete persistence", e);
        }
    }
    
    @Override
    public void clear() {
        try (var conn = dataSource.getConnection();
             var stmt = conn.prepareStatement("DELETE FROM persistence")) {
            stmt.executeUpdate();
        } catch (SQLException e) {
            throw new RuntimeException("Failed to clear persistence", e);
        }
    }
}
```

💡 **设计意图**：
- **JDBC**：标准数据库访问接口
- **UPSERT**：使用 `ON CONFLICT DO UPDATE` 实现 upsert
- **批量删除**：使用 `ANY(?)` 批量删除
