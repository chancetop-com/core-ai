## 5.1 工具系统总览

### 5.1.1 工具系统的角色

工具系统是 agent 与外部世界交互的**唯一通道**。Agent 通过工具：
- 执行 bash 命令
- 读写文件
- 搜索网页
- 调用 API
- 执行代码
- 调用子 agent

💡 **设计意图**：工具系统是 agent 的"手和脚"，让 agent 能超越纯文本生成，与真实世界交互。

### 5.1.2 核心类关系图

```
┌──────────────────┐         ┌──────────────────┐
│   ToolProvider   │◄────────│  ToolRegistry    │
│   (interface)    │  注册   │                  │

│  + id(): String  │         │  - providerCache │
│  + provide():    │         │                  │
│    Map<name,     │         │  + registerProvider()

│  + priority()    │         │    : ToolMaterialization
│  + refreshPolicy()         └────────┬─────────┘

                                      ▼
┌──────────────────┐         ┌──────────────────┐
│    ToolCall      │◄────────│ToolOrchestration │
│   (abstract)     │  包含   │                  │

│  - name          │         │      toolCalls)   │
│  - description   │         │    : List<Message>│

```

### 5.1.3 工具执行流程

```
Agent.turn()
  │
  ├─ 1. toolRegistry.materialize()  ← 物化工具
  │      │
  │      ├─ 收集所有 ToolProvider
  │      ├─ 按 priority 排序
  │      ├─ 调用 provide() 获取工具列表
  │      └─ 返回 ToolMaterialization（definitions + dispatchMap）
  │
  ├─ 2. ModelGateway.handLLM()  ← 调 LLM
  │      │
  │      └─ LLM 返回 FunctionCall（工具名 + 参数）
  │
  └─ 3. Agent.handleFunc()  ← 执行工具
         │
         └─ ToolOrchestration.execute()
                │
                ├─ 3.1 partition()  ← 按 concurrencyGroup 分批
                │
                ├─ 3.2 executeBatch()  ← 并发执行
                │      │
                │      ├─ 调用 ToolExecutor.execute()
                │      │      │
                │      │      ├─ lifecycle.beforeTool()
                │      │      ├─ tool.execute(args)
                │      │      └─ lifecycle.afterTool()
                │      │
                │      └─ 返回 ToolCallResult 列表
                │
                └─ 3.3 转换成 Message 列表
```

### 5.2.2 类定义

```java
public abstract class ToolCall {
    public static final long DEFAULT_TIMEOUT_MS = 5 * 60 * 1000L;  // 5 分钟
    public static final String SAVE_TO_FILE_PARAM = "save_to_file";
    static final int MAX_SAVE_TO_FILE_SIZE = 10 * 1024 * 1024;  // 10 MB

    // 核心字段
    String namespace;              // 命名空间（用于分组）
    String name;                   // 工具名（唯一标识）
    String description;            // 工具描述（给 LLM 看）
    List<ToolCallParameter> parameters;  // 参数列表
    Boolean needAuth;              // 是否需要认证
    Boolean directReturn;          // 是否直接返回（不继续对话）
    Boolean llmVisible;            // 是否对 LLM 可见
    Boolean discoverable;          // 是否可发现
    String concurrencyGroup;       // 并发组名（同组工具可并发执行）
    String sourceType;             // 来源类型（builtin/mcp/api-tools 等）
    protected Long timeoutMs;      // 超时时间
    ToolExposure exposure;         // 暴露级别（DIRECT/INTERNAL）

    // 核心方法：执行工具
    public abstract ToolCallResult execute(String arguments);
    
    // 可选方法：轮询、提交输入、取消（用于异步工具）
    public ToolCallResult poll(String taskId) {
        throw new UnsupportedOperationException("Tool '" + name + "' does not support polling");
    }
    public ToolCallResult submitInput(String taskId, String input) {
        throw new UnsupportedOperationException("Tool '" + name + "' does not support user input");
    }
    public ToolCallResult cancel(String taskId) {
        throw new UnsupportedOperationException("Tool '" + name + "' does not support cancellation");
    }
    
    // 转换成 LLM 可见的 Tool 定义
    public Tool toTool(ExecutionContext context) {
        var tool = new Tool();
        tool.type = ToolType.FUNCTION;
        var func = new Function();
        func.name = name;
        func.description = getDescription();
        func.parameters = toJsonSchema();
        tool.function = func;
        return tool;
    }
    
    // 参数解析与校验
    public Map<String, Object> parseArguments(String arguments) {
        var args = JsonUtil.toMap(arguments);
        // 处理 LLM 传递的非标准参数（如嵌套 JSON 对象）
        if (parameters != null) {
            for (var param : parameters) {
                var value = args.get(param.getName());
                if (value != null && !(value instanceof String) && isStringTyped(param)) {
                    args.put(param.getName(), JsonUtil.toJson(value));
                }
            }
        }
        return args;
    }
    
    public List<String> findMissingRequiredParams(Map<String, Object> args) {
        if (parameters == null || parameters.isEmpty()) return List.of();
        var required = parameters.stream().filter(p -> Boolean.TRUE.equals(p.isRequired())).toList();
        if (required.isEmpty()) return List.of();
        return required.stream()
                .map(ToolCallParameter::getName)
                .filter(pName -> args.get(pName) == null)
                .toList();
    }
    
    // 并发安全性检查
    public boolean isConcurrencySafe(String arguments) {
        return true;  // 默认安全
    }
}
```

### 5.2.3 关键字段详解

| 字段 | 类型 | 作用 | 示例 |
|---|---|---|---|
| `name` | String | 工具名（唯一标识） | `"bash"`, `"read_file"` |
| `description` | String | 工具描述（给 LLM 看） | `"Execute a bash command"` |
| `parameters` | List<ToolCallParameter> | 参数定义 | `[{"name": "command", "type": "string", "required": true}]` |
| `concurrencyGroup` | String | 并发组名 | `"BatchBash"`, `"FileSearch"` |
| `timeoutMs` | Long | 超时时间（毫秒） | `300000`（5 分钟） |
| `needAuth` | Boolean | 是否需要认证 | `true`（删除文件等危险操作） |
| `directReturn` | Boolean | 是否直接返回 | `true`（工具执行后不继续对话） |
| `llmVisible` | Boolean | 是否对 LLM 可见 | `false`（内部工具） |
| `sourceType` | String | 来源类型 | `"builtin"`, `"mcp"`, `"api-tools"` |

💡 **设计意图**：
- **`concurrencyGroup`**：同组工具可并发执行，不同组工具串行。这允许你控制工具间的依赖关系。
- **`needAuth`**：危险操作需要用户确认（human-in-the-loop）。
- **`directReturn`**：某些工具执行后直接返回结果，不继续对话（如退出命令）。

### 5.3.2 类定义

```java
public class ToolExecutor {
    private static final Logger LOGGER = LoggerFactory.getLogger(ToolExecutor.class);

    private final List<AbstractLifecycle> lifecycles;  // 生命周期钩子链
    private final AgentTracer tracer;
    private final Consumer<NodeStatus> statusUpdater;
    private final BiConsumer<String, Usage> llmUsageConsumer;  // 工具内部 LLM 调用的 token 使用量
    private final Supplier<SpanContext> llmSpanContextSupplier;  // 父 LLM span 上下文
    private boolean authenticated = false;

    public ToolExecutor(List<AbstractLifecycle> lifecycles, AgentTracer tracer, 
                        Consumer<NodeStatus> statusUpdater,
                        BiConsumer<String, Usage> llmUsageConsumer, 
                        Supplier<SpanContext> llmSpanContextSupplier) {
        this.lifecycles = lifecycles;
        this.tracer = tracer;
        this.statusUpdater = statusUpdater;
        this.llmUsageConsumer = llmUsageConsumer;
        this.llmSpanContextSupplier = llmSpanContextSupplier;
    }

    public ToolCallResult execute(ToolCall tool, String arguments, ExecutionContext context) {
        // 1. 解析参数
        var args = tool.parseArguments(arguments);
        
        // 2. 校验必填参数
        var missing = tool.findMissingRequiredParams(args);
        if (!missing.isEmpty()) {
            return ToolCallResult.error("Missing required parameters: " + String.join(", ", missing));
        }
        
        // 3. 构建 FunctionCall（用于 lifecycle）
        var funcCall = new FunctionCall();
        funcCall.name = tool.getName();
        funcCall.arguments = arguments;
        
        // 4. 触发 beforeTool lifecycle
        for (var lifecycle : lifecycles) {
            lifecycle.beforeTool(funcCall, context);
        }
        
        // 5. 执行工具（带超时、取消、tracing）
        ToolCallResult result;
        try {
            result = executeWithTimeout(tool, args, context);
        } catch (Exception e) {
            result = ToolCallResult.error("Tool execution failed: " + e.getMessage());
        }
        
        // 6. 触发 afterTool lifecycle
        for (var lifecycle : lifecycles) {
            lifecycle.afterTool(funcCall, context, result);
        }
        
        return result;
    }

    private ToolCallResult executeWithTimeout(ToolCall tool, Map<String, Object> args, ExecutionContext context) {
        var timeout = tool.getTimeoutMs();
        var future = CompletableFuture.supplyAsync(() -> {
            context.throwIfCancelled();
            return tool.execute(JsonUtil.toJson(args));
        });
        
        try {
            return future.get(timeout, TimeUnit.MILLISECONDS);
        } catch (TimeoutException e) {
            future.cancel(true);
            return ToolCallResult.error("Tool execution timed out after " + timeout + "ms");
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            return ToolCallResult.error("Tool execution interrupted");
        } catch (ExecutionException e) {
            return ToolCallResult.error("Tool execution failed: " + e.getCause().getMessage());
        }
    }
}
```

### 5.3.3 执行流程

```
ToolExecutor.execute(tool, arguments, context)
  │
  ├─ 1. 解析参数
  │      └─ tool.parseArguments(arguments)
  │
  ├─ 2. 校验必填参数
  │      └─ tool.findMissingRequiredParams(args)
  │
  ├─ 3. 构建 FunctionCall
  │
  ├─ 4. 触发 beforeTool lifecycle
  │      └─ lifecycle.beforeTool(funcCall, context)
  │
  ├─ 5. 执行工具（带超时）
  │      └─ executeWithTimeout()
  │             │
  │             ├─ CompletableFuture.supplyAsync()
  │             └─ future.get(timeout)
  │
  ├─ 6. 触发 afterTool lifecycle
  │      └─ lifecycle.afterTool(funcCall, context, result)
  │
  └─ 返回 ToolCallResult
```

💡 **设计意图**：
- **超时控制**：每个工具有独立的超时时间，防止长时间阻塞
- **取消支持**：检查 `context.throwIfCancelled()`，支持用户取消
- **Lifecycle 钩子**：在工具执行前后调用 lifecycle，支持权限检查、日志记录等

## 5.4 ToolOrchestration 并发编排

### 5.4.1 文件位置

```
core-ai/src/main/java/ai/core/tool/ToolOrchestration.java
```

### 5.4.2 类定义

```java
public class ToolOrchestration {
    private static final int DEFAULT_MAX_CONCURRENCY = 10;

    private final int maxConcurrency;
    private final List<AbstractLifecycle> lifecycles;
    private final ToolExecutor toolExecutor;
    private final ExecutionContext context;
    private final Map<String, String> groupIndex;  // toolName → concurrencyGroup
    private final Map<String, ToolCall> toolIndex;  // toolName → ToolCall

    public ToolOrchestration(Map<String, ToolCall> dispatchMap, List<AbstractLifecycle> lifecycles, 
                             ToolExecutor toolExecutor, ExecutionContext context) {
        this.toolExecutor = toolExecutor;
        this.lifecycles = lifecycles;
        this.context = context;
        this.maxConcurrency = DEFAULT_MAX_CONCURRENCY;
        this.toolIndex = dispatchMap;
        this.groupIndex = getGroupIndexFromMap(dispatchMap.values());
    }

    private Map<String, String> getGroupIndexFromMap(Collection<ToolCall> tools) {
        Map<String, String> groupIndex = new LinkedHashMap<>();
        for (var tc : tools) {
            if (tc.getConcurrencyGroup() != null) {
                groupIndex.put(tc.getName(), tc.getConcurrencyGroup());
            }
        }
        return groupIndex;
    }

    public List<Message> execute(List<FunctionCall> toolCalls) {
        // 1. 按 concurrencyGroup 分批
        var batches = partition(toolCalls);
        List<Message> allMessages = new ArrayList<>();
        
        // 2. 逐批执行（同批内并发，批间串行）
        for (var batch : batches) {
            context.throwIfCancelled();
            allMessages.addAll(executeBatch(batch));
        }
        return allMessages;
    }

    private List<List<FunctionCall>> partition(List<FunctionCall> toolCalls) {
        var batches = new ArrayList<List<FunctionCall>>();
        var current = new ArrayList<FunctionCall>();
        String currentGroup = null;

        for (var tc : toolCalls) {
            var group = resolveGroup(tc);
            if (!isCallConcurrencySafe(tc)) {
                group = null;  // 不安全，独占一批
            }
            boolean sameGroup = group != null && group.equals(currentGroup);

            if (current.isEmpty()) {
                current.add(tc);
                currentGroup = group;
            } else if (sameGroup) {
                current.add(tc);
            } else {
                batches.add(current);
                current = new ArrayList<>();
                current.add(tc);
                currentGroup = group;
            }
        }
        if (!current.isEmpty()) {
            batches.add(current);
        }
        return batches;
    }

    private String resolveGroup(FunctionCall tc) {
        return groupIndex.get(tc.name);
    }

    private boolean isCallConcurrencySafe(FunctionCall tc) {
        var tool = toolIndex.get(tc.name);
        return tool != null && tool.isConcurrencySafe(tc.arguments);
    }

    private List<Message> executeBatch(List<FunctionCall> batch) {
        if (batch.isEmpty()) return List.of();
        
        var group = resolveGroup(batch.get(0));
        
        // 1. 触发 beforeBatch lifecycle
        for (var lifecycle : lifecycles) {
            lifecycle.beforeBatch(group, batch, context);
        }
        
        // 2. 并发执行
        var semaphore = new Semaphore(maxConcurrency);
        var futures = batch.stream()
            .map(fc -> {
                var tool = toolIndex.get(fc.name);
                return CompletableFuture.supplyAsync(() -> {
                    try {
                        semaphore.acquire();
                        context.throwIfCancelled();
                        var result = toolExecutor.execute(tool, fc.arguments, context);
                        return new ToolResult(fc.name, result);
                    } catch (InterruptedException e) {
                        Thread.currentThread().interrupt();
                        return new ToolResult(fc.name, ToolCallResult.error("Interrupted"));
                    } finally {
                        semaphore.release();
                    }
                });
            })
            .toList();
        
        // 3. 等待所有完成
        var results = futures.stream()
            .map(CompletableFuture::join)
            .toList();
        
        // 4. 触发 afterBatch lifecycle
        for (var lifecycle : lifecycles) {
            lifecycle.afterBatch(group, batch, context);
        }
        
        // 5. 转换成 Message 列表
        return results.stream()
            .map(r -> Message.toolMessage(r.name, r.result.content))
            .toList();
    }

    private record ToolResult(String name, ToolCallResult result) {}
}
```

### 5.4.3 并发编排逻辑

```
ToolOrchestration.execute(toolCalls)
  │
  ├─ 1. partition()  ← 按 concurrencyGroup 分批
  │      │
  │      ├─ 同组工具放同一批
  │      ├─ null group 工具独占一批（作为屏障）
  │      └─ 不安全工具独占一批
  │
  └─ 2. 逐批执行
         │
         ├─ executeBatch(batch1)
         │      │
         │      ├─ beforeBatch lifecycle
         │      ├─ 并发执行（Semaphore 控制最大并发数）
         │      └─ afterBatch lifecycle
         │
         ├─ executeBatch(batch2)
         │      │
         │      └─ ...
         │
         └─ executeBatch(batchN)
```

💡 **设计意图**：
- **并发组**：同组工具可并发执行（如多个文件搜索），提高性能
- **屏障**：没有 `concurrencyGroup` 的工具独占一批，后续批次等它完成（如写文件）
- **最大并发数**：默认 10，通过 Semaphore 控制，防止资源耗尽
- **安全性检查**：`isConcurrencySafe()` 允许动态判断工具是否可并发

### 5.4.4 并发组示例

**场景 1**：多个文件搜索可并发

```java
var searchTool1 = new SearchTool()
    .name("search_java")
    .concurrencyGroup("FileSearch");

var searchTool2 = new SearchTool()
    .name("search_python")
    .concurrencyGroup("FileSearch");

// LLM 同时调用 search_java 和 search_python
// ToolOrchestration 会把它们放同一批，并发执行
```

**场景 2**：写文件必须独占

```java
var writeFileTool = new WriteFileTool()
    .name("write_file")
    .concurrencyGroup(null);  // null 表示独占

// LLM 调用 write_file
// ToolOrchestration 会把它独占一批，后续批次等它完成
```

**场景 3**：bash 命令按组并发

```java
var bashTool = new BashTool()
    .name("bash")
    .concurrencyGroup("BatchBash");

// LLM 调用多个 bash 命令
// ToolOrchestration 会把它们放同一批（同属 BatchBash 组），并发执行
```

### 5.5.2 类定义

```java
public class ToolRegistry {
    private static final Logger LOGGER = LoggerFactory.getLogger(ToolRegistry.class);

    private final Map<String, ToolProvider> providers = new ConcurrentHashMap<>();
    private final Map<String, Map<String, ToolCall>> providerCache = new ConcurrentHashMap<>();

    public void registerProvider(ToolProvider provider) {
        if (provider == null) {
            LOGGER.debug("null provider");
            return;
        }
        var previous = providers.put(provider.id(), provider);
        providerCache.remove(provider.id());  // 清缓存
        if (previous != null) {
            LOGGER.info("replaced provider, id={}", provider.id());
        } else {
            LOGGER.info("registered provider, id={}", provider.id());
        }
    }

    public List<ToolCall> getToolCalls() {
        return List.copyOf(materialize().getDispatchMap().values());
    }

    public void unregisterProvider(String providerId) {
        providers.remove(providerId);
        providerCache.remove(providerId);
        LOGGER.info("unregistered provider, id={}", providerId);
    }

    public void invalidateCache(String providerId) {
        providerCache.remove(providerId);
        LOGGER.debug("invalidated cache, id={}", providerId);
    }

    public ToolMaterialization materialize() {
        return materialize(null);
    }

    public ToolMaterialization materialize(ExecutionContext context) {
        // 1. 收集所有工具（按 priority 排序）
        var collected = collectTools();
        
        // 2. 转换成 Tool 定义列表（给 LLM 看）+ dispatch map（用于派发）
        var definitions = new ArrayList<Tool>();
        var dispatchMap = new LinkedHashMap<String, ToolCall>();
        
        for (var entry : collected.tools.entrySet()) {
            var tool = entry.getValue();
            if (tool.getExposure() == ToolExposure.DIRECT) {
                definitions.add(tool.toTool(context));  // 转换成 LLM 可见的 Tool 定义
            }
            dispatchMap.put(entry.getKey(), tool);  // 加入 dispatch map
        }
        
        LOGGER.debug("materialized {} definitions from {} tools", definitions.size(), collected.tools.size());
        return new ToolMaterialization(definitions, dispatchMap, collected.toolProviderIndex);
    }

    private CollectResult collectTools() {
        // 1. 按 priority 排序 provider
        var sorted = providers.values().stream()
            .sorted(Comparator.comparingInt(ToolProvider::priority))
            .toList();
        
        // 2. 依次调用 provide()，高优先级覆盖低优先级同名工具
        var tools = new LinkedHashMap<String, ToolCall>();
        var toolProviderIndex = new HashMap<String, String>();
        
        for (var provider : sorted) {
            var provided = getOrCache(provider);
            for (var entry : provided.entrySet()) {
                tools.put(entry.getKey(), entry.getValue());  // 高优先级覆盖
                toolProviderIndex.put(entry.getKey(), provider.id());
            }
        }
        
        return new CollectResult(tools, toolProviderIndex);
    }

    private Map<String, ToolCall> getOrCache(ToolProvider provider) {
        return switch (provider.refreshPolicy()) {
            case ONCE -> providerCache.computeIfAbsent(provider.id(), k -> provider.provide());
            case MANUAL -> providerCache.computeIfAbsent(provider.id(), k -> provider.provide());
            case EVERY_TURN -> provider.provide();
        };
    }
}
```

### 5.5.3 物化流程

```
ToolRegistry.materialize(context)
  │
  ├─ 1. collectTools()  ← 收集所有工具
  │      │
  │      ├─ 按 priority 排序 provider
  │      ├─ 依次调用 provide()
  │      └─ 高优先级覆盖低优先级同名工具
  │
  ├─ 2. 转换成 Tool 定义列表
  │      │
  │      └─ tool.toTool(context)  ← 给 LLM 看
  │
  └─ 3. 构建 dispatch map
         │
         └─ name → ToolCall 映射  ← 用于派发
```

💡 **设计意图**：
- **优先级覆盖**：高优先级 provider 的工具覆盖低优先级同名工具。例如，用户自定义的 `bash` 工具覆盖内置的 `bash`。
- **刷新策略**：
  - `EVERY_TURN`：每次 materialize 都调用 provide()（动态工具）
  - `ONCE`：只调用一次，永久缓存（静态工具）
  - `MANUAL`：手动调用 invalidateCache() 清缓存

### 5.5.4 `ToolMaterialization` 物化结果

```java
public record ToolMaterialization(
    List<Tool> definitions,              // 给 LLM 看的工具定义列表
    Map<String, ToolCall> dispatchMap,   // name → ToolCall 映射（用于派发）
```

💡 **设计意图**：`ToolMaterialization` 封装了物化结果，包含：
- **definitions**：给 LLM 看的工具定义（JSON Schema）
- **dispatchMap**：工具名到 ToolCall 的映射，用于派发

```java
public interface ToolProvider {
    // 内置 provider 常量
    String BUILTIN_ALL = "builtin-all";
    String BUILTIN_PLANNING = "builtin-planning";
    String BUILTIN_FILES = "builtin-files";
    String BUILTIN_FILE_OPERATIONS = "builtin-file-operations";
    String BUILTIN_FILE_READ_ONLY = "builtin-file-read-only";
    String BUILTIN_MULTIMODAL = "builtin-multimodal";
    String BUILTIN_WEB = "builtin-web";
    String BUILTIN_BASH = "builtin-bash";
    String BUILTIN_CODE_EXECUTION = "builtin-code-execution";
    String BUILTIN_GITHUB = "builtin-github";
    String BUILTIN_MEDIA_GENERATION = "builtin-media-generation";

    String BUILTIN = "builtin";
    String USER = "user-provided";
    String API_TOOLS = "api-tools";
    String DYNAMIC = "dynamic";
    String DATASET = "dataset";
    String SANDBOX = "sandbox";

    // 核心方法
    String id();                           // provider 唯一标识
    Map<String, ToolCall> provide();       // 提供工具列表
    
    // 可选方法
    default int priority() { return 100; }  // 优先级（越小越高）
    default RefreshPolicy refreshPolicy() { return RefreshPolicy.EVERY_TURN; }

    // 刷新策略
    enum RefreshPolicy {
        EVERY_TURN,  // 每次 materialize() 都调用 provide()
        ONCE,        // 只调用一次，永久缓存
        MANUAL       // 手动调用 invalidateCache() 清缓存
    }
}
```

### 5.6.3 刷新策略详解

| 策略 | 调用时机 | 适用场景 | 示例 |
|---|---|---|---|
| `EVERY_TURN` | 每次 materialize | 动态工具（可能变化） | MCP 工具、API 工具 |
| `ONCE` | 只调用一次 | 静态工具（不变） | 内置工具（bash、read_file） |
| `MANUAL` | 手动清缓存 | 需要手动刷新的工具 | 用户自定义工具 |

💡 **设计意图**：
- **EVERY_TURN**：每次 agent turn 都会重新获取工具列表，适用于工具可能变化的场景（如 MCP server 动态注册工具）
- **ONCE**：只获取一次，永久缓存，适用于静态工具（如内置的 bash、read_file）
- **MANUAL**：需要手动调用 `invalidateCache()` 清缓存，适用于用户自定义工具

```java
public class BuiltinToolProvider implements ToolProvider {

}
```

```java
        return ToolProvider.MCP;

    public Map<String, ToolCall> provide() {

            .collect(Collectors.toMap(ToolCall::getName, t -> t));

    @Override
    public int priority() {
```

```java
public class BashTool extends ToolCall {
    public BashTool() {
        this.name = "bash";
        this.description = "Execute a bash command in the shell.";
        this.parameters = List.of(
            new ToolCallParameter("command", "The bash command to execute", ToolCallParameterType.STRING, true, null)
        );
        this.concurrencyGroup = "BatchBash";
        this.sourceType = "builtin";
    }
    
    @Override
    public ToolCallResult execute(String arguments) {
        var args = parseArguments(arguments);
        var command = getStringValue(args, "command");
        
        try {
            var process = Runtime.getRuntime().exec(new String[]{"bash", "-c", command});
            var output = new String(process.getInputStream().readAllBytes());
            var error = new String(process.getErrorStream().readAllBytes());
            var exitCode = process.waitFor();
            
            if (exitCode == 0) {
                return ToolCallResult.success(output);
            } else {
                return ToolCallResult.error("Command failed with exit code " + exitCode + "\n" + error);
            }
        } catch (Exception e) {
            return ToolCallResult.error("Failed to execute command: " + e.getMessage());
        }
    }
}
```

```java
    public ReadFileTool() {
        this.name = "read_file";
        this.description = "Read the content of a file.";
        this.parameters = List.of(
            new ToolCallParameter("path", "The file path to read", ToolCallParameterType.STRING, true, null),
            new ToolCallParameter("offset", "Line number to start from (1-indexed)", ToolCallParameterType.NUMBER, false, "1"),
            new ToolCallParameter("limit", "Number of lines to read", ToolCallParameterType.NUMBER, false, "2000")
        );
        this.concurrencyGroup = "FileSearch";
        this.sourceType = "builtin";
    }
    
    @Override
    public ToolCallResult execute(String arguments) {
        var args = parseArguments(arguments);
        var path = getStringValue(args, "path");
        var offset = Integer.parseInt(getStringValue(args, "offset"));
        var limit = Integer.parseInt(getStringValue(args, "limit"));
        
        try {
            var lines = Files.readAllLines(Path.of(path));
            var start = Math.max(0, offset - 1);
            var end = Math.min(lines.size(), start + limit);
            var content = String.join("\n", lines.subList(start, end));
            return ToolCallResult.success(content);
        } catch (Exception e) {
            return ToolCallResult.error("Failed to read file: " + e.getMessage());
        }
    }
}
```

### 5.8.2 示例：数据库查询工具

```java
public class DatabaseTool extends ToolCall {
    private final DataSource dataSource;
    
    public DatabaseTool(DataSource dataSource) {
        this.name = "query_database";
        this.description = "Execute a SQL query against the database.";
        this.parameters = List.of(
            new ToolCallParameter("sql", "SQL query to execute", ToolCallParameterType.STRING, true, null),
            new ToolCallParameter("params", "Query parameters (JSON array)", ToolCallParameterType.STRING, false, "[]")
        );
        this.concurrencyGroup = null;  // 独占，防止并发写冲突
        this.sourceType = "user-provided";
        this.needAuth = true;  // 需要用户确认（危险操作）
        this.dataSource = dataSource;
    }
    
    @Override
    public ToolCallResult execute(String arguments) {
        var args = parseArguments(arguments);
        var sql = getStringValue(args, "sql");
        var paramsJson = getStringValue(args, "params");
        
        try (var conn = dataSource.getConnection();
             var stmt = conn.prepareStatement(sql)) {
            
            var params = JsonUtil.fromJson(paramsJson, List.class);
            for (int i = 0; i < params.size(); i++) {
                stmt.setObject(i + 1, params.get(i));
            }
            
            if (sql.trim().toLowerCase().startsWith("select")) {
                var rs = stmt.executeQuery();
                var results = new ArrayList<Map<String, Object>>();
                var meta = rs.getMetaData();
                while (rs.next()) {
                    var row = new LinkedHashMap<String, Object>();
                    for (int i = 1; i <= meta.getColumnCount(); i++) {
                        row.put(meta.getColumnName(i), rs.getObject(i));
                    }
                    results.add(row);
                }
                return ToolCallResult.success(JsonUtil.toJson(results));
            } else {
                var affected = stmt.executeUpdate();
                return ToolCallResult.success("Affected rows: " + affected);
            }
        } catch (Exception e) {
            return ToolCallResult.error("Database error: " + e.getMessage());
        }
    }
}
```

💡 **设计意图**：
- **`concurrencyGroup = null`**：数据库写操作不能并发，独占执行
- **`needAuth = true`**：SQL 查询是危险操作，需要用户确认
- **参数化查询**：支持 `params` 参数，防止 SQL 注入

### 5.8.3 示例：异步工具（长时间运行）

```java
public class LongRunningTool extends ToolCall {
    private final Map<String, CompletableFuture<String>> tasks = new ConcurrentHashMap<>();
    
    public LongRunningTool() {
        this.name = "long_running_task";
        this.description = "Start a long-running task and get a task ID.";
        this.parameters = List.of(
            new ToolCallParameter("input", "Task input", ToolCallParameterType.STRING, true, null)
        );
        this.concurrencyGroup = null;
        this.sourceType = "user-provided";
    }
    
    @Override
    public ToolCallResult execute(String arguments) {
        var args = parseArguments(arguments);
        var input = getStringValue(args, "input");
        
        var taskId = UUID.randomUUID().toString();
        var future = CompletableFuture.supplyAsync(() -> {
            // 模拟长时间运行
            try {
                Thread.sleep(30000);  // 30 秒
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
            return "Result for: " + input;
        });
        
        tasks.put(taskId, future);
        return ToolCallResult.success("Task started. Task ID: " + taskId);
    }
    
    @Override
    public ToolCallResult poll(String taskId) {
        var future = tasks.get(taskId);
        if (future == null) {
            return ToolCallResult.error("Task not found: " + taskId);
        }
        
        if (future.isDone()) {
            try {
                var result = future.get();
                tasks.remove(taskId);
                return ToolCallResult.success(result);
            } catch (Exception e) {
                return ToolCallResult.error("Task failed: " + e.getMessage());
            }
        } else {
            return ToolCallResult.success("Task still running...");
        }
    }
    
    @Override
    public ToolCallResult cancel(String taskId) {
        var future = tasks.get(taskId);
        if (future != null) {
            future.cancel(true);
            tasks.remove(taskId);
            return ToolCallResult.success("Task cancelled");
        }
        return ToolCallResult.error("Task not found: " + taskId);
    }
}
```

💡 **设计意图**：
- **异步工具**：支持 `poll()` 和 `cancel()` 方法，用于长时间运行的任务
- **任务 ID**：返回任务 ID，agent 可以轮询任务状态
- **取消支持**：支持取消正在运行的任务
