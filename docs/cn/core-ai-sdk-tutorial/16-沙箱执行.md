## 16.1 沙箱系统总览

### 16.1.1 沙箱的角色

沙箱系统是 core-ai 的**安全代码执行环境**，负责：

- **隔离执行**：在容器中运行代码，不影响宿主机
- **资源限制**：限制 CPU、内存、磁盘、网络使用
- **工具拦截**：拦截特定工具（bash、python、文件操作），路由到沙箱执行
- **文件管理**：上传/下载文件到沙箱
- **MCP 集成**：在沙箱内启动 MCP Server

💡 **设计意图**：AI Agent 需要执行代码（bash、python、文件操作），但直接执行有安全风险。沙箱提供隔离环境，即使代码有恶意行为也不会影响宿主机。

### 16.1.2 核心类关系图

```
┌─────────────────────────────────────────────────────────────┐
│                  SandboxProvider (interface)                │
│                                                             │
│  + acquire(config, sessionId, userId): Sandbox              │
│  + attach(sandboxId, config, sessionId, userId): Sandbox    │
│  + release(sandbox)                                         │
│  + renew(sandbox, timeoutSeconds)                           │
│  + getStatus(sandbox): SandboxStatus                        │
└──────────────────────┬──────────────────────────────────────┘
                       │ 实现
        ┌──────────────┼──────────────┐
        ▼              ▼              ▼
┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ Docker       │ │ Kubernetes   │ │ Custom       │
│ Provider     │ │ Provider     │ │ Provider     │
│              │ │              │ │ (用户自定义) │
│ Docker 容器  │ │ K8s Pod      │ │              │
└──────────────┘ └──────────────┘ └──────────────┘

┌─────────────────────────────────────────────────────────────┐
│                  Sandbox (interface)                        │
│                                                             │
│  + shouldIntercept(toolName): boolean                       │
│  + execute(toolName, arguments, context): ToolCallResult    │
│  + getStatus(): SandboxStatus                               │

│  + hostname(): String                                       │
│  + materializeSkill(name, version, tarBytes)                │
│  + downloadFile(path): SandboxFile                          │

│  + startMcpServer(id, command, args, env, timeout)          │
│  + stopMcpServer(id)                                        │

│  + close()                                                  │
└─────────────────────────────────────────────────────────────┘
```

### 16.1.3 工具拦截机制

```
Agent 调用工具
  │
  ├─ 1. ToolExecutor 检查是否需要拦截
  │      │
  │      └─ SandboxConstants.INTERCEPTED_TOOLS 包含：
  │             - shell_command (bash)
  │             - python_script
  │             - read_file
  │             - edit_file
  │             - write_file
  │             - glob_file
  │             - grep_file
  │
  ├─ 2. 如果需要拦截
  │      │
  │      └─ sandbox.execute(toolName, arguments, context)
  │             │
  │             └─ 在沙箱内执行工具
  │
  └─ 3. 如果不需要拦截
         │
         └─ 正常执行工具（在宿主机）
```

💡 **设计意图**：
- **透明拦截**：Agent 不需要知道工具在沙箱内执行，调用方式不变
- **安全隔离**：危险工具（bash、python、文件操作）在沙箱内执行
- **灵活配置**：可以选择哪些工具需要拦截

## 16.2 Sandbox 接口

### 16.2.1 文件位置

```
core-ai/src/main/java/ai/core/sandbox/Sandbox.java
```

### 16.2.2 接口定义

```java
public interface Sandbox extends AutoCloseable {
    
    /**
     * 判断工具是否需要拦截
     */
    boolean shouldIntercept(String toolName);
    
    /**
     * 在沙箱内执行工具
     */
    ToolCallResult execute(String toolName, String arguments, ExecutionContext context);
    
    /**
     * 获取沙箱状态
     */
    SandboxStatus getStatus();
    
    /**
     * 获取沙箱 ID
     */
    String getId();
    
    /**
     * 获取沙箱主机名（容器名或 Pod 名）
     */
    String hostname();
    
    /**
     * 物化 Skill 到沙箱文件系统
     */
    void materializeSkill(String name, String version, byte[] tarBytes);
    
    /**
     * 从沙箱下载文件
     */
    SandboxFile downloadFile(String path);
    
    /**
     * 上传文件到沙箱
     */
    void uploadFile(String path, byte[] content);
    
    /**
     * 获取沙箱 IP 地址
     */
    String ip();
    
    /**
     * 获取沙箱端口
     */
    int port();
    
    /**
     * 获取沙箱镜像
     */
    String image();
    
    // ========== MCP Server 生命周期 ==========
    
    /**
     * 在沙箱内启动 MCP Server
     */
    String startMcpServer(String id, String command, List<String> args, 
                          Map<String, String> env, int timeoutSeconds);
    
    /**
     * 停止 MCP Server
     */
    void stopMcpServer(String id);
    
    /**
     * 获取 MCP 端点
     */
    String getMcpEndpoint();
    
    /**
     * 关闭沙箱
     */
    @Override
    void close();
}
```

💡 **设计意图**：
- **AutoCloseable**：支持 try-with-resources，自动释放资源
- **工具拦截**：`shouldIntercept()` 判断工具是否需要拦截
- **文件操作**：支持上传/下载文件
- **MCP 集成**：可以在沙箱内启动 MCP Server
- **网络信息**：提供 IP、端口、主机名，便于调试

### 16.2.3 核心方法说明

| 方法 | 作用 | 返回值 |
|---|---|---|
| `shouldIntercept(toolName)` | 判断工具是否需要拦截 | boolean |
| `execute(toolName, args, ctx)` | 在沙箱内执行工具 | ToolCallResult |
| `getStatus()` | 获取沙箱状态 | SandboxStatus |
| `downloadFile(path)` | 下载文件 | SandboxFile |
| `uploadFile(path, content)` | 上传文件 | void |
| `startMcpServer(...)` | 启动 MCP Server | serverId |
| `stopMcpServer(id)` | 停止 MCP Server | void |
| `close()` | 关闭沙箱 | void |

## 16.3 SandboxProvider SPI

### 16.3.1 文件位置

```
core-ai/src/main/java/ai/core/sandbox/SandboxProvider.java
```

### 16.3.2 接口定义

```java
public interface SandboxProvider {
    
    /**
     * 获取沙箱（创建或复用）
     * @param config 沙箱配置
     * @param sessionId 会话 ID
     * @param userId 用户 ID
     * @return 沙箱实例
     */
    Sandbox acquire(SandboxConfig config, String sessionId, String userId);
    
    /**
     * 附加到已存在的沙箱
     * @param sandboxId 沙箱 ID
     * @param config 沙箱配置
     * @param sessionId 会话 ID
     * @param userId 用户 ID
     * @return 沙箱实例（如果存在）
     */
    default Optional<Sandbox> attach(String sandboxId, SandboxConfig config, 
                                     String sessionId, String userId) {
        return Optional.empty();
    }
    
    /**
     * 释放沙箱
     */
    void release(Sandbox sandbox);
    
    /**
     * 续期沙箱
     * @param sandbox 沙箱实例
     * @param timeoutSeconds 新的超时时间
     */
    default void renew(Sandbox sandbox, int timeoutSeconds) {
    }
    
    /**
     * 获取沙箱状态
     */
    SandboxStatus getStatus(Sandbox sandbox);
}
```

💡 **设计意图**：
- **acquire/release**：标准的资源管理模式
- **attach**：支持复用已存在的沙箱（如会话恢复）
- **renew**：延长沙箱生命周期
- **默认方法**：`attach` 和 `renew` 有默认实现，简化实现

### 16.3.3 使用方式

```java
// 1. 获取 Provider
var provider = new DockerSandboxProvider();

// 2. 配置
var config = SandboxConfig.enabled();
config.image = "chancetop/core-ai-sandbox-runtime:latest";
config.memoryLimitMb = 512;
config.cpuLimitMillicores = 500;
config.timeoutSeconds = 1800;

// 3. 获取沙箱
var sandbox = provider.acquire(config, "session-123", "user-456");

// 4. 使用沙箱
try {
    var result = sandbox.execute("shell_command", "{\"command\": \"ls -la\"}", context);
    System.out.println(result.content);
} finally {
    // 5. 释放沙箱
    provider.release(sandbox);
}
```

💡 **提示**：推荐使用 try-with-resources 自动释放：

```java
try (var sandbox = provider.acquire(config, sessionId, userId)) {
    // 使用沙箱
}
```

## 16.4 SandboxConfig 配置

### 16.4.1 文件位置

```
core-ai/src/main/java/ai/core/sandbox/SandboxConfig.java
```

### 16.4.2 配置字段

```java
public class SandboxConfig {
    // 基础配置
    public Boolean enabled = Boolean.FALSE;              // 是否启用沙箱
    public String image = SandboxConstants.DEFAULT_IMAGE; // 镜像名称
    public Integer memoryLimitMb = 512;                  // 内存限制 (MB)
    public Integer cpuLimitMillicores = 500;             // CPU 限制 (毫核)
    public Integer timeoutSeconds = 1800;                // 超时时间 (秒)
    public Boolean networkEnabled = Boolean.FALSE;       // 是否启用网络
    
    // Git 配置
    public String gitRepoUrl;                            // Git 仓库 URL
    public String gitBranch = "main";                    // Git 分支
    
    // 资源限制
    public String tmpSizeLimit = "512Mi";                // 临时目录大小限制
    public Integer maxAsyncTasks = 5;                    // 最大异步任务数
    
    // 环境变量
    public Map<String, String> env;                      // 环境变量
    
    /**
     * 验证配置
     */
    public void validate() {
        // 内存限制：64MB - 2048MB
        if (memoryLimitMb != null) {
            if (memoryLimitMb < 64) memoryLimitMb = 64;
            if (memoryLimitMb > 2048) memoryLimitMb = 2048;
        }
        
        // CPU 限制：100 - 2000 毫核
        if (cpuLimitMillicores != null) {
            if (cpuLimitMillicores < 100) cpuLimitMillicores = 100;
            if (cpuLimitMillicores > 2000) cpuLimitMillicores = 2000;
        }
        
        // 超时限制：300s - 86400s (24小时)
        if (timeoutSeconds != null) {
            if (timeoutSeconds < 300) timeoutSeconds = 300;
            if (timeoutSeconds > 86400) timeoutSeconds = 86400;
        }
        
        // 环境变量检查：禁止危险变量
        if (env != null) {
            var blocked = Set.of("PATH", "LD_PRELOAD", "LD_LIBRARY_PATH", 
                                 "HOME", "SHELL", "HOSTNAME", "MAX_ASYNC_TASKS");
            for (var key : env.keySet()) {
                if (blocked.contains(key.toUpperCase())) {
                    throw new IllegalArgumentException("env var '" + key + "' is not allowed");
                }
            }
        }
    }
}
```

💡 **设计意图**：
- **资源限制**：防止沙箱消耗过多资源
- **网络隔离**：默认禁用网络，防止数据泄露
- **环境变量检查**：禁止危险的环境变量（如 PATH、LD_PRELOAD）
- **自动校正**：超出范围的值自动调整到合理范围

### 16.4.3 配置示例

```java
// 基础配置
var config = SandboxConfig.enabled();

// 自定义配置
config.image = "chancetop/core-ai-sandbox-runtime:v1.0";
config.memoryLimitMb = 1024;        // 1GB 内存
config.cpuLimitMillicores = 1000;   // 1 核 CPU
config.timeoutSeconds = 3600;       // 1 小时
config.networkEnabled = true;       // 启用网络

// Git 配置
config.gitRepoUrl = "https://github.com/user/repo.git";
config.gitBranch = "develop";

// 环境变量
config.env = Map.of(
    "API_KEY", "xxx",
    "DEBUG", "true"
);

// 验证配置
config.validate();
```

### 16.5.2 状态枚举

```java
public enum SandboxStatus {
    PENDING,      // 等待创建
    CREATING,     // 创建中
    READY,        // 就绪（可以执行）
    EXECUTING,    // 执行中
    ERROR,        // 错误
    TERMINATED    // 已终止
}
```

💡 **设计意图**：
- **状态流转**：PENDING → CREATING → READY → EXECUTING → TERMINATED
- **错误处理**：ERROR 状态表示沙箱出现异常
- **生命周期**：通过状态管理沙箱的生命周期

### 16.5.3 状态流转图

```
PENDING
  │
  │ acquire()
  ▼
CREATING
  │
  │ 容器启动完成
  ▼
READY ←──────────┐
  │              │
  │ execute()    │ 执行完成
  ▼              │
EXECUTING ───────┘
  │
  ├─ 错误
  │    ▼
  │  ERROR
  │
  └─ 正常终止
       ▼
     TERMINATED
```

## 16.6 拦截工具与沙箱路由

### 16.6.1 文件位置


### 16.6.2 拦截工具列表

```java
public final class SandboxConstants {
    /**
     * 需要拦截的工具
     */
    public static final Set<String> INTERCEPTED_TOOLS = Set.of(
        ShellCommandTool.TOOL_NAME,      // "shell_command"
        PythonScriptTool.TOOL_NAME,      // "python_script"
        ReadFileTool.TOOL_NAME,          // "read_file"
        EditFileTool.TOOL_NAME,          // "edit_file"
        WriteFileTool.TOOL_NAME,         // "write_file"
        GlobFileTool.TOOL_NAME,          // "glob_file"
        GrepFileTool.TOOL_NAME           // "grep_file"
    );
    
    /**
     * Git 环境变量（防止交互式提示）
     */
    public static final Map<String, String> SANDBOX_GIT_ENV = Map.of(
        "GIT_TERMINAL_PROMPT", "0",
        "GH_PROMPT", "disabled",
        "GH_NO_UPDATE_NOTIFIER", "1"
    );
}
```

💡 **设计意图**：
- **危险工具拦截**：bash、python、文件操作等危险工具在沙箱内执行
- **安全工具放行**：其他工具（如 web_search）在宿主机执行
- **Git 环境**：设置环境变量防止 Git 交互式提示（沙箱无法交互）

### 16.6.3 工具路由流程

```
Agent 调用 "shell_command"
  │
  ├─ 1. ToolExecutor 检查
  │      │
  │      └─ INTERCEPTED_TOOLS.contains("shell_command") → true
  │
  ├─ 2. 路由到沙箱
  │      │
  │      └─ sandbox.execute("shell_command", args, context)
  │
  └─ 3. 沙箱内执行
         │
         └─ 返回结果
```

## 16.8 MCP Server 集成

### 16.8.1 在沙箱内启动 MCP Server

```java
// 启动 MCP Server
var serverId = sandbox.startMcpServer(
    "filesystem",                    // Server ID
    "npx",                           // 命令
    List.of("-y", "@modelcontextprotocol/server-filesystem", "/workspace"),  // 参数

System.out.println("MCP Server ID: " + serverId);

// 获取 MCP 端点
var endpoint = sandbox.getMcpEndpoint();

// 输出: "http://10.0.0.5:8080/mcp"
```

💡 **设计意图**：
- **隔离运行**：MCP Server 在沙箱内运行，不影响宿主机
- **动态启动**：可以按需启动/停止 MCP Server
- **网络桥接**：通过 HTTP 端点访问沙箱内的 MCP Server

### 16.8.2 停止 MCP Server

```java
// 停止 MCP Server
sandbox.stopMcpServer("filesystem");
```

💡 **使用场景**：
- 清理资源
- 重启 MCP Server
- 切换 MCP Server 配置

### 16.8.3 MCP 超时配置

```java
// SandboxConstants 中的 MCP 超时配置
public static final int MCP_STARTUP_TIMEOUT_SECONDS = 180;        // 启动超时
```

- **防止逃逸**：禁止危险的环境变量，防止容器逃逸
- **安全审计**：自动检查环境变量配置
- **快速失败**：配置错误时立即抛出异常

### 16.9.4 Git 安全配置

```java
// 自动设置 Git 环境变量
public static final Map<String, String> SANDBOX_GIT_ENV = Map.of(
    "GIT_TERMINAL_PROMPT", "0",     // 禁止 Git 交互式提示
    "GH_PROMPT", "disabled",        // 禁止 GitHub CLI 交互式提示
    "GH_NO_UPDATE_NOTIFIER", "1"    // 禁止更新通知
);
```

💡 **设计意图**：
- **非交互模式**：沙箱无法交互，必须禁用所有交互式提示
- **快速失败**：缺少凭证时立即报错，而不是等待用户输入
- **减少干扰**：禁用更新通知，减少不必要的输出

### 16.10.1 基础沙箱使用

```java
// 1. 创建 Provider
var provider = new DockerSandboxProvider();
```

### 16.10.2 Agent 集成沙箱

```java
// 1. 创建沙箱 Provider
var sandboxProvider = new DockerSandboxProvider();

// 2. 创建 Agent
var agent = Agent.builder()
    .name("coding-assistant")
    .systemPrompt("你是一个编程助手，可以在沙箱中执行代码")
    .llmProvider(llmProvider)
    .sandboxProvider(sandboxProvider)  // 设置沙箱 Provider
    .sandboxConfig(SandboxConfig.enabled())
    .build();

// 3. 执行（自动使用沙箱）
var result = agent.execute("请在沙箱中执行 Python 代码：print(2 + 2)", null);
System.out.println(result);
// Agent 会自动在沙箱中执行 python_script 工具
```

💡 **设计意图**：
- **透明集成**：Agent 不需要知道工具在沙箱中执行
- **自动拦截**：危险工具自动路由到沙箱
- **资源管理**：沙箱生命周期由 Agent 管理
