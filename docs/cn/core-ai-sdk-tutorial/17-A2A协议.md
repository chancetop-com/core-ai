## 17.1 A2A 协议总览

### 17.1.1 A2A 协议的角色

A2A（Agent-to-Agent）协议是 core-ai 的**跨服务 Agent 协作基础设施**，负责：

- **远程调用**：调用其他服务托管的 Agent
- **能力发现**：通过 AgentCard 发现远程 Agent 的能力
- **任务管理**：管理异步任务的创建、查询、取消
- **流式通信**：支持 SSE 流式输出
- **权限协作**：支持跨服务工具审批

💡 **设计意图**：复杂的 AI 应用通常需要多个 Agent 协作。A2A 协议提供标准化的远程调用机制，让 Agent 可以跨服务、跨进程协作。

### 17.1.2 核心类关系图

### 17.1.3 A2A vs MCP

| 特性 | A2A | MCP |
|---|---|---|
| **粒度** | Agent 级别 | 工具级别 |
| **调用方式** | 发送消息，接收响应 | 调用工具，返回结果 |
| **状态管理** | 有状态（任务、会话） | 无状态（工具调用） |
| **适用场景** | 复杂任务协作 | 简单工具集成 |
| **协议** | HTTP/JSON + SSE | JSON-RPC |

💡 **设计意图**：
- **A2A**：Agent 之间的协作，适合复杂任务分解和协作
- **MCP**：工具集成，适合简单的功能扩展

## 17.2 A2A 协议核心概念

### 17.2.1 核心概念

| 概念 | 说明 | 示例 |
|---|---|---|
| **AgentCard** | Agent 的能力描述 | 名称、技能、支持的接口 |
| **Task** | 异步任务 | 任务 ID、状态、结果 |
| **Message** | 消息 | 用户输入、Agent 输出 |
| **Artifact** | 任务产出物 | 文本、文件、数据 |
| **Context** | 会话上下文 | 会话 ID、历史记录 |

💡 **设计意图**：
- **AgentCard**：让调用方知道远程 Agent 能做什么
- **Task**：管理异步任务的生命周期
- **Message**：标准化的消息格式
- **Artifact**：任务的产出物（可以是文本、文件等）

### 17.2.2 任务状态

```java
public enum TaskState {
    SUBMITTED,       // 已提交
    WORKING,         // 执行中
    INPUT_REQUIRED,  // 需要输入（如权限审批）
    COMPLETED,       // 已完成
    FAILED,          // 失败
    CANCELED,        // 已取消
    REJECTED,        // 已拒绝
    AUTH_REQUIRED    // 需要认证
}
```

💡 **设计意图**：
- **SUBMITTED**：任务已提交，等待执行
- **WORKING**：任务正在执行
- **INPUT_REQUIRED**：任务需要用户输入（如工具审批）
- **COMPLETED**：任务成功完成
- **FAILED**：任务执行失败
- **CANCELED**：任务被取消
- **REJECTED**：任务被拒绝
- **AUTH_REQUIRED**：需要认证

### 17.2.3 调用流程

```
调用方 Agent
  │
  ├─ 1. 获取 AgentCard
  │      └─ client.getAgentCard()
  │
  ├─ 2. 发送消息
  │      └─ client.send(request)
  │             │
  │             └─ 返回 Task（异步）或 直接返回结果（同步）
  │
  ├─ 3. 查询任务状态
  │      └─ client.getTask(taskId)
  │
  ├─ 4. 流式接收输出（可选）
  │      └─ client.stream(request)
  │
  └─ 5. 取消任务（可选）
         └─ client.cancelTask(taskId)
```

## 17.3 AgentCard 能力发现

### 17.3.1 AgentCard 结构

```java
public class AgentCard {
    public String name;                    // Agent 名称
    public String description;             // Agent 描述
    public String version;                 // 版本号
    public List<AgentInterface> supportedInterfaces;  // 支持的接口
    public AgentCapabilities capabilities; // 能力
    public List<Skill> skills;             // 技能列表
    public List<String> defaultInputModes; // 默认输入模式
    public List<String> defaultOutputModes; // 默认输出模式
    
    public static class AgentInterface {
        public String protocolBinding;     // 协议绑定（如 "HTTP_JSON"）
        public String protocolVersion;     // 协议版本
    }
    
    public static class AgentCapabilities {
        public Boolean streaming;          // 是否支持流式
        public Boolean pushNotifications;  // 是否支持推送通知
    }
    
    public static class Skill {
        public String id;                  // 技能 ID
        public String description;         // 技能描述

            var skill = new Skill();
            skill.id = id;
            skill.description = description;
            return skill;
        }
    }
}
```

💡 **设计意图**：
- **name/description**：让调用方知道 Agent 是什么
- **skills**：让调用方知道 Agent 能做什么
- **capabilities**：让调用方知道 Agent 支持什么特性（如流式）
- **supportedInterfaces**：让调用方知道如何连接 Agent

### 17.4.2 接口定义

```java
public interface RemoteAgentClient extends AutoCloseable {
    /**
     * 获取 Agent 能力描述
     */
    AgentCard getAgentCard();
    
    /**
     * 发送消息（同步或异步）
     */
    A2AInvocationResult send(SendMessageRequest request);
    
    /**
     * 流式发送消息
     */

    /**
     * 查询任务
     */
    Task getTask(GetTaskRequest request);
    
    /**
     * 取消任务
     */

    /**
     * 关闭客户端
     */
    @Override
    default void close() {
    }
}
```

💡 **设计意图**：
- **AutoCloseable**：支持 try-with-resources，自动释放资源
- **send**：支持同步和异步调用
- **stream**：支持流式输出
- **getTask/cancelTask**：任务管理

### 17.4.3 SendMessageRequest 消息请求

```java
public class SendMessageRequest {
    public Message message;                  // 消息内容
    public Configuration configuration;      // 配置
    public String tenant;                    // 租户（多租户场景）
    
    public static class Configuration {
        public Boolean returnImmediately;    // 是否立即返回（异步）
        public BlockingPolicy blockingPolicy; // 阻塞策略
    }
}

public class Message {
    public String messageId;                 // 消息 ID
    public String role;                      // 角色（user/agent）
    public String contextId;                 // 上下文 ID（会话 ID）
    public String taskId;                    // 任务 ID
    public List<Part> parts;                 // 消息部分
}
```

💡 **设计意图**：
- **message**：消息内容
- **configuration**：调用配置（同步/异步、阻塞策略）
- **tenant**：多租户支持
- **contextId**：会话上下文，支持多轮对话

### 17.4.4 A2AInvocationResult 调用结果

```java
public class A2AInvocationResult {
    public Task task;                        // 任务（异步）
    public Message message;                  // 消息（同步）
    public SendMessageResponse response;     // 完整响应
    
    public static A2AInvocationResult ofTask(Task task) {
        var result = new A2AInvocationResult();
        result.task = task;
        return result;
    }
    
    public static A2AInvocationResult ofMessage(Message message) {
        var result = new A2AInvocationResult();
        result.message = message;
        return result;
    }
}
```

💡 **设计意图**：
- **task**：异步调用返回任务
- **message**：同步调用返回消息
- **response**：完整响应（包含所有信息）

### 17.5.4 使用示例

```java
// 1. 创建客户端
try (var client = HttpA2AClient.builder()
        .baseUrl("http://remote-agent:8080")
        .bearerToken("api-key")
        .build()) {
    
    // 2. 获取 AgentCard
    var card = client.getAgentCard();
    System.out.println("Remote Agent: " + card.name);
    
    // 3. 发送消息（同步）
    var request = new SendMessageRequest();
    request.message = new Message();
    request.message.role = "user";
    request.message.parts = List.of(Part.text("请帮我分析这段代码"));
    
    var result = client.send(request);
    if (result.task != null) {
        System.out.println("Task ID: " + result.task.id);
        System.out.println("Status: " + result.task.status.state);
    }
    
    // 4. 查询任务
    var task = client.getTask(new GetTaskRequest(result.task.id));
    System.out.println("Task completed: " + task.status.state);
}
```

## 17.6 A2ARunManager 任务管理

### 17.6.1 文件位置

### 17.6.2 核心职责

A2ARunManager 是**本地 Agent 的 A2A 服务端**，负责：

- **任务创建**：创建同步/异步任务
- **任务管理**：管理任务状态、查询、取消
- **会话管理**：管理 Agent 会话
- **权限协作**：处理跨服务工具审批
- **流式输出**：支持 SSE 流式输出

💡 **设计意图**：
- **服务端角色**：把本地 Agent 暴露为 A2A 服务
- **任务管理**：管理异步任务的生命周期
- **权限协作**：支持跨服务工具审批

### 17.6.3 构造方法

```java
// 基础构造
var manager = new A2ARunManager(agentFactory);

// 自动审批所有工具
var manager = new A2ARunManager(agentFactory, true, null);

// 使用权限存储
var manager = new A2ARunManager(agentFactory, false, permissionStore);

// 持久化会话
var manager = new A2ARunManager(agentFactory, false, permissionStore, "session-123");
```

💡 **设计意图**：
- **agentFactory**：Agent 工厂，用于创建 Agent 实例
- **autoApproveAll**：自动审批所有工具（开发/测试）
- **permissionStore**：权限存储，持久化审批决策
- **sessionId**：持久化会话 ID，支持会话恢复

### 17.6.4 核心方法

```java
public class A2ARunManager implements A2AAgentProvider {
    
    /**
     * 获取 Agent 能力描述
     */
    @Override
    public AgentCard getAgentCard() {
        var card = new AgentCard();
        card.name = "core-ai";
        card.description = "AI coding assistant";
        card.version = "1.0.0";
        card.skills = List.of(
            AgentCard.Skill.of("code-generation", "Generate and modify code"),
            AgentCard.Skill.of("file-operations", "Read, write, search files"),
            AgentCard.Skill.of("shell-execution", "Execute shell commands")
        );
        return card;
    }
    
    /**
     * 发送消息
     */
    @Override
    public A2AInvocationResult send(SendMessageRequest request) {
        // 处理权限审批
        if (request.message.taskId != null) {
            var decision = extractDecision(request.message);
            resumeTask(request.message.taskId, decision, extractCallId(request.message));
            return A2AInvocationResult.ofTask(getTask(request.message.taskId));
        }
        
        // 异步调用
        if (request.configuration.returnImmediately) {
            return A2AInvocationResult.ofTask(createStreamingTask(request, null).toTask());
        }
        
        // 同步调用
        return A2AInvocationResult.ofTask(createSyncTask(request));
    }
    
    /**
     * 流式发送
     */
    @Override
    public Flow.Publisher<A2AStreamEvent> stream(SendMessageRequest request) {
        return new A2AStreamPublisher(sender -> createStreamingTaskEvents(request, sender));
    }
    
    /**
     * 创建同步任务
     */
    public Task createSyncTask(SendMessageRequest request) {
        var session = getOrCreateSession(contextId);
        var taskId = UUID.randomUUID().toString();
        var state = new A2ATaskState(taskId, session.id(), session);
        state.setState(TaskState.WORKING);
        tasks.put(taskId, state);
        
        var future = new CompletableFuture<Task>();
        var adapter = new A2AEventAdapter(taskId, state, null, future);
        state.attachEventListener(adapter);
        
        session.sendMessage(userText);
        
        return future.get(5, TimeUnit.MINUTES);
    }
    
    /**
     * 查询任务
     */
    @Override
    public Task getTask(GetTaskRequest request) {
        var state = tasks.get(request.id);
        return state != null ? state.toTask() : null;
    }
    
    /**
     * 取消任务
     */
    @Override
    public Task cancelTask(CancelTaskRequest request) {
        var state = tasks.get(request.id);
        if (state != null) {
            state.session.cancelTurn();
            state.setState(TaskState.CANCELED);
        }
        return getTask(request.id);
    }
    
    /**
     * 恢复任务（权限审批）
     */
    public void resumeTask(String taskId, String decision, String callId) {
        var state = tasks.get(taskId);
        if (state.getState() != TaskState.INPUT_REQUIRED) {
            throw new IllegalStateException("task is not awaiting input");
        }
        
        var approvalDecision = "deny".equalsIgnoreCase(decision) 
            ? ApprovalDecision.DENY 
            : ApprovalDecision.APPROVE;
        
        state.setState(TaskState.WORKING);
        state.clearAwait();
        state.session.approveToolCall(callId, approvalDecision);
    }
}
```

💡 **设计意图**：
- **同步任务**：阻塞等待结果（5 分钟超时）
- **异步任务**：立即返回任务 ID，后续查询
- **流式任务**：SSE 流式输出
- **权限审批**：通过 `resumeTask` 处理跨服务权限审批

## 17.7 任务状态与生命周期

### 17.7.1 A2ATaskState 任务状态

```java
public class A2ATaskState {
    public final String taskId;                    // 任务 ID
    public final String contextId;                 // 上下文 ID
    public final AgentSession session;             // Agent 会话
    
    private volatile TaskState state = TaskState.SUBMITTED;  // 状态
    private volatile String awaitCallId;           // 等待的工具调用 ID
    private volatile String awaitTool;             // 等待的工具名称
    private volatile String awaitArguments;        // 等待的工具参数
    private final StringBuilder outputBuffer = new StringBuilder();  // 输出缓冲
    
    public volatile Long inputTokens;              // 输入 token 数
    public volatile Long outputTokens;             // 输出 token 数
    public volatile String errorMessage;           // 错误消息
    
    /**
     * 是否为终态
     */
    public boolean isTerminal() {
        return state == TaskState.COMPLETED
            || state == TaskState.FAILED
            || state == TaskState.CANCELED
            || state == TaskState.REJECTED;
    }
    
    /**
     * 设置等待状态
     */
    public void setAwait(String callId, String tool, String arguments) {
        this.awaitCallId = callId;
        this.awaitTool = tool;
        this.awaitArguments = arguments;
        setState(TaskState.INPUT_REQUIRED);
    }
    
    /**
     * 转换为 Task
     */
    public Task toTask() {
        var task = new Task();
        task.id = taskId;
        task.contextId = contextId;
        task.status = TaskStatus.of(state);
        
        var output = getFullOutput();
        if (!output.isEmpty()) {
            task.artifacts = List.of(Artifact.text(output));
        }
        
        if (state == TaskState.INPUT_REQUIRED && awaitCallId != null) {
            var detail = awaitTool != null ? awaitTool : "tool approval required";
            task.status = TaskStatus.of(state, Message.agent("Tool requires approval: " + detail));
        }
        
        if (errorMessage != null) {
            task.status = TaskStatus.of(TaskState.FAILED, Message.agent(errorMessage));
        }
        
        return task;
    }
}
```

💡 **设计意图**：
- **状态管理**：跟踪任务状态（SUBMITTED → WORKING → COMPLETED/FAILED）
- **等待状态**：记录等待的工具调用，支持权限审批
- **输出缓冲**：收集 Agent 输出
- **Token 统计**：记录 token 使用量
- **错误处理**：记录错误消息

### 17.7.2 任务生命周期

```
SUBMITTED
  │
  │ 开始执行
  ▼
WORKING ←──────────┐
  │                │
  ├─ 需要输入      │ 恢复执行
  │    ▼           │
  │  INPUT_REQUIRED ┘
  │
  ├─ 成功完成
  │    ▼
  │  COMPLETED
  │
  ├─ 执行失败
  │    ▼
  │  FAILED
  │
  ├─ 被取消
  │    ▼
  │  CANCELED
  │
  └─ 被拒绝
       ▼
     REJECTED
```

```java
    request.message.role = "user";
    request.message.parts = List.of(Part.text("请帮我写一个 Java 程序"));
    
    // 3. 流式接收
    var publisher = client.stream(request);
    
    publisher.subscribe(new Flow.Subscriber<>() {
        @Override
        public void onSubscribe(Flow.Subscription subscription) {
            subscription.request(Long.MAX_VALUE);
        }
        
        @Override
        public void onNext(A2AStreamEvent event) {
            if (event.statusUpdate != null) {
                System.out.println("Status: " + event.statusUpdate.status.state);
            }
            if (event.artifactUpdate != null) {
                System.out.println("Output: " + event.artifactUpdate.artifact.parts.get(0).text);
            }
        }
        
        @Override
        public void onError(Throwable throwable) {
            System.err.println("Error: " + throwable.getMessage());
        }
        
        @Override
        public void onComplete() {
            System.out.println("Completed");
        }
    });
}
```

💡 **设计意图**：
- **SSE**：Server-Sent Events，单向流式输出
- **Flow.Publisher**：Java 9+ 的响应式流 API
- **实时更新**：实时接收 Agent 输出，无需等待完成

### 17.9.3 流式调用

```java
// 1. 创建客户端
try (var client = HttpA2AClient.builder()
        .baseUrl("http://remote-agent:8080")
        .bearerToken("api-key")
        .build()) {
    
    // 2. 流式发送
    var request = new SendMessageRequest();
    request.message = new Message();
    request.message.role = "user";
    request.message.parts = List.of(Part.text("请帮我写一个 Java 程序"));
    
    var publisher = client.stream(request);
    
    // 3. 接收流
    var latch = new CountDownLatch(1);
    publisher.subscribe(new Flow.Subscriber<>() {
        @Override
        public void onSubscribe(Flow.Subscription subscription) {
            subscription.request(Long.MAX_VALUE);
        }
        
        @Override
        public void onNext(A2AStreamEvent event) {
            if (event.artifactUpdate != null) {
                var text = event.artifactUpdate.artifact.parts.get(0).text;
                System.out.print(text);  // 实时输出
            }
        }
        
        @Override
        public void onError(Throwable throwable) {
            System.err.println("Error: " + throwable.getMessage());
            latch.countDown();
        }
        
        @Override
        public void onComplete() {
            System.out.println("\nCompleted");
            latch.countDown();
        }
    });
    
    latch.await();
}
```

### 17.9.4 暴露本地 Agent 为 A2A 服务

```java
// 1. 创建 Agent 工厂
Supplier<Agent> agentFactory = () -> Agent.builder()
    .name("coding-assistant")
    .systemPrompt("你是一个编程助手")
    .llmProvider(llmProvider)
    .toolRegistry(toolRegistry)
    .build();

// 2. 创建 RunManager
var manager = new A2ARunManager(agentFactory, false, permissionStore);

// 3. 注册 HTTP 端点（在 core-ai-server 中）
http().route("GET", A2AHttpPaths.AGENT_CARD, (req, resp) -> {
    resp.json(manager.getAgentCard());
});

http().route("POST", A2AHttpPaths.MESSAGE_SEND, (req, resp) -> {
    var request = req.json(SendMessageRequest.class);
    var result = manager.send(request);
    resp.json(result);
});

http().route("POST", A2AHttpPaths.MESSAGE_STREAM, (req, resp) -> {
    var request = req.json(SendMessageRequest.class);
    var publisher = manager.stream(request);
    // SSE 流式输出
    resp.sse(publisher);
});

http().route("GET", A2AHttpPaths.TASKS + "/:id", (req, resp) -> {
    var taskId = req.param("id");
    var task = manager.getTask(new GetTaskRequest(taskId));
    resp.json(task);
});

http().route("POST", A2AHttpPaths.TASKS + "/:id/cancel", (req, resp) -> {
    var taskId = req.param("id");
    var task = manager.cancelTask(new CancelTaskRequest(taskId));
    resp.json(task);
});
```

💡 **设计意图**：
- **Agent 工厂**：每次请求创建新的 Agent 实例
- **权限存储**：持久化审批决策
- **HTTP 端点**：遵循 A2A 协议规范
