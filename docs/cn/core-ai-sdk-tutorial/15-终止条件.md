## 15.1 终止条件系统总览

### 15.1.1 终止条件的角色

终止条件系统是 core-ai 的**Agent 执行控制机制**，负责：

- **控制执行时长**：防止 Agent 无限循环
- **资源保护**：限制 token 使用量，控制成本
- **用户意图识别**：当 Agent 输出特定消息时自动终止
- **用户控制**：允许用户手动取消执行

💡 **设计意图**：AI Agent 可能陷入死循环或产生意外行为，终止条件提供多层保护机制，确保系统可控、成本可控。

### 15.1.2 核心类关系图

```
┌─────────────────────────────────────────────────────────────┐
│                  Termination (interface)                    │
│                                                             │
│  + DEFAULT_TERMINATION_WORD = "TERMINATE"                   │
│  + terminate(node: Node): boolean                           │
└──────────────────────┬──────────────────────────────────────┘
                       │ 实现
        ┌──────────────┼──────────────┬──────────────┬──────────────┐
        ▼              ▼              ▼              ▼              ▼
┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ MaxRound     │ │ StopMessage  │ │ MaxToken     │ │ UserCancelled│ │ Custom       │
│ Termination  │ │ Termination  │ │ Termination  │ │ Termination  │ │ Termination  │
│              │ │              │ │              │ │              │ │ (用户自定义) │
│ 限制轮次     │ │ 检测终止消息 │ │ 限制 token   │ │ 用户取消     │ │              │
└──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘
```

### 15.1.3 4 种内置终止条件对比

| 终止条件 | 触发条件 | 适用场景 | 实现状态 |
|---|---|---|---|
| **MaxRoundTermination** | 轮次 > 最大轮次 | 防止死循环 | ✅ 已实现 |
| **StopMessageTermination** | 输出包含 "TERMINATE" | Agent 主动结束 | ✅ 已实现 |
| **MaxTokenTermination** | token 使用量 > 限制 | 控制成本 | ⚠️ 未实现（占位） |
| **UserCancelledTermination** | 用户取消 | 用户控制 | ⚠️ 未实现（占位） |

💡 **设计意图**：
- **MaxRound** 和 **StopMessage** 是核心终止条件，已完整实现
- **MaxToken** 和 **UserCancelled** 是预留接口，当前返回 false（不触发），等待后续实现

## 15.2 Termination 接口

### 15.2.1 文件位置

```
core-ai/src/main/java/ai/core/termination/Termination.java
```

### 15.2.2 接口定义

```java
public interface Termination {
    /**
     * 默认终止词
     */
    String DEFAULT_TERMINATION_WORD = "TERMINATE";
    
    /**
     * 判断是否应该终止
     * @param node 当前执行的节点（Agent 或 FlowNode）
     * @return true 表示应该终止，false 表示继续执行
     */
    boolean terminate(Node<?> node);
}
```

💡 **设计意图**：
- **简单接口**：只有一个 `terminate()` 方法，易于实现
- **Node 参数**：可以访问节点的完整状态（消息历史、轮次、输出等）
- **常量**：`DEFAULT_TERMINATION_WORD` 提供标准的终止词

### 15.2.3 Node 接口

```java
public abstract class Node<T extends Node<T>> {
    // 核心状态
    protected String id;
    protected String name;
    protected NodeStatus status;
    protected List<Message> messages;
    protected String input;
    protected String output;
    protected Integer round;              // 当前轮次
    protected Integer maxRound;           // 最大轮次
    
    // 使用量统计
    protected Usage currentTokenUsage;    // token 使用量
    
    // 取消控制
    protected CancellationToken cancellationToken;
    
    // getter 方法
    public Integer getRound() { return round; }
    public Integer getMaxRound() { return maxRound; }
    public String getOutput() { return output; }
    public Usage getCurrentTokenUsage() { return currentTokenUsage; }
    public CancellationToken getCancellationToken() { return cancellationToken; }
}
```

💡 **设计意图**：Node 提供完整的状态信息，Termination 可以根据不同条件判断是否终止。

### 15.2.4 终止条件的检查时机

```
Agent 执行循环
  │
  ├─ 1. 执行一轮（turn）
  │
  ├─ 2. 更新状态（round++, output, tokenUsage）
  │
  ├─ 3. 检查终止条件
  │      │
  │      └─ for (Termination termination : terminations) {
  │             if (termination.terminate(this)) {
  │                 return output;  // 终止执行
  │             }
  │         }
  │
  └─ 4. 如果未终止，继续下一轮
```

## 15.3 MaxRoundTermination 轮次终止

### 15.3.1 文件位置

```
core-ai/src/main/java/ai/core/termination/terminations/MaxRoundTermination.java
```

### 15.3.2 核心实现

```java
public class MaxRoundTermination implements Termination {
    @Override
    public boolean terminate(Node<?> node) {
        return node.getRound() > node.getMaxRound();
    }
}
```

💡 **设计意图**：
- **简单逻辑**：当前轮次 > 最大轮次时终止
- **防止死循环**：Agent 陷入工具调用循环时，达到最大轮次后自动终止
- **默认值**：`maxRound` 通常在 AgentBuilder 中设置（如 `.maxRound(10)`）

### 15.3.3 工作原理

```
轮次 1: round=1, maxRound=10 → 继续
轮次 2: round=2, maxRound=10 → 继续
...
轮次 10: round=10, maxRound=10 → 继续（10 > 10 为 false）
轮次 11: round=11, maxRound=10 → 终止（11 > 10 为 true）
```

### 15.3.4 使用方式

```java
var agent = Agent.builder()
    .name("assistant")
    .systemPrompt("你是一个助手")
    .llmProvider(llmProvider)
    .maxRound(10)  // 设置最大轮次
    .termination(new MaxRoundTermination())  // 添加终止条件
    .build();
```

## 15.4 StopMessageTermination 消息终止

### 15.4.1 文件位置

```
core-ai/src/main/java/ai/core/termination/terminations/StopMessageTermination.java
```

### 15.4.2 核心实现

```java
public class StopMessageTermination implements Termination {
    @Override
    public boolean terminate(Node<?> node) {
        var agent = (Agent) node;
        return agent.getOutput().contains(DEFAULT_TERMINATION_WORD);
    }
}
```

💡 **设计意图**：
- **主动终止**：Agent 可以在 system prompt 中被指示，当任务完成时输出 "TERMINATE"
- **灵活控制**：Agent 可以根据任务完成情况自主决定是否终止
- **类型转换**：需要转换为 Agent 类型，因为只有 Agent 有 `getOutput()` 方法

### 15.4.3 工作原理

```
Agent 执行
  │
  ├─ 输出: "任务已完成，以下是结果... TERMINATE"
  │
  └─ StopMessageTermination.terminate()
         │
         └─ output.contains("TERMINATE") → true → 终止
```

### 15.4.4 使用方式

```java
var agent = Agent.builder()
    .name("assistant")
    .systemPrompt("""
        你是一个任务执行助手。
        当你完成任务后，请在回答末尾输出 "TERMINATE" 表示任务完成。
        """)
    .llmProvider(llmProvider)
    .termination(new StopMessageTermination())
    .build();
```

💡 **提示**：在 system prompt 中明确指示 Agent 在任务完成时输出 "TERMINATE"。

## 15.7 自定义终止条件

### 15.7.1 示例：基于输出长度终止

```java
public class MaxOutputLengthTermination implements Termination {
    private final int maxLength;
    
    public MaxOutputLengthTermination(int maxLength) {
        this.maxLength = maxLength;
    }
    
    @Override
    public boolean terminate(Node<?> node) {
        var output = node.getOutput();
        return output != null && output.length() > maxLength;
    }
}
```

💡 **使用场景**：限制 Agent 输出长度，防止生成过长的回答。

### 15.7.2 示例：基于时间终止

```java
public class TimeoutTermination implements Termination {
    private final long startTime;
    private final long timeoutMs;
    
    public TimeoutTermination(long timeoutMs) {
        this.startTime = System.currentTimeMillis();
        this.timeoutMs = timeoutMs;
    }
    
    @Override
    public boolean terminate(Node<?> node) {
        var elapsed = System.currentTimeMillis() - startTime;
        return elapsed > timeoutMs;
    }
}
```

💡 **使用场景**：限制 Agent 执行时间，防止长时间阻塞。

### 15.7.3 示例：基于消息内容终止

```java
public class KeywordTermination implements Termination {
    private final List<String> keywords;
    
    public KeywordTermination(List<String> keywords) {
        this.keywords = keywords;
    }
    
    @Override
    public boolean terminate(Node<?> node) {
        var output = node.getOutput();
        if (output == null) return false;
        
        return keywords.stream().anyMatch(output::contains);
    }
}
```

💡 **使用场景**：当 Agent 输出特定关键词时终止（如 "任务完成"、"错误"）。

### 15.7.4 示例：基于消息历史终止

```java
public class DuplicateOutputTermination implements Termination {
    private final int threshold;
    
    public DuplicateOutputTermination(int threshold) {
        this.threshold = threshold;
    }
    
    @Override
    public boolean terminate(Node<?> node) {
        var messages = node.getMessages();
        if (messages.size() < threshold) return false;
        
        // 检查最近 N 条消息是否重复
        var recentOutputs = messages.subList(messages.size() - threshold, messages.size())
            .stream()
            .map(Message::getContent)
            .toList();
        
        return recentOutputs.stream().distinct().count() == 1;
    }
}
```

💡 **使用场景**：检测 Agent 是否陷入重复输出的死循环。

## 15.8 终止条件的组合使用

### 15.8.1 多条件 AND（所有条件都满足才终止）

```java
public class AndTermination implements Termination {
    private final List<Termination> terminations;
    
    public AndTermination(List<Termination> terminations) {
        this.terminations = terminations;
    }
    
    @Override
    public boolean terminate(Node<?> node) {
        return terminations.stream().allMatch(t -> t.terminate(node));
    }
}
```

💡 **使用场景**：需要同时满足多个条件才终止（如轮次达到 AND 输出包含特定词）。

### 15.8.2 多条件 OR（任一条件满足就终止）

```java
public class OrTermination implements Termination {
    private final List<Termination> terminations;
    
    public OrTermination(List<Termination> terminations) {
        this.terminations = terminations;
    }
    
    @Override
    public boolean terminate(Node<?> node) {
        return terminations.stream().anyMatch(t -> t.terminate(node));
    }
}
```

💡 **使用场景**：满足任一条件就终止（如轮次达到 OR token 超限 OR 用户取消）。

### 15.8.3 推荐组合

```java
var agent = Agent.builder()
    .name("assistant")
    .systemPrompt("你是一个助手，完成任务后输出 TERMINATE")
    .llmProvider(llmProvider)
    .maxRound(10)
    // 组合使用多个终止条件（OR 逻辑）
    .terminations(List.of(
        new MaxRoundTermination(),           // 轮次达到 10
        new StopMessageTermination(),        // 输出包含 TERMINATE
        new UserCancelledTermination()       // 用户取消（预留）
    ))
    .build();
```

💡 **设计意图**：
- **多层保护**：多个终止条件提供多层保护，确保系统可控
- **OR 逻辑**：Agent 内部使用 `for` 循环检查，任一条件满足就终止（相当于 OR）
- **灵活性**：可以根据场景选择不同的终止条件组合

## 15.9 实战示例

### 15.9.1 轮次终止

```java
var agent = Agent.builder()
    .name("assistant")
    .systemPrompt("你是一个助手")
    .llmProvider(llmProvider)
    .maxRound(5)  // 最多 5 轮
    .termination(new MaxRoundTermination())
    .build();

var result = agent.execute("请帮我写一个复杂的程序", null);
// 如果 5 轮内未完成，自动终止
```

### 15.9.2 消息终止

```java
var agent = Agent.builder()
    .name("assistant")
    .systemPrompt("""
        你是一个任务执行助手。
        当你完成任务后，请在回答末尾输出 "TERMINATE"。
        """)
    .llmProvider(llmProvider)
    .termination(new StopMessageTermination())
    .build();

var result = agent.execute("请完成数据分析任务", null);
// Agent 完成任务后输出 "TERMINATE"，自动终止
```

### 15.9.3 组合终止

```java
var agent = Agent.builder()
    .name("assistant")
    .systemPrompt("""
        你是一个助手。
        完成任务后输出 "TERMINATE"。
        """)
    .llmProvider(llmProvider)
    .maxRound(10)
    .terminations(List.of(
        new MaxRoundTermination(),
        new StopMessageTermination(),
        new MaxOutputLengthTermination(5000)  // 自定义：输出超过 5000 字符终止
    ))
    .build();
```

### 15.9.4 自定义终止

```java
// 自定义：5 分钟内未完成则终止
var timeoutTermination = new TimeoutTermination(5 * 60 * 1000);

var agent = Agent.builder()
    .name("assistant")
    .termination(timeoutTermination)
    .build();
```
