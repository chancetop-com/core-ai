## 12.1 遥测系统总览

### 12.1.1 遥测的角色

遥测系统是 core-ai 的**可观测性基础设施**，负责：

- **分布式追踪**：跟踪请求在多个组件间的流转
- **指标收集**：收集性能指标（延迟、吞吐量、错误率）
- **日志关联**：把日志与追踪关联，便于排查问题
- **调试支持**：提供详细的执行轨迹，便于调试和优化

💡 **设计意图**：AI Agent 系统复杂（多轮对话、工具调用、LLM 交互），需要完善的可观测性来理解系统行为、定位问题、优化性能。

### 12.1.2 核心类关系图

```
┌─────────────────────────────────────────────────────────────┐
│                    OpenTelemetry SDK                        │
│                                                             │
│  - TracerProvider                                           │
│  - SpanProcessor                                            │
│  - SpanExporter (OTLP/Jaeger/Zipkin)                        │
└──────────────────────┬──────────────────────────────────────┘
                       │ 提供
                       ▼
┌─────────────────────────────────────────────────────────────┐
│                      Tracer (abstract)                      │
│                                                             │
│  - tracer: io.opentelemetry.api.trace.Tracer                │
│  - enabled: boolean                                         │
│                                                             │
│  + startSpan(name): Span                                    │
│  + trace(name, operation): T                                │
│  + getCurrentSpan(): Span                                   │
└──────────────────────┬──────────────────────────────────────┘
                       │ 继承
        ┌──────────────┼──────────────┬──────────────┐
        ▼              ▼              ▼              ▼
┌──────────────┐ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ LLMTracer    │ │ AgentTracer  │ │ FlowTracer   │ │ GroupTracer  │
│              │ │              │ │              │ │              │
│ 追踪 LLM     │ │ 追踪 Agent   │ │ 追踪 Flow    │ │ 追踪 Group   │
│ 调用         │ │ 执行         │ │ 执行         │ │ 执行         │
└──────────────┘ └──────────────┘ └──────────────┘ └──────────────┘
```

### 12.1.3 Tracer vs Span

| 概念 | 说明 | 示例 |
|---|---|---|
| **Tracer** | 创建 Span 的工厂 | LLMTracer、AgentTracer |
| **Span** | 一次操作的追踪记录 | "LLM 调用"、"Agent 执行" |
| **SpanContext** | Span 的上下文（traceId、spanId） | 用于关联子 Span |
| **Attribute** | Span 的键值对属性 | `llm.model=gpt-4`、`agent.name=assistant` |

💡 **设计意图**：
- **Tracer**：领域特定的追踪器（LLM/Agent/Flow），封装了领域知识
- **Span**：具体的操作记录，OpenTelemetry 标准概念
- **Attribute**：附加信息，便于查询和分析

## 12.2 OpenTelemetry 集成

### 12.2.1 OpenTelemetry 简介

OpenTelemetry 是云原生计算基金会（CNCF）的开源项目，提供标准化的可观测性 API：

- **Traces**：分布式追踪
- **Metrics**：指标收集
- **Logs**：日志关联

💡 **设计意图**：使用 OpenTelemetry 标准，可以无缝集成各种后端（Jaeger、Zipkin、Langfuse、Prometheus 等）。

### 12.2.2 配置 OpenTelemetry

```java
// 1. 创建 OpenTelemetry 实例
var openTelemetry = OpenTelemetrySdk.builder()
    .setTracerProvider(
        SdkTracerProvider.builder()
            .addSpanProcessor(
                BatchSpanProcessor.builder(
                    OtlpGrpcSpanExporter.builder()
                        .setEndpoint("http://localhost:4317")
                        .build()
                ).build()
            )
            .build()
    )
    .build();

// 2. 创建 Tracer
var tracer = openTelemetry.getTracer("CoreAI", "1.0.0");

// 3. 注入到 LLMProvider
llmProvider.setTracer(new LLMTracer(openTelemetry, true));
```

💡 **设计意图**：
- **OTLP Exporter**：使用 OpenTelemetry Protocol，兼容各种后端
- **BatchSpanProcessor**：批量发送 Span，提高性能
- **可配置**：可以切换不同的 Exporter（Jaeger、Zipkin、Langfuse 等）

### 12.2.3 Span 生命周期

```java
// 1. 创建 Span
var span = tracer.spanBuilder("operation-name")
    .setSpanKind(SpanKind.INTERNAL)
    .startSpan();

// 2. 设置为当前 Span
try (var scope = span.makeCurrent()) {
    // 执行操作
    var result = doSomething();
    
    // 3. 添加属性
    span.setAttribute("key", "value");
    
    // 4. 记录事件
    span.addEvent("event-name");
    
    return result;
} catch (Exception e) {
    // 5. 记录错误
    span.setStatus(StatusCode.ERROR, e.getMessage());
    span.recordException(e);
    throw e;
} finally {
    // 6. 结束 Span
    span.end();
}
```

💡 **设计意图**：
- **try-with-resources**：自动管理 Span 的生命周期
- **属性**：附加信息，便于查询（如 `llm.model=gpt-4`）
- **事件**：时间线上的标记（如 "工具调用开始"、"工具调用结束"）
- **状态**：成功（OK）或失败（ERROR）

## 12.3 Tracer 基类

### 12.3.1 文件位置

```
core-ai/src/main/java/ai/core/telemetry/Tracer.java
```

### 12.3.2 核心实现

```java
public abstract class Tracer {
    protected static final String INSTRUMENTATION_NAME = "CoreAI";
    protected static final String INSTRUMENTATION_VERSION = "1.0.0";
    
    // Langfuse 特定属性
    static final AttributeKey<String> LANGFUSE_OBSERVATION_TYPE = 
        AttributeKey.stringKey("langfuse.observation.type");
    static final AttributeKey<Boolean> CORE_AI_CANCELLED = 
        AttributeKey.booleanKey("core_ai.cancelled");
    static final AttributeKey<String> CORE_AI_CANCEL_REASON = 
        AttributeKey.stringKey("core_ai.cancel.reason");
    
    protected final io.opentelemetry.api.trace.Tracer tracer;
    protected final boolean enabled;
    
    protected Tracer(OpenTelemetry openTelemetry, boolean enabled) {
        this.tracer = openTelemetry.getTracer(INSTRUMENTATION_NAME, INSTRUMENTATION_VERSION);
        this.enabled = enabled;
    }
    
    /**
     * 检查是否启用
     */
    public boolean isEnabled() {
        return enabled;
    }
    
    /**
     * 获取底层 OpenTelemetry Tracer
     */
    public io.opentelemetry.api.trace.Tracer getTracer() {
        return tracer;
    }
    
    /**
     * 获取当前 Span
     */
    public Span getCurrentSpan() {
        return Span.current();
    }
    
    /**
     * 创建子 Span
     */
    public Span startSpan(String spanName) {
        if (!enabled) {
            return Span.getInvalid();
        }
        return tracer.spanBuilder(spanName)
            .setSpanKind(SpanKind.INTERNAL)
            .startSpan();
    }
    
    /**
     * 追踪操作（带自动 Span 管理）
     */
    @SuppressWarnings("try")
    protected <T> T trace(String spanName, SpanKind spanKind, Supplier<T> operation) {
        if (!enabled) {
            return operation.get();
        }
        
        var span = tracer.spanBuilder(spanName)
            .setSpanKind(spanKind)
            .startSpan();
        
        try (var ignored = span.makeCurrent()) {
            return operation.get();
        } catch (Exception e) {
            span.setStatus(StatusCode.ERROR, e.getMessage());
            span.recordException(e);
            throw e;
        } finally {
            span.end();
        }
    }
    
    /**
     * 截断文本（避免 Span 属性过大）
     */
    protected String truncate(String text, int maxLength) {
        if (text == null) return "";
        if (text.length() <= maxLength) return text;
        return text.substring(0, maxLength) + "...";
    }
}
```

💡 **设计意图**：
- **enabled 标志**：可以动态启用/禁用追踪，不影响性能
- **trace() 方法**：封装 Span 生命周期管理，简化使用
- **truncate()**：避免 Span 属性过大（如 LLM 输出可能很长）
- **Langfuse 属性**：支持 Langfuse 特定的属性，便于集成

## 12.4 LLMTracer

### 12.4.1 文件位置

```
core-ai/src/main/java/ai/core/telemetry/LLMTracer.java
```

### 12.4.2 核心职责

LLMTracer 追踪**LLM 调用**，记录：

- **模型信息**：model name、provider
- **请求信息**：messages、tools、temperature
- **响应信息**：completion、token usage、finish reason
- **性能信息**：延迟、吞吐量

💡 **设计意图**：LLM 调用是 Agent 的核心操作，需要详细追踪来理解成本、性能和行为。

### 12.4.3 核心实现

```java
public class LLMTracer extends Tracer {
    public LLMTracer(OpenTelemetry openTelemetry, boolean enabled) {
        super(openTelemetry, enabled);
    }
    
    /**
     * 追踪 LLM 调用
     */
    public CompletionResponse traceLLMCall(
        String modelName,
        CompletionRequest request,
        Supplier<CompletionResponse> operation
    ) {
        return trace("llm.call", SpanKind.CLIENT, () -> {
            var span = getCurrentSpan();
            
            // 1. 设置 Langfuse 属性
            span.setAttribute(LANGFUSE_OBSERVATION_TYPE, "generation");
            
            // 2. 记录请求信息
            span.setAttribute("llm.model", modelName);
            span.setAttribute("llm.request.messages", 
                truncate(JsonUtil.toJson(request.messages), 10000));
            
            if (request.tools != null && !request.tools.isEmpty()) {
                span.setAttribute("llm.request.tools", 
                    truncate(JsonUtil.toJson(request.tools), 5000));
            }
            
            if (request.temperature != null) {
                span.setAttribute("llm.temperature", request.temperature);
            }
            
            // 3. 执行 LLM 调用
            var startTime = System.currentTimeMillis();
            var response = operation.get();
            var duration = System.currentTimeMillis() - startTime;
            
            // 4. 记录响应信息
            if (response.choices != null && !response.choices.isEmpty()) {
                var choice = response.choices.get(0);
                span.setAttribute("llm.response.finish_reason", 
                    choice.finishReason.name());
                
                if (choice.message != null && choice.message.content != null) {
                    span.setAttribute("llm.response.content", 
                        truncate(choice.message.content, 10000));
                }
                
                if (choice.message.toolCalls != null) {
                    span.setAttribute("llm.response.tool_calls", 
                        truncate(JsonUtil.toJson(choice.message.toolCalls), 5000));
                }
            }
            
            // 5. 记录 token 使用量
            if (response.usage != null) {
                span.setAttribute("llm.usage.prompt_tokens", response.usage.promptTokens);
                span.setAttribute("llm.usage.completion_tokens", response.usage.completionTokens);
                span.setAttribute("llm.usage.total_tokens", response.usage.totalTokens);
            }
            
            // 6. 记录性能
            span.setAttribute("llm.duration_ms", duration);
            
            return response;
        });
    }
}
```

💡 **设计意图**：
- **SpanKind.CLIENT**：表示这是对外部服务的调用（LLM API）
- **Langfuse 属性**：`langfuse.observation.type=generation` 让 Langfuse 识别为 LLM 调用
- **截断**：messages 和 content 可能很长，截断到 10000 字符
- **性能指标**：记录延迟（duration_ms），便于分析性能瓶颈

## 12.5 AgentTracer

### 12.5.1 文件位置

```
core-ai/src/main/java/ai/core/telemetry/AgentTracer.java
```

### 12.5.2 核心职责

AgentTracer 追踪**Agent 执行**，记录：

- **Agent 信息**：name、id
- **执行信息**：input、output、message count
- **工具调用**：tool calls、tool results
- **状态信息**：status、cancel reason

💡 **设计意图**：Agent 是用户交互的核心，需要追踪整个执行过程，便于调试和优化。

### 12.5.3 核心实现

```java
public class AgentTracer extends Tracer {
    public AgentTracer(OpenTelemetry openTelemetry, boolean enabled) {
        super(openTelemetry, enabled);
    }
    
    /**
     * 追踪 Agent 执行
     */
    public <T> T traceAgentExecution(
        AgentTraceContext context,
        Supplier<T> operation,
        BooleanSupplier isCancelled
    ) {
        return trace("agent.execute", SpanKind.INTERNAL, () -> {
            var span = getCurrentSpan();
            
            // 1. 设置 Langfuse 属性
            span.setAttribute(LANGFUSE_OBSERVATION_TYPE, "span");
            
            // 2. 记录 Agent 信息
            span.setAttribute("agent.name", context.getName());
            span.setAttribute("agent.id", context.getId());
            
            if (context.getSessionId() != null) {
                span.setAttribute("session.id", context.getSessionId());
            }
            
            if (context.getUserId() != null) {
                span.setAttribute("user.id", context.getUserId());
            }
            
            // 3. 记录执行信息
            span.setAttribute("agent.input", truncate(context.getInput(), 5000));
            span.setAttribute("agent.with_tools", context.isWithTools());
            span.setAttribute("agent.with_rag", context.isWithRag());
            
            // 4. 执行 Agent
            var result = operation.get();
            
            // 5. 记录输出信息
            if (context.getOutput() != null) {
                span.setAttribute("agent.output", truncate(context.getOutput(), 5000));
            }
            
            span.setAttribute("agent.status", context.getStatus());
            span.setAttribute("agent.message_count", context.getMessageCount());
            
            // 6. 记录取消信息
            if (isCancelled.getAsBoolean()) {
                span.setAttribute(CORE_AI_CANCELLED, true);
                if (context.getCancelReason() != null) {
                    span.setAttribute(CORE_AI_CANCEL_REASON, context.getCancelReason());
                }
            }
            
            return result;
        });
    }
}
```

💡 **设计意图**：
- **SpanKind.INTERNAL**：表示这是内部操作
- **Langfuse 属性**：`langfuse.observation.type=span` 让 Langfuse 识别为普通 Span
- **会话关联**：记录 sessionId 和 userId，便于关联同一会话的多个 Agent 执行
- **取消追踪**：记录取消原因，便于调试

### 12.6.2 核心职责

FlowTracer 追踪**Flow 执行**，记录：

- **Flow 信息**：id、name
- **节点信息**：nodeId、nodeName

public class FlowTracer extends Tracer {

            // 2. 记录 Flow 信息
            span.setAttribute("flow.id", context.getFlowId());
            span.setAttribute("flow.name", context.getFlowName());
            
            // 3. 记录节点信息
            span.setAttribute("flow.node.id", context.getNodeId());
            span.setAttribute("flow.node.name", context.getNodeName());

## 12.7 全链路追踪

### 12.7.1 追踪链路示例

```
用户请求
  │
  └─ Agent 执行 (AgentTracer)
         │
         ├─ Turn 1
         │    │
         │    ├─ LLM 调用 (LLMTracer)
         │    │    ├─ model: gpt-4
         │    │    ├─ input: "你好"
         │    │    └─ output: "你好！我是..."
         │    │
         │    └─ 工具调用: search
         │         │
         │         └─ Tool Span
         │              ├─ tool: search
         │              └─ result: "搜索结果..."
         │
         ├─ Turn 2
         │    │
         │    └─ LLM 调用 (LLMTracer)
         │         ├─ model: gpt-4
         │         ├─ input: "根据搜索结果..."
         │         └─ output: "根据搜索结果，..."
         │
         └─ 完成
```

💡 **设计意图**：
- **层级关系**：Agent Span 是父 Span，LLM/Tool Span 是子 Span
- **traceId**：所有 Span 共享同一个 traceId，便于关联
- **spanId**：每个 Span 有唯一 spanId，形成树状结构

### 12.7.2 追踪可视化

使用 Jaeger 或 Langfuse 可视化追踪链路：

```
Trace: agent.execute (1.2s)
  ├─ Span: agent.execute (1.2s)
  │    ├─ Span: llm.call (0.8s)
  │    │    └─ Attributes: model=gpt-4, tokens=150
  │    ├─ Span: tool.execute (0.3s)
  │    │    └─ Attributes: tool=search
  │    └─ Span: llm.call (0.1s)
  │         └─ Attributes: model=gpt-4, tokens=50
```

## 12.8 Langfuse 集成

### 12.8.1 Langfuse 简介

Langfuse 是开源的 LLM 工程平台，提供：

- **追踪可视化**：可视化追踪链路
- **成本分析**：统计 token 使用量和成本
- **性能分析**：分析延迟和吞吐量
- **提示词管理**：管理和版本化提示词

💡 **设计意图**：Langfuse 是 AI 应用的标准可观测性工具，core-ai 通过 OpenTelemetry 协议无缝集成。

### 12.8.2 配置 Langfuse

```java
// 1. 创建 Langfuse Exporter
var langfuseExporter = OtlpGrpcSpanExporter.builder()
    .setEndpoint("https://cloud.langfuse.com/api/public/otel/v1/traces")
    .addHeader("Authorization", "Bearer " + langfuseApiKey)
    .build();

// 2. 创建 OpenTelemetry
var openTelemetry = OpenTelemetrySdk.builder()
    .setTracerProvider(
        SdkTracerProvider.builder()
            .addSpanProcessor(BatchSpanProcessor.builder(langfuseExporter).build())
            .build()
    )
    .build();

// 3. 创建 Tracer
var llmTracer = new LLMTracer(openTelemetry, true);
var agentTracer = new AgentTracer(openTelemetry, true);

// 4. 注入到组件
llmProvider.setTracer(llmTracer);
agent.setTracer(agentTracer);
```

💡 **设计意图**：
- **OTLP 协议**：Langfuse 支持 OpenTelemetry 协议，无需特殊适配
- **API Key**：通过 Authorization header 传递 Langfuse API key
- **无缝集成**：使用标准 OpenTelemetry SDK，无需 Langfuse 特定代码

### 12.8.3 Langfuse 特定属性

core-ai 通过 Langfuse 特定属性增强追踪：

```java
// LLM 调用标记为 "generation"
span.setAttribute(LANGFUSE_OBSERVATION_TYPE, "generation");

// Agent/Flow 标记为 "span"
span.setAttribute(LANGFUSE_OBSERVATION_TYPE, "span");
```

💡 **设计意图**：
- **generation**：Langfuse 识别为 LLM 调用，显示 token 使用量和成本
- **span**：Langfuse 识别为普通 Span，显示执行时间

## 12.9 实战示例

### 12.9.1 启用追踪

```java
// 1. 配置 OpenTelemetry
var openTelemetry = OpenTelemetrySdk.builder()
    .setTracerProvider(
        SdkTracerProvider.builder()
            .addSpanProcessor(
                BatchSpanProcessor.builder(
                    OtlpGrpcSpanExporter.builder()
                        .setEndpoint("http://localhost:4317")
                        .build()
                ).build()
            )
            .build()
    )
    .build();

// 2. 创建 Tracer
var llmTracer = new LLMTracer(openTelemetry, true);
var agentTracer = new AgentTracer(openTelemetry, true);

// 3. 注入到 LLMProvider
llmProvider.setTracer(llmTracer);

// 4. 创建 Agent
var agent = Agent.builder()
    .name("assistant")
    .systemPrompt("你是一个助手")
    .llmProvider(llmProvider)
    .tracer(agentTracer)
    .build();

// 5. 执行（自动追踪）
var result = agent.execute("你好", null);
```

### 12.9.2 禁用追踪

```java
// 禁用追踪（不影响性能）
var llmTracer = new LLMTracer(openTelemetry, false);
llmProvider.setTracer(llmTracer);

// 执行（不会创建 Span）
var result = agent.execute("你好", null);
```

### 12.9.3 自定义属性

```java
// 在 Agent 执行前添加自定义属性
var span = agentTracer.getCurrentSpan();
span.setAttribute("custom.user_tier", "premium");
span.setAttribute("custom.feature_flag", "enabled");
```
