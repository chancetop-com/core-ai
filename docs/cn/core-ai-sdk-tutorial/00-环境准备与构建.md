## 0.1 硬件要求

### 最低配置
- **CPU**：4 核（推荐 8 核+）
- **内存**：8 GB（推荐 16 GB+）
- **磁盘**：10 GB 可用空间（推荐 20 GB+，含 Gradle 缓存）

### 推荐配置
- **CPU**：8 核+
- **内存**：32 GB+（运行多个 agent + 向量库时内存消耗较大）
- **磁盘**：50 GB+（SSD，Gradle 缓存 + Docker 镜像）

💡 **设计意图**：core-ai 内核本身轻量，但运行 agent 时可能调用多个 LLM、向量库、沙箱，内存消耗较大。构建时 Gradle 并行编译也需要内存。

| 软件 | 说明 |

### 0.2.1 安装 JDK 25

⚠️ **重要**：core-ai 构建锁定的是 **Java 25**，不是 21。

#### macOS（推荐用 SDKMAN）

```bash
# 安装 SDKMAN
curl -s "https://get.sdkman.io" | bash
source ~/.sdkman/bin/sdkman-init.sh

# 安装 Java 25（Oracle 或 OpenJDK）
sdk install java 25-oracle
# 或
sdk install java 25-open

# 设置为默认
sdk default java 25-oracle

# 验证
java -version
# 输出应为：java version "25" ...
```

#### Linux（Ubuntu/Debian）

```bash
# 用 SDKMAN 安装（同上）
# 或用 apt（如果有 Java 25 包）
sudo apt update
sudo apt install openjdk-25-jdk

# 验证
java -version
```

#### Windows

```powershell
# 用 SDKMAN for Windows
# 或手动下载 Oracle JDK 25
# https://www.oracle.com/java/technologies/downloads/

# 设置 JAVA_HOME
[System.Environment]::SetEnvironmentVariable('JAVA_HOME', 'C:\Program Files\Java\jdk-25', 'User')

# 验证
java -version
```

💡 **设计意图**：项目用 Java 25 的虚拟线程（Virtual Threads）和模式匹配（Pattern Matching）等新特性，必须用 25。

### 0.2.2 验证 Java 版本

```bash
java -version
# 期望输出：java version "25" ...

javac -version
# 期望输出：javac 25
```

如果版本不对，检查 `JAVA_HOME` 环境变量：

```bash
echo $JAVA_HOME
# 应指向 JDK 25 安装目录
```

## 0.3 克隆仓库

```bash
# 克隆仓库
git clone https://github.com/chancetop-com/core-ai.git
cd core-ai

# 查看目录结构
ls -la
```

### 目录结构概览

```
core-ai/
├── core-ai/                    ← 内核模块（本教程重点）
│   ├── src/main/java/          ← 内核源码
│   ├── src/test/java/          ← 内核测试
│   └── build.gradle.kts        ← 模块构建配置
├── core-ai-api/                ← 契约模块（DTO + 接口）
├── core-ai-server/             ← 运行时宿主 + HTTP 服务
├── core-ai-cli/                ← 交互式 REPL
├── core-ai-frontend/           ← 浏览器管理台（npm）
├── core-ai-sandbox-runtime/    ← Go 沙箱 sidecar
├── core-ai-benchmark/          ← BFCL 基准测试
├── buildSrc/                   ← Gradle 约定插件
├── docs/                       ← 文档（本教程在这里）
├── build.gradle.kts            ← 根构建配置
├── settings.gradle.kts         ← 模块注册
├── gradlew                     ← Gradle wrapper（Unix）
└── gradlew.bat                 ← Gradle wrapper（Windows）
```

💡 **设计意图**：`settings.gradle.kts` 只注册了 5 个 Gradle 模块（core-ai、core-ai-api、core-ai-server、core-ai-cli、core-ai-benchmark）。前端和沙箱不归 Gradle 管。

## 0.4 构建项目

### 0.4.1 全量构建

```bash
# 构建整个项目（包括 5 个 Gradle 模块 + 前端 npm）
./gradlew build
```

**构建过程**：
1. 下载 Gradle wrapper（首次运行）
2. 解析 `settings.gradle.kts`，注册 5 个模块
3. 按依赖顺序编译（core-ai-api → core-ai → core-ai-server/cli/benchmark）
4. 运行 `npm install` + `npm run build`（前端）
5. 拷贝前端产物到 server 安装目录
6. 运行所有单元测试
7. 生成 JAR 文件

**预计时间**：5-10 分钟（首次构建，含依赖下载）

💡 **设计意图**：根 `build.gradle.kts` 通过 npm 任务把前端串进构建链，但本教程不需要前端，可以跳过。

### 0.4.2 只构建内核模块

```bash
# 只构建 core-ai 模块（最快）
./gradlew :core-ai:build

# 或构建 core-ai + core-ai-api（依赖关系）
./gradlew :core-ai:build :core-ai-api:build
```

💡 **设计意图**：`core-ai` 依赖 `core-ai-api`，所以构建 `core-ai` 时会自动构建 `core-ai-api`。

### 0.4.3 构建产物

构建成功后，产物在：

```
core-ai/build/libs/
├── core-ai-*.jar              ← 内核 JAR
└── core-ai-*-sources.jar      ← 源码 JAR

core-ai-api/build/libs/
└── core-ai-api-*.jar          ← 契约 JAR
```

### 0.4.4 清理构建

```bash
# 清理所有构建产物
./gradlew clean

# 清理特定模块
./gradlew :core-ai:clean
```

## 0.6 IDE 配置

### 0.6.1 IntelliJ IDEA（推荐）

#### 打开项目

1. **File → Open** → 选择 `core-ai/` 目录
2. IntelliJ 自动识别 Gradle 项目，开始导入
3. 等待 Gradle sync 完成（右下角进度条）

#### 配置 JDK

1. **File → Project Structure → Project**
2. **SDK** → 选择 **JDK 25**
3. **Language level** → 选择 **25**
4. 点击 **Apply** → **OK**

#### 配置 Gradle

1. **File → Settings → Build, Execution, Deployment → Build Tools → Gradle**
2. **Gradle JVM** → 选择 **JDK 25**
3. 勾选 **Delegate IDE build/run actions to Gradle**（可选）
4. 点击 **Apply** → **OK**

#### 安装插件（可选）

- **Lombok**：如果项目用 Lombok（core-ai 没用）
- **SonarLint**：代码质量检查
- **GitToolBox**：增强 Git 功能

💡 **设计意图**：IntelliJ 对 Gradle + Java 25 支持最好，推荐用 Community 版（免费）或 Ultimate 版。

### 0.6.2 VS Code（备选）

#### 安装扩展

- **Extension Pack for Java**
- **Gradle for Java**
- **Language Support for Java(TM) by Red Hat**

#### 打开项目

```bash
code core-ai/
```

VS Code 自动识别 Gradle 项目，开始导入。

💡 **设计意图**：VS Code 对 Java 支持不如 IntelliJ，但轻量。建议用 IntelliJ。

### 0.6.3 Eclipse（不推荐）

Eclipse 对 Java 25 + Gradle 支持较差，不建议用。

## 0.7 常见构建问题

### 问题 1：Java 版本不对

**症状**：

```
Execution failed for task ':core-ai:compileJava'.
> No matching toolchain found for Java 25
```

**原因**：`JAVA_HOME` 指向的不是 Java 25。

**解决**：

```bash
# 检查当前 Java 版本
java -version

# 如果不是 25，切换到 25
sdk use java 25-oracle  # SDKMAN
# 或
export JAVA_HOME=/path/to/jdk-25  # 手动设置
```

### 问题 2：Gradle 下载慢

**症状**：

```
Downloading Gradle distribution...
（卡住不动）
```

**原因**：Gradle 从国外服务器下载，国内网络慢。

**解决**：用国内镜像。

编辑 `gradle/wrapper/gradle-wrapper.properties`：

```properties
# 把 distributionUrl 改成腾讯云镜像
distributionUrl=https\://mirrors.cloud.tencent.com/gradle/gradle-8.x-bin.zip
```

### 问题 3：依赖下载慢

**症状**：

```
Resolving dependencies...
（卡住不动）
```

**原因**：Maven Central 从国外下载。

**解决**：在 `build.gradle.kts` 加阿里云镜像。

```kotlin
repositories {
    maven { url = uri("https://maven.aliyun.com/repository/public") }
    mavenCentral()
}
```

💡 **设计意图**：项目已经配了镜像，如果还是慢，检查网络或 VPN。

### 问题 4：内存不足

**症状**：

```
java.lang.OutOfMemoryError: Java heap space
```

**原因**：Gradle 并行编译 + 多模块构建，内存消耗大。

**解决**：增加 Gradle 内存。

编辑 `gradle.properties`：

```properties
org.gradle.jvmargs=-Xmx4g -XX:MaxMetaspaceSize=1g
```

### 问题 5：前端构建失败

**症状**：

```
Execution failed for task ':core-ai-server:npmInstallServer'.
> npm install failed
```

**原因**：Node.js 未安装或版本不对。

**解决**：

```bash
# 检查 Node.js 版本
node -version

# 如果不是 20+，安装 Node.js 20
# macOS
brew install node@20

# 或跳过前端构建
./gradlew :core-ai:build  # 只构建内核，不构建前端
```

💡 **设计意图**：本教程不需要前端，可以跳过前端构建。

### 问题 6：Docker 未安装（仅影响沙箱）

**症状**：

```
Execution failed for task ':core-ai-sandbox-runtime:build'.
> Docker not found
```

**原因**：沙箱需要 Docker。

**解决**：

```bash
# 安装 Docker Desktop
# https://www.docker.com/products/docker-desktop/

# 或跳过沙箱构建（本教程不需要）
./gradlew :core-ai:build
```

💡 **设计意图**：沙箱是 Go 写的 sidecar，本教程不需要。
