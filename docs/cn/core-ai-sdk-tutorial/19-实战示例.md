## 19.2 示例 1：基础 Agent

### 19.2.1 目标

构建一个简单的 Agent，能够：
- 与用户对话
- 执行 bash 命令
- 读写文件

### 19.2.2 完整代码

```java
package ai.core.tutorial;

import ai.core.agent.Agent;
import ai.core.llm.LLMProvider;
import ai.core.llm.providers.LiteLLMProvider;
import ai.core.tool.tools.BashTool;
import ai.core.tool.tools.ReadFileTool;
import ai.core.tool.tools.WriteFileTool;

public class BasicAgentExample {
    public static void main(String[] args) {
        // 1. 配置 LLM Provider
        var config = new LLMProviderConfig();
        config.setModel("gpt-4");
        config.setBaseUrl("https://api.openai.com/v1");
        config.setApiKey(System.getenv("OPENAI_API_KEY"));
        
        LLMProvider llmProvider = new LiteLLMProvider(config);
        
        // 2. 构建 Agent
        var agent = Agent.builder()
            .name("basic-assistant")
            .systemPrompt("""
                你是一个编程助手，可以帮助用户：
                1. 回答编程问题
                2. 执行 bash 命令
                3. 读写文件
                
                请始终使用中文回答。
                """)
            .llmProvider(llmProvider)
            .tool(new BashTool())
            .tool(new ReadFileTool())
            .tool(new WriteFileTool())
            .maxRound(10)  // 最多 10 轮对话
            .build();
        
        // 3. 执行对话
        var result = agent.execute("请帮我列出当前目录的文件", null);
        System.out.println("Agent 输出：");
        System.out.println(result);
        
        // 4. 继续对话
        result = agent.execute("请创建一个 test.txt 文件，内容为 'Hello, World!'", null);
        System.out.println("\nAgent 输出：");
        System.out.println(result);
        
        // 5. 读取文件
        result = agent.execute("请读取 test.txt 的内容", null);
        System.out.println("\nAgent 输出：");
        System.out.println(result);
    }
}
```

## 19.3 示例 2：RAG Agent

### 19.3.1 目标

构建一个 RAG Agent，能够：
- 从知识库检索相关信息
- 基于检索结果回答问题

### 19.3.2 完整代码

```java
package ai.core.tutorial;

import ai.core.agent.Agent;
import ai.core.document.Document;
import ai.core.llm.LLMProvider;
import ai.core.llm.providers.LiteLLMProvider;
import ai.core.rag.RagConfig;
import ai.core.vectorstore.VectorStore;
import ai.core.vectorstore.vectorstores.HnswLibVectorStore;

import java.util.List;

public class RagAgentExample {
    public static void main(String[] args) {
        // 1. 配置 LLM Provider
        var config = new LLMProviderConfig();
        config.setModel("gpt-4");
        config.setBaseUrl("https://api.openai.com/v1");
        config.setApiKey(System.getenv("OPENAI_API_KEY"));
        
        LLMProvider llmProvider = new LiteLLMProvider(config);
        
        // 2. 创建向量库
        VectorStore vectorStore = new HnswLibVectorStore();
        
        // 3. 添加文档到知识库
        var documents = List.of(
            new Document("Java 21 引入了虚拟线程（Virtual Threads），可以大幅提高并发性能。"),
            new Document("core-ai 是一个基于 Java 21 的 AI Agent 框架。"),
            new Document("core-ai 支持多种 LLM 提供商，包括 OpenAI、Azure、DeepSeek。"),
            new Document("core-ai 提供了丰富的工具系统，包括 bash、文件操作、MCP 集成。"),
            new Document("core-ai 支持 Flow 编排，可以构建复杂的工作流。")
        );
        
        // 生成嵌入并存储
        for (var doc : documents) {
            var embedding = llmProvider.embedding(doc.content);
            doc.setEmbedding(embedding);
            vectorStore.add(doc);
        }
        
        // 4. 配置 RAG
        var ragConfig = RagConfig.builder()
            .vectorStore(vectorStore)
            .llmProvider(llmProvider)
            .topK(3)  // 检索 top 3 相关文档
            .threshold(0.7)  // 相似度阈值
            .build();
        
        // 5. 构建 RAG Agent
        var agent = Agent.builder()
            .name("rag-assistant")
            .systemPrompt("""
                你是一个技术助手，基于知识库回答用户问题。
                
                {{rag_context}}
                
                请基于上述上下文回答问题。如果上下文中没有相关信息，请明确说明。
                """)
            .llmProvider(llmProvider)
            .ragConfig(ragConfig)
            .build();
        
        // 6. 执行对话
        var result = agent.execute("core-ai 是什么？", null);
        System.out.println("Agent 输出：");
        System.out.println(result);
        
        // 7. 另一个问题
        result = agent.execute("Java 21 有什么新特性？", null);
        System.out.println("\nAgent 输出：");
        System.out.println(result);
    }
}
```

### 19.3.3 运行说明

```bash

# 2. 编译和运行

## 19.4 示例 3：Flow 工作流

### 19.4.1 目标

构建一个 Flow 工作流，能够：
- 分类用户问题（技术问题 vs 一般问题）
- 根据分类路由到不同的 Agent
- 执行多步骤任务

### 19.4.2 完整代码

```java
package ai.core.tutorial;

import ai.core.agent.Agent;
import ai.core.flow.Flow;
import ai.core.flow.nodes.AgentFlowNode;
import ai.core.flow.edges.DirectEdge;
import ai.core.flow.edges.ConditionalEdge;
import ai.core.llm.LLMProvider;
import ai.core.llm.providers.LiteLLMProvider;

import java.util.List;

public class FlowExample {
    public static void main(String[] args) {
        // 1. 配置 LLM Provider
        var config = new LLMProviderConfig();
        config.setModel("gpt-4");
        config.setBaseUrl("https://api.openai.com/v1");
        config.setApiKey(System.getenv("OPENAI_API_KEY"));
        
        LLMProvider llmProvider = new LiteLLMProvider(config);
        
        // 2. 创建分类 Agent
        var classifyAgent = Agent.builder()
            .name("classifier")
            .systemPrompt("""
                你是一个问题分类器。
                判断用户的问题是"技术问题"还是"一般问题"。
                只返回"技术问题"或"一般问题"，不要返回其他内容。
                """)
            .llmProvider(llmProvider)
            .build();
        
        // 3. 创建技术 Agent
        var techAgent = Agent.builder()
            .name("tech-assistant")
            .systemPrompt("""
                你是一个技术专家，专门回答编程和技术问题。
                请提供详细、准确的技术解答。
                """)
            .llmProvider(llmProvider)
            .build();
        
        // 4. 创建通用 Agent
        var generalAgent = Agent.builder()
            .name("general-assistant")
            .systemPrompt("""
                你是一个通用助手，回答一般性问题。
                请提供友好、有帮助的回答。
                """)
            .llmProvider(llmProvider)
            .build();
        
        // 5. 创建 Flow 节点
        var classifyNode = new AgentFlowNode(classifyAgent);
        var techNode = new AgentFlowNode(techAgent);
        var generalNode = new AgentFlowNode(generalAgent);
        
        // 6. 创建 Flow 边
        var techEdge = new ConditionalEdge(
            "classify", 
            "tech", 
            output -> output.contains("技术问题")
        );
        var generalEdge = new ConditionalEdge(
            "classify", 
            "general", 
            output -> output.contains("一般问题")
        );
        var fallbackEdge = new DirectEdge("classify", "general");
        
        // 7. 构建 Flow
        var flow = Flow.builder()
            .name("question-router")
            .nodes(List.of(classifyNode, techNode, generalNode))
            .edges(List.of(techEdge, generalEdge, fallbackEdge))
            .build();
        
        // 8. 执行 Flow
        System.out.println("问题：如何写一个 Java 程序？");
        var result = flow.run("classify", "如何写一个 Java 程序？", null);
        System.out.println("回答：" + result);
        
        System.out.println("\n问题：今天天气怎么样？");
        result = flow.run("classify", "今天天气怎么样？", null);
        System.out.println("回答：" + result);
    }
}
```

### 19.4.3 运行说明

```bash
# 1. 设置环境变量
export OPENAI_API_KEY=your-api-key

# 2. 编译和运行
javac -cp "core-ai/build/libs/*" FlowExample.java
java -cp ".:core-ai/build/libs/*" ai.core.tutorial.FlowExample
```

## 19.5 示例 4：MCP 集成

### 19.5.1 目标

构建一个集成 MCP Server 的 Agent，能够：
- 连接外部 MCP Server
- 使用 MCP Server 提供的工具
- 动态发现 MCP 工具

### 19.5.2 完整代码

```java
package ai.core.tutorial;

import ai.core.agent.Agent;
import ai.core.llm.LLMProvider;
import ai.core.llm.providers.LiteLLMProvider;
import ai.core.mcp.client.McpClientManager;
import ai.core.mcp.client.McpServerConfig;
import ai.core.tool.mcp.McpToolProvider;

import java.util.List;
import java.util.Map;

public class McpIntegrationExample {
    public static void main(String[] args) {
        // 1. 配置 LLM Provider
        var config = new LLMProviderConfig();
        config.setModel("gpt-4");
        config.setBaseUrl("https://api.openai.com/v1");
        config.setApiKey(System.getenv("OPENAI_API_KEY"));
        
        LLMProvider llmProvider = new LiteLLMProvider(config);
        
        // 2. 配置 MCP Server
        var filesystemConfig = McpServerConfig.builder()
            .name("filesystem")
            .command("npx")
            .args(List.of("-y", "@modelcontextprotocol/server-filesystem", "/tmp"))
            .build();
        
        var githubConfig = McpServerConfig.builder()
            .name("github")
            .command("npx")
            .args(List.of("-y", "@modelcontextprotocol/server-github"))
            .env(Map.of("GITHUB_TOKEN", System.getenv("GITHUB_TOKEN")))
            .build();
        
        // 3. 创建 MCP Client Manager
        var mcpManager = McpClientManager.of(filesystemConfig, githubConfig);
        
        // 4. 创建 MCP Tool Provider
        var mcpToolProvider = new McpToolProvider(mcpManager);
        
        // 5. 构建 Agent
        var agent = Agent.builder()
            .name("mcp-assistant")
            .systemPrompt("""
                你是一个助手，可以使用文件系统工具和 GitHub 工具。
                
                文件系统工具：
                - 读取、写入、列出文件
                - 搜索文件内容
                
                GitHub 工具：
                - 列出仓库
                - 创建 PR
                - 查看 issues
                
                请根据用户需求选择合适的工具。
                """)
            .llmProvider(llmProvider)
            .toolProvider(mcpToolProvider)
            .build();
        
        // 6. 执行对话
        System.out.println("列出 /tmp 目录的文件：");
        var result = agent.execute("请列出 /tmp 目录的文件", null);
        System.out.println(result);
        
        System.out.println("\n创建文件：");
        result = agent.execute("请在 /tmp 创建一个 test.txt 文件，内容为 'Hello from MCP!'", null);
        System.out.println(result);
        
        System.out.println("\n读取文件：");
        result = agent.execute("请读取 /tmp/test.txt 的内容", null);
        System.out.println(result);
        
        // 7. 关闭 MCP Manager
        mcpManager.close();
    }
}
```

## 19.6 示例 5：多 Agent 协作

### 19.6.1 目标

构建一个多 Agent 协作系统，能够：
- 本地 Agent 调用远程 Agent
- 远程 Agent 执行复杂任务
- 通过 A2A 协议协作

### 19.6.2 完整代码

**远程 Agent 服务（core-ai-server）**

```java
package ai.core.tutorial;

import ai.core.agent.Agent;
import ai.core.a2a.A2ARunManager;
import ai.core.llm.LLMProvider;
import ai.core.llm.providers.LiteLLMProvider;
import core.framework.module.Module;

public class RemoteAgentModule extends Module {
    @Override
    protected void initialize() {
        // 1. 配置 LLM Provider
        var config = new LLMProviderConfig();
        config.setModel("gpt-4");
        config.setBaseUrl("https://api.openai.com/v1");
        config.setApiKey(System.getenv("OPENAI_API_KEY"));
        
        LLMProvider llmProvider = new LiteLLMProvider(config);
        
        // 2. 创建 Agent 工厂
        var agentFactory = () -> Agent.builder()
            .name("remote-assistant")
            .systemPrompt("""
                你是一个远程编程助手，专门帮助分析代码。
                请提供详细的代码分析和改进建议。
                """)
            .llmProvider(llmProvider)
            .build();
        
        // 3. 创建 A2A Run Manager
        var runManager = new A2ARunManager(agentFactory);
        
        // 4. 注册 HTTP 端点
        http().route("GET", "/.well-known/agent.json", (req, resp) -> {
            resp.json(runManager.getAgentCard());
        });
        
        http().route("POST", "/message/send", (req, resp) -> {
            var request = req.json(SendMessageRequest.class);
            var result = runManager.send(request);
            resp.json(result);
        });
        
        http().route("POST", "/message/stream", (req, resp) -> {
            var request = req.json(SendMessageRequest.class);
            var publisher = runManager.stream(request);
            resp.sse(publisher);
        });
    }
}
```

**本地 Agent 客户端**

```java
package ai.core.tutorial;

import ai.core.agent.Agent;
import ai.core.a2a.HttpA2AClient;
import ai.core.a2a.A2ARemoteAgentDescriptor;
import ai.core.llm.LLMProvider;
import ai.core.llm.providers.LiteLLMProvider;
import ai.core.tool.tools.RemoteAgentTool;

public class MultiAgentExample {
    public static void main(String[] args) throws Exception {
        // 1. 配置 LLM Provider
        var config = new LLMProviderConfig();
        config.setModel("gpt-4");
        config.setBaseUrl("https://api.openai.com/v1");
        config.setApiKey(System.getenv("OPENAI_API_KEY"));
        
        LLMProvider llmProvider = new LiteLLMProvider(config);
        
        // 2. 创建远程 Agent 客户端
        var remoteClient = HttpA2AClient.builder()
            .baseUrl("http://localhost:8080")
            .bearerToken(System.getenv("API_KEY"))
            .build();
        
        // 3. 获取远程 Agent 能力
        var agentCard = remoteClient.getAgentCard();
        System.out.println("远程 Agent: " + agentCard.name);
        System.out.println("技能:");
        for (var skill : agentCard.skills) {
            System.out.println("  - " + skill.id + ": " + skill.description);
        }
        
        // 4. 创建远程 Agent 工具
        var remoteTool = new RemoteAgentTool(
            A2ARemoteAgentDescriptor.builder()
                .id("remote-assistant")
                .toolName("code_analyzer")
                .toolDescription("分析代码并提供改进建议")
                .client(remoteClient)
                .build()
        );
        
        // 5. 构建本地 Agent
        var localAgent = Agent.builder()
            .name("local-coordinator")
            .systemPrompt("""
                你是一个协调者 Agent。
                当用户需要代码分析时，请调用 code_analyzer 工具。
                其他问题你可以直接回答。
                """)
            .llmProvider(llmProvider)
            .tool(remoteTool)
            .build();
        
        // 6. 执行对话
        System.out.println("\n用户：请帮我分析这段代码");
        var result = localAgent.execute("""
            public class Test {
                public void method() {
                    System.out.println("Hello");
                }
            }
            """, null);
        System.out.println("本地 Agent 输出：");
        System.out.println(result);
        
        // 7. 关闭客户端
        remoteClient.close();
    }
}
```

### 19.6.3 运行说明

```bash

# 在 core-ai-server 中加载 RemoteAgentModule

# 2. 运行本地 Agent 客户端

## 19.7 综合应用

### 19.7.1 组合使用多个功能

实际应用中，通常需要组合使用多个功能：

```java
// 综合示例：RAG + Flow + MCP + A2A

var agent = Agent.builder()
    .name("comprehensive-assistant")
    .systemPrompt("你是一个综合助手")
    .llmProvider(llmProvider)
    .ragConfig(ragConfig)                    // RAG 增强
    .tool(new BashTool())                    // 本地工具
    .toolProvider(mcpToolProvider)           // MCP 工具
    .tool(remoteAgentTool)                   // 远程 Agent
    .lifecycle(new CompressionLifecycle())   // 压缩
    .lifecycle(new DoomLoopLifecycle())      // 死循环检测
    .maxRound(20)                            // 最多 20 轮
    .build();

var flow = Flow.builder()
    .nodes(List.of(
        new AgentFlowNode(agent),
        new AgentFlowNode(testAgent)
    ))
    .edges(List.of(new DirectEdge("agent", "test")))
    .build();

var result = flow.run("agent", "请帮我完成一个复杂的任务", null);
```

💡 **设计建议**：
- 按需组合功能，不要过度设计
- 每个功能都有明确的职责
- 通过配置控制功能的启用/禁用
