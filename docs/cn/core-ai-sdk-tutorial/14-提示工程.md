## 14.1 提示工程系统总览

### 14.1.1 提示工程的角色

提示工程系统是 core-ai 的**LLM 输入管理基础设施**，负责：

- **模板渲染**：把变量注入到提示词模板中
- **模块化组装**：把 system prompt 拆成多个独立片段（身份、环境、指令、记忆等）
- **系统变量**：提供内置变量（如 `{{system.session.id}}`）
- **版本管理**：通过 Langfuse 管理提示词版本

💡 **设计意图**：AI Agent 的提示词复杂且动态（包含身份、环境、记忆、工具说明等），需要模块化、可组合、可版本化的管理机制。

### 14.1.2 核心类关系图

```
┌─────────────────────────────────────────────────────────────┐
│                  PromptTemplate (interface)                 │
│                                                             │
│  + execute(template, scopes, name): String                  │
└──────────────────────┬──────────────────────────────────────┘
                       │ 实现
                       ▼
┌─────────────────────────────────────────────────────────────┐
│              MustachePromptTemplate                         │
│                                                             │
│  - 使用 Mustache.java 引擎                                  │
│  - 支持 {{变量}}、{{#条件}}、{{^反向条件}}、{{#each}}       │
│  - 自动解码 HTML 实体                                        │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                  PromptInject (@FunctionalInterface)        │
│                                                             │
│  + inject(): String                             ← 注入片段 │
│  + type(): SectionType                          ← 片段类型 │
│                                                             │
│  SectionType: IDENTITY / ENVIRONMENT / INSTRUCTIONS /       │
│               MEMORY / HOOK / CUSTOM                        │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│                  SystemVariables                            │
│                                                             │
│  内置变量：                                                  │
│  - system.session.id                                        │
│  - system.user.id                                           │
│  - system.agent.name                                        │
│  - system.datetime                                          │
│  - system.agent.dataset.desc                                │
│  - ...                                                      │
└─────────────────────────────────────────────────────────────┘
```

### 14.1.3 提示词组装流程

```
Agent 构建
  │
  ├─ 1. 收集 systemPromptSections（PromptInject 列表）
  │
  ├─ 2. 按 SectionType 排序
  │      └─ IDENTITY → ENVIRONMENT → INSTRUCTIONS → MEMORY → HOOK → CUSTOM
  │
  ├─ 3. 拼接所有片段
  │      └─ identity + environment + instructions + memory + hooks + custom
  │
  ├─ 4. 注入 SystemVariables
  │      └─ {{system.session.id}} → "session-123"
  │
  └─ 5. 渲染 Mustache 模板
         └─ {{user_name}} → "张三"
```

## 14.2 PromptTemplate 模板接口

### 14.2.1 文件位置

```
core-ai/src/main/java/ai/core/prompt/PromptTemplate.java
```

### 14.2.2 接口定义

```java
public interface PromptTemplate {
    /**
     * 渲染模板
     * @param template 模板字符串（如 "Hello, {{name}}!"）
     * @param scopes 变量映射（如 {name: "张三"}）
     * @param name 模板名称（用于缓存和调试）
     * @return 渲染后的字符串
     */
    String execute(String template, Map<String, Object> scopes, String name);
}
```

💡 **设计意图**：
- **简单接口**：只有一个方法，易于实现和测试
- **scopes 参数**：变量映射，支持嵌套对象
- **name 参数**：模板名称，用于缓存 key 和调试日志

### 14.2.3 使用方式

```java
// 1. 创建模板引擎
var engine = new MustachePromptTemplate();

// 2. 定义模板和变量
var template = "Hello, {{name}}! You are {{age}} years old.";
var scopes = Map.of(
    "name", "张三",
    "age", 28
);

// 3. 渲染
var result = engine.execute(template, scopes, "greeting");
// 结果: "Hello, 张三! You are 28 years old."
```

## 14.3 Mustache 模板引擎

### 14.3.1 文件位置

```
core-ai/src/main/java/ai/core/prompt/engines/MustachePromptTemplate.java
```

### 14.3.2 核心实现

```java
public class MustachePromptTemplate implements PromptTemplate {
    
    public static String compile(String template, Map<String, Object> scopes) {
        return new MustachePromptTemplate().execute(template, scopes, UUID.randomUUID().toString());
    }

    @Override
    public String execute(String template, Map<String, Object> scopes, String name) {
        if (scopes == null) return template;
        
        var output = new ByteArrayOutputStream();
        var writer = new OutputStreamWriter(output, StandardCharsets.UTF_8);
        
        // 使用 Mustache.java 编译模板
        var m = new DefaultMustacheFactory().compile(new StringReader(template), name);
        m.execute(writer, scopes);
        
        try {
            writer.flush();
        } catch (IOException e) {
            throw new RuntimeException(e);
        }
        
        // 解码 HTML 实体（Mustache 默认会转义）
        return decodeHtmlEntities(output.toString(StandardCharsets.UTF_8));
    }

    private String decodeHtmlEntities(String text) {
        return text.replace("&#96;", "`")
                   .replace("&#10;", "\n")
                   .replace("&amp;", "&")
                   .replace("&lt;", "<")
                   .replace("&gt;", ">")
                   .replace("&quot;", "\"")
                   .replace("&#39;", "'");
    }
}
```

💡 **设计意图**：
- **Mustache.java**：使用 Mustache 逻辑less模板引擎，语法简单、安全
- **HTML 实体解码**：Mustache 默认转义特殊字符，但提示词中需要原样输出（如代码块中的 `<`、`>`），所以反转义
- **静态 compile 方法**：方便快速渲染，不需要创建实例

### 14.3.3 Mustache 语法速查

```
{{变量}}              → 变量替换（HTML 转义）
{{{变量}}}            → 变量替换（不转义）
{{#section}}...{{/}}  → 条件/循环（变量为 true 或数组时执行）
{{^section}}...{{/}}  → 反向条件（变量为 false 或空时执行）
{{#each array}}...{{/each}} → 循环遍历数组
```

### 14.3.4 语法示例

**变量替换**：

```java
var template = "Hello, {{name}}!";
var scopes = Map.of("name", "张三");
// 结果: "Hello, 张三!"
```

**条件渲染**：

```java
var template = "{{#has_tool}}You have tools.{{/has_tool}}{{^has_tool}}No tools.{{/has_tool}}";

var scopes1 = Map.of("has_tool", true);
// 结果: "You have tools."

var scopes2 = Map.of("has_tool", false);
// 结果: "No tools."
```

**循环遍历**：

```java
var template = "Tools: {{#tools}}{{name}}, {{/tools}}";
var scopes = Map.of("tools", List.of(
    Map.of("name", "bash"),
    Map.of("name", "read_file")
));
// 结果: "Tools: bash, read_file, "
```

**嵌套对象**：

```java
var template = "Session: {{system.session.id}}";
var scopes = Map.of("system", Map.of("session", Map.of("id", "session-123")));
// 结果: "Session: session-123"
```

💡 **设计意图**：
- **逻辑less**：Mustache 不支持 if/else 语句，只有条件段和循环，避免在模板中写复杂逻辑
- **嵌套支持**：支持 `a.b.c` 形式的嵌套访问
- **HTML 转义**：默认转义，但可以通过 `{{{ }}}` 不转义

## 14.4 PromptInject 注入机制

### 14.4.1 文件位置

```
core-ai/src/main/java/ai/core/prompt/PromptInject.java
```

### 14.4.2 接口定义

```java
@FunctionalInterface
public interface PromptInject {
    /**
     * 注入提示词片段
     */
    String inject();

    /**
     * 片段类型（用于排序）
     */
    default SectionType type() {
        return SectionType.CUSTOM;
    }

    enum SectionType {
        IDENTITY,        // 身份定义（如 "你是一个助手"）
        ENVIRONMENT,     // 环境信息（如当前时间、用户信息）
        INSTRUCTIONS,    // 行为指令（如 "请使用中文回答"）
        MEMORY,          // 记忆内容（如用户偏好）
        HOOK,            // 钩子（如工具说明）
        CUSTOM           // 自定义
    }
}
```

💡 **设计意图**：
- **@FunctionalInterface**：可以用 Lambda 表达式简化
- **SectionType 排序**：按类型排序，确保 system prompt 结构一致
- **模块化**：每个 PromptInject 负责一个独立片段，便于复用和测试

### 14.4.3 组装顺序

```
IDENTITY       → "你是一个编程助手"
ENVIRONMENT    → "当前时间：2024-01-01，用户：张三"
INSTRUCTIONS   → "请使用中文回答，代码使用 Java 21"
MEMORY         → "用户喜欢简洁的代码风格"
HOOK           → "可用工具：bash, read_file, write_file"
CUSTOM         → 其他自定义内容
```

### 14.4.4 使用方式

```java
// 方式 1：Lambda 表达式
var identity = (PromptInject) () -> "你是一个编程助手";

// 方式 2：匿名类
var env = new PromptInject() {
    @Override
    public String inject() {
        return "当前时间：" + LocalDateTime.now();
    }
    
    @Override
    public SectionType type() {
        return SectionType.ENVIRONMENT;
    }
};

// 方式 3：注册到 AgentBuilder
var agent = Agent.builder()
    .name("assistant")
    .systemPromptSection(() -> "你是一个编程助手")      // IDENTITY
    .systemPromptSection(() -> "用户：" + userName, SectionType.ENVIRONMENT)
    .systemPromptSection(() -> "请使用中文回答", SectionType.INSTRUCTIONS)
    .build();
```

💡 **设计意图**：
- **灵活注册**：可以用 Lambda 或匿名类
- **类型指定**：可以指定片段类型，控制排序
- **组合使用**：多个 PromptInject 按类型排序后拼接

### 14.5.2 内置变量

| 变量 | 说明 | 示例值 |
|---|---|---|
| `system.session.id` | 会话 ID | `"session-123"` |
| `system.user.id` | 用户 ID | `"user-456"` |
| `system.agent.name` | Agent 名称 | `"assistant"` |
| `system.datetime` | 当前时间 | `"2024-01-01T12:00:00"` |
| `system.agent.dataset.desc` | 数据集描述 | `"用户偏好数据集"` |

💡 **设计意图**：
- **标准化**：提供统一的系统变量命名规范
- **动态注入**：在运行时自动注入，无需手动设置
- **可扩展**：用户可以添加自定义系统变量

### 14.5.3 使用方式

```java
// 在 system prompt 中使用系统变量
var systemPrompt = """
    你是 {{system.agent.name}}。
    当前会话 ID：{{system.session.id}}
    当前用户：{{system.user.id}}
    当前时间：{{system.datetime}}
    """;

// Agent 执行时自动注入系统变量
var agent = Agent.builder()
    .name("assistant")
    .systemPrompt(systemPrompt)
    .build();

// 执行时 system prompt 会被渲染为：
// "你是 assistant。
//  当前会话 ID：session-123
//  当前用户：user-456
//  当前时间：2024-01-01T12:00:00"
```

### 14.5.4 自定义系统变量

```java
// 添加自定义系统变量
var agent = Agent.builder()
    .name("assistant")
    .systemVariable("company_name", "Chancetop")
    .systemVariable("department", "AI Lab")
    .build();

// 在 system prompt 中使用
var systemPrompt = "你为 {{company_name}} 的 {{department}} 工作。";
// 渲染后: "你为 Chancetop 的 AI Lab 工作。"
```

## 14.7 Langfuse 提示词管理

### 14.7.1 Langfuse 简介

Langfuse 是开源的 LLM 工程平台，提供提示词版本管理、A/B 测试、性能分析等功能。

💡 **设计意图**：生产环境中，提示词需要版本管理、灰度发布、性能分析，Langfuse 提供这些能力。

### 14.7.2 LangfusePromptConfig

```java
public class LangfusePromptConfig {
    private String baseUrl;          // Langfuse 服务地址
    private String publicKey;        // 公钥
    private String secretKey;        // 私钥
    private boolean enabled;         // 是否启用
    
    // getters and setters
}
```

### 14.7.3 LangfusePrompt

```java
public class LangfusePrompt {
    private String name;             // 提示词名称
    private String prompt;           // 提示词内容
    private int version;             // 版本号
    private Map<String, Object> config;  // 配置
    
    // getters and setters
}
```

### 14.7.4 LangfusePromptProvider

```java
public class LangfusePromptProvider {
    private final LangfusePromptConfig config;
    private final HttpClient httpClient;
    
    /**
     * 获取最新版本的提示词
     */
    public LangfusePrompt getPrompt(String name, String label) {
        // 调用 Langfuse API 获取提示词
        var url = config.getBaseUrl() + "/api/public/prompts/" + name;
        var request = HttpRequest.newBuilder()
            .uri(URI.create(url))
            .header("Authorization", basicAuth(config.getPublicKey(), config.getSecretKey()))
            .GET()
            .build();
        
        try {
            var response = httpClient.send(request, HttpResponse.BodyHandlers.ofString());
            return JsonUtil.fromJson(response.body(), LangfusePrompt.class);
        } catch (Exception e) {
            throw new RuntimeException("Failed to fetch prompt from Langfuse", e);
        }
    }
}
```

💡 **设计意图**：
- **版本管理**：Langfuse 管理提示词版本，支持回滚
- **灰度发布**：通过 label（如 "production"、"staging"）控制不同环境使用不同版本
- **性能分析**：Langfuse 追踪每个提示词版本的效果

### 14.7.5 使用 Langfuse 提示词

```java
// 1. 配置 Langfuse
var langfuseConfig = new LangfusePromptConfig();
langfuseConfig.setBaseUrl("https://cloud.langfuse.com");
langfuseConfig.setPublicKey("pk-xxx");
langfuseConfig.setSecretKey("sk-xxx");
langfuseConfig.setEnabled(true);

// 2. 创建 Provider
var langfuseProvider = new LangfusePromptProvider(langfuseConfig);

// 3. 获取提示词
var prompt = langfuseProvider.getPrompt("assistant-system", "production");

// 4. 使用提示词
var agent = Agent.builder()
    .name("assistant")
    .systemPrompt(prompt.getPrompt())
    .build();
```

💡 **设计意图**：
- **动态获取**：从 Langfuse 动态获取提示词，无需重启应用
- **版本控制**：可以指定 label（如 "production"），获取对应版本的提示词
- **集中管理**：所有提示词在 Langfuse 平台统一管理
