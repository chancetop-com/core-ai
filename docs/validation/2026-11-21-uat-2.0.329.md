## 变更内容

- `EventPublisher` 先校验 ownership 再使用本地 hub；ownership 迁移后删除 stale hub 并转发给真正的 owner。
- `PgCommandConsumer` 对带 `target_pod` 的命令也校验 ownership；不是 owner 就重新入队。
- `PgCommandQueue.retryLater` 清空 `target_pod`、重置 `attempts`；`cleanup()` 清理指向心跳失效 Pod 的 target。

- 首轮等待 sandbox MCP 时发送 `SANDBOX/CREATING` 和 `SANDBOX/READY` 进度事件。
