## P1.4 dev gateway secret

- `app.gateway_provider` 4 条记录，4 条都有 `apiKeyEncrypted`。
- 当前没有显式 `SYS_GATEWAY_SECRET_KEY`，`sys.gateway.secret.key` 仍是默认 `change-me`；legacy key 仍使用 `SYS_MONGO_URI`。
- **待办**：设置强随机 `SYS_GATEWAY_SECRET_KEY`，用管理接口重新保存 4 个 provider 使 secret 用新 key 加密，验证可解密/测试连接后，把 legacy key 从 `sys.mongo.uri` 解耦。
