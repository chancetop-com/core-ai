# ocg (vendored)

Vendored from the npm package [`openclaw-channel-gateway@1.3.1`](https://www.npmjs.com/package/openclaw-channel-gateway),
which generates `skills/ocg/SKILL.md` at publish time. The skill is published here so core-ai-cli
users without a server login, and other agent tools, can install the same IM-channel instructions.

The desktop app installs this copy into `~/.core-ai/skills/ocg` when IM channels are enabled or an
`ocg` executable is detected. Credentials, channel configuration and QR login stay with the user's
local OCG daemon; the desktop app does not store or manage them.
