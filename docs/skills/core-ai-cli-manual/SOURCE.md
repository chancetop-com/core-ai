# core-ai-cli-manual

Canonical source: this repository, `docs/skills/core-ai-cli-manual`.

The text is the core-ai-cli operation manual and doubles as the `core-ai-cli-manual` agent skill.
The desktop app installs it from the bundled copy; CLI users can download the zip from the public
skills site or pull it from a core-ai-server skill hub.
