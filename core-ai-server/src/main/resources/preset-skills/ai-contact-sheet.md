# 多机位九宫格（Cinematic Contact Sheet）

专业平台"多机位九宫格"的提示词等价物：确定一个镜头的构图前，先花一张图的钱把 9 种可能全部摆出来，人眼挑一格——比逐镜试错便宜 9 倍。

## 模板（generate_image，1 次）

```
以参考图中的角色与场景为准，生成 3x3 电影接触表（contact sheet），九格分别为：
远景建立镜 / 全景 / 中全景 / 中景 / 中近景 / 特写 / 大特写 / 过肩镜 / 低角度仰拍。
所有格保持同一角色、同一服装、同一光线与色调，严格一致；
横屏 16:9，格间细白边，每格左下角标注景别名。[风格词]
```

## 用法

1. 带上角色设定表 + 场景设定表作为 input_images；
2. 挑中某格后，把该格的景别/机位描述抄进正式镜头的构图描述，再单独生成大图；
3. 九宫格本身只是选版工具，**不要**直接裁切某格当成品（分辨率不够）；
4. 变体玩法：把九格换成"同一机位的 9 种情绪/9 种姿态"，用于挑表演。
