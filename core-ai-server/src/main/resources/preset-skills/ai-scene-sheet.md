# 场景参考资产（Scene References）

与角色参考同构：一致性不靠 prompt 描述，靠**引用图锚定**。喂给**视频模型**的参考图必须是干净的单张场景图——四格拼贴会被当成画面内容（分栏、纯色底、四个视角挤在一张里），还占满引用槽。

## 视频参考组（generate_image，3–4 次；挂进场景的 refImageFileIds）

```
1. 主视角（master）：[场景描述]。场景全景，[画幅]，[时段/天气]，[光源方向]，无人物。
2. 反向视角：图片1 为场景模板，生成同一场景对象改为平视回望（相机转 180°，从对面看回来，平视，同镜头感）。
3. 纵深视角：图片1 为场景模板，生成同一场景的 45° 俯视全景（保留物体远近关系）。
4. 道具特写（可选）：[道具描述]。置于场景内的特写，交代材质与磨损状态。
```

**反向视角必须有**：正反打两个机位都要有参考，否则反打镜的背景一定漂移。纵深视角解决物体远近关系——平视和纯正俯都表达不了。道具状态是最常见的穿帮点，剧情要用的道具单独出一张。

同一场景所有镜头引用**同一套**参考组；不要用某一镜的产物反哺当参考。补图与 master 同画幅同镜头感，且只以 master 为参考——拿补图再补图，漂移会累加。

## 拓扑视图配方（随空间类型变，别死守 90° 正俯）

| 空间类型 | 拓扑配方 |
|---|---|
| 室内封闭（房间/咖啡馆/客厅） | 90° 垂直正俯平面布局 |
| 大型室内（教堂/厂房/体育馆） | 90° 正俯 + 高点斜俯看结构 |
| 半开放（庭院/露台/有顶商业街） | 含地平线的高点斜俯 |
| 开阔室外（街道/广场/海滩/山谷） | 含地平线的高角度鸟瞰 60–75°；**不要 90°**（垂直关系、天际线、尺度参照全丢） |
| 移动空间（车厢/船舱/机舱） | 沿运动轴的侧视或后视剖视 |

室外另加两条：**时间、天气、主光是一级变量**——同一地点不同时段属于不同参考组，不能混用；**天际线与远景单独锁**——在拓扑图里点名远处能看到什么（楼群轮廓/山脊线/树线），后续逐字复用。

## 锚定段（consistencyClause）

写一次、跨镜**逐字复制**：地点 / 空间结构（墙·开口·固定家具的左右关系）/ 主光方向 + 阴影方向（任何机位下都不镜像）/ 天际线与远景 / 色调与材质 / 不变项 / 可变项（行人、车辆、云形、水面反光等允许变化）。

镜头提示词只写**增量**（人物动作 + 机位景别 + 构图 + 情绪），不要重新描述空间——图里已经有的再写一遍，等于给模型两套打架的指令。

## 四格场景设定表（设计定稿用，给人看；generate_image，1 次）

```
[场景描述：地点/时段/氛围/关键道具]。场景设定图，横屏 16:9，纯色底，四格布局：
主视角全景 / 反向视角（180 度对面看回来）/ 关键道具局部特写 / 入口或纵深视角。
四格为同一空间，几何结构、光源方向、色温、材质完全一致。[风格词]
```

设定表用于定稿评审与**关键帧图像模型**的参考，**不要作为视频模型的参考**（拼贴占引用槽且被当作画面内容）。

## 状态变体

场景在剧情里有状态变化（打斗后凌乱 / 时段变化 / 破坏程度）→ 各出一套独立参考组，命名 `咖啡馆_战后`，不要在一段文字里混写多个状态。

## 漂移修复（单变量重试，别全部重写）

| 崩坏 | 修法 |
|---|---|
| 反打后左右镜像 | 删掉所有方向词，只写"从对面回望"，让参考图决定 |
| 房间变大 / 多出一扇门 | 删掉文字里的空间描述，改为纯参考图驱动 |
| 物体远近关系错乱 | 补 45° 俯视全景 |
| 两张图光照方向相反 | 锚定段写死阴影方向，禁止镜像 |
| 远景/天际线每次都变 | 拓扑图里点名远景，锚定段逐字复用 |
| 正俯图看不出是什么地方 | 90° 正俯用在室外/超大空间 → 换含地平线的俯瞰 |

## 校验

同一空间？开口数量与位置一致？主要家具没位移？光向与阴影一致且未镜像？同画幅？道具状态一致？反打能对上 master？——有一条不过就重生成，不要将就用。
