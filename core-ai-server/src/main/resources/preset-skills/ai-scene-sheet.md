# 场景设定表（Scene Sheet）

与角色设定表同构：每个主场景生成一张多角度场景表，之后该场景所有镜头都引用它作为环境参考——几何、光源、色温、材质从此锁定。

## 模板（generate_image，1 次/场景）

```
[场景描述：地点/时段/氛围/关键道具]。场景设定图，横屏 16:9，纯色底，四格布局：
主视角全景 / 反向视角（180 度对面看回来）/ 关键道具局部特写 / 入口或纵深视角。
四格为同一空间，几何结构、光源方向、色温、材质完全一致。[风格词]
```

## 要点

- **反向视角必须有**：对手戏正反打两个机位都要有参考，否则反打镜的背景会漂移；
- 关键道具（剧情要用的）单独占一格特写——道具状态是最常见的穿帮点；
- 同一场景的所有镜头引用同一张场景表，不要用某一镜的产物反哺当参考；
- 场景在剧情里有状态变化（打斗后凌乱/时段变化）→ 生成变化后的第二张表，两张都保留。
