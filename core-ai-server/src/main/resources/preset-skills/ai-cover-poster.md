# 爆款封面（Cover Poster）

## 模板（generate_image，1 次）

```
竖屏 9:16 短剧封面海报：以 [角色设定表] 为准，主角 [高冲突瞬间的表情与动作] 占画面 2/3，
背景 [冲突场景] 虚化，顶部预留 1/4 高度的标题安全区，
高对比打光，情绪拉满，[风格词]。不要出现任何文字。
```

## 纪律

- **不让模型画字**（乱码高发），标题文字后期叠加在预留安全区；
- 封面选剧中情绪最高的瞬间（打脸/揭穿/重逢），不选平静镜；
- 表情比构图重要：表情表里挑最有张力的一格作参考；
- 一次生成 2-4 版供挑选（并发调用），别单张赌。
