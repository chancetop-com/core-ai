# 角色设定表（Character Sheet）

一致性不靠 prompt 描述，靠**引用图锚定**。标准资产是单图多格的设定表——画一次，之后所有生成都引用它。

## 三视图设定表（generate_image，1 次）

```
[角色描述：年龄/体型/发型/服装/标志物]。
角色设计图，横屏 16:9，纯白背景，固定 4 格分屏布局，从左到右：
左侧第 1 格为脸部超大特写（五官锚点），
右侧一字排开正面、侧面、背面全身三视图。
三视图站姿统一、人物高度一致、四格宽度均等；
所有视图中五官、身材比例、服装缝线、颜色、配饰完全一致。
中性表情，均匀顶光。[风格词]
```

要点：左侧大特写显著降低侧/背视图"不像同一人"的概率；必须横屏（16:9 或 3:2），竖版会重叠；纯白底方便后续取用。

## 表情九宫格（以设定表为 input_images，1 次）

```
以参考图中的角色为准，生成 3x3 九宫格表情表，每格为头肩特写：
微笑 / 大笑 / 平静 / 严肃 / 愤怒 / 担忧 / 哭泣 / 惊讶 / 轻蔑。
严格复制参考图的脸型、五官、年龄感、发型、服装与机位，
只允许改变眉、眼睑、视线、嘴、脸颊与头部微倾——其余一律不变。
横屏，纯白背景，格宽均等。
```

## 漂移修复（单变量重试，别全部重写）

| 崩坏 | 追加约束词 |
|---|---|
| 侧脸不像同一人 | "侧视图与正面特写保持同一眼位线、鼻梁、下颌长度、发型剪影" |
| 视图高低错位 | "全身三视图人物高度一致，脚底对齐同一地平线" |
| 格宽不均/重叠 | "四格宽度均等，格间留白，人物完整不出格" |
| 服装细节漂移 | 把漂移项写成明确特征（如"左襟三颗金扣"）加进描述 |
| 年龄变化需求 | "只老化皮肤、软组织与发色；颅骨比例、眼距、鼻梁、下颌不变" |

2 轮修不好就换 seed 重生成整张表，不要在坏表上叠补丁。生成后用 caption_image 验图（各视图是否同一人、服装是否一致）再投入使用。
